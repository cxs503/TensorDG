## ① 案例介绍（物理背景 / 几何 / 参数表）

二维可压缩 Euler 方程（理想气体 γ = 1.4）中的等熵涡，以恒定速度 |u_inf| = √2 在周期域 [-5,5]² 中平流输运。密度/压力扰动具有高斯包络，流动处处等熵，存在封闭形式的解析解。精确解无变形地平移，因此离散误差应是网格/格式的属性，而非时间的属性——这正是"误差守恒"在涡输运中的物理含义。

| 参数 | 值 |
|---|---|
| 域 / 边界条件 | [-5, 5]²，双周期 |
| 涡强度 β | 5.0 |
| 来流速度 | (1, 1)，|u_inf| = √2 ≈ 1.4142 |
| 周期长度 | L = 10（每轴） |
| 完整周期时间 | T = L/|u_inf| ≈ 7.07（对角输运） |
| 参考解 | 解析等熵涡（machine-verified） |
| 容差 | 6%（相对 L2，t=1 快照） |
| 误差增长上限 | 5×（从 t=1 到 t=10） |
| 参考模型 | min_image（周期最小镜像折叠） |

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **参考解缺陷修复**：早期轮次（round 1–3）使用自由空间公式作为参考，导致 t>5 时出现虚假的"误差放大"。m20824 已修复为周期最小镜像（min_image）参考，误差放大消失。
2. **C11 证据溯源**：5 个 DG 配置（dg_d2_n32_t10_cfl0.2, dg_d2_n32_t10_cfl0.4, dg_d2_n32_t5_cfl0.2, dg_d2_n64_t10_cfl0.2, dg_d2_n64_t2_cfl0.2）尚缺重放证书。已递交集群作业 cj4204 生成证书。
3. **P0 基线的长时误差**：P0/64² 在 t=10 时误差达 14.3%，远超 6% 容差。这是一阶格式数值耗散的已知行为，不作为判据失败（C1x 仅登记）。
4. **适用范围**：本结论适用于双周期边界下的等熵涡输运。壁面反射、激波捕捉等场景需另行验证。
