## ① 案例介绍（物理背景 / 几何 / 参数表）

一维均质线弹性细杆纵波，写成速度—应力一阶双曲系统（与母算例同一物理问题）：

```
v_t - sigma_x/rho = 0 ,   sigma_t - E v_x = 0      =>  U_t + F(U)_x = 0
U = (v, sigma) ,  F(U) = (-sigma/rho, -E v) ,  lambda± = ±c ,  c = sqrt(E/rho)
```

初始条件为静止杆内的 Gauss 速度脉冲，`sigma(x,0)=0`；解析解为 d'Alembert 双行波（纯行波叠加，**无物理弥散**）：

```
v(x,t)     = (1/2)[ v0(x-ct) + v0(x+ct) ]
sigma(x,t) = (rho c/2)[ v0(x+ct) - v0(x-ct) ] ,  v0 = exp(-((x-0.5)/0.05)^2)
```

| 参数 | 值 | 来源 |
|---|---|---|
| 杆长 L | 1 | 算例真源 `tensordg/cases/elastic_rod_1d.py` |
| 密度 rho | 1 | 同上（无量纲化） |
| 杨氏模量 E | 1 | 同上 |
| 杆速 c = sqrt(E/rho) | 1 | 由 E/rho 程序内算出 |
| 脉冲中心 / 宽度 | 0.5 / 0.05 | 算例真源 |
| 校核时刻 t | 0.2（c·t = 0.2 < 0.5，未过周期缝） | 算例真源 |
| 探针位置 x_p | 0.8 | 母算例到达时锚点 |
| DG 设定（剖面锚点） | N=400, p=2, CFL=0.3, dt=0.000149925, 1334 步 | 母算例 |
| 判定容差 | 2 % | 算例池锚点 acceptance |

文献锚：K. F. Graff, *Wave Motion in Elastic Solids*, Ohio State University Press, 1975（Dover 重印 1991），第 1 章细杆纵波——d'Alembert 一维解、`c=sqrt(E/rho)`、自由端 `sigma=0` / 固定端 `v=0` 反射规则；次级标识 DOI 10.1177/058310247901100605。**零手抄声明**：本环境读不到原书，报告内所有 ref 值均由闭式解或独立数值参考在程序内算出，无任何数字抄自原书表格。

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### (A) 参考解独立性：三条互不共享代码的独立参考

| 参考 | 方法 | 独立性 |
|---|---|---|
| R0 | `tensordg.elastic_1d.dalembert_pulse`（母算例所用闭式解） | 与求解器同模块（**被检对象**） |
| R1 | Fourier 伪谱**时间精确**传播子：逐波数解 2×2 常微分方程 `exp(Mt)=cos(wt)I+sin(wt)M/w`，`w=c|K|` | 无时间推进、无空间截断误差；不共享任何求解器代码 |
| R2 | 特征线法（method of characteristics）：numpy 直接写 d'Alembert 双行波叠加 | 独立 numpy 实现，无 torch / 无镜像求和 |
| R3 | 交错跳点（Yee）二阶格式细网格 + Richardson 外推 `(4f_{h/2}-f_h)/3` | 与 DG 不同离散族 |

设置：比较网格 x ∈ [0.02, 0.98]（避开周期缝与端点半格），R1 模态数 2048，R3 基础网格 2048/4096 外推，t = 0.2。

### (B) 到时估计器修正：把误差拆成「估计器偏差」与「数值弥散」

母算例用 11 个快照 + **最近单元中心**采样 + 抛物线细化测 `t*(x_p=0.8)`，`ncells_dynamic=25`（h=0.04），最大锚点误差 0.602%。新版估计器做两处最小改动：

1. **探针定位**：在含 `x_p` 的单元内用模态多项式在**精确坐标**求值（消除 O(h) 定位偏差）；
2. **时间采样**：直接取求解器每一步的探针值（等距 dt，序列稠密），再抛物线细化；
   该步进循环复用库内 `_operators/_project/_rhs`，`tests/test_elastic_1d_crosscheck.py::test_probe_series_reproduces_the_shipped_solver` 断言其末态与 `solve_elastic_1d` 逐元素一致到 1e-14——测的是**已发布求解器**而非克隆。

工具链：`python -m benchmarks.elastic_1d_crosscheck --output-dir validation/elastic_1d_crosscheck`（单线程 CPU，float64），`tools/case_dg_dalembert_crosscheck_report.py` 由 JSON 渲染本文（零手抄）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **交错网格的半格错位坑（本次真踩到）**：R3 最初把初速采样在应力半节点上，整对交错量整体偏移 h/2，误差变成 O(h)——观测收敛阶 1.03/1.01/1.01（看着像「二阶格式常数很大」而不是 bug）。互相关查偏移得到 −0.500h（N=1024 与 N=4096 一致到三位），改回整节点采样后恢复 1.99/2.01/2.00，外推参考降到 7e-4%。`tests/...::test_staggered_reference_has_no_residual_half_cell_offset` 把这条钉死。
2. **0.602% 的真实归属**：不是「抛物线插值方法限制」（母审计报告的判断），而是 N=25 网格的**数值弥散**为主、探针吸附到单元中心（x=0.798982，偏 −0.127%）为辅。证据：固定网格只加密快照，误差不下降（表 4）。
3. **修正估计器仍有残余**：p=1 的扫描非单调（0.0092% → 0.0175% → 0.0045%），因为抛物线只在最近局部极值上拟合，而 p=1 探针序列本身振荡；故对 p=1 只声称 ≲0.02%，不声称单调收敛。
4. **适用范围**：全部结论限于线性弹性、均质杆、t < 0.5/c（未过周期缝）的纯行波窗口；过缝后须用镜像求和参考（母算例 `_dalembert_periodic_images`），本报告未覆盖。
5. **R3 只能作为「粗但独立」的参考**：外推后仍有 7e-4% 残差，比 R1/R2 的 1e-13 差 9 个量级；判 DG 是否达标够用（比 2% 门槛低 4 个量级），不能用它做千万分之一级的结论。

诚实结论：

- 母算例 9 条锚点的判定**不变**（最大 0.602% < 2%），本报告不重写那 9 行；
- 参考解独立性缺口已闭合：DG 解与三条独立参考的最大偏差 2.09e-03%，比 2% 门槛低约 4 个量级，说明「参考与求解器同模块」不再是该算例的隐性风险；
- 到时锚点的 0.602% 已定位为网格弥散而非插值缺陷，并用修正估计器把同一物理量测到 -7.1e-06%；
- 未做：过周期缝（t>0.5/c）区间的参考交叉校验，留作后续条目。
