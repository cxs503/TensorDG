# CASE-DG-EULER-VORTEX-ERR round 10：等熵涡移动误差守恒——全证据综合与终态裁决

锚点 `CASE-DG-EULER-VORTEX-ERR`（算例池·等熵涡移动误差守恒，ref: Yee et al. 2000，容差 <6%）。
数字全部由 `benchmarks/case_euler_vortex_errconserve.py` 工件程序化注入
（`case_euler_vortex_errconserve/metrics.json` + `results/*.json`），零手抄。

## ① 案例介绍

等熵涡以匀速 u_inf 在周期箱 `[-5,5]^2` 中平移，密度/压力扰动为高斯包络，流场处处等熵，
故有闭式解。算例池用它检验「误差是否随时间累积」：真解不变形，守恒良好的格式在固定网格上
的误差应当是网格属性（投影误差为主），而非时间属性。

| 参数 | 值 |
|---|---|
| 域 / 边界 | [-5, 5]^2，周期 |
| 涡强度 beta | 5.0 |
| 背景 (rho_inf, p_inf) | (1.0, 1.0)，gamma = 1.4 |
| 输运速度模 | \|u_inf\| = sqrt(2) = 1.4142 |
| 设计族 | DG p=2，32x32，CFL 0.2（HLLC + SSP-RK3） |
| 交叉族 | P0 有限体积（Rusanov + SSP-RK3） |
| 参考解 | 周期 min-image 折叠（`min_image`） |
| 容差 | <6%（t=1 快照，各族最大场相对 L2） |

**物理背景**：等熵涡是 Euler 方程的一个精确解，其密度/压力/速度场在均匀平移下保持形状不变。
在周期边界条件下，涡每经过一个周期（L/\|u_inf\| = 10/1.4142 ≈ 7.07）回到原位。
如果数值格式的误差主要来自初始投影（网格分辨率决定的离散化误差），那么误差应当随时间保持有界，
而非线性增长。这就是「误差守恒」的物理含义。

## ② 怎么做的

本综合报告汇总 rounds 1–9 的全部证据，涵盖 10 个门禁判据（C1–C10）：

* **C1**：t=1 快照容差（<6%）
* **C2**：误差守恒（alpha <= 1，设计族）
* **C3**：离散守恒（质量/动量/能量漂移 < 1e-10）
* **C4**：熵预算（\|dS\|/S(0) < 1e-3）
* **C5**：交叉族收敛阶（P0 观测阶 >= 0.8）
* **C6**：阶梯完整性（LADDER 声明的 40 个检查点全部有结果）
* **C7**：设计空间不变性（网格/CFL 轴）
* **C8**：阶数不变性（p=1/2/3 轴）
* **C9**：设计阶（观测阶 >= 0.8*(p+1)）
* **C10**：方向不变性（三方向轴）

两条独立代码路径：
* `dg` — 模态 DG（HLLC + SSP-RK3，L2 投影初态）
* `p0` — P0 有限体积（Rusanov + SSP-RK3，精确单元平均度量）

| t | 步数 | rho % | u % | p % | 最大场 % |
|---|---|---|---|---|---|

**关键发现**：DG-P2/32² 的误差从 t=1 到 t=10 仅增长 1.6 倍（e(t=10)/e(t=1) = 1.608），

## ⑤ 注意点

1. **参考解缺陷**：min-image 参考在 t>2 时产生速度-only 截断误差（~1.5e-6），
   密度/压力缺陷 ~4e-13。这不影响 DG 族的误差测量（误差远大于参考缺陷），
   但限制了可测量的最小误差地板。
2. **P0 一阶族的长时行为**：P0 族的误差随时间线性增长（alpha ≈ 0.5–0.6），
   这是一阶格式耗散抹平涡核的固有属性，不是失稳。
3. **C3 度量修复**：网格对齐输运下横向动量精确为零，旧度量报成 O(1) 守恒失败。
   修复后分母取 `max(|参考值|, mass*|u_inf|)`，最差漂移 3.91e-13。
4. **未完成部分**：11 个检查点（p=1/3 阶数轴、p=1 细网格、t=20）仍在 `cj3432` 队列，
   C6/C8/C9 仍为 INCOMPLETE。

## ⑥ 误差判定：关键量 vs 基准

| 量 | 基准 | 实测 | 是否 <3% |

| P0 一阶族长时最差 | 闭式周期解 | 14.3047% | 否 |

**明确回答**：
* DG 族（p=2）在所有检查点的误差均 <3%（实际 <0.1%），**成立**。
* P0 一阶族 t=1 快照 4.93% < 6%（算例池容差），但 >3%，**不成立**。
* P0 一阶族长时误差 14.3%，**不成立**（格式阶数固有属性）。
