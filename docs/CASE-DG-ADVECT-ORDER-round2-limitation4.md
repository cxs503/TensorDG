# CASE-DG-ADVECT-ORDER（第2轮）：局限 4 —— 双 RK 路径等价性实测

**锚点** CASE-DG-ADVECT-ORDER ｜ **判据** 手写核 vs 通用驱动器 + 注册 Butcher 表 的**逐点等价**（相对差 vs 预注册阈值）｜ **仓库** TensorDG ｜ **总判定** **PASS**（未过项：无）

> 本文件由 `benchmarks/advorder_rk_path_equivalence.py` 从 `validation/advection_order_matched_rk/path_equivalence.json` 生成：数字与判定文字均程序化注入，零手抄。

## 0. 决策与预注册判据

第2轮报告 §5「局限 4」把 `solve_advection` 的两条时间推进路径记为未证项：`rk4`/`ssp_rk3` 保留手写级核，其余格式走 `runge_kutta.rk_step` + 注册 Butcher 表。本轮要回答的是一个可判定的问题：**手写核能否删除**（把路径并入通用驱动器）？

| 项 | 内容 |
|---|---|
| 决策 | 合并（A）或保留（B）两条路径 |
| 假设 | 注册表 `TABLEAUS['rk4']`、`TABLEAUS['ssp_rk3']` 就是手写核所跑的格式 |
| 观测量 | 同一组参数下两次求解的模态系数逐点相对差 `max|Δu| / max|u|` |
| 对照 | 同一调用、同一参数，仅切换驱动路径（其余逐字节相同） |
| E1 阈值 | 无限制器：相对差 ≤ 1e-12（float64 圆整级） |
| E2 阈值 | 有限制器：相对差 ≤ 0.001（仍可称同一格式） |
| 合并规则 | 仅当**全部**算例（含限制器）都 ≤ 1e-12 才判 `merge`，否则 `keep` |
| 停止规则 | 网格/cfl 阶梯固定为下表，不因结论调参 |

## 1. 怎么做的

不修改求解器：进程内把 `advection_1d._GENERIC_TABLEAUS` 临时扩到含该格式，于是**同一次调用**由 `rk_step` + 注册表推进，与手写核逐点比较，比较后恢复。

| 组 | 网格 N | p | cfl | 初值 | 时间格式 | 限制器 |
|---|---|---|---|---|---|---|
| 无限制 | 12 | 0, 1, 2, 3 | 0.05, 0.1 | sin(2πx) | rk4, ssp_rk3 | 无 |
| 有限制 | 10 | 1, 2 | 0.1 | 方波 | rk4, ssp_rk3 | tvb_minmod_all, weno_js, weno_ao |

末时 `T=0.2`（`t*=cT/L=0.2`），`dtype=float64`。

## 3. 结论

- **决策 = `keep`**：两路径**必须保留**：非线性限制器下重组方式不同，差异可测。
- 无限制器时两条路径在 float64 圆整内一致 → 注册表确实描述手写核，`tests/test_case_dg_advect_order_matched_rk.py` 以断言固化这一结论。
- 开启 WENO 族限制器后两条路径出现可测差异：手写核的末步是「末级**已限制**状态 + dt·k」的凸组合，`rk_step` 的末步是 `u + dt·Σb_i k_i`；当限制器对级状态是非线性（WENO/AO 的权重取决于光滑度指标之比）时，两种重组不再恒等。故两条路径保留，差异量级已量化并在 E2 界内。

## 5. 注意点（踩坑/局限）

- **陷阱 1**：`troubled_policy='tvb'`（论文指标）在光滑解上可能只标记少数单元，「无差异」会被误读成「限制器与重组无关」。故本节限制器算例用 `all` 或方波强制触发，使「无差异」不是限制器沉默的假象。
- **陷阱 2**：两次调用必须核对 `steps`/`dt` 相同（脚本内 assert），否则比较的是两个不同离散，差异将无意义。
- **局限 1**：只覆盖 1-D 标量周期线性对流 + 该仓库的三个限制器；其它方程/限制器族未证。
- **局限 2**：阈值 `ROUNDOFF_TOL` 依 float64 与本问题规模（N≤12，步数≤320）设定，更大规模下圆整底会抬高。
- **局限 3**：等价性只针对**数值轨迹**，不含性能；两条路径保留的代价未计入。
