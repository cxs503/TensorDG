# TensorDG 广义熵收支解析基准（全四类波型）

> 任务：m3472（platform 席自找活）。锚点= `docs/entropy_verification.md` §⑤ 记录在案的缺口：
> "解析基准只实现「右侧激波」构型（$p^*>p_R$，Sod/Lax 均属此类）；左侧激波/双稀疏波未覆盖。"
> 本单把该基准推广到**全部四类波型**，并对其自身做两道独立锚定。
> 全部数字由 `benchmarks/entropy_budget_general.py` 生成
> `validation/entropy_1d_general/summary.json` 后**程序化注入本文件**——零手抄。

## ① 案例介绍

**物理背景。** 理想气体 Euler 方程（$\gamma=1.4$）的比熵
$s=\ln(p/\rho^\gamma)$ 在光滑区满足守恒律
$\partial_t(\rho s)+\partial_x(\rho us)=0$，在含激波的弱解上满足熵不等式
$\partial_t(\rho s)+\partial_x(\rho us)=P\ge 0$，$P$ 以激波为支撑。
对单一激波（速度 $\sigma$，上游/下游态 $a,b$）：

$$P=\sigma\,[\rho s]-[\rho us],\qquad [\cdot]=(\cdot)_b-(\cdot)_a,$$

时间 $t$ 内的总产量 $P\,t$（自相似⇒产率恒定），前提是没有波抵达计算域端。
原基准只实现了**右行**激波（$p^*>p_R$）。

**参数表（本单覆盖的四类波型）。**

| 案例 | 左态 $(\rho,u,p)_L$ | 右态 $(\rho,u,p)_R$ | $t$ | 波型 |
|---|---|---|---|---|
| `sod_right_shock` | (1, 0, 1) | (0.125, 0, 0.1) | 0.2 | 左稀疏 + 右激波 |
| `mirror_sod_left_shock` | (0.125, 0, 0.1) | (1, 0, 1) | 0.2 | **左激波** + 右稀疏 |
| `symmetric_two_rarefaction` | (2, −1, 1) | (2, 1, 1) | 0.15 | **双稀疏波**（等熵，$P\equiv0$） |
| `near_vacuum_123` | (1, −2, 0.4) | (1, 2, 0.4) | 0.15 | 近真空双稀疏波（Toro test 2） |

域 $[0,1]$、膜片 $x=0.5$；四例均满足"无波出域"（`domain_clean=True`）。

## ② 怎么做的（方法 / 关键设置 / 工具链）

1. **推广 RH 基准**：`analytic_entropy_budget(left, right, t)` 按 $p^*\gtrless p_{(L,R)}$ 分类两侧波型，
   激波侧用 Rankine–Hugoniot 组装产率，稀疏侧产率恒为 0（等熵），总计 $P\,t$。
   API 与原 `analytic_right_shock_budget` 兼容（Sod 上逐位相等，见测试）。
2. **符号约定的坑**：`shock_speed_and_production` 的两个参数是**空间左/右**态，不是"上游/下游"。
   左行激波必须写成 `(star, left_state)`，写反会得到 **负产率**（违反第二定律）。
   本单用**镜像对称**把这一约定钉死：把 Sod 镜像（$x\to-x,\ u\to-u$）后 $\int\rho s$ 不变，
   故 $P\,t$ 必须逐位相同——实测相对差 $<10^{-12}$。
3. **两道自锚**（不依赖任何文献数字）：
   (i) *精确解锚*——对精确采样解算 $\Delta\int\rho s\,dx$，并补上**边界熵通量项**
   $t\,[\rho us]_{\partial\Omega}$：双稀疏波必然有穿透流（初始态带速度），漏掉该
   项会把 0 产率算成 0.55 的假产量——这是本单踩到的最大坑；
   (ii) *文献锚*——Toro《Riemann Solvers》3rd ed. Table 4.1 的四个标准算例
   $(p^*,u^*)$ 复现到印刷精度（见测试 `test_star_state_matches_toro_table_4_1`）。
4. **数值侧**：`tensordg.euler_dg_1d` 模态 DG（P2）+ HLLC + SSP-RK3 + TVB 限制器（M=1.0），
   熵积分在全 DG 多项式上求积（不用单元平均值），CFL=0.3，网格 32/64。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **边界熵通量项不可省**：初始态带速度（双稀疏波必然如此）时，透射边界持续输运熵，
   $\Delta\int\rho s\ne P\,t$。漏项时 123 算例给出 0.5498 的假产量。
2. **左激波符号**：见 §②.2；镜像对称是判据，别靠"上游/下游"直觉。
3. **$s$ 的平移不变性**：$s\to s+c$ 会让 $\Delta\int\rho s$ 带来 $c\,\Delta\int\rho\,dx$，
   所以"有净质量流出"的算例必须用本单的通量修正公式；纯 RH 产率本身与 $c$ 无关。
4. **等熵参考值恰为 0** 时相对误差无定义，只能给绝对量并与熵积分尺度比较（本单如此处理）。
5. **限制器强烈过产熵**：同一算例 TVB(M=1) 在 64 单元给出的产量是无限制器时的 1.9 倍
   （5.04e-3 vs 2.60e-3，后者由本单独立复算）；TVB 是 TVD 型限制器，会削平稀疏波光滑极值，
   这是 3% 门失败的**格式原因**，不是基准问题。
6. **未覆盖**：只有 1-D、Cartesian、均匀网格、HLLC+SSP-RK3；真空生成（$p^*\to0$ 的强 123 问题）
   未做 DG 数值对比（弱解非光滑且可能真空）。$\gamma$ 固定 1.4。

## ⑥ 误差判定（逐项 vs 基准，是否 <3%）

| 量 | 基准 | 实测误差 | <3%？ |
|---|---|---|---|
| 星态 $p^*,u^*$（Sod/镜像/Toro3/Toro4） | Toro Table 4.1 印刷值 | $<10^{-3}$ 相对 | ✅ 是 |
| 星态 $p^*,u^*$（Toro test2, 3 位印刷） | 0.00189 / 0 | $<10^{-2}$ 相对 | ✅ 是 |
| RH 预算 vs 精确解（Sod / 左激波） | 精确解 $\Delta\int\rho s$（含边界通量） | $9.3\times10^{-6}$ 相对 | ✅ 是 |
| RH 预算 vs 精确解（双稀疏波，解析值 0） | 0 | 绝对 $7.2\times10^{-6}$ vs 熵尺度 2 | ✅ 是 |
| DG 产量（Sod, P2+TVB, 64 单元） | 解析 $2.364621\times10^{-3}$ | **113%** | ❌ **否** |
| DG 产量（左激波, P2+TVB, 64 单元） | 同上 | **115.5%** | ❌ **否** |
| DG 产量（双稀疏波, P2+TVB, 64 单元） | 0（等熵） | 绝对值 0.596 vs 熵尺度 1.94（≈31%） | ❌ **否** |
| 第二定律（全部 DG 算例） | $P\ge0$ | 全部 $\ge 0$（含 32/64 单元） | ✅ 是（定性） |

**结论（如实）**：本轮**基准侧全绿**（解析基准对文献 $<10^{-3}$、对精确解 $<10^{-5}$，并推广到左激波/双稀疏波）；
**数值侧在 3% 门上失败**：P2+TVB 在 32/64 单元对熵产量的偏差为 113%–115%（且随网格收敛：
32→64 单元从 208% 降到 113%），双稀疏波上过产熵约 31%。即
"熵产量"仍是 TensorDG 现有的**弱项指标**，需更高阶/更小耗散格式或更细网格才可能进 3% 门；
本单不粉饰该结论，只把失败量化并定位到限制器（无限制器时 64 单元误差 11.6%，128 单元 7.3%）。
