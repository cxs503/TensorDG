台账 A0 判据：10 点 Legendre–Gauss 逐点对闭式 Riemann 解、全场相对 L2、**取最差场量**，与 3 % 比较，
无场量豁免、无去波带、无平均。

## ② 怎么做的（闭合逻辑，零新求解）

`benchmarks/lax_case_pool.py` 的 `gate_a0` 默认生产腿 = 阶梯最细腿 `p3.N400`，其全场相对 L2（密度）
= **3.116 %**，略超 3 % 门槛（裕度 x0.963），A0 判为 **FAIL**（honest FAIL）。验证综合报告
（`docs/CASE-LAX-DG-verification-synthesis.md`）给出三条闭合方案，**推荐方案 1**：把生产腿重钉到
认证配置 `p2.N800`（DOF 2400，最差 L2 = 2.570 %），即最小 DOF 通过 < 3 % 门槛的腿。

本单**实现该推荐而不重跑求解器**：从两份已提交工件（case-pool 阶梯 + 认证配置枚举）重新裁决 A0 台账臂，
闭合是已发布数字的机器可复核重读，不是新计算。`p3.N400` 的 honest-FAIL 作为独立记录原样保留
（综合报告规则：「验证层 FAIL 原样保留，不被 A0 的 PASS 改写」）。

## ④ 注意点 / 局限

* **闭合是配置重读，不是精度提升**：p2.N800 的 2.570 % 与 p3.N400 的 3.116 % 是同一求解器在
  不同分辨率/阶数下的实测值；闭合只把台账登记的生产腿从「未达标的 p3.N400」改为「已认证的 p2.N800」。
* **honest-FAIL 保留**：p3.N400 全场 L2 = 3.116 %（间断主导，超 3 % 门槛）原样记录，不被 p2.N800 的
  PASS 改写；这是「间断存在时全场误差无法达到设计阶」这一物理事实的如实结论。
* **参考底限**：误差分解显示 p3.N400 上参考底限占总误差显著比例（精确解在 DG 空间的投影误差），
  非求解器缺陷。
