## 1. 案例介绍

### 1.1 物理背景与几何

二维压缩 Navier–Stokes，无量纲，`R = 1`、γ = 1.4，故 `T = p/ρ`、
`c_v = 2.5`、`c_p = 3.5`、`κ = μ c_p / Pr`。计算域 `[0,1]²`，x 周期、y 双壁，
上下壁为**等温无滑移壁**：`T_wall = 1.0`（下，热）/ `0.5`（上，冷），`u = v = 0`。

被验证的算例是纯热传导（流体静止、无黏性耗散）：

    u = v = 0,  p = p₀ = 1,  T(y) = 1 - 0.5 y,  ρ = p₀ / T(y)

它**精确满足**可压缩方程：能量方程退化为 `κ ∇²T = 0`（线性 T 自动满足），
动量方程 `∇p = 0` 与 `u = 0` 相容，连续性 `∇·(ρu) = 0` 平凡成立。

| 参数 | 值 |
|---|---|
| 网格 | `2 × {16, 32, 64, 128}` 单元，P1；另 `2 × 32` 的 P2 |
| μ / Pr / κ | 0.1 / 0.71 / 0.492958 |
| p₀ | 1.0 |
| 壁温 | 下 1.0，上 0.5 |
| 罚项 σ | `2 (p+1)²`（P1 → 8，P2 → 18） |
| 壁面梯度取法 | `"taylor"` 与 `"face"` 两种（`wall_gradient`） |

### 1.2 为什么这是缺口

`ns_dg_2d` 的验证矩阵（m2496/m2589/m3168）覆盖了周期衰减剪切波（设计阶 2.02–2.07）、
Couette 稳态、脉冲启动与 Stokes 第二问题，但**纯热传导这条入口从未被任何基准碰过**：
它连自己文档里写的默认参数都跑不完（见 §3 E3）。这是「能量方向（热流/等温壁）
到底能不能用」的前置判断，必须清算。

## 2. 怎么做的

三步，全部程序化、零手抄（数字由脚本写入 `evidence.json` 后回读）：

1. **解析自洽（E1）**：对 `heat_conduction_exact` 做离散拉普拉斯（257 点、二阶差分）、
   理想气体密度回代、壁温端点、`gas_constants` 的热力学恒等式（`c_p - c_v = R`、
   `γ = c_p/c_v`）检查。
2. **算子对解析稳态残差（E2）**：把精确稳态 **L2 投影**到 DG 模态空间后，
   直接调用模块内部强形式残差 `_rhs_ns`（不做时间推进），按行（冷壁/内区/热壁）
   与按方程分（质量/动量/能量）拆开，做网格序列 `ny = 16 → 128` 的斜率判读；
   对 `wall_gradient ∈ {taylor, face}` 各做一遍，确认缺陷是在**闭合**里还是在**重构**里。
3. **后果（E3）**：跑 `solve_heat_conduction_dg_2d()` 文档默认参数；再把
   `final_time` 二分定位崩溃时刻；最后**从精确稳态出发**推进（`steady` 初始条件）
   以及把 CFL 从 0.3 降到 0.05，判别「是不是时间步稳定性极限」。

## 3. 计算结果

### 3.1 E1 解析态确实是精确解（通过）

| 检查项 | 实测 |
|---|---|
| `max |∇²T|`（257 点二阶差分） | 0.0（线性剖面，二阶差分精确为零） |
| `max |ρ - p₀/(R T)|` | 0.0 |
| 壁温端点 / 速度 | 1.0、0.5 / 精确 0 |
| `c_p - c_v - R`、`γ - c_p/c_v` | 0.0、0.0 |

### 3.2 E2 精确稳态上的能量残差（**判据不通过**）

冷壁行（`T=0.5` 侧）、内区行、质量/动量行的最大绝对残差（P1）：

| ny | 冷壁能量残差 | 热壁能量残差 | 内区能量残差 | 质量残差 | 动量残差 |
|---:|---:|---:|---:|---:|---:|
| 16 | 0.8150 | 0.4821 | 1.709e-01 | 1.0e-14 | 2.2e-15 |
| 32 | 0.8966 | 0.4878 | 9.291e-02 | 3.8e-14 | 4.4e-15 |
| 64 | 0.9402 | 0.4904 | 4.855e-02 | 7.3e-14 | 8.8e-15 |
| 128 | 0.9628 | 0.4917 | 2.484e-02 | 8.1e-14 | 1.8e-14 |

- 内区斜率 `d log E / d log h = +0.93`（≈ 一阶，随 h 衰减）；质量/动量行 1e-14（机器零，**算子的其余部分是对的**）。
- 冷壁行斜率 **`-0.08`**（即随网格加密反而增大）：不衰减，并向 `κ = 0.492958` 的 2 倍量级趋近；
  热壁行 0.4821 → 0.4917，向 `κ = 0.492958` 本身趋近。
- 换 `wall_gradient="face"`：冷壁 0.1292 → 0.2305（斜率 `-0.42`，同样不衰减），
  热壁 0.8669 → 0.8632（常数）。**两种重构都失败** ⇒ 缺陷在等温壁能量闭合本身，
  不在壁面梯度重构（与 m3168 对 ns 壁面瞬态的归纳一致）。
- P2（`2×32`，`wall_gradient="taylor"`）：冷壁 0.0423、热壁 0.0241、内区 5.50e-02。
  提高阶确实把壁面残差压小约 21 倍，但它**仍不随 h 归零**，即闭合误差的量级
  由阶数而非网格决定。

### 3.3 E3 后果：随箱即用的入口直接崩

| 初始条件 | final_time | CFL | 结果 |
|---|---:|---:|---|
| uniform（shipped 默认：T≡1） | 0.010 | 0.3 | ok，`p_min = 0.669`（已掉 33%） |
| uniform | 0.020 | 0.3 | ok，`p_min = 0.632` |
| uniform | 0.050 | 0.3 | `FloatingPointError: nonphysical cell average` |
| **steady（精确稳态）** | 0.050 | 0.3 | `FloatingPointError`（同样崩） |

崩溃时刻 `t* ∈ (0.02, 0.05)`，与 **CFL 无关、与初始条件无关（精确稳态也崩）、

且失效通道只有压力/能量（`p` 由 1 掉到 0.63 后穿负），质量与动量残差始终机器零。

## 4. 注意点（踩过的坑与适用范围）

- **陷阱 1：默认参数就是坏的。** `solve_heat_conduction_dg_2d()` 的默认
  `final_time=40.0` 在 `ncells=(2,16)` 上根本到不了；先跑通再谈精度的直觉在这里失效，
  必须先做「默认能否运行」的黑箱门。
- **陷阱 2：不能用「缩 CFL」的常规手段救。** 该崩与 `cfl=0.3`/`0.05` 无关，
  也与「初始条件与边界不协调」无关（从精确稳态出发一样崩）。缩时间步只会烧预算。
- **陷阱 3：晶格式比较量级会误判。** 强形式残差含模态因子 `(2k+1)(2l+1)/(2Δy)`，
  不能直接与物理热流 `κ ΔT/h` 比大小；唯一可靠判据是**网格序列斜率**
  （本单：内区 +0.93 vs 壁面 −0.08，均按 `d log E / d log h`）。
- **陷阱 4：`cell_fields()` 不含温度。** 只有 (ρ, u, v, p, conservative)；
  `T = p/ρ` 需自己算（首版探针在此踩 `KeyError: 'temperature'`）。
- 适用范围：结论限于**强形式 BR1/SIPG + 等温 Dirichlet 壁**这条闭合（`wall_gradient`
  两选项均在内）、P1/P2、Cartesian 张量积网格、CPU/float64。
  周期方向的黏性算子（剪切波设计阶 2.02–2.07）**不受影响**，动量的无滑移壁
  （m2589 已证多项式数据下 1e-12 精确）也不受影响，缺陷**专属于能量/温度通道的壁面闭合**。
- 未做：**没有修复**。定位到「等温壁能量通量多出一项不随 h 衰减的 `O(1)` 贡献
  （冷壁 → 2κ 量级、热壁 → κ 量级）」之后，正确的修法是重推该壁面的 BR1 强形式闭合
  （对称化项与体积项配对），属于需单独验证的改动，本单不夹带；已在 §5 列为后续单。

## 5. 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 基准 | 实测 | 误差 | <3%？ |
|---|---|---|---|---|
| 冷壁能量残差（ny=16→128） | 应随 h → 0 | 0.815 → 0.963（斜率 −0.08） | 不收敛，相对收敛目标 100% 偏离 | **否** |
| 热壁能量残差（ny=16→128） | 应随 h → 0 | 0.4821 → 0.4917（≈κ） | 同上 | **否** |
| 内区能量残差（ny=16→128） | 一阶衰减 | 1.709e-01 → 2.484e-02（斜率 +0.93） | 与一阶理论一致 | 是（阶次判据） |
| 质量/动量残差（精确稳态） | 机器零 | ≤ 1.8e-14 | — | 是 |
| 解析稳态自洽（E1） | 精确满足 | ∇²T = 0.0，ρ 回代 0.0 | — | 是 |
| `solve_heat_conduction_dg_2d()` 默认运行 | 应能推进到 t=40 | `FloatingPointError`（t*∈(0.02,0.05)） | 功能不可用 | **否** |
| t=0.01 时压力下限 | 保持 p≈1 | 0.669（掉 33%） | 33% | **否** |

**honest FAIL**：纯热传导这条入口的证据等级从「未验证」升级为
**WITHHELD→已验证不可用（等温壁能量闭合不一致）**；不粉饰、不声明修复。
