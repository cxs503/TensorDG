## 1. 案例介绍：被复核的欠账与它的判据漏洞

m3257 在教科书式纯导热稳态

```
u = v = 0,  p = p0 = const,  T(y) = 1 - y/2,  rho = p0 / T(y)
```

上量得两件事：**(a)** 精确稳态的壁面能量残差停在 `O(1)`、不随加密衰减；**(b)** 壁面法向热流
相对解析 `kappa dT/dy = -0.246479` 只有**一阶**（16→64 单元误差 1.868e-2 → 4.536e-3），并据此把
「Dirichlet 罚项 `sigma/h (T^- - T_D)` 主导」写成闭合缺陷的结论。

漏洞在于：`rho = p0/T` 是**有理函数**，不属于任何 `P_k` 空间，上面测的所有量都是该精确态的
**L2 投影**上的量。投影态不是离散不动点，因此「残差不为零」**无法区分**「闭合错」与「投影误差」。
m3257 的 E1 已经用 `T = 1` 的均匀态给出「闭合无符号错」的正面证据，但均匀态热流为零，
**没有验证过任何一个非零壁面热流**——恰恰是 (b) 指控的对象。

本单把判据补上：取一个**既在空间内、又带非零壁面热流**的精确稳态（稳定层结 + 定热流，
物理上=静力平衡的等温层）：

```
u = v = 0,  T(y) = 1 - y/2,
rho(y) = 1 + a y^2          (a = 0 -> P0 可表示；a = 0.5 -> P2 可表示)
p(y)   = rho T              (a=0 时 P1；a=0.5 时 P3)
S      = (0, 0, dp/dy, 0)   守恒变量 y-动量源（压力梯度支撑=等效体力）
```

连续性 `d(rho v)/dy = 0`，能量方程退化为 `kappa T'' = 0`（T 线性，精确为零），
故只要 `degree >= 3`（a=0 时 `>= 1`）该态是**离散精确不动点**，而壁面热流
`kappa dT/dy = -mu c_p/(2 Pr) = -0.24647887` 非零。

| 参数 | 值 |
|---|---|
| 域 | `[0,1]^2`，x 周期，y 双等温无滑移壁 |
| 壁温 | 下 1.0，上 0.5（`dT/dy = -0.5`） |
| mu / Pr / kappa | 0.1 / 0.71 / 0.4929577 |
| 罚项 sigma | `2(p+1)^2`（8/18/32） |
| 网格 | `2 x {8,16,32}`（p=1/2/3），教科书态另加 `ny=64` |
| 壁面梯度 | `"face"`（默认） |

## 2. 怎么做的

三支探针全部程序化（数字只经 `evidence.json` 回读，零手抄）：

- **E1 可表示态残差**：`_rhs_ns` 直接求残差（含 `source_quad`），按底壁行/内区行/顶壁行与方程拆开。
  判据：机器零（`< 1e-9`）。
- **E2 可表示态壁面热流**：`_face_primitives` + `_boundary_flux` 给出闭合的两壁能量通量
  （闭合返回 `F_inv - F_visc`，故数值为 `-kappa dT/dy = +0.24647887`），与解析值比。
  判据：机器零（`< 1e-12`）。
- **E3 教科书态因果链**：`ny = 8..64`，分别量 **(i)** 壁面温度迹缺陷 `delta = |T^- - T_D|`、
  **(ii)** 壁面热流误差 `|q_h - q|`、**(iii)** 强形式壁面能量残差；
  再算决定性比值 `|q_h - q| / ((sigma/h) delta)`：若热流误差就是罚项作用在投影缺陷上，
  该比值应与网格无关。

### 3.2 E3：教科书态的一阶热流 = 罚项 × 投影缺陷（比值恒定 0.863）

| ny | 壁面迹缺陷 delta | 热流误差 &vert;q_h - q&vert; | 壁面能量残差 | 比值 &vert;q_h-q&vert;/((sigma/h)delta) |
|---:|---:|---:|---:|---:|
| 8 | 7.036e-04 | 3.889e-02 | 0.1204 | 0.864 |
| 16 | 1.691e-04 | 1.868e-02 | 0.1292 | 0.863 |
| 32 | 4.147e-05 | 9.160e-03 | 0.1850 | 0.863 |
| 64 | 1.027e-05 | 4.536e-03 | 0.2150 | 0.863 |

观测阶（8→64，最小二乘）：`delta` **2.03**（=投影误差 O(h^2)，符合 `rho` 有理、`T` 由商得到）、
热流误差 **1.03**、残差 **-0.30**（O(1) 且缓慢上升）。
比值在 4 个网格上为 0.864/0.863/0.863/0.863——**散布 1.001 倍**。

因果链因此闭合：`rho = p0/T` 的 O(h^2) 投影缺陷 → 罚项 `sigma/h × O(h^2) = O(h)` 的热流通量误差
→ 强形式散度再除 `h`，残差停在 `O(1)`。这条链上**没有一处是闭合的错**，全部由「用保守变量
存储有理函数 `rho = p/T`」这一步引入。

## 5. 注意点（局限与适用范围）

1. **本单没有证明「收敛的离散稳态解」的壁面热流阶次。** 显式时间推进该教科书态在 m3257 E3 中
   会失稳（`sigma` 越大越早崩），本单因此只做了「残差求值」与「一次性通量求值」，
   没有做 Newton/隐式求 `R(U_h)=0`。要回答「离散稳态解是否达设计阶」需要解稳态方程（后续单建议）。
2. 可表示族需要**体力源** `S_y = dp/dy`（物理上是静力平衡的支撑力）；无源的纯导热精确态
   只要 `rho = p/T` 就必然不可表示，因此 `tests/test_ns_heat_conduction.py` 里那两条
   `xfail(strict=True)` 断言的属性（投影态的壁面能量残差随加密衰减）**在数学上不可达**。
   本单**保留**这两条 xfail（honest 记录不覆盖），但把它们的语义写明：它们度量的是投影假象，
   不是闭合缺陷；正确的回归钉子是本单新增的 `tests/test_ns_hydrostatic_conduction.py`。
   xfail 的退役需 owner/评审裁定，不在本单范围内自行翻转。
3. 壁面高阶模态失稳（m2972 谱证据，增长率 `~ mu sigma / h^2`）与本单无关，未被触及。
4. 结论只对 Cartesian 张量积网格 + BR1/SIPG 闭合 + `wall_gradient="face"`（默认）成立；
   `"taylor"` 重构未在可表示态上复测（其缺陷已在 m3139 定性）。
5. 范数：残差为模态系数尺度的逐模态最大值（不是 L2），故数值随 `degree` 增大而增大
   （高阶模态带 `(2k+1)^2/(2h)` 因子），跨 degree 之间不可直接比较，跨网格/同 degree 可比。

## 6. 误差判定

| 关键量 | 基准 | 实测（最差值） | 相对误差 | &lt;3%？ |
|---|---|---:|---:|---|
| 可表示态壁面热流 q_h | `kappa dT/dy = -0.24647887` | 0.24647887 | 1.4e-12 | ✅ |
| 可表示态离散残差 | 0（精确不动点） | 1.77e-10（模态尺度） | 机器零 | ✅ |
| 教科书态壁面迹缺陷阶次 | 2（`rho` 有理导致的投影误差） | 2.03 | 1.5% | ✅ |
| 教科书态热流误差阶次 | 1（罚项 `sigma/h` × O(h^2)） | 1.03 | 3% | ✅（边界值，如实报告） |
| 教科书态热流误差 / 罚项预测 | 1（恒等因果） | 0.863（网格无关） | 13.7% | ❌（常数 0.863 而非 1；说明还有 O(1) 的同阶因子来自内区迹与模态投影，不改变因果判定） |

**核心判定**：m3257 把「壁面热流一阶」归因为等温壁 Dirichlet 罚项**闭合缺陷**是**证据不足**的；
在可精确表示的状态上同一闭合把非零壁面热流复现到 **3.4e-13**，一阶误差完全由
`rho = p0/T` 的 O(h^2) 投影缺陷经罚项放大产生（比值 0.863 网格无关）。原结论应改写为
「保守变量表示有理密度 `rho = p/T` 带来的初始化/表示误差」，而非闭合方案缺陷。
