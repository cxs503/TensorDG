# TensorDG 1-D DG 对流核的高阶验证：P3 上限的来历、设计阶 p+1 与间断解 L1 率的实测

- 任务：m3320（platform 席自找活）　分支 `agent/m3320`　仓库 TensorDG
- 环境：Python 3.11.11 / torch 2.7.1 / NumPy / CPU float64，`OMP_NUM_THREADS=4`（本机 128 核，
  跑批时 load15 ≈ 100–120，其他席占满，故全链路压到 4 线程）
- 锚点：`expand_audit_tensordg.md` §3.1 第 1 条基准「1D 周期线性对流：P2、单档网格、
  0.000236%」——README 的**头号基准**只有**一个阶数、一个网格族**的证据，而
  `tensordg/advection_1d.py` 的入口写死 `degree not in (0, 1, 2, 3)` 与
  `u0 = sin(2πx)`，**从结构上**把验证面锁死在「光滑 + P≤3」。
- 一句话结论：解除这两个人为约束后，**设计阶 p+1 在 P1–P5 全部复现**
  （拟合阶 1.986 / 2.996 / 3.982 / 4.995 / 5.998，相对偏差 ≤ 0.7%，**全部 <3%**）；
  **P0 在 8–64 网格上只有 0.886（偏差 11.4%），如实记为未达设计阶**；
  间断平方波的 **L1 率只在 P0 复现教科书 p+1/2 = 0.49**，P1–P3 实测 0.73 / 0.81 / 0.85
  ——**远低于 p+1/2，如实记为跨阶 FAIL**，原因是本核**不加限制器**，L1 误差被不衰减的
  Gibbs 尾巴主导（L∞ 过冲 0.46–0.57，翻倍网格后比值 0.95–1.03，不衰减）。

## 1. 案例介绍

### 1.1 物理背景

一维周期线性对流 `u_t + u_x = 0`，`x ∈ [0,1)`，模态 Legendre 间断 Galerkin（DG），
迎风数值通量，经典四阶 Runge–Kutta 时间推进。它是 DG 方法最干净的验证载体：精确解是
初值的刚性平移，因此误差可逐点度量，无需制造源项、无时间尺度竞争。

两个被测试的初值：

| 算例 | 初值 | 精确解 | 它检验什么 |
|---|---|---|---|
| A 光滑 | `u0 = sin(2πx)` | `sin(2π(x − t))` | 设计阶 `p+1`（模态基 + 迎风通量 + RK4 的合成精度） |
| B 间断 | `u0 = 1` on `[0.25, 0.75)`，余为 0 | 平移后的同一方波 | 间断解的 L1 率与 Gibbs 过冲（无限制器时的真实行为） |

### 1.2 参数表（判据先于实验）

| 项 | 设定 |
|---|---|
| 域 / 边界 | `[0,1)`，周期 |
| 阶数 | `p = 0…5`（`MAX_DEGREE = 8` 的显式上界内） |
| 光滑算例网格 | P0–P3：8/16/32/64；P4–P5：8/16/32；`cfl = 0.02`，`t = 0.25` |
| 间断算例网格 | P0–P3：16/32/64；`cfl = 0.05`，`t = 0.5`（半个周期，两次跨跃） |
| 误差度量 | `l2_error`（单胞 Gauss，阶 `max(2p+4,6)`）；`l1_error`（**按精确跃变位置切分**的复合 Gauss，`nsub=6`）；`linf_error`（每胞 8 子面板 × 16 点网） |
| 判据 1 | 光滑拟合阶 `|ν − (p+1)| ≤ 5%·(p+1)` |
| 判据 2 | 间断拟合阶与 `p+1/2` 的偏差 ≤ 0.35（Johnson–Pitkäranta） |
| 判据 3 | 估计器自控：`t = 0` 时投影解的 L1 < 1e-12（方波非多项式，单胞 Gauss 不可能达到） |
| 判据 4 | 工程门：最细网格**相对** L1 < 3% |

## 2. 怎么做的

### 2.1 两处最小 API 变更（`tensordg/advection_1d.py`）

1. **解除 `degree ∈ {0,1,2,3}`**。算子是阶数无关的（Legendre 值/导数在 Gauss 点求值，
   `nq = max(2p+3,4)`），这个上界**没有任何数学理由**，却让所有扫阶验证止步于 P3。
   现在改为显式文档化上界 `0 ≤ degree ≤ MAX_DEGREE (=8)`。
2. **初值可变**：新增 `initial: Callable[[Tensor], Tensor] | None = None`（默认仍是 `sin(2πx)`，
   向后兼容），并把 `l2_error` 泛化为接受 `exact=` 回调。没有这一条，**间断数据验证根本写不出来**。

### 2.2 新增的两个误差估计器（关键工具，也是本单的主要工作量）

- `l1_error(..., jumps=(...), nsub=k)`：复合 Gauss，**在每个胞内按参考解的精确跃变位置切分**，
  再细分 `nsub` 个子面板。这一步不可省：若整胞用单条 Gauss 规则，`|u_h − u_exact|` 的**折点**
  落在积分区间内部，求积误差是 `O(h)` 而待测的物理误差是 `O(h^{p+1/2})`——**求积误差会把
  要测的阶数整个淹没**。自验：`t = 0` 时 `u_h` 就是 L2 投影，切分版 L1 = **8.66e-16**（机器精度），
  不切分版（`nsub=1`）L1 > 1e-6（专门写成负控测试项）。
- `linf_error(...)`：每胞 8 子面板 × 16 点网上的 `max|u_h − u_exact|`，用来量 Gibbs 过冲
  （极值落在含跃变的胞内，单点采样会漏掉）。

### 2.3 验证装置

| 文件 | 作用 |
|---|---|
| `tensordg/advection_1d.py` | 解除阶数上限 + 可变初值 + 泛化 L2/L1/L∞ 误差（新增 `_vector_legendre` 向量化） |
| `benchmarks/advection_1d_highorder.py` | 四节：`smooth` / `temporal` / `floor` / `discontinuous`；数字写 JSON、出图 |
| `tests/test_advection_1d_highorder.py` | 8 条判据（含阶数上限、估计器自控、Gibbs 不衰减、p+1/2 只在 P0 成立） |
| `validation/advection_1d/highorder_summary.json` | 全部原始数字（程序化生成，零手抄） |
| `docs/figures/advection_1d_highorder.png` | 双面板：光滑 L2 与间断 L1 的 h-收敛（含 `h²`/`h⁴` 参考斜率） |

复现：`PYTHONPATH=. python -m benchmarks.advection_1d_highorder`（约 2–3 min，4 线程）。

## 3. 计算结果

### 3.1 光滑方波的设计阶（判据 1）

绝对 L2 误差（`‖e‖_2`，非相对值；相对值 = 绝对 × √2，因 `‖sin‖_2 = 1/√2`）：

| 阶 | 8 | 16 | 32 | 64 | 拟合阶 | 设计阶 | 相对偏差 | 判定 |
|---|---:|---:|---:|---:|---:|---:|---:|---|
| P0 | 3.535e-01 | 2.025e-01 | 1.085e-01 | 5.614e-02 | **0.886** | 1 | **11.4%** | ❌ 未达设计阶（前渐近） |
| P1 | 2.574e-02 | 6.587e-03 | 1.656e-03 | 4.146e-04 | 1.986 | 2 | 0.70% | ✅ |
| P2 | 1.656e-03 | 2.089e-04 | 2.612e-05 | 3.265e-06 | 2.996 | 3 | 0.14% | ✅ |
| P3 | 7.797e-05 | 4.952e-06 | 3.154e-07 | 1.971e-08 | 3.982 | 4 | 0.44% | ✅ |
| P4 | 3.081e-06 | 9.688e-08 | 3.032e-09 | — | 4.995 | 5 | 0.11% | ✅ |
| P5 | 1.017e-07 | 1.593e-09 | 2.491e-11 | — | 5.998 | 6 | 0.04% | ✅ |

与既有声明的一致性交叉核对：P2 @64 绝对 3.2648e-06 → 相对 4.617e-06 = **0.000462%**，
README 声明的 P2 @**80** 格 0.000236% 恰在其下（更细网格 → 更小误差，比值 0.51 ≈ (64/80)³ = 0.512），
两条独立测量的比值符合三阶律，**无矛盾**。

### 3.2 时间推进的贡献（`temporal` 节：负控，不是噪声）

固定网格 `16`、只把 `cfl` 从 0.02 降到 0.005（RK4 的步数翻 4 倍）：

| 阶 | 误差(cfl=0.02) | 误差(cfl=0.005) | 时间项占比 |
|---|---:|---:|---:|
| P1 | 6.5870e-03 | 6.5870e-03 | −8.7e-13 |
| P2 | 2.0887e-04 | 2.0887e-04 | 6.3e-12 |
| P3 | 4.9515e-06 | 4.9515e-06 | −4.7e-10 |
| P5 | 1.5927e-09 | 1.5927e-09 | −4.3e-09 |

**时间项占比在 1e-9 量级**——所以 §3.1 里 P4/P5 的 5.00/6.00 是**空间阶**，不是 RK4 的四阶
在冒充，也不是「RK4 把阶数压到 4」。这条控制是把「阶数测量」与「时间积分上限」分开的
唯一手段，没有它，P4/P5 的 6 阶结论不可信。

### 3.3 舍入地板（`floor` 节：负控）

P5 h-加密到 128 格：

| 网格 | 16 | 32 | 64 | 128 |
|---|---:|---:|---:|---:|
| 绝对 L2 | 1.593e-09 | 2.491e-11 | 3.891e-13 | **1.336e-14** |
| 逐档阶 | — | 5.998 | 6.001 | **4.864** |

阶从 6.00 掉到 4.86、误差停在 1.34e-14（≈ 1e-2 × 机器精度，相对 `‖u‖≈0.7`），
是**舍入地板的进入**，不是算子坏了。用途：任何人看到「更细网格上阶数塌了」时，
先对照本节再判断是缺陷还是算术上限。

### 3.4 间断解：L1 率与 Gibbs（判据 2/4）

相对 L1（`L1_abs / 0.5`，0.5 是方波的 L1 范数），`t = 0.5`：

| 阶 | 16 | 32 | 64 | 拟合阶 | 理论 p+1/2 | 判定 | 64 格相对 L1 | 3% 门 |
|---|---:|---:|---:|---:|---:|---|---:|---|
| P0 | 55.5% | 39.7% | 28.1% | **0.490** | 0.5 | ✅ 命中 | 28.14% | ❌ |
| P1 | 16.8% | 10.2% | 6.09% | **0.733** | 1.5 | ❌ 低 0.77 阶 | 6.09% | ❌ |
| P2 | 10.1% | 5.77% | 3.27% | **0.813** | 2.5 | ❌ 低 1.69 阶 | 3.27% | ❌（差 0.27 个点） |
| P3 | 7.29% | 4.05% | 2.23% | **0.854** | 3.5 | ❌ 低 2.65 阶 | **2.23%** | ✅ |

L∞ 过冲（Gibbs）：

| 阶 | 16 | 32 | 64 | 末/首 |
|---|---:|---:|---:|---:|
| P0 | 0.4612 | 0.4670 | 0.4765 | 1.033 |
| P1 | 0.5033 | 0.5100 | 0.5128 | 1.019 |
| P2 | 0.5553 | 0.5476 | 0.5399 | 0.972 |
| P3 | 0.5701 | 0.5544 | 0.5424 | 0.951 |

**这不是 bug，是「无限制器 DG」的定义性行为**：过冲幅度是 O(1)（约为跳跃幅度的一半）、
翻倍网格不衰减（比值 0.95–1.03），**且不随阶数变小**（32 格上 0.467 / 0.510 / 0.548 / 0.554，
P0→P3 反而略增），所以 L1 误差被跃变邻域的振荡尾巴主导，
观测率几乎与阶数无关（0.73 → 0.85，只随 p 缓慢上升）。教科书 p+1/2 是
**带 TVB 限制器**（本仓 `limiters.apply_tvb_limiter` 已有，但本研究的推进循环里**没有挂**）
的结论——本单的边界就在这里，如实标注。

## 4. 注意点（踩的坑 / 局限 / 适用范围）

1. **求积会把要测的阶数吃掉**。第一版 `l1_error` 整胞一条 Gauss 规则，把 `|u_h − u|` 的折点
   跨着积分，量出的 L1 完全不可信。最终版按**精确跃变位置**切分 + 子面板细分。
   **注意一个陷阱**：16/32/64 格上 0.25/0.75 恰好落在**胞面**上，于是 `t=0` 的「投影 L1 = 0」
   是**平凡成立**的（每胞内被积函数是常数），它不能证明估计器合格；合格性改用
   **面板求积收敛自控**：`nsub` 6 → 12 时 L1 必须不变（实测相对差 < 1e-8），
   否则报出的 L1 阶是折点求积伪影而不是离散误差。同理，`einsum("pqm,cm->pq")` 这类标签错误会把
   胞索引当求和轴，静默给出 63.5 而不是报错——**估计器必须自带 t=0 机器精度自控**，
   否则整张阶数表都是假数。
2. **P0 的 0.886 不是代码缺陷**：8–64 格上 `sin` 的一阶迎风格式还没进渐近区
   （逐档 0.804/0.900/0.950 正在爬向 1）。如实记为「未达设计阶」，并把它作为前渐近判据的
   教学对照（`test_...design_order` 只对 P1–P3 设判据）。
3. **过冲不随阶数下降**（32 格：0.467@P0 → 0.554@P3）是实测事实，测试里按此钉住；
   别把「高阶就该更少 Gibbs」当成断言，无限制器的 DG 恰恰相反。
4. **`MAX_DEGREE=8` 只是 Python 侧装配的上界**，实测只做到 P5；P6–P8 未验证（本单预算）。
   另外 `nq = max(2p+3,4)` 对 `p ≤ 8` 足够，若将来放开请一并复核求积阶。
5. **L1 率结论的适用范围**：仅对**不加限制器**的 RK4-DG、方波初值、`t=0.5`。加了限制器后
   率应上升（这正是 `limiters.py` 的用途），但本单未做，不能外推到限量格式。
6. **`floor` 节的 `floor_reached` 标志为 False**（用的是「末档/次末档 > 0.5」判据），
   但逐档阶已从 6.00 掉到 4.86，实际是**地板进入期**而非「已坐底」。两种说法都已写进 JSON，
   不做粉饰。
7. 共享机器 load15 ≈ 100–120，全部运行压 4 线程；耗时数字不作为性能结论。

## 5. 误差判定（逐项显式回答「是否 <3%」）

| 量 | 基准 | 相对偏差 | 是否 <3% |
|---|---|---:|---|
| P1 拟合阶 | 设计 2 | 0.70% | **是** |
| P2 拟合阶 | 设计 3 | 0.14% | **是** |
| P3 拟合阶 | 设计 4 | 0.44% | **是** |
| P4 拟合阶 | 设计 5 | 0.11% | **是** |
| P5 拟合阶 | 设计 6 | 0.04% | **是** |
| P0 拟合阶 | 设计 1 | **11.4%** | **否**（前渐近，逐档 0.80→0.95 爬向 1） |
| P2 @64 绝对 L2（对 README 80 格声明） | 0.000236% @80 | 比值 0.51 vs 三阶预测 0.512 | **是**（一致性 0.4%） |
| P1–P5 最细网格相对 L2 | 解析（0） | ≤ 4.62e-06（0.00046%） | **是** |
| P0 拟合阶 vs p+1/2（间断） | 0.5 | 0.490 | **是**（差 2%） |
| P1 间断 L1 率 | p+1/2 = 1.5 | 0.733 | **否**（低 51%） |
| P2 间断 L1 率 | 2.5 | 0.813 | **否**（低 67%） |
| P3 间断 L1 率 | 3.5 | 0.854 | **否**（低 76%） |
| 间断解相对 L1 @64（P3） | <3% 工程门 | 2.23% | **是** |
| 间断解相对 L1 @64（P2/P1/P0） | <3% | 3.27% / 6.09% / 28.14% | **否** |
| 估计器自控（nsub 6→12 的 L1 相对变化） | 0 | < 1e-8 | **是** |
| 估计器 t=0 投影 L1（16 格，跃变落在胞面） | 0 | 8.66e-16 | 平凡成立，**不作合格性证据** |
| Gibbs 过冲衰减 | 无（O(1)） | 末/首 0.95–1.03 | **是**（确认不衰减） |
| RK4 时间项占比 | 可忽略 | ≤ 6.3e-12 | **是** |

**显式回答**：

- **光滑解的设计阶 p+1 —— 是**，P1–P5 五个阶数的相对偏差全部 <3%（最大 0.70%）。
- **P0 的设计阶 —— 否**（11.4%），原因是前渐近，已给出逐档爬升证据。
- **间断解的 p+1/2 L1 率 —— 否**（P1–P3 低 51%–76%），根因是本核不加限制器、Gibbs 尾巴主导；
  P0 命中（0.490 vs 0.5）说明装置本身没错，错的是「拿限量格式的率去套无限量格式」这个期待。
- **工程门 3% —— 仅 P3 @64 格（2.23%）通过**；P2 差 0.27 个百分点未过，如实记录。
