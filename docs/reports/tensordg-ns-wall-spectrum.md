# TensorDG 压缩 Navier–Stokes 壁面通道：二阶单侧梯度 + 失稳机制的谱判定

- 任务：m2920（models 席自找活）　分支 `agent/m2920`　日期 2026-11-03
- 环境：Python 3.11 / torch 2.7.1 / numpy / pytest 9.2.0 / CPU，float64，单核
- 上游：m2496 交付 `tensordg/ns_dg_2d.py`（BR1/SIPG 粘性 DG）并 honest-FAIL 壁面瞬态；
  m2589 复核（`docs/reports/tensordg-ns-wall-verification.md`）把根因定位为
  「壁面通量只有 O(h) 精度 → 强形式残差 O(1) → 瞬态失稳」，并建议「实现二阶壁面梯度修法」。
- 一句话结论：**m2589 的「O(h) 壁面梯度是失稳种子」这一因果链被本单证伪**。
  本单交付了二阶单侧梯度（壁面通量误差减半，纯精度收益），但**失稳依旧**：
  半离散算子的谱显示壁面通道存在 `max Re(λ) = +382`，且增长率**随 SIPG 罚项线性增长**
  （σ=0.5→101.6 … σ=16→2960.9，指数 1.00），而把罚项关掉只把 `max Re` 从 382 降到 290，
  把扩散通量关掉则降到 0。→ 壁面缺的是**与罚项配对的伴随（Nitsche）边界项**，
  不是梯度精度；任何罚项量级都补不回来。**瞬态失稳仍为 OPEN（honest FAIL）**。

## 1. 案例介绍

二维压缩 Navier–Stokes，量纲一，`R = 1`（`T = p/rho`、`c_v = 2.5`、`c_p = 3.5`），γ = 1.4，
常 μ，`kappa = mu c_p / Pr`（Pr = 0.71）。粘性项 BR1（Cartesian 上即 SIPG），
壁面（Dirichlet）用镜像 ghost。

| 量 | 值 |
|---|---|
| 域 | [0,1]²，x 周期，y 双壁（下壁静止、上壁 U=1，均 T_w=1） |
| 网格 | 2×{8,16,32,64} 单元，P1（谱判定另用 2×8 P1） |
| μ, κ | 0.1, 0.4930 |
| 罚项 | `penalty = σ (p+1)²`，σ = 2（默认，P1 → 8） |
| 解析稳态 | `u = U y`、`T = 1 + A y(1−y)`、`A = μU²/(2κ) = 0.10142`、`p = 1` |

谱判定全部在**解析稳态**上做：该状态是（几乎）精确解，算子对它的残差与谱决定
「壁面算子能否自持推进」。

## 2. 怎么做的

### 2.1 修法（精度面）

壁面只有一侧数据，DG 多项式在壁面的法向导数误差是 O(h)；内部面靠两侧平均把 O(h) 抵消成 O(h²)，
壁面无法抵消。修法：用**单元中心法向导数做单侧二阶外推**

    f'(wall) = 1.5 f'(壁面单元) − 0.5 f'(第一个内层单元) + O(h²)

单元中心导数取 `(q(ξ=+1) − q(ξ=−1))/h`（对 P1 即最优拟合斜率，误差 O(h²)；
两者之差/h 为 O(h)，再乘 h/2 → O(h²)）。实现为 `tensordg/ns_dg_2d.py::_wall_normal_derivative`，
经 `_boundary_flux(..., normal_derivative=...)` 注入，公开入口
`solve_navier_stokes_dg_2d(..., wall_gradient="taylor")`（默认），保留 `"face"` 旧路径供 A/B。

### 2.2 失稳机制（谱判定，本单新增）

残差对模态系数可微（autograd），故 `J = ∂(rhs)/∂U` 可精确取得；
对 2×8 P1（128 DOF）直接做特征分解。用 `tools/spectrum_ns_wall.py` 一键复现：

    PYTHONPATH=. python -m tools.spectrum_ns_wall          # 写 validation/ns_dg_2d_wall/spectrum.json + 图
    PYTHONPATH=. python -m tools.diag_ns_wall              # m2589 的五节诊断（含新 A/B 开关）

`ns._boundary_flux` 在工具内被替换以逐项关掉壁面项（`default / inviscid / grad / penalty`），
每种配置都由同一 autograd 路径求谱。

## 3. 计算结果（`validation/ns_dg_2d_wall/spectrum.json` 直读）

### 3.1 谱：谁制造了正特征值

| 配置 | max Re(λ) | min Re(λ) | 主导通道 | 峰值 DOF（x,y,k,l,var） |
|---|---:|---:|---|---|
| 全周期（无壁） | **0.000** | −1335.6 | ρv | (0,5,0,0,2) |
| 壁面，旧单侧梯度 | **+348.5** | −1313.9 | E | (0,0,0,1,3) |
| 壁面，二阶单侧梯度 | **+382.4** | −1314.8 | E | (0,0,0,1,3) |
| 壁面，只留无粘（绝热/自由滑移） | **0.000** | −1313.4 | E | (0,0,0,0,3) |
| 壁面，只留梯度（无罚项） | **+290.5** | −1315.3 | E | (0,0,0,1,3) |
| 壁面，只留罚项（无梯度） | **+0.58** | −1313.4 | ρ | (0,7,0,0,1) |

读法（逐条都是「翻掉一项」的受控实验）：

1. 无壁（全周期）`max Re = 0`：内部格式没有增长模，失稳由**壁面**制造。
2. 主导增长模 95% 能量在 **energy 通道**、峰值在**壁面单元**——与 m2589 的通道拆分（只有 T 通道失稳）一致。
3. 关掉扩散壁面通量（绝热）→ `max Re = 0`；只留罚项 → `+0.58`；只留梯度 → `+290`。
   **正特征值几乎全部来自壁面法向梯度项**，罚项贡献比它小三个数量级。
4. 把梯度换成二阶（本单修法）→ 正特征值**不降反微升**（348→382）：
   m2589 的「O(h) 梯度致失稳」因果链**不成立**；梯度精度是独立问题（见 §3.2）。

### 3.2 谱：增长率随罚项线性增长（反耗散指纹）

| σ | penalty | max Re(λ) | max Re / penalty |
|---:|---:|---:|---:|
| 0.5 | 2 | 101.599 | 50.8 |
| 1.0 | 4 | 196.448 | 49.1 |
| 2.0 | 8 | 382.447 | 47.8 |
| 4.0 | 16 | 751.692 | 47.0 |
| 8.0 | 32 | 1488.439 | 46.5 |
| 16.0 | 64 | 2960.932 | 46.3 |

双对数拟合指数 **1.00**：增长率 ∝ σ。正常 SIPG 罚项越大越耗散（越稳），这里反向 →
壁面项**反耗散**。机理：内部面的罚项与「梯度跳跃」项成对出现、互相配对成耗散双线性型；
壁面只有罚项、**没有配对的伴随（Nitsche）边界项** ∮ κ ∂_n φ (q − g) ds，
于是罚项变成正反馈。任何 σ 都无法补偿（σ→0 只是把壁面退化成近 Neumann，物理错）。

### 3.3 精度面：修法的收益（壁面热流 vs 解析值 −κ dT/dy 底部 = −0.05）

| cells(y) | 旧单侧梯度误差 | 二阶外推误差 | 比值 | 旧斜率 | 新斜率 |
|---:|---:|---:|---:|---:|---:|
| 8 | 1.2704e-02 | 7.312e-03 | 0.576 | — | — |
| 16 | 6.3452e-03 | 3.639e-03 | 0.573 | 1.002 | 1.007 |
| 32 | 3.1724e-03 | 1.816e-03 | 0.572 | 1.000 | 1.003 |
| 64 | 1.5864e-03 | 9.074e-04 | 0.572 | 1.000 | 1.001 |

误差**减半（比值 0.57）**但**阶仍为 1**：残余 O(h) 来自罚项 `(σ/h)(q⁻ − g)`，
其中 `q⁻ − g` 是多项式在壁面的迹误差 O(h²)（P1 的 L2 投影壁面迹偏 `A h²/6`，实测去掉梯度误差后
残余 = `σ A h/6` 量级，与实测 14.6% ↔ 预测 16.7% 吻合）。内部面没有这一项，因为两个单元的壁面迹误差
在跳跃里同阶相消（→ O(h³)）。

### 3.4 精确稳态残差与瞬态

| cells(y) | 旧残差 max | 二阶外推残差 max | 壁面占比 |
|---:|---:|---:|---:|
| 2×8 P1 | 3.0453e-01 | 1.9973e-01 | 1.000 |
| 2×16 P1 | 3.0450e-01 | 2.0684e-01 | 1.000 |
| 2×32 P1 | 3.0454e-01 | 2.1066e-01 | 1.000 |

残差降 35% 但**不随网格衰减**（甚至微升）——与 §3.2 的结论一致：壁面残差由罚项的反耗散结构主导，
不是网格精度问题。瞬态推进：两种梯度都在 **t = 0.03282（第 67 步）** 因 `min_pressure < 0` 失败，
与 m2589 的 dt 无关性结论一致。

## 5. 注意点（坑 / 局限）

1. **m2589 的因果链被证伪**：O(h) 壁面梯度确实存在且已修（误差减半），但它**不是**失稳种子；
   失稳是壁面项结构缺失（无伴随项）造成的反耗散。这条修正应回写进后续所有引用。
2. **罚项符号翻转无救**：把壁面罚项符号翻过来，`max Re` 几乎不变（382.45 vs 382.45），
   因为罚项本身贡献只有 0.58；**不要**再用「调 σ」当修法。
3. **残余 O(h) 通量误差来自罚项**：二次外推只治梯度，治不了罚项迹误差；
   要拿到二阶壁面通量必须同时换成「高阶单侧重建壁面值 + 正确配对的伴随项」。
4. **谱判定的适用范围**：线性化于解析稳态、2×8 P1、Cartesian、常 μ；
   谱只能证明「存在增长模」（充分条件），不能证明「所有网格都失稳」；
   但 8/16/32 的残差不衰减 + 3 个 dt/通道实验已独立支持同一结论。
5. **未完成（OPEN）**：伴随（Nitsche）边界项尚未实现。实现要点已明确：
   在残差中补 `−∮_Γ κ ∂_n φ (q − g) ds`（每个守恒通道一条），并把壁面罚项符号改成与
   Nitsche 配对时的耗散号；验收判据已就位且一键可跑（`tests/test_ns_dg_2d_wall.py` 的
   `strict=True` xfail 会在修好后转 XPASS 强制退休局限）。
