## ① 案例介绍

**物理背景与几何**：平面 Couette 剪切流，计算域 `[0,1]²`，x 方向周期、y 方向两道等温无滑移壁。
量纲一，`R = 1`（`T = p/ρ`、`c_v = 1/(γ-1) = 2.5`、`c_p = 3.5`），γ = 1.4。
解析定常解 `u = U y/H`、`v = 0`、`p = p0`、`T = T_w + μU²/(2κ)·s(1-s)`（Brinkman 抛物型温度）。

| 参数 | 值 |
|---|---|
| μ / κ / γ | 0.1 / 0.492958 / 1.4 |
| 壁速 U / 壁温 T_w / 压力 p0 | 1.0 / 1.0 / 1.0 |
| 网格 / 单元阶 | 2×{8,16,32}，P1/P2/P3（模态 Legendre DG） |
| 罚项 | `σ_scale·(p+1)²`，σ_scale ∈ [0.0, 0.5, 2.0, 8.0, 32.0, 128.0] |

**要复核的问题**：m2589/m2786/m2879 三单都在**解析定常态**上测到「残差 O(1)、100% 集中在壁面行」，
并据此判为「离散不一致 / 罚项主导」。三条报告都没有做**决定性的对照**：
*若一个态可以被多项式空间精确表示，一致的壁面算子必须给出机器零残差*。
本单补上这个对照，并把「O(1) 残差」拆成两个可命名的机制。

## ② 怎么做的

1. **可精确表示控制态** `(ρ, u, v, p) = (1, y, 0, 1)`：这是无粘 Euler 的精确定常解；在 P2/P3 下其守恒态
   （`E = p/(γ-1) + ½ρu²` 为 y 的二次式）**可被空间精确表示**。于是质量/动量残差必须为舍入级，
   能量残差必须等于物理耗散 `τ:∇u = μU²`。该对照把「壁面算子」与「投影误差」彻底分开。
2. **罚项标度律**：解析定常态（`ρ = p/T` 为有理函数、温度是抛物线，**不可精确表示**）的残差对
   σ_scale ∈ [0.0, 0.5, 2.0, 8.0, 32.0, 128.0] 扫描，逐 (阶, 网格) 做最小二乘线性拟合并报告 R²。
3. **失稳起始时间**：从**可精确表示的**控制态出发做 SSP-RK3 推进（时间步按声学 CFL 与粘性 CFL 双约束），
   记录第一次出现非物理态（ρ≤0 或 p≤0）的物理时间，扫描 σ_scale。
   起点无壁面间断，因此任何失稳都不是「脉冲启动奇异性」。
4. 判据先于实验：一致性判据 `< 1e-11`（舍入级，float64 累积）；能量判据 `|R_E − μU²| < 1e-9`；
   标度律判据 `R² > 0.999`。全部写进 `tests/test_ns_wall_penalty_scaling.py`（5 条，4.2 s 跑完）。

## ③ 计算结果

### 3.1 壁面算子是一致的（可精确表示态，2×8 网格，含两侧 Dirichlet 壁）

| 阶 | 粘性配置 | mass | x-momentum | y-momentum | energy | \|energy − μU²\| |
|---|---|---|---|---|---|---|
| P1 | inviscid | 6.3e-15 | 7.0e-15 | 2.5e-02 | 2.5215e-14 | 2.5e-14 |
| P1 | momentum_only | 6.3e-15 | 9.6e-14 | 2.5e-02 | 1.0000e-01 | 7.4e-15 |
| P1 | conduction_only | 6.3e-15 | 7.0e-15 | 2.5e-02 | 6.9014e-01 | 6.9e-01 |
| P1 | full | 6.3e-15 | 9.6e-14 | 2.5e-02 | 6.9014e-01 | 5.9e-01 |
| P2 | inviscid | 2.0e-14 | 4.5e-14 | 9.1e-14 | 8.1825e-14 | 8.2e-14 |
| P2 | momentum_only | 2.0e-14 | 1.4e-13 | 9.1e-14 | 1.0000e-01 | 1.7e-14 |
| P2 | conduction_only | 2.0e-14 | 4.5e-14 | 9.1e-14 | 2.9427e-12 | 2.9e-12 |
| P2 | full | 2.0e-14 | 1.4e-13 | 9.1e-14 | 1.0000e-01 | 1.1e-13 |
| P3 | inviscid | 3.6e-14 | 6.0e-14 | 1.5e-13 | 1.2979e-13 | 1.3e-13 |
| P3 | momentum_only | 3.6e-14 | 5.7e-13 | 1.5e-13 | 1.0000e-01 | 3.1e-14 |
| P3 | conduction_only | 3.6e-14 | 6.0e-14 | 1.5e-13 | 7.0824e-12 | 7.1e-12 |
| P3 | full | 3.6e-14 | 5.7e-13 | 1.5e-13 | 1.0000e-01 | 3.2e-13 |

- P2/P3：质量与两个动量通道残差 **≈ 1e-13（舍入级）**，即壁面通量与罚项在可表示数据上**逐项一致**；
- P2/P3「momentum_only / full」的能量残差 = **0.1000**，恰为物理耗散 `μU² = 0.1·1.0²`，
  误差 1.1e-13——**壁面没有贡献任何额外源项**；
- P1 的 y-momentum 残差 2.5e-02 与能量残差 0.690 是 P1 存不下二次式
  `E`（能量投影丢掉了 y² 分量，反解出的 p、T 不再是 1）造成的**投影误差**，与壁面算子无关：
  同一 P1 态在**全周期**边界下给出完全相同的 2.5e-02。

### 3.2 解析定常态的残差是「投影误差 × 罚项」，故对罚项线性

| 阶 | 网格 | 斜率 k (每单位 σ_scale) | 截距 R(0) | R² |
|---|---|---|---|---|
| P1 | 2×8 | 9.6899e-02 | 7.9295e-02 | 0.999675 |
| P2 | 2×8 | 8.9986e-03 | 9.8815e-04 | 0.999988 |
| P3 | 2×8 | 1.3076e-04 | 5.9470e-05 | 0.999715 |
| P1 | 2×32 | 1.0294e-01 | 6.6853e-02 | 0.999674 |
| P2 | 2×32 | 2.3240e-03 | 2.4414e-04 | 0.999988 |
| P3 | 2×32 | 9.5049e-06 | 1.2273e-06 | 0.999634 |

- 9 组 (阶 × 网格) 拟合 **R² 全部 > 0.9996**（最差 P3/2×32 = 0.999634），
  截距随阶下降（P1 0.079 → P2 9.88e-04 → P3 5.95e-05），
  即 R(0) 就是**投影误差地板**，σ 只是把它放大 `σ/h` 倍。
- 结论修正：m2589/m2786 记录的「O(1) 残差、与 h 无关」= **R(σ = 2(p+1)²) 落在投影误差地板上、并被罚项放大约 1/σ 倍**，
  不是「离散不一致」。m2879 的「罚项主导」方向正确，但缺少这条标度律与 3.1 的对照，因而无法排除「算子本身错」。

### 3.3 失稳起始时间（可精确表示起点，2×8）

| 阶 | σ_scale | 罚项 | 首次非物理时间 | 步数 | 峰值 \|v\| |
|---|---|---|---|---|---|
| P1 | 2 | 8 | 0.03107 | 62 | 1.427e-01 |
| P1 | 8 | 32 | 0.00841 | 16 | 3.841e-02 |
| P1 | 32 | 128 | 0.00297 | 5 | 1.338e-02 |
| P2 | 2 | 18 | 0.01677 | 201 | 2.704e+01 |
| P2 | 8 | 72 | 0.00691 | 95 | 1.369e+02 |
| P2 | 32 | 288 | 0.00078 | 7 | 2.877e-03 |

- σ_scale 从 2 增到 32（16×）时，P1 失稳时间从 0.03107 提前到 0.00297
  （提前 10.5×），P2 从 0.01677 提前到 0.00078
  （提前 21.4×）——**近似 `t_fail ∝ 1/σ`**；
- 起点是 `(1, y, 0, 1)`，与壁面完全相容（无启动间断），**仍然失稳**，因此「脉冲启动奇异性」不是唯一机理；
- 同一 σ 下高阶更早失稳（P2 0.01677 < P1 0.03107），与 `σ/h` 随阶放大的罚项图像一致。

## ⑤ 注意点 / 局限

- **不改求解器**：本单只做验证与判据，`tensordg/ns_dg_2d.py` 一行未动（壁面通道的默认闭合仍是 `"face"`）。
- **失稳仍未修**：3.3 说明默认闭合下壁面**瞬态**在 (2×8, P2) 于 t≈0.017 崩溃，
  且与 σ 单调相关；`"fd2"` 闭合下同一算例可跑到 t=0.1 并与 Stokes 级数解差 0.84%（既有测试
  `test_impulsively_started_couette_matches_fourier_series` 覆盖）。因此工程结论：**壁面瞬态请用 `"fd2"`，
  默认 `"face"` 闭合仅适用于定常/短时（t ≲ 1e-2）问题**。
- 一致性对照只覆盖常数/线性/二次数据的**定常残差**，不证明时间方向的稳定性；3.3 反而证明定常残差一致 ≠ 瞬态稳定。
- 网格仅到 2×32、阶仅到 P3；np=1 单核 float64，未做向量化或 GPU 复算。

## ⑥ 误差判定（关键量 vs 基准，逐项）

| 关键量 | 基准 | 实测 | 相对误差 | 是否 < 3% |
|---|---|---|---|---|
| y-momentum 壁面残差（P2，可表示态） | 0（一致离散的精确解） | 9.06e-14 | — （相对 0 无定义） | **是**（绝对 < 1e-11） |
| 同上（P3） | 0 | 1.49e-13 | — | **是**（绝对 < 1e-11） |
| 能量残差（P2，full） | μU² = 0.1 | 0.100000 | 1.15e-10% | **是** |
| 罚项标度律拟合 | 线性（R²=1） | R² ≥ 0.999634 | 1−R² = 3.66e-04 | **是** |
| 失稳时间 − 罚项幂律 | 斜率 −1 | P2 log-斜率 1.105 | 210.5% | **否（210.5% > 3%）** |

最后一行如实标注为**未达 3%**：`t_fail` 对 σ 只是「近似」1/σ（P2 在对数-对数坐标下斜率偏离 −1），
因为失稳还含投影误差地板与阶数效应；本单不宣称精确幂律。
