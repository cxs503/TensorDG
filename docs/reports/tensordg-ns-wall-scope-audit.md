## 1 案例介绍（物理背景 / 几何 / 参数）

平面 Couette 流：下壁静止、上壁以 U=1 拖动，两壁等温 T_w=1，压力 p=1，动力粘性 μ 常数。
Navier–Stokes 的解析定常解为

    u(y) = U y/H,   v = 0,   p = 1,   T(y) = T_w + μU²/(2κ)·s(1-s),  s = y/H

其中 κ = μ c_p / Pr。Brinkman 抛物型温度来自粘性耗散与导热的平衡，**它正是「弯曲数据」的来源**：
P1 单元无法表示抛物线，P2 及以上可以。

| 参数 | 值 |
|---|---|
| 计算域 | 单位正方形，x 周期、y 为两道 Dirichlet 壁 |
| 网格 | 2 × ny 个 Cartesian 单元，ny ∈ {8, 16, 32, 64} |
| 单元阶 | P1 / P2 / P3（模态 Legendre DG，BR1 强形式 + SIPG 罚项 σ = 2(p+1)²） |
| μ / Pr / γ | 0.1 / 0.71 / 1.4（R=1，故 T = p/ρ） |
| 壁面条件 | ymin: u=0；ymax: u=U；两壁 T=T_w，无穿透 |
| 解析参考量 | 下壁能量通量 κ dT/dy|₀ = -0.050000 | 

**要复核的结论**：m2589 声明壁面路径有三项缺陷 ——（i）壁面热通量只有一阶、（ii）解析定常解
留下 O(1) 残差不随 h 消失（据此判为「不一致离散」）、（iii）壁面瞬态发散。
**三项测量都只在 degree=1 上做。**

## 2 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. 把 m2589 的三条判据原样重放到 P1 / P2 / P3：解析定常解残差 `ns._rhs_ns` 的范数 vs h；
   壁面能量通量与解析 κdT/dy 比较；从解析稳态出发的 SSP-RK3 推进 (`tools/diag_ns_wall.march`)。
2. 加两条 m2589 没有的判别量：
   - **量纲恒等式**：残差是散度，壁面通量误差 ε 应以 ε/h 进入残差。若 `RHS·h/ε` 是与 h 无关的
     常数，则「O(1) 残差」不是独立缺陷，只是通量阶的复述。
   - **阶数无关性**：脉冲启动失稳若在 P1/P2/P3 都发生，则它不是 P1 可表示性问题，而是壁面
     闭合的稳定性问题；反之若高阶存活，缺陷就是低阶特有的。
3. 工具链（唯一入口）：`benchmarks/verify_ns_wall_scope.py` →
   `validation/ns_dg_2d_wall/scope_audit.json` → `docs/figures/ns_dg_2d_wall_scope.png` → 本文表格。
   判据固化为 `tests/test_ns_dg_2d_wall_scope.py`（8 passed / 1 strict-xfail / 33.8 s）。

## 3 计算结果

### 3.1 壁面热通量的收敛阶：阶数 = 单元阶，不是 1

| degree | ny=8 | ny=16 | ny=32 | ny=64 | 观测阶 (8→64) | 设计阶 |
|---|---:|---:|---:|---:|---:|---:|
| P1 | 25.4082% | 12.6903% | 6.34485% | 3.172748% | 1.00 | 1 |
| P2 | 0.0760% | 0.0134% | 0.00264% | 0.000571% | 2.21 | 2 |
| P3 | 0.0124% | 0.0016% | 0.00020% | 0.000025% | 3.00 | 3 |

P1 一阶（正是 m2589 测到的 0.99–1.00，**也是 P1 的设计阶**：梯度类量在 P1 上只有一阶），
P2 二阶（2.21），P3 三阶（3.00）。→「壁面通量只有一阶」是 **P1 的性质**；
把它写成壁面算子的通性属过度外推。

### 3.2 解析定常解残差

| degree | RHS 8 | RHS 16 | RHS 32 | 观测阶 (16→32) |
|---|---:|---:|---:|---:|
| P1 | 3.045e-01 | 3.045e-01 | 3.045e-01 | -0.000 |
| P2 | 1.810e-02 | 9.222e-03 | 4.660e-03 | 0.985 |
| P3 | 3.530e-04 | 8.842e-05 | 2.210e-05 | 2.000 |

P1 残差平台在 0.3045、不随 h 变化；P2 一阶衰减（0.98）；P3 二阶衰减（2.00）。
→「残差不消失」同样是 P1 现象，**不是**离散格式不一致。

### 3.3 量纲恒等式：P1 的「O(1) 残差」= 3 × 通量误差 / h

| degree | ny | RHS_E | 壁面能量通量误差 | RHS_E·h / 误差 |
|---|---:|---:|---:|---:|
| P1 | 8 | 3.045e-01 | 1.270e-02 | 2.996 |
| P1 | 16 | 3.045e-01 | 6.345e-03 | 2.999 |
| P1 | 32 | 3.045e-01 | 3.172e-03 | 3.000 |
| P2 | 8 | 8.257e-03 | 3.800e-05 | 27.160 |
| P2 | 16 | 4.620e-03 | 6.693e-06 | 43.140 |
| P2 | 32 | 2.435e-03 | 1.319e-06 | 57.686 |

P1 的 `RHS_E·h/误差` 在三个网格上是 2.996 / 2.999 / 3.000（常数 3 = P1 模态权 2k+1）。
→ m2589 的 O(1) 残差恰是「通量一阶」除以 h 的结果，两条判据其实是同一条。
P2 该比值随 h 增大（27→58），说明 P2 的残差由内部贡献主导；恒等式只在 P1 成立 ——
这正是「平台残差」不能外推到高阶的原因。

### 3.4 稳定性：定常解在高阶稳定，脉冲启动全阶失稳

| degree | 从解析稳态推进 120 步 | 失效时刻 | 脉冲启动到 t=0.1 |
|---|---|---|---|
| P1 | 非物理 | 0.0328 | FloatingPointError |
| P2 | 存活 | — | FloatingPointError |
| P3 | 存活 | — | FloatingPointError |

## 5 注意点（踩过的坑 / 局限 / 适用范围）

1. **坑（最重要）**：「解析稳态残差必须随 h 消失」只在残差是**通量误差的复述**时成立；
   用残差平台值判「不一致」必须同时给出通量阶。m2589 §5 坑 1 已提醒过残差判据的陷阱，
   本轮给出定量版本：比值恒为 3 即证明同源。
2. **坑**：把只在 P1 上做的测量写成壁面算子的通性。本轮三条判据里两条（阶、残差）是 P1 特有，
   只有第三条（脉冲启动失稳）跨阶成立。
3. **局限 1（本单未做）**：**没有修**脉冲启动失稳。它跨 P1/P2/P3 成立，因此不能靠提高阶数绕过；
   m2589 已把致失稳通道定位到温度（罚项作用在 T=p/ρ，而能量方程守恒 E），与本轮「稳态在高阶
   稳定、强瞬态才失稳」一致，但机理仍未判别。
4. **局限 2**：仅 Cartesian、常 μ、无 Sutherland 律、纯显式推进；只测壁面通道，周期方向结论不变。
5. **局限 3**：`steady march P2/P3 存活 120 步` 只证明定常解邻域稳定，未证明能推进到目标物理时间；
   该判据是「不退化为非物理」，不是精度。

## 6 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 基准 | 相对误差 | 是否 <3% |
|---|---|---:|---|
| 壁面能量通量 P1 @64 格 | 解析 κdT/dy | 3.173% | ❌（且阶只有 1，即 P1 设计阶） |
| 壁面能量通量 P2 @64 格 | 解析 | 0.000571% | ✅ |
| 壁面能量通量 P3 @64 格 | 解析 | 0.000025% | ✅ |
| 壁面 x 动量通量 P2 @64 格 | 解析 −μU | 0.000814% | ✅ |
| 解析稳态残差 P2 (8→32) | 应随 h 消失 | 观测阶 0.98 | ✅ 判为一致（→0） |
| 解析稳态残差 P1 | 应随 h 消失 | 阶 0.00（平台） | ❌ 但已证明 = 3×通量误差/h |
| 脉冲启动推进到 t=0.1 | 应到达 | 不可比 | ❌ **honest FAIL（未修）** |

**显式回答**：
- 「壁面热通量 <3%」——**P2/P3 在 64 格下远优于 3%（0.000571% / 0.000025%）**；P1 的 3.173% 是
  P1 设计阶（1 阶）的必然结果，不构成算子的错误；
- 「残差一致性 <3%」——P2/P3 残差随 h 衰减（阶 0.98 / 2.00），判为**一致**；P1 的平台值已被
  §3.3 证明是同一件事的另一面；
- 「瞬态精度」——**无法给出且不达标**：三次脉冲启动全部触发正性守卫。这是本单保留的唯一
  诚实 FAIL，与 m2589 同向，但范围从「P1 + 算子通性」收窄为「跨阶的瞬态失稳」。
