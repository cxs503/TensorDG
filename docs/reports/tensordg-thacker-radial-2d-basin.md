## 1. Case

Non-linear shallow water in a circular paraboloid basin, one of the few members of Thacker's
family whose surface stays a paraboloid of revolution while the velocity stays linear in the
radius. Because both assumptions are *invariant* under the equations, the 2-D system reduces to
a closed ODE system that is solvable in closed form — i.e. an exact solution with a moving
shoreline, which is exactly the regime `swe_2d`'s well-balanced / wet–dry path has to reproduce.

| quantity | symbol | value |
|---|---|---|
| still-water depth | `h0` | 1.0 |
| basin scale radius (`z_b = 0`) | `L` | 1.0 |
| sloshing amplitude parameter | `A` | 0.2 |
| gravity | `g` | 9.81 |
| angular frequency `sqrt(8 g h0)/L` | `omega` | 8.8589 s⁻¹ |
| period `2 pi / omega` | `T` | 0.70925 s |
| bed | `z_b(r)` | `-h0 (1 - r²/L²)`, **not truncated** at `r = L` |
| computational box (DG) | | `[-1.45, 1.45]²` |

Exact solution (`r = sqrt(x²+y²)`, `omega = sqrt(8 g h0)/L`):

```
H(t)      = h0 sqrt(1-A²) / (1 - A cos(omega t))        depth at the centre
B(t)      = -H² / (h0 L²)                               depth  h = H + B r²
eta(r,t)  = (H - h0) + (B + h0/L²) r²                   free surface
u_r(r,t)  =  A omega r sin(omega t) / (2 (1 - A cos(omega t)))
r_s(t)    = L sqrt(h0 / H(t))                           moving shoreline
```

The radial factor is **8**, not the 2 of the 1-D planar basin
(`swe_exact._thacker_params`) — a unit test pins the ratio `OMEGA/omega_1d == 2`.

## 2. Method

The deliverable is a *reference*, so the priority is that the algebra be right; three
independent checks were run instead of trusting the derivation:

1. **PDE residual.** The closed form is differentiated with 4th-order central differences in
   `(r, t)` and substituted into the radial shallow-water equations
   `h_t + (1/r)(r h u)_r = 0` and `u_t + u u_r + g eta_r = 0`. A step ladder
   (`eps = 2e-2 … 2.5e-3`) shows the residual decaying at the expected 4th order, so the
   number is truncation error and not a residual mismatch.
2. **Independent ODE reduction.** The same solution satisfies
   `H'' = (3/2) H'²/H + 4 g H (K H² + h0/L²)` with `B = K H²`, `f = -H'/(2H)`,
   `K = -1/(h0 L²)`. Integrating that ODE with `DOP853`, `rtol = 1e-13`, from the closed-form
   initial data recovers `H(t)`; this path shares no algebra with the closed form.
3. **Invariants.** Enclosed volume, shoreline root, period, and the zero initial velocity are
   checked analytically/numerically (`tests/test_thacker_radial_2d.py`, 7 tests).

Finally the analytic initial state is pushed through `swe_2d.solve_swe_2d` with
`final_time = 0` (no time stepping) to prove the reference is *consumable* by the DG solver:
finite state, non-negative cell-average depth, and the projected volume within the expected
projection deficit.

## 5. Notes / limitations

- **Sign of `u_r` caught by the certificate.** The first implementation carried
  `u_r = -A omega r sin / (2(1-A cos))`. The residual was O(0.2) and, crucially,
  *step independent* — the signature of an algebra error rather than truncation. The correct
  sign is `+`; after the fix the residual decays at order 4.00. Lesson: run the residual ladder
  before believing any closed form, and read a flat ladder as "wrong equation", not "bad FD".
- **Bed must be untruncated.** `r_s` reaches `1.107 L`, so a bowl clipped at `r = L` (a common
  "flat rim" setup) is incompatible with this member of the family; the outer box must be dry
  and larger than `max r_s`, otherwise water leaves the bowl.
- **The clipped initial condition is not a polynomial**, so its DG projection loses the
  sub-cell shoreline sliver: -0.76 % of the volume at 16×16 P1. Any quantitative DG run must
  therefore compare against *cell averages of the clipped exact solution* (computed by
  quadrature), not against point values, and must quote the volume budget separately.
- **Time-accurate DG evaluation is not part of this unit.** A `swe_2d` run of this case at
  24×24/P1 (`cfl = 0.2`, `dt ≈ 2.4e-3`) completed 20 steps (to `t = 0.05`) in 4.9 s, but
  quarter-period runs did not finish inside this unit's per-command compute budget, so **no DG
  discretisation error is claimed here**. The reference, the certificate and the consumability
  check are the delivered increment; the quantitative DG comparison (mesh/degree ladder over
  one period, wet-region L2 + shoreline-radius error + volume budget) is the immediate
  follow-up and needs a background/cluster run rather than an interactive one.
- Scope: one member of Thacker's family (circular basin, paraboloid surface). The elliptic
  (non-axisymmetric) members and the sloshing over a sloping beach are not covered.
