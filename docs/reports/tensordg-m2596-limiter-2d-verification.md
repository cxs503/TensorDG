# TensorDG 二维 TVB 限制器验证与修复（m2596）

## 1. 案例介绍

二维张量积模态 DG（`tensordg/euler_dg_2d.py`）的 **限制器路径**自 m2496/m2549 合并以来，
只在「挤压 Sod」与「限制器是否触发」层面被检查过，从未对**解析基准**做过精度阶验证。
本单做的是**验证欠账 + 连带缺陷修复**。

物理场景（解析基准，无需求解器自证）：
* 二维**等熵涡**（isentropic vortex），强度 B=5、背景速度 (1,1)、周期域 [-5,5]²，
  初值 L2 投影，SSP-RK3 + HLLC，CFL=0.2，t=1.0；相对 L2 误差按 4×4 Gauss-Legendre 求积对
  解析解逐场计算（ρ, p）。
* 参数表：degree ∈ {1,2,3}；网格 8²–24²；TVB 常数 M ∈ {1,3,10,100}。

## 2. 怎么做的

1. **读账**：`expand_audit_tensordg.md` 的验证面清单里，二维限制器**无解析基准**；`tests/test_euler_dg_2d.py`
   只有残差恒等式与挤压 Sod 六条测试；`tests/test_limiter_policy.py` 的设计阶验证只在 **1-D**。
2. **写基准**：`benchmarks/verify_limiter_2d.py`（A 检测器对偶 / B 涡设计阶 / B2 M 扫描 / C Sod / D 四象限黎曼）。
3. **测出缺陷**（三处，全部在 `tensordg/euler_dg_2d.py`）：
   * **D1 网格依赖的受困单元判据**：判据拿 `max(|ΔL|,|ΔR|)`（O(dx·u′)）去比 `M·dx²`，
     等效容差变成 O(dx/M) → 网格越细**标记得越多**，M 不可调。平滑涡上 16²/24² 有 10–14% 单元被误标，
     P1 误差**随加密上升**（EOC = −0.26）。
   * **D2 degree≥2 广播崩溃**：高阶模态块用 4-D bool 掩码去 broadcast 5-D 块，
     `limiter="tvb"` 只要有一个单元被标记就 `RuntimeError`（P≥2 的限制器路径等于不可用）。
   * **D3 `tvb_constant` 丢失**：`solve_euler_dg_2d_vortex` 没有 `tvb_constant` 形参，
     M 在这条基准上被静默丢弃，永远用默认 1.0。
4. **修复**（最小改动）：判据改为与 1-D 一致的 `|ΔL − minmod(ΔL,ΔR)| > M·dx² + 1e-12·scale`
   （量纲一致、网格无关）；高阶模态掩码改为 `[nx,ny,1,1,1]` 五维；涡包装器补 `tvb_constant` 并转发。
5. **回归**：`tests/test_euler_dg_2d_limiter.py`（9 条）。

## 3. 计算结果（程序化注入，零手抄）

判据输出：`validation/euler_dg_2d/limiter_order_2d.json`（本表由该 JSON 渲染）。

| degree | N² | 无限制器 ρ 相对L2 | M=10 限制 ρ 相对L2 | EOC(无) | EOC(M=10) |
|---|---:|---:|---:|---:|---:|


**修复后 M=10 的受限解与无限制器解逐位相同**（flagged=0），设计阶 p+1 完整保留：
P1 ≈ 1.9/2.0，P2 ≈ 3.0/2.95，P3 ≈ 3.9（设计 4）。

TVB 常数可调性（P2，16²，修复后的判据）：

| M | ρ 相对L2 | 标记比例 | 相对无限制器 |
|---:|---:|---:|---:|
| 1 | 1.0526e-02 | 3.99e-02 | 26.5x |
| 3 | 3.5366e-03 | 6.73e-04 | 8.9x |
| 10 | 3.9756e-04 | 0.00e+00 | 1.0x |
| 100 | 3.9756e-04 | 0.00e+00 | 1.0x |

M→10 起与无限制器**完全重合**（误差比 1.0x），这才是「TVB 常数」应有的语义；修复前无论 M 取何值都
等价于 M=1（对数表里 M=1 与 M=10 逐位相同即为证据）。

检测器对偶（A 节）：平滑周期波与 Sod 跳跃上，二维轴向判据与一维 `_troubled_cell_indicator`
**逐单元一致**（interior）；平滑波在 M=10、20/40/80/160 网格上标记数恒为 0（网格无关）。

## 5. 注意点（坑与局限）

* **未完成项（honest）**：C 节（挤压 Sod，P2/200 单元，限制器开/关的激波捕捉与超调量）与
  D 节（Lax–Liu 四象限黎曼的正性与网格自收敛）在本次会话预算内未跑完——单条 Sod 配置在本机
  load15>100 的条件下需 >35 s，驱动被提前停止，因此**本报告不主张任何激波侧数字**。
  对应代码已就位（`benchmarks/verify_limiter_2d.py` 的 `extruded_sod`/`four_quadrant`），
  下张单可只跑 C/D 两节补齐。
* 网格只到 24²：涡核在 24² 仍未被充分解析，这正是 M=1（默认）在这些网格上仍标记 4% 单元、
  误差比无限制器大 26 倍的原因——**默认 M=1 是「偏保守/偏激波」的选择**，不是缺陷；
  平滑流要精度必须把 M 调到 ≳ 局部 |u″| 量级（本基准 M=10 即完全惰性）。
* `_troubled_1d` 用 `torch.roll` 做邻居，即边界按周期处理；对非周期（挤压 Sod / 四象限）算例，
  边界单元的判据语义是「周期延续」，当前数据（边界均匀）下不触发，但这是已知近似，未在本单改动。
* 判据的 M=1 在**粗网格欠解析**区域仍会标记，这是 TVB 的固有性质（Cockburn & Shu 1989），
  不是本修复引入的。

## 6. 误差判定（vs 解析解，逐项）

| 关键量 | 基准 | 实测 | 是否 < 3% |
|---|---|---:|---|
| P1 涡 ρ 相对 L2（24²，M=10） | 等熵涡解析解 | 0.167% | 是 |
| P2 涡 ρ 相对 L2（24²，M=10） | 等熵涡解析解 | 0.0120% | 是 |
| P3 涡 ρ 相对 L2（16²，M=10） | 等熵涡解析解 | 0.0038% | 是 |
| 设计阶 P1/P2/P3 | p+1 = 2/3/4 | 2.03 / 2.95 / 3.88 | 阶次相对误差 ≤ 3%：是 |
| 限制器对平滑流的污染（M=10） | 无限制器解 | 0（逐位相同） | 是（0%） |
| 限制器对平滑流的污染（M=1，修复前默认行为） | 无限制器解 | +2550%（26.5x） | 否（这是修复的对象） |

修复前基线（对照）：P1 24² 受限解 1.03%，EOC 1.21；P2 16² 直接 `RuntimeError`。

> 声明：以上「是否 <3%」均以解析等熵涡解为基准；激波类无基准量**未主张**（见第 5 节）。
