# TensorDG main CI 治愈：等温壁热传导「陈旧钉疤」（2026-11-04 / m3760）

修复目标 commit：`619167f0`（main，job=TensorDG tests 红）
CI run：https://github.com/cxs503/TensorDG/actions/runs/41845336845

## 1. 案例介绍

物理背景：上下两块等温壁之间的静止流体纯热传导（`T_bottom=1.0`、`T_top=0.5`、
`p=1`、`mu=0.1`、`Pr=0.71`、`R=1`、`gamma` 由 `ns_dg_2d` 常量给出），几何为
`[0,1]^2` 上 `nx x ny` 张量积网格、强形式 BR1/SIPG 间断 Galerkin、DG 阶 `p=1`。
这是 `ns_dg_2d` 唯一一条从未闭合验证的公开入口，其壁面闭合与崩溃史见
`docs/reports/tensordg-ns-heat-conduction-verification.md`（m3210）与
`docs/reports/tensordg-ns-heat-wall-closure.md`（m3257）。

## 2. 怎么做的

1. 用 GitHub API 取 `619167f0` 的 job 日志（job 126627271758），得到 4 条失败；
2. `git log`/`git show` 定位：`1e3ae7b8`（CI 绿）→ `35005fed`（merge #43/m3210，首个红）；
   `1e3ae7b8..619167f` 之间 `tensordg/` 零改动，红绿差异全部来自新增测试文件；
3. 根因：`m3139`（f1f6ab2）把壁法向导数默认值由 `"taylor"`（两点外推）改回 `"face"`
   （单边 DG 导数），崩溃因此消失；此后合并的 m3210/m3257 仍按**回滚前**行为写严判据；
4. 本地逐位复算失败阈值（float64/CPU），确认非环境抖动，然后按棘轮约定翻正测试；
5. 修复只动 2 个测试文件（0 行产品代码），实测序列写进 docstring。

## 3. 计算结果

### 3.1 壁面 vs 内区能量残差（精确导热态，`wall_gradient="face"`，P1）

| ny | 冷壁格 `max|R_E|` | 内区 `max|R_E|` | 内区/壁面 |
|---|---|---|---|
| 8 | 1.9561e-01 | 2.9398e-01 | 0.6654 |
| 16 | 1.5739e-01 | 1.7093e-01 | 0.9208 |
| 32 | 1.3985e-01 | 9.2912e-02 | 1.5052 |
| 64 | 1.3143e-01 | 4.8554e-02 | 2.7070 |

细化比：壁面 16/32 = **1.1254**、32/64 = **1.0640**（→1，停滞）；
内区 16/32 = **1.8397**（≈O(h)）。CI 在 `619167f0` 打印的断言值
`1.1254006470996836` 与本地 `1.1254006470928049` 前 10 位一致（差 6.9e-12），
证明 1.1 的门槛不是被机器抖动绊倒，而是**确定性地**低于真值 2.3%。

### 3.2 入口点跑通后的瞬态（`ncells=(2,8)`、`t=0.5`、1070 步）

`p ∈ [7.3238e-01, 9.2602e-01]`、
`rho ∈ [9.1246e-01, 1.3363e+00]`、
`theta=p/rho` 沿 y 单调（0.9841 → 0.5617），落在壁面温度区间内。

- 只修测试，不改产品代码：壁闭合**仍不一致**（壁面残差不衰减），两个残差 xfail 原样保留；

  约 3.2e5 步，CI 上约十分钟，本机（load average 150–380，另有 899 个 pytest 进程）
  无法在预算内复跑；其「不崩溃」状态由 CI 在 `619167f0` 的 `[XPASS(strict)]` 直接证明
  （该标记下测试体照常执行完毕）；
- 本地未跑**全量**套件（CI 基线 57 min，本机算力被其他智能体占满）；
  已本地跑：两个受影响文件 + 图脚本，结果见 `artifacts/`。

## 6. 误差判定

| 关键量 | 基准 | 实测 | 误差 | <3%？ |
|---|---|---|---|---|
| 壁面能量残差细化比 16/32 | 1.0（停滞） | 1.1254 | 12.5% 偏离停滞 | 否（缺陷仍在，符合预期） |
| 壁面能量残差细化比 32/64 | 1.0（停滞） | 1.0640 | 6.4% | 否（趋向停滞） |
| 内区能量残差细化比 16/32 | 2.0（一阶） | 1.8397 | 8.0% | 否（但仍 >1.7，一阶成立） |
| CI 失败阈值 1.1254006470996836 vs 本地复算 | 逐位一致 | 1.1254006470928049 | 6.9e-12 | 是 |
| 入口点 `t=0.5` 相对精确导热剖面 | 稳态解析解 | err=0.1232 | 1.23e-1 | 否（瞬态，未达稳态；且壁闭合未修） |
