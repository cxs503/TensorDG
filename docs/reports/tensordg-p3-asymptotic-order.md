## 1 案例介绍（物理背景 / 几何 / 参数）

二维可压缩 Euler 方程（γ=1.4，单位气体常数）在周期盒 `[-5,5]²` 上的**等熵涡**
（Klein 涡，强度 β=5）随背景流 (1,1) 平流一个时间单位：

    u = 1 - β y/(2π) exp((1-r²)/2),   v = 1 + β x/(2π) exp((1-r²)/2)
    T = 1 - (γ-1) β²/(8 γ π²) exp(1-r²),   ρ = T^{1/(γ-1)},   p = ρ T

它是 Euler 方程的**精确解**（无制造源项），因此误差逐点对解析式度量，基准是解析的而非数值的。

| 项 | 设定 |
|---|---|
| 域 / 边界 | `[-5,5]²`，双周期 |
| 精确解 | 等熵涡 β=5，背景 (1,1)，t=1.0 |
| 空间离散 | 张量积模态 Legendre DG，P1/P2/P3，L2 初始投影 |
| 时间推进 | SSP-RK3（时间阶 3） |
| CFL 阶梯 | 0.2、0.1、0.05（固定 CFL=0.2 是生产默认） |
| 网格阶梯 | P3 12²/16²/24²/32² |
| 误差度量 | 体求积节点上 (ρ,u,v,p) 相对 L2，求积阶 max(p+2,3) |
| 判据 | ①精修 dt 的观测时间阶 = 3（RK3）②dt→0 极限的观测空间阶 = p+1 ±3% |

### 1.1 要复核的欠账

m3024 报告（`docs/reports/tensordg-euler-dg-2d-design-order.md`）测得 P3 的拟合阶
只有 3.85/3.52/3.48/3.85（设计阶 4），并**如实留下两条未做**：P3 网格阶梯只到 16²（前渐近窗口），以及 SSP-RK3 的时间阶 3 < 空间阶 4，固定 CFL 下 `dt ∝ h` 使 `O(dt³)=O(h³)` 污染观测阶。
本单把这两条一起补上：**固定 h 精修 dt** 得到 `e(dt) = e0 + C dt^q`，
Richardson/最小二乘给出 `e0 = e(dt→0)`（纯空间误差），再看 `e0` 跨网格的阶。

## 2 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **时间精修**：每个网格上按 CFL 0.2、0.1、0.05 各跑一次，误差 `e(h,dt)`，平均步长 `dt = t_final/steps`
   （注：`metadata['dt']` 是最后一步的 dt，不是平均步长，本单不使用该字段）。
2. **时间阶 q**：相邻 dt 档的 `log(e_i/e_{i+1})/log(dt_i/dt_{i+1})`，取最细两档的中位数；若整条 dt 阶梯的相对散布 < 1e-4（时间误差在舍入水平之下），
   记 `temporal_negligible=true`、`q=3`（RK3 理论阶）、极限取最细 CFL 的原始误差，并给出时间误差占总误差的**上界**。
3. **空间极限 e0**：`e0 = e_fine - (e_coarse - e_fine)/(r^q - 1)`（Richardson，r = dt 比），并用三参数最小二乘 `e0 + C dt^q` 交叉核对；两者都截断在 `[0, e_fine]`。
4. **空间阶**：对 `e0(h)` 做最小二乘 log-log 斜率（`fit_limit`），并列出逐区间 EOC；同时给出**未做时间修正**的 `raw` 版本作对照——两者的差就是 m3024 看到的「缺失阶数」的时间成分。
5. **判据先于实验**：`tests/test_euler_dg_2d_temporal_order.py` 固化（Richardson 对纯幂律精确、三参数拟合回收 e0、CFL 少于 3 档报错、
   固定网格时间阶 ≈ 3、P2 的 dt→0 极限仍为 3 阶、P3 极限阶 > 3.9）。
6. **工具链**：

```

    --degrees 3 --meshes 12 16 24 32 --cfls 0.2 0.1 0.05

    --degrees 2 --meshes 8 12 16 --cfls 0.2 0.1 0.05
```

### 4.1 速度通道误差地板（Helmholtz 分解）

ρ 与 p 在 16²→24²→32² 上是干净的 4 阶，而速度通道在 24² 之后**几乎不动**，且该残差对 dt 精修完全不变（时间误差已排除）。`benchmarks/diagnose_p3_velocity_floor.py` 在单元中心格点上做 Helmholtz 分解（格点等距，谱导数无差分误差）：

| cells | ρ | p | ρu | E | u | v | |ω| 占比 | max|u_err| |
|---|---|---|---|---|---|---|---|---|
| 12² | 1.1695e-04 | 1.7516e-04 | 2.7713e-04 | 2.1142e-04 | 3.4576e-04 | 3.4427e-04 | 0.631 | 4.5845e-03 |
| 16² | 3.8310e-05 | 5.3853e-05 | 1.1682e-04 | 7.2261e-05 | 1.1621e-04 | 1.1623e-04 | 0.752 | 1.5644e-03 |
| 24² | 7.7041e-06 | 1.0856e-05 | 8.7569e-05 | 3.7334e-05 | 8.6293e-05 | 8.6289e-05 | 0.799 | 1.6331e-03 |

读法：ρ、p 逐区间 EOC 3.88→3.96→4.04 与 4.10→3.95→4.24（设计阶 4），速度通道 3.79→0.73→0.05 —— **误差地板 ≈ 8.4e-5，与 h 无关**。误差以旋转模态为主（|ω| 占比 0.63→0.80），说明它不是声学/压缩性模态，而是**伪涡量（rotational）误差**，与 ρ/p 的收敛性解耦。

**这是本单最重要的否定性结论**：m3024 把 P3 速度通道的阶数亏损（3.52/3.48）归因于「前渐近 + 时间阶污染」，本单证明两者都不是——时间误差在 5 位有效数字下不可测，网格加密到 32² 后速度通道也不再改善。剩余嫌疑是离散化本身产生的、与 h 无关的伪涡量（下一单应查体积/面通量求积阶与 `_primitive` 反算链路）。

## 5 注意点（踩坑 / 局限 / 适用范围）

1. **时间误差在本算例上小到无法测**：固定 h 精修 dt 后误差在 4–5 位有效数字内不动，于是 `temporal_negligible=true`、`e0` 取原始值并给出上界——本单因此**否定**了 m3024 §5.3 的「时间阶污染」猜想在这个涡算例上的主导作用。
1b. **速度通道的地板是空间侧的**：既然 dt 精修不动它，它不是时间误差；它是 24² 之后不再随 h 下降的伪涡量误差（§4.1），本轮只定位到「旋转模态 + h 无关」，**未定位到代码级根因**，如实标注。
2. **Richardson 在零信号下会炸**：`q≈0` 时 `(2^q-1)≈0`，若不加散布门限会得到负误差或天文数字；代码里用 1e-4 的相对散布判据 + `[0, e_fine]` 截断兜住。
3. **仍只做二维 Cartesian**：非结构网格、3D、限制器开启的阶数均不在本单范围。
4. **负载纪律**：共享机 load15 在 73–220 之间波动，全部算例单线程 `OMP_NUM_THREADS=1`，最大 32² P3（1.1e5 DOF·3 档 CFL）。
5. **CFL 阶梯收益有限**：既然时间误差不可测，生产上把 CFL 调小并不改善这个算例的精度，它改变的是稳定性边界而不是精度——这是可复用的工程结论。
