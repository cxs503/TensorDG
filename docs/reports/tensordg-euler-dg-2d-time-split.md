# TensorDG 2D 高阶 Euler DG：时间误差 vs 空间误差 的误差预算分离

- 任务：m3625（tp-doc-2 席自找活）　分支 `agent/m3625`　日期 2026-11-06
- 上游：`tensordg/euler_dg_2d.py`（2D 张量积模态 DG + HLLC + SSP-RK3）、
  `benchmarks/design_order_euler_dg_2d.py`（m3024 设计阶扫描）
- 环境：Python 3.11 / torch 2.x / CPU float64，**单线程**（`OMP_NUM_THREADS=1`）；
  跑批期间本机 load15 ≈ 128（128 核共享机被其他席占满，故全链路单线程，见 §5）
- 产物：`benchmarks/euler_dg_2d_time_split.py`、`validation/euler_dg_2d/time_split.json`、
  `docs/figures/euler_dg_2d_time_split.png`、`tests/test_euler_dg_2d_time_split.py`
- 一句话结论：m3024 遗留的疑点「P3 只到 3.83（设计 4）是不是被 SSP-RK3 的三阶时间误差
  拖住？」——**否**。固定网格上把 dt 连续减半 8 倍，对解析解误差变化仅 1e-6→1e-8（相对），
  自差序列拟合出时间阶 **2.97（P2）/ 2.98（P3）**，即 SSP-RK3 三阶如实达标，而时间误差
  仅占总误差的 **~2e-6**。把面通量求积阶从 5 提到 8 也不改变 P3 的 EOC（3.828→3.825），
  **所以 P3 的 4% 阶数亏损是空间侧的、且不是非线性通量混叠**。附带发现一个真缺陷：
  默认 `tvb_constant=1.0` 的 TVB 限制器**在光滑涡上误触发**，误差放大 34 倍（8²）/136 倍（12²）。

## 1. 案例介绍

### 1.1 为什么这是验证欠账

`benchmarks/design_order_euler_dg_2d`（m3024，2026-11-04 合并）在等熵涡上扫 P1/P2/P3 × 4 档网格，
结论是 P1/P2 达设计阶、**P3 只到 3.85/3.52/3.48/3.85（设计 4）**，并在其 §5 局限 3 明确写道：

> 时间推进共同限速：SSP-RK3 的时间阶 3 < P3 的空间阶 4，阶数验证必须让 dt 比空间尺度更快
> 收敛（本单靠 CFL 让 dt∝h，仍可能污染最后一位）；严谨做法是固定 dt 做「空间-only」扫描。

该单没有 `dt` 控制手段，无法验证。于是留下三条未裁决的问题：

1. P3 的 4% 阶数亏损是**时间污染**还是**空间真实亏损**？
2. 时间推进器（SSP-RK3）在 2D Euler 上是否真的三阶？
3. 文档里的「< 3% 误差门」在给定网格上到底混了多少时间误差？

本单给出可机器裁的答案，并顺手把 `dt=` 固定步长入口加进求解器（此前只有 CFL 自适应步长）。

### 1.2 物理与精确解

二维可压缩 Euler（γ=1.4）在周期盒 `[-5,5]²` 上的**等熵涡**（Klein 涡，解析精确解）：

    u = 1 - β y/(2π) e^{(1-r²)/2},  v = 1 + β x/(2π) e^{(1-r²)/2},
    T = 1 - (γ-1)β²/(8γπ²) e^{1-r²},  ρ = T^{1/(γ-1)},  p = ρT,  β = 5

随背景 (1,1) 平流，终时 t=1.0。参考解是解析式，无需制造源项，适合干净的阶数度量。

### 1.3 参数表（判据先于实验）

| 项 | 设定 |
|---|---|
| 域 / 边界 | `[-5,5]²`，双周期 |
| 精确解 | 等熵涡 β=5，背景 (1,1)，t=1.0 |
| 空间离散 | 张量积模态 Legendre DG，P2/P3，`initial_projection="l2"` |
| 面通量 | HLLC（含 Rusanov 退化解回退） |
| 时间推进 | SSP-RK3，CFL=0.2（生产默认）或**固定 dt** |
| Part A 网格 / dt | 8²，dt 阶梯：CFL 步 → 0.9·dt_CFL，逐次减半共 3 档 |
| Part B 网格阶梯 | P2: 8²/12²/16²；P3: 6²/8²/12²；Gauss 规则 5 与 8（P2 为 5 与 8） |
| 误差度量 | 体求积节点上 `(ρ,u,v,p)` 相对 L2，报告 ρ 与四场最大 |
| 判据 | ①时间自差阶 ∈ [2.6,3.4]；②解析解误差对 dt 不敏感（相对变化 <1e-3）；③EOC 对求积阶不敏感（<1%）；④最细网格误差 <3% |

## 2. 怎么做的

### 2.1 代码改动（最小、可验证）

`tensordg/euler_dg_2d.py`：`solve_euler_dg_2d()` 新增关键字 `dt=None`（并透传到
`solve_euler_dg_2d_vortex`）。

- `dt=None` 时走原 CFL 自适应步长，**默认路径逐位不变**（metadata 增记 `dt_mode`、
  `prescribed_dt`，其余字段不动）；
- `dt=<float>` 时以固定步长推进，最后一步裁剪到 `final_time`；`dt<=0` 抛 `ValueError`；
- 稳定性由调用方负责（固定步长超过显式稳定界会由既有的非有限/非物理检查报错）。

这是阶数分离验证的必要工具，且不改变任何生产线行为。

### 2.2 度量方法

- **Part A（时间阶）**：固定网格上 dt 减半。解析解误差因空间误差主导而饱和，故另用
  **相邻解自差** `||u_{k+1}-u_k||/||u_k||`（模态加权 L2）拟合时间阶——自差把空间误差
  一阶主项抵消，只留时间项 `C·dt³(1-2^{-3})`。
- **Part B（空间阶）**：重复 m3024 的网格阶梯，并用**更高 Gauss 规则**（P3: 5→8）检验
  「HLLC 面通量的非线性混叠」假设——同一 `weights` 既用于体裁积也用于面通量投影，
  提高规则即可判断混叠是否限速。
- 交叉校验：本单默认规则阶梯与 m3024 的 `validation/euler_dg_2d/design_order.json`
  逐位比对（下方 §3.4）。

工具链：`python -m benchmarks.euler_dg_2d_time_split`（本单新增）→ JSON + matplotlib 图；
`pytest tests/test_euler_dg_2d_time_split.py` 钉住回归。

## 3. 计算结果（`validation/euler_dg_2d/time_split.json` 直读，零手抄）

### 3.1 Part A：固定网格（8²）时间细化

| 阶 | dt | 步数 | ρ 相对 L2（vs 解析） | 解析解误差相对变化 |
|---|---:|---:|---:|---:|
| P2 | 8.547e-03 (CFL) | 117 | 3.2751e-03 | — |
| P2 | 3.802e-03 | 263 | 3.2751e-03 | 1.60e-06 |
| P2 | 1.905e-03 | 525 | 3.2751e-03 | 1.38e-07 |
| P2 | 9.533e-04 | 1049 | 3.2751e-03 | 1.16e-08 |
| P3 | 6.098e-03 (CFL) | 164 | 5.6481e-04 | — |
| P3 | 2.252e-03 | 444 | 5.6481e-04 | 4.38e-06 |
| P3 | 1.126e-03 | 888 | 5.6481e-04 | 2.37e-07 |
| P3 | 5.631e-04 | 1776 | 5.6481e-04 | 1.22e-08 |

**时间阶（自差拟合）**：P2 = **2.966**，P3 = **2.982**（相邻档 2.97 / 2.98），SSP-RK3 的三阶达标。
**时间误差占总误差的份额**：P2 ≈ 7.96e-09 / 3.2751e-03 = **2.4e-06**；P3 ≈ 1.79e-09 / 5.6481e-04 = **3.2e-06**。

### 3.2 Part B：网格阶梯 × Gauss 规则

| 阶 | 规则 | 8²/6² 误差 | 12²/8² 误差 | 16²/12² 误差 | 逐档 EOC | 全局拟合 |
|---|---|---:|---:|---:|---|---:|
| P2 | 5（默认 4→此处 5） | 3.2435e-03 | 9.1266e-04 | 3.9704e-04 | 3.13 / 2.89 | 3.037 |
| P2 | 8 | 3.2442e-03 | 9.1268e-04 | 3.9705e-04 | 3.13 / 2.89 | 3.037 |
| P3 | 5（默认） | 1.6570e-03 | 5.6481e-04 | 1.1695e-04 | 3.74 / 3.88 | 3.828 |
| P3 | 8 | 1.6480e-03 | 5.6338e-04 | 1.1662e-04 | 3.73 / 3.88 | 3.825 |

求积 5→8 带来的误差变化：P2 ≤0.03%，P3 ≤0.55%，**EOC 变化 <0.1%** → 面通量混叠不是 P3 的限速机制。
P2 达设计阶 3（3.037，+1.2%）；**P3 全局拟合 3.828 vs 设计 4，亏损 4.3%，如实记为「未达设计阶」**。
最细网格（P3 12²，1.17e-4；P2 16²，3.97e-4）远低于 3% 门。

### 3.3 附带发现：TVB 限制器在光滑涡上误触发（honest-FAIL）

P3、默认 `tvb_constant=1.0`：

| 网格 | 无限幅器 ρ 误差 | TVB(M=1.0) | 放大倍数 | M=10 / 100 / 1000 |
|---|---:|---:|---:|---|
| 8² | 5.6481e-04 | 1.9034e-02 | **33.7×** | 5.6481e-04（= 无限幅器，逐位一致） |
| 12² | 1.1695e-04 | 1.5922e-02 | **136.2×** | 1.1695e-04（同上） |

即：光滑解上「troubled cell」判据（TVB 阈值 `M·dx²` 与单元差比对）在默认常数下几乎遍地点火，
把高阶多项式降为线性重构，误差退化到 ~1e-2（仍 <3% 门，但对光滑流是纯损失）。
把常数抬到 10 即完全静默（逐位恢复无限幅器结果）→ 这是**阈值尺度/量纲标定**问题，
不是限制器机械结构问题（与 `docs/reports/tensordg-m1618-tvb-slope-units.md` 的尺度线索一致）。
本单**不修改默认常数**（会改变已合并行为、需要全量冲击面验证），只如实登记为缺陷并下钉。

### 3.4 与 m3024 的交叉校验

默认规则 P3 阶梯与 `design_order.json` 逐位比对：6² 1.6570169938132959e-03、
8² 5.648103033606634e-04、12² 1.1695079824100424e-04，**相对差 0.0（逐位一致）**。

## 5. 注意点（坑 / 局限 / 适用边界）

1. **坑：自差必须用「严格减半」的档位**。CFL 档的 dt 被裁剪到 `final_time`，与相邻档不成 2 倍
   关系，混入拟合会把阶数拉偏；本单只用固定 dt 档（dt0, dt0/2, dt0/4）做时间阶。
2. **坑：`metadata["dt"]` 是最后一步的 dt**（可能被裁剪），时间研究必须用 `final_time/steps`
   的平均步长——m3024 §5 局限 5 已记，本单沿用该口径。
3. **坑（本单踩到）**：`tvb_constant` 默认值在 4² 网格上不触发（dx² 大），8² 起才暴露；
   验证「限制器对光滑流惰性」必须用 ≥8² 网格，否则假绿。
4. **局限**：固定步长入口不检查稳定界；超过显式稳定界由既有的非有限/非负检查报错，
   不做 CFL 预检。
5. **局限**：P3 的 4.3% 阶数亏损**未定位根因**。本单只排除了两个假设（时间污染、面通量混叠），
   剩余候选：预渐近窗口（12² 仍偏粗）、初值 L2 投影的高阶模态误差、以及 HLLC 在光滑区的
   数值耗散与 DG 高阶项的相互作用。需要更细网格（16²/24² P3）才能裁决，本单受负载纪律约束未做。
6. **局限**：仅等熵涡一族光滑解。激波/接触间断上的阶数是另一件事（限制器系列已单独验证）。
7. **范围**：CPU float64、Cartesian、常 γ；结论不外推到 3D 或非结构网格。

## 6. 误差判定（逐项，显式回答「是否 <3%」）

| 判据 | 基准/参考 | 实测 | 允许 | 是否 <3% |
|---|---|---|---|---|
| 时间阶（P2，自差拟合） | SSP-RK3 = 3 | 2.966 | 3% | **是**（-1.1%） |
| 时间阶（P3，自差拟合） | SSP-RK3 = 3 | 2.982 | 3% | **是**（-0.6%） |
| 空间阶（P2，全局拟合） | 设计阶 3 | 3.037 | 3% | **是**（+1.2%） |
| 空间阶（P3，全局拟合） | 设计阶 4 | 3.828 | 3% | **否**（-4.3%，如实记 FAIL） |
| P3 12² ρ 相对 L2 | 解析等熵涡 | 1.17e-04 | 3% | **是** |
| P2 16² ρ 相对 L2 | 解析等熵涡 | 3.97e-04 | 3% | **是** |
| 时间误差份额（P2/P3 @CFL 0.2） | 总误差 | 2.4e-06 / 3.2e-06 | — | 时间误差可忽略（这本身即结论） |
| 求积 5→8 的 EOC 变化（P3） | 3.828 | 3.825（-0.08%） | 1% | **是**（排除混叠假设） |
| TVB(M=1.0) 对光滑流惰性 | 无限幅器误差 | 放大 33.7× / 136.2× | 惰性 | **否——honest FAIL**（M≥10 惰性） |
