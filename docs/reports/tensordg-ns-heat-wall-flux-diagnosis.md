## 1. 案例介绍

### 1.1 物理背景与算例

二维压缩 Navier–Stokes（无量纲，`R = 1`，γ = 1.4，`T = p/ρ`，`c_v = 2.5`，`c_p = 3.5`，
`κ = μ c_p/Pr`）。计算域 `[0,1]²`，x 周期，y 为上下两块**等温无滑移壁**：
下壁 `T = 1.0`（热）、上壁 `T = 0.5`（冷），`u = v = 0`。

被检验的是**纯热传导精确解**

    u = v = 0,  p = p₀ = 1,  T(y) = 1 − 0.5 y,  ρ = p₀ / T(y)

它精确满足可压缩方程：能量方程退化为 `κ ∇²T = 0`（线性 `T` 自动满足），
动量式 `∇p = 0` 与 `u = 0` 相容，连续性平凡成立。

| 参数 | 值 |
|---|---|
| 网格 | `2 × {8, 16, 32, 64}`，P1 与 P2 |
| μ / Pr / κ | 0.1 / 0.71 / 0.492958 |
| p₀ | 1.0 |
| 壁温 | 下 1.0（热），上 0.5（冷） |
| 罚项 σ | `2 (p+1)²`（P1 → 8，P2 → 18） |
| 壁面梯度取法 | `"taylor"`（二次恢复）与 `"face"`（单侧 DG 迹导数） |
| 精确壁热流 | `−κ ∂T/∂n = κ/2 = 0.246479` |

### 1.2 判据（先于动手）

三个量，全部可机器裁：

1. **壁面能量通量本身**是否收敛到 `κ/2`，几阶？（闭合一致性的**直接**度量）
2. 相邻**内面**通量的收敛阶（决定壁行看到的通量**失配**量级）；
3. 壁行残差与**体积加权**残差 `‖R‖` 的收敛阶（区分「边界一行」与「全场」）。

## 2. 怎么做的

1. 把精确守恒变量 L2 投影到 DG 模态空间（`_initial_coefficients`）；
2. 直接调用算子内部接口 `_axis_fluxes_ns` 取 **y 方向壁面与内面的投影通量**
   `∫ F* φ_k dξ`，取 `k = 0` 模除以 `∫φ₀ dξ = 2` 还原面值，与 `κ/2` 比较；
3. 用 `_rhs_ns` 取**能量行**残差：壁行（`ny=0`）最大模、体积加权 L2
   `‖R‖ = sqrt(Σ (R_k² / ((2k+1)(2j+1))))·sqrt(dx dy/4)`；
4. 对 `{8,16,32,64}` 做 log–log 最小二乘斜率 = 观测阶；P1/P2 × taylor/face 四处独立；
5. 数字全部由脚本写入 `wall_flux_order.json` 后回读，本文表内数字零手抄。

## 3. 计算结果

### 3.1 壁面能量通量收敛到精确值（关键结论）

| 阶 | 壁面梯度 | `F_wall(ny=8)` | `ny=16` | `ny=32` | `ny=64` | 观测阶 |
|---|---|---:|---:|---:|---:|---:|
| P1 | taylor | 0.224265 | 0.235806 | 0.241245 | 0.243887 | **1.03** |
| P1 | face | 0.240973 | 0.243821 | 0.245173 | 0.245831 | **1.03** |
| P2 | taylor | 0.247113 | 0.246624 | 0.246513 | 0.246487 | **2.07** |
| P2 | face | 0.246802 | 0.246555 | 0.246497 | 0.246483 | **2.05** |

精确值 `κ/2 = 0.246479`。壁面通量误差按 `h^{p}` 消失（P1 → 1 阶，P2 → 2 阶），
最细网格 P2 误差 `8.5e-06`（0.003%）。**等温壁能量闭合是一致（consistent）的。**

### 3.2 内面通量是超收敛的，所以壁行看到 O(h^p) 失配

| 阶 | `F_int(ny=8)` | `ny=16` | `ny=32` | `ny=64` | 观测阶 |
|---|---:|---:|---:|---:|---:|
| P1 | 0.244314 | 0.245974 | 0.246357 | 0.246449 | **2.06** |
| P2 | 0.247806 | 0.246787 | 0.246553 | 0.246497 | **2.06** |

内面（两侧单侧导数平均，`O(h)` 误差相消）是 `O(h²)` 超收敛，与壁面 `O(h^p)` 不同阶，
所以壁行的「壁面通量 − 内面通量」失配是 `O(h^p)`（P1 是 `O(h)`，P2 是 `O(h²)`）。

### 3.3 壁行残差 = 失配 / h，因此只能以 `p − 1` 阶衰减

| 阶 | 壁行残差 `ny=8→64` | 观测阶 | 预测 `p−1` | 内区行残差阶 | `‖R‖` 阶 |
|---|---|---:|---:|---:|---:|
| P1 taylor | 0.5966 → 0.5048 | **0.08** | 0 | 0.87 | **0.48** |
| P1 face | 0.1956 → 0.1314 | **0.19** | 0 | 0.87 | **0.73** |
| P2 taylor | 0.0520 → 0.0057 | **1.06** | 1 | 0.87 | **0.98** |
| P2 face | 0.0445 → 0.0050 | **1.05** | 1 | 0.87 | **0.98** |

观测阶与 `p − 1` 逐一相符（P1：0.08/0.19 ≈ 0；P2：1.06/1.05 ≈ 1）。
P2 的壁行残差**确实在衰减**（`5.2e-2 → 5.7e-3`），只是阶为 1 而非 2；
m3210 用 P1（`p − 1 = 0`，残差按构造不会衰减）作判据，因此把 `1/h` 放大
误判成「闭合不一致」。

体积加权残差 `‖R‖` 单调衰减（P1 0.48/0.73 阶；P2 0.98 阶），说明 O(1) 分量
**只存在于一条量级 `O(h)` 的边界单元行**内，域平均意义下算子是一致的。

## 4. 注意点（踩过的坑与适用范围）

- **坑 1：残差判据本身是有阶的。** 强形式 DG 的边界行残差 = 边界通量误差 / `h`，
  边界通量只有 `p` 阶时该行残差按构造只能 `p−1` 阶衰减（P1 恒为 O(1)）。
  「精确稳态的壁行残差必须衰减」这条判据在 P1 上**永远不成立**，用它判闭合一致性会误判。
  正确的量是**通量本身**的阶 + **体积加权**残差的阶。
- **坑 2：`‖R‖` 的权重要用质量矩阵。** 模态残差直接取 `max` 会被高阶模（`(2k+1)(2j+1)` 放大）主导；
  必须除以模态质量 `1/((2k+1)(2j+1))` 再开方，才是域 L2。
- **坑 3：投影通量要还原面值。** `_axis_fluxes_ns` 返回的是 `∫F*φ_k`（不是面值），
  `k=0` 模除以 `∫φ₀ = 2` 才是面通量；直接当通量读会差 2 倍。
- **适用范围**：结论针对 `u = v = 0` 的纯热传导精确态与 `2×N` 张量积网格；
  对流主导（Couette/剪切波）壁面精度面另有既有基准（`test_ns_dg_2d_wall*`）。
- **未做**：本单没有改算子实现（无需改：闭合本身是对的）；
  `tests/test_ns_heat_conduction.py` 的两条 `xfail(strict=True)` **保留**（它们仍然失败），
  但 `reason=` 已改写为「强形式壁行残差按构造为 `p−1` 阶」的口径并指向本报告与证据文件，
  避免把正确实现记成缺陷。真正剩下的开放性问题是**壁面通量能否提到与内面同阶（`O(h²)`）**，
  那是精度优化（P1 壁热流 3.9% → 更低），不是正确性缺陷。

## 5. 误差判定（逐项 vs 基准）

| 关键量 | 基准 | 实测（最细网格） | 相对误差 | 是否 < 3% |
|---|---|---:|---:|---|
| 壁面能量通量，P1 taylor | `κ/2 = 0.246479` | 0.243887 | **1.05%** | ✅ |
| 壁面能量通量，P1 face | 同上 | 0.245831 | **0.26%** | ✅ |
| 壁面能量通量，P2 taylor | 同上 | 0.246487 | **0.0034%** | ✅ |
| 壁面能量通量，P2 face | 同上 | 0.246483 | **0.0018%** | ✅ |
| 内面能量通量，P1 | 同上 | 0.246449 | 0.012% | ✅ |
| 质量/动量行残差（m3210 已测） | 机器零 | ≤ 1e-14 | — | ✅ |
| 壁行能量残差（判据本身失效，不作精度结论） | 0 | 0.50（P1）/ 0.0057（P2） | — | ⛔ 不适用（见 §3.3） |

**结论**：壁面热流的实测误差在 P1 为 1.05%（taylor）/ 0.26%（face），P2 为 0.003% 量级，
**全部 < 3%**；m3210 的 honest FAIL 应改判为「判据选错」，闭合无一致性缺陷。

## 6. 能力化（m14554 返修：诊断脚本 → 库能力 + 集成基准）

第 1–5 节把问题判清楚了，但通量读回只活在本基准脚本里（`_axis_fluxes_ns` + `∫φ₀=2`
魔数）。本轮把它变成被求解器和测试真实调用的库能力，并补上 ref/got 基准与运行工件。

### 6.1 新增公共 API（`tensordg/ns_dg_2d.py`）

| 符号 | 作用 |
|---|---|
| `wall_heat_flux(...)` | 每个壁面单元一条物理壁面热流 `q_axis = -κ ∂T/∂x_axis`；两侧壁**同号**（热壁进入域内、冷壁离开域外都为正），空边界/周期轴返回 `{}` |
| `wall_heat_flux_summary(...)` | 沿壁面单元取平均的 float 版本 |
| `solve_navier_stokes_dg_2d(...)["wall_heat_flux"]` | 求解器在自己返回的 `metadata` 里直接给出**自己状态**的壁面热流（集成路径，不用再手工调内部接口） |

实现就是"读回算子用的面通量"：取 `_axis_fluxes_ns` 投影面通量的 `k = 0` 模，除以
`∫φ₀ dξ = 2`（L2 面投影对面常数通量的精确逆）。`∫φ₀` 现在由 `weights @ basis[:,0]`
数值算，不再是硬编码 2.0；`tests/test_ns_wall_heat_flux_api.py::test_api_is_the_inverse_of_the_operator_projection`
断言 API 与 `_axis_fluxes_ns` 的 `k=0` 模**逐元素相等**（`atol=0.0`），保证"零重推导"。

### 6.6 局限（未做完的部分，如实列出）

1. **壁面通量仍按求解器所用面通量读回**，其阶由 `wall_gradient` 决定：P1 是 `O(h)`，
   最细网格 0.26%（face）/1.05%（taylor）。把它做成与内面同阶（`O(h²)`）的**后处理
   重构**仍未做——那需要另立判据，不在本单范围。
2. 只对**等温无滑移壁**（Dirichlet 温度 + 速度）定义；绝热壁、滑移壁没有对应通量。
3. `xmin/xmax` 壁面走同一 `_axis_fluxes_ns` 调用，由**旋转等价 pin** 覆盖
   （x 向算例与 y 向算例逐值一致，最大差 1.3e-14 = 舍入）；但仍**没有独立于 y 向的
   解析基准算例**（横竖同解只证明了轴无关性，不额外增加物理覆盖）。
4. 集成基准用精确稳态作初值、只推进 `0.01` 时间单位（P1 81 步 / P2 408 步）：它验证的是
   "求解器自己回报通量"这条链，不是长时间趋稳（`final_time=40` 需 ~3×10⁵ 步，未在单机跑）。
5. §3.3 的残差结论不变：算子实现未改动，`tests/test_ns_heat_conduction.py` 的两条
   `xfail(strict=True)` 仍然 xfail（判据本身在 P1 上不成立）。
