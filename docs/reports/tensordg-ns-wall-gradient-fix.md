## 1. 案例介绍

### 1.1 物理背景与几何

二维压缩 Navier–Stokes，量纲一，`R = 1`（`T = p/ρ`、`c_v = 1/(γ-1) = 2.5`、`c_p = 3.5`），
γ = 1.4，常数动力粘度 μ，`κ = μ c_p / Pr`。粘性项用 **BR1**（Bassi–Rebay 1989），
Cartesian 网格上即 SIPG 梯度：

    {grad q · n}_f = ½ (grad q|-_f + grad q|+_f)·n − (σ/h)(q|-_f − q|+_f)

壁面（Dirichlet）用镜像 ghost：`q|+ = q_wall`、`grad q|+ = grad q|-`。

**算例（沿用 m2496/m2589 已发布的命名算例，不新增物理）**

| 项 | 值 |
|---|---|
| 计算域 | [0,1]²，x 周期、y 双壁 |
| 网格 | 2×{8,16,32,64} 格，P1 |
| 参数 | μ = 0.1，U = 1，T_w = 1，p = 1，`κ = μ c_p/Pr = 0.4930`（Pr = 0.71） |
| 解析稳态 | `u = U y`，`T = T_w + A y (1−y)`，`A = μU²/(2κ) = 0.1014286`，p = 1 |
| 壁面热流真值 | 底壁 `F_E = −κ dT/dy|_(y=0) = −κA = −0.05000` |

### 1.2 修的是什么（m2589 定位到的缺陷）

m2589 测得：壁面热流误差对 h 的**斜率 = 1.00**（一阶），据此把根因判为
「壁面粘性通量用单侧单元梯度，对弯曲（非多项式）数据只有 O(h) 精度」。
本单复核后确认**一半对**，真正的机制有两层（§2.2），m2589 只看到了第一层。

## 2. 怎么做的

### 2.1 判据先于实验（三条，机器可裁，已在 `tests/test_ns_dg_2d_wall.py` 落地）

1. **重构壁面热流二阶**：`(σ=0)` 的纯重构通量与解析值之差，对 h 的斜率 > 1.8，
   且 8 格相对误差 < 1%。
2. **罚项主导性记账**：整条数值通量（含罚项）的斜率必须在 1.0±0.15，且罚项占
   总误差 > 95%——即「剩余的 O(h) 不是梯度造成的」。
3. **回归不可退化**：m2496 的周期剪切波设计阶（2.02–2.07）与 m2589 的
   「多项式数据壁面通量机器精度」判据必须继续绿。

### 2.2 两个改动（都在 `tensordg/ns_dg_2d.py`）

**(a) 商法则的分母改用单元中心状态**（`_cell_centre_state` + `_gas_gradients(conversion_state=...)`）

`T = p/ρ` 是有理量，`grad T` 靠对守恒量导数做商法则得到。原实现把分母（ρ、u、T）
取在**每个面**上，于是**同一个单元的两个面给出不同的 grad T**：ny=8 时底单元的
`dT/dy|左面 = 0.1124`、`|右面 = 0.0644`（差 75%！真值 0.1014）。
这不是精度问题而是**自相矛盾**——内部界面靠「两侧一阶误差 ±h/2 相消」得到二阶，
而面依赖的伪梯度让这个相消失效。改成分母取单元中心后，grad T 变成单元量
（左右面一致，`dT/dy|cell = A(1−h)` ✓ 一阶）。

**(b) 壁面法向导数做二阶外推**（`_extrapolate_trace_derivative` + `_shift_along`，
`_boundary_flux(..., neighbour=...)`）

内部面只有一阶梯度却能二阶，靠的是两面平均；壁面只有一侧，于是用最里面**两个单元**
线性外推到面：

    g_face = 1.5 g_cell − 0.5 g_neighbour      （对二次分布精确）

ny=8 实测：`1.5×0.08880 − 0.5×0.06343 = 0.101481`，真值 `0.101429`（误差 5.3e-5）。
改动最小：新参数默认 `None`（旧行为），所有既有调用零改动；
`tools/diag_ns_wall.py` 的五节诊断与 `benchmarks/verify_ns_wall_gradient.py` 已接上。

### 2.3 工具链

    PYTHONPATH=. python -m benchmarks.verify_ns_wall_gradient      # 生成 JSON + 图
    PYTHONPATH=. python -m pytest tests/test_ns_dg_2d_wall.py -q   # 5 条判据
    PYTHONPATH=. python -m tools.diag_ns_wall residual fluxconv    # m2589 原始诊断

全部数字由 `benchmarks/verify_ns_wall_gradient.py` 程序化写入
`validation/ns_dg_2d_wall/gradient_fix.json`，本文件由该 JSON 直读，零手抄。

| 8 | 0.125 | 0.088796 | 1.263e-02 | 0.101481 | **5.275e-05** | 2.601e-05 | **0.052%** |
| 16 | 0.0625 | 0.095102 | 6.327e-03 | 0.101442 | 1.321e-05 | 6.511e-06 | 0.013% |
| 32 | 0.03125 | 0.098262 | 3.166e-03 | 0.101432 | 3.303e-06 | 1.628e-06 | 0.0033% |

**观测阶**：单侧 **1.00** → 外推/重构热流 **2.00**（三次加密，斜率 1.998/1.999/2.000）。
解析真值 `dT/dy = 0.1014286`、`F_E = −0.05000`。

### 3.2 剩余项分解：罚项 `(σ/h)[[T]]` 才是 O(h) 的主人（**未修，记账**）

| ny | 重构误差（σ=0） | 罚项贡献 | 整条数值通量误差 | 罚项占比 |
|---:|---:|---:|---:|---:|
| 8 | 2.60e-05 | 7.286e-03 | 7.312e-03 | **99.6%** |
| 16 | 6.51e-06 | 3.633e-03 | 3.639e-03 | **99.8%** |
| 32 | 1.63e-06 | 1.815e-03 | 1.816e-03 | **99.9%** |
| 64 | 4.07e-07 | 9.070e-04 | 9.074e-04 | **99.96%** |

罚项斜率 **1.00**（h 每减半误差减半）。机理：壁面迹值的跳变 `[[T]] = T|− − T_wall`
本身是 O(h²)（ny=8: 2.31e-4；16: 5.76e-5 —— 斜率 2.0），乘 `σ/h` 后降到 O(h)，
于是**除以体积 h 进强形式残差后必然是 O(1)**。这不是实现缺陷，是 SG 罚项的
stabilisation 结构：它把壁面条件弱施加，数值通量与物理通量之间本来就差 O(h^p)
（p = 1 时即 O(h)），与「格式是否收敛」是两件事。

### 3.3 强形式残差：壁面行仍 O(1)，内部行照常收敛

| 16 | 2.042e-01 | 2.042e-01 | 2.042e-01 | 1.301e-02 | 0.96 |

修前（m2589 归档）：能量通道 **0.3045**（8/16/32 格常数）。修后 0.195/0.204/0.209：
**降了 36% 但仍然不随 h 消失**，且 100% 集中在壁面行——与 §3.2 的罚项记账一致。

### 3.4 脉冲启动 Couette（m2496 P0 算例）：**仍未通过（honest FAIL）**

| 项 | 修前（m2589） | 修后（本单） |
|---|---:|---:|
| 失稳时刻 | t = 0.032817 | t = **0.033287**（+1.4%） |
| 步数 | 67 | 68 |
| min p | −0.00244 | −0.02940 |
| dt 缩 4× 后失稳时刻 | 0.031735 | 0.031731 |
| 通道归因 | 仅温度通道复现 | 仅温度通道复现 |
| σ 加倍 ⇒ 失稳时刻 | 折半 | 折半 |

失稳时刻只动了 1.4%（而梯度误差降了 240×），因此**「一阶壁面梯度导致失稳」的
假设被证伪**（m2589 §5 局限 4 的候选机理 (i) 退休）。剩下的机理指向 (ii)
「罚项作用在导出量 T 上、与守恒变量配对不自伴」，本单未实现。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **坑：`grand T` 的面依赖伪梯度**。第一版只做了 (b) 二阶外推、没做 (a) 单元中心化，
   结果**误差反而变大**（8 格 0.0127 → 0.0188，斜率仍 1.00）。原因是同单元两面梯度
   差 75%，外推把伪差异放大成 3 倍。「内部面靠两侧平均取二阶」这条经验，
   隐含前提是「同一单元的梯度是单元量」——商法则取在面上就破坏了这个前提。
2. **坑（判据层面）：解析稳态残差≠格式一致性的充分判据**。m2589 §5 坑 1 立的
   「解析稳态残差必须随 h 消失」在 SG 罚项下**不可能**成立：罚项贡献 `(σ/h)[[T]]`
   = O(h)，除体积 h 后 O(1)。正确用法是把它用在**罚项无关**的部分（重构通量），
   或按 §3.2 做项分解后再判。本单没有推翻 m2589 的**实测**，只是修正了它的**解释**。
3. **局限（本单未做）**：①壁面瞬态仍失稳，未实现候选机理 (ii)（罚项改施加于
   `ρT = p` 或加伴随对称项）；②P2 壁面只做了残余诊断（P2 的迹导数本身面依赖，
   单元中心化对 P2 只是「把伪差压小」而非消除，需要重构型（BR2/recovery）梯度）；
   ③未测**稳态解**的 L2 误差对解析解的收敛阶——因为瞬态路径不可用到稳态，
   单核显式推进到稳态代价过高（m2496 §5 局限 5 已记）。
4. **适用范围**：本结论只覆盖 `ns_dg_2d` 的强形式 BR1/SIPG 壁面路径（Cartesian、
   常数 μ、显式 SSP-RK3）。内部面/周期的粘性算例不受本次改动影响（回归绿）。

## 6. 误差判定（是否 <3%，逐项）

| 关键量 | 基准 | ny=8 | ny=16 | ny=32 | ny=64 | <3%？ |
|---|---|---:|---:|---:|---:|---|
| 重构壁面热流（σ=0） | −κA = −0.05000 | 0.052% | 0.013% | 0.0033% | 0.0008% | **是（全部）** |
| 壁面 `dT/dy`（外推） | 0.1014286 | 0.052% | 0.013% | 0.0033% | 0.0008% | **是（全部）** |
| 整条数值壁面热流（含罚项） | −0.05000 | 14.6% | 7.28% | 3.63% | **1.81%** | ny ≥ 64 才达到 |
| 强形式残差（精确稳态） | 0（一致格式） | O(1) | O(1) | O(1) | — | **否（honest FAIL）** |
| 脉冲启动 Couette 到 t=0.1 | 不过失稳 | — | — | — | — | **否（honest FAIL）** |
| 周期剪切波设计阶（回归） | 2.02–2.07 | 未退化（测试绿） | | | | 是 |

**结论**：壁面**梯度/重构通量**已 <3%（且二阶收敛，8 格即 0.052%）；
**整条数值通量**在 ny ≥ 64 才 <3%（罚项 O(h) 所致，属 SG 结构而非实现缺陷）；
**强形式残差与壁面瞬态两条判据仍不达标，如实记为未完成**，不粉饰。
