## 1. 案例介绍

### 1.1 为什么这是缺口

Tensordg 全部 9 个求解器都是**无粘**的：`grep -riE "viscous|navier|reynolds|br1|lifting" tensordg/`
在本单开工前**零命中**。没有粘性 → 无边界层、无剪切应力、无导热，只能做无粘可压缩流验
证，无法进入真实 CFD（阻力/热流）问题。

### 1.2 物理与方程

二维压缩 Navier–Stokes，量纲一，**单位气体常数 R = 1**（与 `euler_dg_2d._pressure` 一致，
故 `T = p/rho`、`c_v = 1/(γ-1) = 2.5`、`c_p = 3.5`），γ = 1.4，常数动力粘度 μ，
Prandtl 数给定：

    tau_xx = 2 μ u_x - (2/3) μ (u_x + v_y)
    tau_yy = 2 μ v_y - (2/3) μ (u_x + v_y)
    tau_xy = μ (u_y + v_x)
    kappa  = μ c_p / Pr                     （导热系数）
    F_v    = [0, tau_xn, tau_yn, u tau_xn + v tau_yn + kappa T_n]
    dU/dt  = -div(F_inv) + div(F_v)

### 1.3 算例参数表

| 算例 | 几何 / 网格 | 参数 | 判据 |
|---|---|---|---|
| A 粘性极限一致性 | [-5,5]² 周期，6² 格 | P1，μ=0，t=0.05 | 与 `solve_euler_dg_2d` 逐点相对差 < 1e-12，步数相同 |
| B 衰减剪切波 | [0,1]² 全周期，2×{6,8,12,16} | P1/P2，μ=0.05，Pr=0.71，A=0.01，k=2π，t=0.1 | vs `u = A sin(ky) e^{-νk²t}`；相对 L2 < 3% 且观测阶 ≈ 2 |
| C 静止流体等温壁 | [0,1]²，2×8 格，x 周期 / y 壁面 | P1，μ=0.1，T: 1.0 → 0.5，p=1 | 动量残差 ≈ 0（壁面不得注入动量） |

算例 B 是该模块的**设计阶验证**：剪切波是线性化 NS 的精确解，右端只剩 ν·u_yy，
viscous heating 为 O(A²) ≈ 1e-4（相对 T 为 1e-4），故它同时是「精确解对照」和「阶数验证」。
算例 C 用线性 T / 均匀 p 的纯导热精确解，专门检查壁面 Dirichlet 处理是否引入伪速度。

## 2. 怎么做的

### 2.1 数值方法（新增 `tensordg/ns_dg_2d.py`，约 850 行）

- **离散**：沿用 `euler_dg_2d` 的张量积 Legendre 模态基、Gauss 求积、HLLC 无粘法向通量、
  SSP-RK3、局部正性回退；粘性项用 **BR1**（Bassi–Rebay 1989），在 Cartesian 网格上即 SIPG：

      {grad q · n}_f = 1/2 (grad q|-_f + grad q|+_f)·n - (penalty/h)(q|-_f - q|+_f)

  n 恒取 **+axis** 方向（左面的朝向由弱形式里的 `P_k(-1)` 因子承担，与 `euler_dg_2d` 一致）；
  切向导数取两侧平均；Dirichlet 壁面用镜像 ghost（`q|+ = q_wall`、`grad q|+ = grad q|-`），
  内面与壁面共用同一条代码路径。
- **面值/面导数**：用 Legendre 的精确端点值 `P_k(±1) = ±1^{k}`、
  `P_k'(+1) = k(k+1)/2`、`P_k'(-1) = (-1)^{k-1}k(k+1)/2` 直接从模态系数取迹，
  不需要额外插值。
- **原始量梯度**：`u = m/rho`、`T = p/rho` 对守恒模态是有理函数，用**商法则**从守恒量导数
  精确得到（`_gas_gradients`），保证粘性通量的状态与 HLLC 完全同一。
- **强形式残差**：`dU/dt = -div(F_inv - F_v)`，因此**面项与体项都必须含 F_v**
  （见 §5 坑 1）。
- **显式步长**：粘性稳定域用无量纲群 `S = dt·max(4ν/3, α)·(p+1)^4 / h²`，
  在剪切波与 Couette 上用二分法实测 `S_max ≈ 0.3–0.5`，取 `S = 0.1`（3–5 倍余量）；
  `cfl_viscous = 1` 时 `dt = 0.1 h² / (max(4ν/3, α)(p+1)^4)`。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **坑：粘性通量必须同时进面项与体项**。初版只把 F_v 加到界面通量、体项仍只用 F_inv，
   结果剪切波衰减只有解析值的 ~1/5、残差永远不收敛（比值随网格发散）。
   强形式 `dU/dt = -div(F_inv - F_v)` 的体项必须用**单元局部梯度**的 F_v；
   补上 `_viscous_volume` 后，衰减/阶数才与精确解对上（2.07 → 收敛）。
2. **坑：SIPG 的「插值场残差」不是合法判据**。罚项 (penalty/h)·[[q]] 对光滑场是 O(h^p)，
   当解的有理量（`rho = p/T`、`T = p/rho`）被投影到多项式空间时，O(h²) 的状态投影误差会被
   放大 `penalty/h = 64` 倍，产生 O(0.1–4) 的假残差。**正确判据是「解误差 vs 精确解 + 观测阶」**
   （§3.2），本单据此判定粘性通量达标；残差判据只保留给「恒为零」的三个通道
   （动量/质量，实测机器零）。
3. **坑：面值/面导数得用 Legendre 端点公式，不能拿求积节点内插外推**。
   `P_k'(±1)` 的符号 (`(-1)^{k-1}`) 与 `P_k(-1) = (-1)^k` 必须与弱形式的 `signs` 一致，
   否则左右面通量朝向反号、残差不对称。
4. **局限（最重要，honest）**：**壁面 Dirichlet 的瞬态推进不稳定**。用作者写的
   `solve_couette_dg_2d`（从静止起动，T=const 壁、U=1、μ=0.1、P1/8 格）在 t≈0.05 内即触
   `nonphysical cell average`；静止初值（算例 C）动量通道残差却是机器零，说明问题不在
   「平衡态空间算子」而在**壁面罚项与显式 RK3 的组合**（罚系数或壁面能量通量的时间刚性）。
   本单据此删除了 Couette 的精度断言，只保留可证为真的判据，**不宣称壁面瞬态可用**。
5. **局限**：常数 μ（无 Sutherland 律）、仅 Cartesian 网格、纯显式时间推进
   （稳定域 O(h²)，稳态算例步数 ∝ (H/h)²，故壁面算例在单核上很贵：8 格约 10³–10⁴ 步）。
6. **适用于**：周期/无壁的粘性可压缩流（剪切层、衰减湍流小尺度、粘性激波结构初探）、
   高阶精度研究、可微 CFD 原型。**不适用于**：边界层/壁面热流工程计算（壁面路径未验证）。
