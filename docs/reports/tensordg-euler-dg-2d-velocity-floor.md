# TensorDG P3 二维 Euler DG 涡速度通道：阶数地板与「平移框架」判别

- 任务：m3304（applications 席自找活）　分支：`agent/m3304`
- 锚点：`docs/reports/tensordg-euler-dg-2d-design-order.md`（m3024）§5 局限 2–3
  「P3 只到 16²，只能给出阶数下界」；以及 m3259 报告留下的未决项
  「速度通道地板只定位到『旋转模态 + 与 h 无关』，未定位到代码级根因」。
- 结论一句话：在**当前主干**上，P3 等熵涡的 ρ/p 通道 12²→20² 全程设计阶 4
  （实测 3.88–4.10），但**速度通道在 16²→20² 掉到 EOC≈1.0**；
  把同一个精确解做伽利略平移（`u_bg=(0,0)`，同一网格同一方程）后速度通道
  **正常收敛（EOC 3.77 / 4.72）且零模误差为机器零**。
  → 该地板**不是 DG 装配本身的缺陷**，而是**只在平移框架下出现**的缺陷，
  并伴随一个 h 无关的**领域均值速度偏置 −1.10e-05**。本单给出可执行回归，
  把这两条事实钉成测试；代码级根因**未闭合**（如实声明）。

## 1. 案例介绍

二维可压缩 Euler，理想气体 γ=1.4，无量纲。精确解 = 等熵涡
（β=5，背景速度 (u_bgx, u_bgy)），周期域 [−5,5]²，t=1.0：

    T(r) = 1 − (γ−1)β²/(8γπ²) e^{1−r²},  ρ = T^{1/(γ−1)},  p = ρ^γ,
    u = u_bgx − (β/2π) e^{(1−r²)/2} (y − u_bgy t),
    v = u_bgy + (β/2π) e^{(1−r²)/2} (x − u_bgx t)

该场对任意背景速度都是 Euler 方程的**精确解**（径向动量平衡 dp/dr = ρu_θ²/r，
本单已按此逐项核对 `tensordg/euler_2d.py::vortex_primitive`）。

| 参数 | 值 |
|---|---|
| 离散 | 张量积 Legendre 模态 DG，P3，HLLC 法向通量，SSP-RK3 |
| 求积 | q = degree + 2 = 5（平滑 Gauss–Legendre，体积与面同一规则） |
| 初值 | 全模态 L2 投影（`initial_projection="l2"`） |
| 网格阶梯 | 12², 16², 20²（另 24² 单点复核，见 §4） |
| CFL / 终时 | 0.2 / t=1.0 |

## 2. 怎么做的

`benchmarks/diagnose_euler_dg_2d_velocity_floor.py`（新增）：

1. 对同一精确解跑三条**框架序列**：`moving=(1,1)`（文档算例）、
   `static=(0,0)`、`subsonic_boost=(0.2,0.2)`（用于区分「伽利略平移」与
   「声速穿越」两种机制；见 §5 局限）。
2. 每个算例除相对 L2 误差外，还做**零模分解**：把逐点误差拆成
   域均值（zero mode）与去均值（centred）两部分，分别对解析解的同场 L2 模归一。
3. 结论全部由脚本打印并写 `validation/euler_dg_2d/velocity_floor.json`，
   测试与报告数字均从该 JSON/日志直读，零手抄。
4. 回归：`tests/test_euler_dg_2d_velocity_frame.py`（6 条，把下面每一条事实
   钉成断言；网格只到 20²，单线程约 1 分钟）。

### 3.3 零模（域均值）误差 —— 关键判别量

| 框架 | mean(u) 12² | 16² | 20² | h 无关？ |
|---|---|---|---|---|
| moving (1,1) | −1.093e-05 | −1.102e-05 | −1.103e-05 | **是（0.9% 内恒定）** |
| static (0,0) | −1.05e-17 | −7.9e-18 | −1.0e-17 | 机器零 |
| 同组 ρ 零模（moving） | −3.8e-10 | −3.0e-10 | — | 机器级 |

即：**平移框架下存在一个与网格无关的动量零模偏置（约 −1.1e-05），
静止框架下严格为零**。这排除了「旋转模态本身 / 体积-面通量装配 / 初值投影
阶数」这类与框架无关的机制（它们会在两个框架里同等出现）。

## 5. 注意点 / 局限（不粉饰）

1. **代码级根因未闭合**。本单只把缺陷**归到框架依赖**这一层：
   静止框架干净、平移框架有 h 无关零模偏置，因此排除装配/求积阶/初值投影
   （这些与框架无关）；剩下的候选是 HLLC 波速估计的绝对速度依赖
   （`speed_l = min(u_l−a_l, u_r−a_r)`：u_bg=1 时 u_n−a_n 跨越 0，通量在声速线上折点）
   与「周期域上的匀速平移 + 数值耗散」的组合。脚本里的 `subsonic_boost=(0.2,0.2)`
   序列正是为此设置的判据（u_bg=0.2 时 u_n−a_n 不穿零），**本次运行未采集完**，
   故本报告不下因果结论。
2. 网格只到 20²（单点 24²）。P3 的设计阶窗要求更细网格，本单的「掉出渐近窗」
   是**贡献者归属**结论，不是完整的渐近阶测量。
3. 只测了 P3/q=5；求积阶扫描（q=6,8 @20²）在同一脚本中，本次未采集完，
   因此「欠积分（aliasing）」未被排除，只是被 §3.3 的框架判别降级为次因候选。
4. 无限制器、无边界层、纯 Cartesian 周期域；结论不外推到含激波/壁面情形。
5. 共享机 load15 58–75，全部单线程；20² P3 单点约 53–63 s，24² 约 250 s。

## 6. 误差判定（逐项，是否 <3%）

本单是**阶数/框架判别**任务，判据是「观测 EOC 是否达到设计阶 4」与
「零模偏置是否随 h 下降」，不是幅值型的 3% 门。仍按要求列出可比量：

| 关键量 | 基准 | 实测 | 相对偏差 | <3%？ |
|---|---|---|---|---|
| P3 20² 速度相对 L2 | 设计阶外推 4.76e-05（16²×(4/5)⁴） | 9.27e-05 | +94.7% | **否**（地板实证） |
| P3 20² 密度相对 L2 | 同上外推 1.571e-05 | 1.5766e-05 | +0.4% | **是** |
| P3 20² 压力相对 L2 | 同上外推 2.182e-05 | 2.1882e-05 | +0.3% | **是** |
| 静止框架 20² 速度相对 L2 | 外推 2.05e-04 | 2.5125e-04 | +22.6% | 否（前渐近，但 EOC=4.72 已恢复） |
| 零模速度偏置（moving，h 无关性） | 12² 值 −1.093e-05 | 20² −1.103e-05 | 0.9% | **是**（说明它确实不随 h 变） |

**判定**：ρ/p 通道达标（偏差 <1%），速度通道**不达标**且缺陷已定位到框架依赖，
本轮 **honest 部分失败**：未给出代码级根因与修复。
