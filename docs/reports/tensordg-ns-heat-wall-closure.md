## 1. 案例介绍

### 1.1 物理背景与几何

二维压缩 Navier–Stokes，无量纲，`R = 1`、`γ = 1.4`（`T = p/ρ`、`c_v = 2.5`、`c_p = 3.5`）。
计算域 `[0,1]²`：x 周期、y 双壁；上下壁为**等温无滑移壁** `T = 1.0`（下）/`0.5`（上），`u = v = 0`。
BR1/SIPG 强形式，Cartesian 张量积网格，P1（另含 `wall_gradient="taylor"` 对照）。

被验证的算例是纯热传导稳态

    u = v = 0,  p = p₀ = 1,  T(y) = 1 - 0.5 y,  ρ = p₀ / T(y),

它精确满足可压缩方程（能量方程退化为 `κ ∇²T = 0`，动量 `∇p = 0`）。

| 参数 | 值 |
|---|---|
| 网格 | `2 × {8, 16, 32, 64}` 单元，P1 |
| μ / Pr / κ | 0.1 / 0.71 / 0.492958 |
| p₀ | 1.0 |
| 壁温 | 下 1.0，上 0.5 |
| 罚项 σ | `2(p+1)²` = 8（并扫 16、32） |
| 壁面梯度 | `"face"`（默认）与 `"taylor"` |

### 1.2 为什么这是缺口

`ns_dg_2d` 的验证矩阵覆盖周期剪切波、Couette/Brinkman、脉冲启动与 Stokes 第二问题，
但**纯热传导这条入口从未通过任何基准**：m3210 已确证「默认参数跑不完 + 精确稳态残差
不随 h 收敛」，并把「重推等温壁 BR1 强形式闭合」列为后续单。本单不重复定位，
而是回答三个上游没有回答的问题：

1. 闭合到底**一致不一致**（用可精确表示的状态做判据，而不是用投影误差混合的判据）；
2. 缺陷是**全局离散**问题还是**壁面闭合**问题（残差按行/按方程拆开）；
3. 上游建议的「加密/加罚项」这两个常规手段**能不能救**（罚项 σ 扫描）。

## 2. 怎么做的

三支探针，全部程序化、数字由脚本写入 `evidence.json` 后回读，零手抄：

- **E1 一致性判据（新）**：取一个 DG 空间**可精确表示**的状态（`ρ = 1`、`u = v = 0`、
  `p = 1`、双壁 `T = 1`，即 `T = p/ρ = 1`）。任何一致闭合都必须在壁面行给出机器零残差。
  这是上游 m3210 没做的判据——它用的精确稳态含 `ρ = p/T`（有理函数，P1 投影有 O(h²) 误差），
  所以「残差不为零」无法区分「闭合错」与「投影误差」。
- **E2 壁面热流阶次**：把精确稳态 L2 投影后，直接调用模块内部 `_boundary_flux`，
  拿闭合给出的壁面法向热流与解析 `κ dT/dy = -0.246479` 比，做 `ny = 16 → 64` 网格序列；
  同时把强形式能量残差按「底壁行 / 内区行 / 顶壁行」与按方程（质量/动量/能量）拆开。
- **E3 失稳归因**：用模块自身残差 `_rhs_ns` + 同样的 SSP-RK3/黏性步长公式推进（与
  `solve_navier_stokes_dg_2d` 同一条路径），从**精确稳态**出发，扫描罚项 `σ = 8/16/32`
  与网格 `ny = 8/4`，记录崩溃时刻与 `p_avg` 极值；另跑「均匀初值 + 弱冷却（T_top = 0.95）」
  作为负控，区分「物理瞬态」与「闭合失稳」。

## 3. 计算结果

### 3.1 E1：闭合在可精确表示的状态上是**一致**的（机器零）

| ny | `wall_gradient="face"` max|residual| | `"taylor"` |
|---:|---:|---:|
| 8 | 1.098e-15 | 5.194e-15 |
| 16 | 2.195e-15 | 2.078e-14 |
| 32 | 4.390e-15 | 8.310e-14 |

结论：`[0,p,0,0]` 无穿透无滑移通量 + Dirichlet 罚项 + 镜像梯度这条闭合**不含符号/量纲错误**。
m3210 看到的「壁面能量残差不收敛」不是硬不一致，而是**精度阶**问题（见 3.2）。
这一条把「重推闭合（可能是符号错）」的最坏假设排除掉了，也是本单最重要的负结果。

### 3.2 E2：壁面热流只有一阶，且 `taylor` 重构一点也没帮上

壁面法向热流误差 `|q_wall - κ dT/dy|`（解析值 `-0.246479`）：

| ny | face 底壁 | face 顶壁 | taylor 底壁 | taylor 顶壁 | 相对误差(face 底壁) |
|---:|---:|---:|---:|---:|---:|
| 16 | 1.868e-02 | 4.799e-03 | 1.868e-02 | 4.799e-03 | 7.6% |
| 32 | 9.160e-03 | 2.481e-03 | 9.160e-03 | 2.481e-03 | 3.7% |
| 64 | 4.536e-03 | 1.262e-03 | 4.536e-03 | 1.262e-03 | 1.8% |

- 底壁加密比 2.04 / 2.02，顶壁 1.93 / 1.97 → **观测阶 1（设计阶 2）**，与 m3139 对 P1 的
  测量（1.005）一致；
- `taylor` 与 `face` 的误差**三位有效数字完全相同**：说明壁面热流的误差由
  **Dirichlet 罚项 `σ/h·(T⁻ - T_wall)` 主导**（`T⁻ - T_wall = O(h²)` 的投影误差 × `σ/h`
  ⇒ `O(h)`），壁面梯度重构怎么改都无效。这直接解释了 m3139 的「taylor 在 P1 不改善阶次」。

强形式能量残差（按行拆开，modal 尺度）：

| ny | 底壁行 | 顶壁行 | 内区行 | 质量行 | 动量行 |
|---:|---:|---:|---:|---:|---:|
| 16 | 0.8669 | 0.1292 | 1.709e-01 | 9.97e-15 | ≤2.2e-15 |
| 32 | 0.8649 | 0.1850 | 9.292e-02 | 3.76e-14 | ≤4.4e-15 |
| 64 | 0.8638 | 0.2150 | 4.855e-02 | 7.27e-14 | ≤8.8e-15 |

内区斜率 `d log E / d log h = +0.93`（≈一阶，正常），壁面斜率 **≈ 0**（不衰减）。
**质量/动量行在精确稳态上是机器零** ⇒ 缺陷只在能量/温度通道的壁面行，是**局部**缺陷，
不是全局离散格式的错（这部分与 m3210 结论一致，但本单用可精确表示状态给了「一致性无错」
的正面证据，而它是 m3210 无法给出的）。

为什么残差在壁面「不衰减」而不是「衰减更慢」：强形式逐模态残差带 `(2k+1)(2l+1)/(2h)`
因子，壁面热流误差 `O(h)` 被 `1/(2h)` 放大 ⇒ 残差停在 `O(1)`。所以「残差不收敛」本身
不是失稳原因，只是阶次的显影。

### 3.3 E3：罚项越大崩得越早 —— 失稳的主因就是等温壁 Dirichlet 罚项

从**精确稳态**出发（本应是离散不动点）：

| 配置 | 结果 | 崩溃时刻 | `p_avg` 范围 |
|---|---|---:|---|
| ny=8, σ=8 | crashed | 0.0503 | -0.100 … 23.59 |
| ny=8, σ=16 | crashed | 0.0306 | -2.160 … 76.92 |
| ny=8, σ=32 | crashed | 0.0178 | -19.15 … 310.6 |
| ny=4, σ=8 | survived（步数上限内） | ≥0.0600 | 0.958 … 1.446 |
| ny=8, σ=8, 均匀初值 | survived | ≥0.0588 | 0.316 … 1.015 |
| ny=8, σ=8, 均匀初值 + 弱冷却 T_top=0.95 | survived | ≥0.0594 | 0.690 … 1.030 |

- **σ 加倍，崩溃时刻提前 1.6 倍；σ 四倍，提前 2.8 倍**。SIPG 的常规「加罚项」是**反向**手段：
  若这是「罚项不足」型失稳，应该相反。可判定：失稳由罚项项本身（`σ/h` 乘在不可表示的温度上）
  驱动，属**离散闭合的稳定性**问题，不是欠罚。
- 精确稳态出发也崩 ⇒ 与「初始条件与边界不协调」无关；等温壁把不可表示的温度投影误差
  以 `σ/h` 的刚度反馈回壁胞能量，随时间步放大。
- 负控：弱冷却（T_top=0.95，扰动仅 5%）在同一网格/罚项下**不崩** ⇒ 失稳需要足够的
  壁面热流幅值，是「强冷却 + 罚项刚度」的组合，不是无条件爆炸。

## 4. 注意点（踩过的坑与适用范围）

- **陷阱 1：`_initial_coefficients` 会按初值回调的返回 shape 建网格。** 若回调只依赖 `y`
  （如 `T = 1 - 0.5y`），返回张量的 x 维会被广播成 1，网格静默塌成 `1×ny`
  （或 `nx×1`），残差/失稳数字全部无效。本单首版探针即栽在此处，表现为「p_max 飙到 27」。
  正解：回调里先 `x + 0*zeros_like(y)`（`tests/test_ns_heat_wall_closure.py::_full`）。
- **陷阱 2：判「闭合一致不一致」必须用空间可精确表示的状态。** 用含 `ρ = p/T` 的精确稳态
  做判据时，「残差非零」既可能是闭合错也可能是投影误差，无法区分。E1 的均匀态判据是
  唯一干净的正面/反面判据（本单由此排除「符号/量纲错」的重推方案）。
- **陷阱 3：残差不能直接当误差量级。** 强形式 modal 残差含 `(2k+1)(2l+1)/(2h)`，
  壁面热流误差 `O(h)` 会被放大成 `O(1)`；唯一可读的是**斜率**与**逐项热流对比**。
- **陷阱 4：撞到「napkin 结论」别急着改代码。** `σ` 扫描（3.3）只花几秒就否掉了上游
  「加密/加罚项」两条常规修法，比直接改闭合省预算得多。
- 适用范围：结论限于强形式 BR1/SIPG + 等温 Dirichlet 壁、P1、Cartesian 张量积网格、
  CPU/float64。周期方向黏性算子、无滑移动量壁（m2589 已证 1e-12 精确）不受影响。
- 未做：**没有修闭合**。E1 已排除硬不一致，E2/E3 把缺陷定位为「罚项作用在不可表示的
  壁面温度上、且以一阶精度反馈」的稳定性问题；正确修法需要把壁面温度罚项改为
  `O(h)` 一致性可保证的形式（候选：把 Dirichlet 值抬升为**壁面温度的多项式延拓**，
  或改用 `σ/(h/2)` 尺度的 BR1 lifting 并重推体积项配对），必须单独验证
  （代价 ≥ 一次完整的设计阶回归 + Couette/Brinkman/剪切波三例复跑），不在本单夹带。
  已把该结论作为后续单线索写入报告 §5。

## 5. 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 基准 | 实测 | 误差 | <3%？ |
|---|---|---|---|---|
| E1 一致性（均匀态残差，ny=32） | 机器零 | 4.390e-15 | — | 是 |
| 精确稳态质量/动量行残差 | 机器零 | ≤ 8.8e-15 | — | 是 |
| 壁面热流 ny=16（face） | `κ dT/dy = -0.246479` | 误差 1.868e-2 | 7.6% | **否** |
| 壁面热流 ny=32（face） | 同上 | 误差 9.160e-3 | 3.7% | **否** |
| 壁面热流 ny=64（face） | 同上 | 误差 4.536e-3 | 1.8% | 是（但靠加密买来） |
| 壁面热流阶次 | 设计阶 2（P1） | 观测 1.98–2.04（比值）→ 阶 1 | 阶次差 1 | **否（阶次判据）** |
| 内区能量残差阶次 | ≈1 | 0.93 | 与一阶理论一致 | 是 |
| 壁面能量残差阶次 | ≈1 | ≈0.00（0.8669→0.8638） | 不衰减 | **否** |
| 精确稳态推进到 t=0.05（ny=8, σ=8） | 应保持不动 | 崩溃于 t=0.0503，`p_avg ∈ [-0.10, 23.6]` | 功能不可用 | **否** |

**honest 结论**：等温壁闭合**不是**硬不一致（E1 正面证据，m3210 未给出的关键负结果），
但壁面热流只有一阶、精确稳态不是离散不动点、且罚项是失稳放大器。证据等级维持
**WITHHELD→已验证不可用（能量/温度壁面通道）**，不声明修复。
