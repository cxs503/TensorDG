## ① 案例介绍

**为什么是这道题。** `tensordg/swe_1d.py` 的 docstring 声明了三个解析基准：
Lake-at-rest（已验证）、**Ritter dam break**（未验证）、Thacker basin（未验证）。
本单补上 Ritter 溃坝这一门考试。

**物理背景。** 1892 年 Ritter 给出了平底干床溃坝问题的自相似解析解：
初始时刻 x < 0 处水深 h₀、x > 0 处干床，t > 0 时产生向右传播的稀疏波和向右推进的湿润锋。
它的判别力在于同时检验：
- 激波/稀疏波捕捉能力（HLL 通量）
- 湿润锋处理（干-湿过渡）
- 质量守恒（平底无源项时应严格守恒）
- 正性保持（h ≥ 0）

**几何与参数**（Ritter 1892 标准配置）：

| 项 | 值 |
|---|---|
| 方程 | 1-D SWE，g = 9.81 m/s²，平底 z_b = 0 |
| 域 | x ∈ [-5.0, 5.0]，透射边界 |
| 初值（x < 0） | h = 1.0 m，u = 0 |
| 初值（x ≥ 0） | h = 1e-8 m（干床近似），u = 0 |
| 终止时刻 | t = 0.5 s |
| 数值格式 | 模态 Legendre DG（P1）+ HLL 通量 + SSP-RK3，CFL = 0.15 |

**解析解**（自相似变量 ξ = x/t，c₀ = √(gh₀)）：

| 区域 | 条件 | h | u |
|---|---|---|---|
| 未扰动区 | x ≤ -c₀t | h₀ | 0 |
| 稀疏波 | -c₀t < x < 2c₀t | (2c₀ - ξ)²/(9g) | (2/3)(c₀ + ξ) |
| 干床区 | x ≥ 2c₀t | 0 | 0 |

湿润锋位置：x_front = 2c₀t = 2√(gh₀)t

## ② 怎么做的

1. **解析解**：闭式公式，直接计算到单元中心。
2. **比较口径**：只在湿润区（h_exact > 1e-8）比较，避免干床区除零。
3. **判据（先定后测）**：
   - 密度相对 L1 误差 < 3%
   - 速度相对 L1 误差 < 5%（湿润锋附近速度梯度大，放宽）
   - 质量守恒误差 < 0.1%
   - 正性：h ≥ -1e-14 处处成立
   - 湿润锋位置误差 < 15 个单元
   - 网格加密时误差单调下降
4. **工具链**：`benchmarks/ritter_dam_break.py` 单次运行 → 指标 + 剖面；
   `tests/test_swe_1d.py::TestRitterDamBreak` 回归门。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **干床处理**：当前用 h = 1e-8 近似干床，不是真正的 wet-dry 算法。
   对于真正的干床（h = 0），需要专门的 wet-dry 重构（如 Audusse 静水重构）。
2. **P2+ 限制**：P2 DG 在默认 CFL = 0.15 下会触发 `FloatingPointError`（非物理态），
   需要降低 CFL（≤ 0.08）才可能稳定。这说明高阶格式在湿润锋附近需要更精细的处理。
3. **湿润锋 smeared**：湿润锋被抹平约 11 个单元，这是 HLL 通量的数值耗散所致。
   更锐利的锋面需要更高分辨率或限制器。
4. **速度误差较大**：rel L1 u = 2.985%，接近 3% 门限。这是因为湿润锋附近速度
   从有限值跳到零，L1 范数对这种间断敏感。
5. **适用范围**：结论适用于「平底 + 中等溃坝强度」类问题；
   非平底床、强稀疏波（Toro 测试 2）、近真空情况未在本单考证。

**结论**：P1 DG 对 Ritter 溃坝问题的所有判据均通过。
质量守恒精确到机器精度（平底无源项的离散一致性），
水深误差仅 0.25%，湿润锋位置偏差约 11 个单元。
P2+ 格式需要更小的 CFL 和/或专门的 wet-dry 处理，留作后续工作。
