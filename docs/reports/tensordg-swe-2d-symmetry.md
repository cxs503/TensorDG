## 1. 为什么做这件事（验证欠账定位）

`tensordg/swe_2d.py` 是 TensorDG 的二维浅水 DG 求解器，其历史缺陷记录集中在
m6386（y 向迹线收缩错误：跨模态 (1,1) 上注入虚假 y 动量源，任何非定常流一步爆
炸；`limiter` 参数被静默丢弃）。m6400 修好了 1-D Thacker 验证面并把壁面质量缺陷
钉住，但**二维侧从未有过一次"不依赖参考解"的独立复核**：现有 `test_swe_2d_dynamics`
只跑动力学位形，没有断言任何"必须精确成立"的量。本单选择的正是这类账：不引入新
物理，而是把**离散格式的代数不变量**变成机器门。

四条不变量（都不涉及截断误差论证，因此只能用舍入误差量级的容差）：

| 编号 | 不变量 | 为什么它必然成立 |
|---|---|---|
| C1 | y 不变问题的二维解 = 一维解 | 张量积 DG + y 向通量在 y 不变状态上逐点相消 |
| C2 | y 不变状态不得产生任何 y 向变化 | m6386 缺陷类的直接否定式 |
| C3 | 径向问题在 (nx,ny) 与 (ny,nx) 上互为转置 | 笛卡尔网格 + 各向同性源项/通量的对称性 |
| C4 | 静水 (h+z_b=const) 保持静止 | 恰良态（well-balanced）性质 |

C4 的判据必须小心：求解器的床面坡度源项用**每个单元一个常梯度**
（`zb_jump/dx`），因此"精确良态"只对**该离散能精确表示的床面**（全局线性床、折
线床且折点落在单元面）成立；弯曲床只有 O(dx²) 残差。这一条本单既当判据也当
**被测出的局限**（第 5 节）。

## 2. 方法与设置

全部算例：单位方域、Legendre 模态 DG、HLL 界面通量、SSP-RK3、CFL 0.15、
`float64`、单线程（`torch.set_num_threads(1)`，避免共享主机上的线程抖动）。

| 算例 | 配置 | 判据 |
|---|---|---|
| `cross_solver_p1/p2` | y 不变溃坝（h=1 for x<0.5 else 0.2），nx=16、ny=4，t=0.02，transmissive | 二维第 0 条 y 列的每个求积点 vs `swe_1d` 同分辨率解，相对差 ≤ 1e-11 |
| `transposition_p1` | 径向溃坝（r<0.3 内 h=1，否则 0.2），(12,20) vs (20,12)，t=0.05 | 场重标号 (i,j,a,b)→(j,i,b,a) 且 hu↔hv 交换后相对差 ≤ 1e-11 |
| `well_balanced_linear_p1` | z_b = 0.2 − 0.3x − 0.1y，h = 1 − z_b，16²，t=0.05 | η=h+z_b 相对 ∞ 范数、动量 ∞ 范数 ≤ 1e-11 |
| `well_balanced_kinked_p1` | z_b = 0.2 − 0.3|x−0.5| − 0.1|y−0.5|（折点落在单元面），同上 | 同上 |
| `well_balanced_smooth*` | z_b = −0.4 exp(−r²/0.02)（弯曲床），16²/32² 与 1-D 16/32，t=0.05 | 只记录（`gating=False`），用来量化局限 |

## 5. 注意点（踩坑 / 局限 / 适用范围）

1. **转置对称的判据本身容易写错**：第一次实现里我把两次运行的 hu 就地比较，
   得 1.518（151%）的"失败"。径向问题的转置伴随的是 **hu↔hv 交换**，加上交换
   后立即降到 3.4e-15。教训：对称性判据必须先自己对称化，再当裁判——否则会把
   自己的判据 bug 记成求解器缺陷（与席位账本 IN28-D1 同类）。
2. **良态（well-balanced）不是无条件精确**：源项用每单元常梯度，只有线性床与
   "折点在面上的折线床"能精确保持静水；弯曲床的静水残差随网格二阶收敛
   （实测 1.76/1.79），n=16 时 2.6% 量级。原一维 `_rhs` docstring 的
   "machine-precision well-balancedness" 只对分段线性床成立，二维侧同理——本单
   把这条写进测试断言（`test_curved_bed_is_not_exactly_well_balanced_but_second_order`），
   防止后来者误以为弯曲床也该是机器精度，或者用隐藏特例把它"修绿"。
3. **共享主机负载**：load15≈120（nproc=128），单次 P1 32×8 二维跑 274 步要 50 s，
   因此本单所有算例都压到 ≤ 32²、t≤0.05；这些不变量不需要长时积分即可判定。
4. 适用范围：笛卡尔均匀网格 + 张量积 Legendre 模态 + HLL；非结构/曲线网格与
   h-自适应不在本单覆盖内。C2 是 m6386 缺陷类的**回归门**，不是对所有可能数值
   源的完备性证明。

## 6. 误差判定

| 量 | 基准 | 误差 | 是否 <3% |
|---|---|---|---|
| 二维 y 不变解 vs 一维解 h（P1/P2） | `swe_1d`（已对 Thacker/Ritter 验证） | 1.08e-16 / 1.41e-15 | 是 |
| 二维 y 不变解 vs 一维解 hu | 同上 | 3.04e-16 / 4.33e-15 | 是 |
| 转置对称（h/hu/hv） | 同问题转置解 | 3.40e-15 | 是 |
| 静水残差（线性床 / 折线床，16²） | h+z_b=const 精确解 | 7.41e-16 / 2.33e-15 | 是 |
| 静水残差（弯曲床，16²） | 同上 | 2.60e-2（2.6%） | 否（已定性为 O(dx²) 局限；32² 降到 7.70e-3 <1%） |

结论：四条代数不变量全部在舍入误差量级成立（最大 3.4e-15，远低于判据）；
唯一的"不精确"项是弯曲床静水残差，属已知的床面表示局限，已量化并钉进测试，
不是新缺陷，也不影响 1-D/2-D 在可表示床面上的良态性。
