# TensorDG 压缩 Navier–Stokes 壁面（Dirichlet）通道：罚项取向缺陷修复与解析验证

- 任务：m2782（models 席自找活，接 m2589 的 P0 欠账）　分支 `agent/m2782`
- 环境：Python 3.11 / torch 2.7.1 / pytest 9.2.0 / CPU / float64 / 单线程（`torch.set_num_threads(1)`）
- 上游：`agent/m2496`（`tensordg/ns_dg_2d.py`，BR1/SIPG 粘性 DG，已合并 PR #19）与
  `agent/m2589`（壁面通道复核，已合并 PR #23）——后者把壁面瞬态失稳定位到「壁面罚项」，
  并把根因猜测为「壁面粘性通量对弯曲数据只有 O(h) 精度」。
- 一句话结论：**根因不是精度阶，而是罚项取向（符号）**。`_boundary_flux` 总是以 `+axis`
  为法向书写数值粘性通量，因此罚项跳跃 `q|-_face - q_wall` 在**低侧壁面必须反号**；
  原实现两侧同号，导致低侧壁面把「热」灌回单元（反耗散边界项），其增长率 ∝ 罚项系数、
  且与时间步无关——正是 m2589 实测到的「dt 缩 4× 失稳时间不变、σ 翻倍失稳时间折半」。
  修复后：同配置从 `FloatingPointError`（t≈0.05）变成稳定推进到 t=0.1 且速度有界；
  壁面通道对解析解误差 0.67%/0.17%/0.04%（8/16/32 格，P1），观测阶 **2.00/2.02**。

## 1. 案例介绍

### 1.1 物理背景与几何

二维可压缩 Navier–Stokes，量纲一，`R = 1`（故 `T = p/rho`、`c_v = 2.5`、`c_p = 3.5`），
γ = 1.4，常数动力粘度 μ，Prandtl 数给定，`kappa = mu c_p / Pr`。粘性项 BR1（Bassi–Rebay 1989），
Cartesian 网格上即 SIPG；壁面（Dirichlet）用镜像 ghost：`q|+ = q_wall`、`grad q|+ = grad q|-`。
本单**不新增物理与求解器功能**，只修壁面罚项取向并给出解析判据。

| 编号 | 几何 / 网格 | 参数 | 用途 |
|---|---|---|---|
| A 罚项取向（代数） | [0,1]²，2×8 格，P1 | ρ=1、u=v=0、p=1（T 均匀 1）；壁温 0.9（冷壁） | 判「两侧壁面是否都从单元取热」 |
| B 稳态残差 | [0,1]²，2×{8,16,32}，P1/P2 | μ=0.1，U=1，T_w=1，Brinkman 抛物线 | 与 m2589 记录的前值逐格对比 |
| C Dirichlet Stokes 模态（**主判据**） | [0,1]²，1×{8,16,32}，P1 | u(y,0)=A sin(πy)，A=0.05，μ=0.1，t=0.02 | 对解析解 `u = A sin(πy) e^{-νπ²t}` 的精度与阶 |
| D 壁面热流（热通道） | [0,1]²，2×{8,16,32}，P1/P2 | ρ=1，p = 1 + 0.5 y(1-y)（T 为抛物线） | 壁面 Fourier 通量的精确性/阶 |
| E 失稳复现（原 P0） | [0,1]²，2×8，P1 | U=1，T_w=1，μ=0.1，t=0.1 | m2589 的崩溃配置是否仍崩 |

### 1.2 缺陷（修复前）

- 壁面数值通量：`normal_q = q_n·(2/h) - (penalty/h)(q|-_face - q_wall)`，两侧壁面同号。
- 低侧壁面物理外法向为 `-axis`，镜像后跳跃量应为 `q_wall - q|-_face`，故罚项必须反号。
- 后果：低侧壁面贡献 `+kappa(σ/h)(T|- - T_wall)/Δy`——壁面比单元冷时**反而加热**单元。

## 2. 怎么做的（方法与工具链）

1. **判据先于修改**（5 条，全部可机器裁）：
   ① 取向：冷壁时两侧壁面都必须从单元取热（`F_y(底) < 0 < F_y(顶)`，且镜像状态反对称）；
   ② 精度主判据：Dirichlet Stokes 模态对解析解的相对 L2 < 3%，且对 h 呈二阶；
   ③ 热通道：T 抛物线在 P2 可精确表示 → 壁面热流与 `-kappa dT/dy` 机器精度一致；
   ④ 复现判据：m2589 崩溃配置必须推进到 t=0.1 且 `|u| <= 壁面速度`；
   ⑤ 残差：只作回归护栏（<0.06），不作精度判据（理由见 §5）。
2. **最小改动**：`tensordg/ns_dg_2d.py::_boundary_flux` 增加参数 `outward_sign`
   （高侧 +1、低侧 -1，由 `_axis_fluxes_ns` 两处调用传入），罚项三通道（u、v、T）统一反号；
   顺带在 `solve_navier_stokes_dg_2d` 的 metadata 里补 `final_time_reached`
   （时间步自适应，`steps*dt` 不是真实时长，解析对比需要真实时长）。
3. **工具链**（全部在 worktree 内）：

| 文件 | 作用 |
|---|---|
| `benchmarks/verify_ns_dg_2d_wall.py` | 五节一键复现（sign/residual/transient/thermal/stability），数字写 JSON、出 PNG |
| `tests/test_ns_dg_2d_wall.py` | 7 条判据（原 3 条 `xfail(strict=True)` 全部退休并替换为 green 判据） |
| `validation/ns_dg_2d_wall/verification.json` | 本报告所有数字的机器可读来源（程序化生成，零手抄） |
| `docs/figures/ns_dg_2d_wall_fix.png` | 三面板图：剖面 vs 解析解 / 壁面路径收敛阶 / 热流与残差 |

## 5. 注意点（坑 / 局限 / 适用范围）

1. **根因是取向不是阶数**：m2589 把 L2 通量阶（O(h)）当作失稳种子，实际是**符号**。
   同一份通量误差若符号正确只是耗散/精度问题，符号错误则变成指数增长（增长率 ∝ σ）。
   判据上，「时间步无关 + 增长率 ∝ 罚项 + 单通道可复现」这套指纹应优先指向取向/反对称性。
2. **m2589 的残差判据（<1e-3）不成立**，已在本单退休并说明理由：P1 下 Brinkman 抛物线不在
   DG 空间内，且 `rho = p/T` 为有理量，解析态本就不是离散稳态；强形式残差之所以 O(1)，
   是因为离散算子在该处的逆尺度为 O(h²)（残差×L⁻¹ = 误差），不是精度不足的证据。
   保留它作为 `< 0.06` 的回归护栏。
3. **P1 壁面点值热流是一阶**（实测 1.00）：BR1 镜像 ghost 的固有性质（`q|- - q_wall = O(h²)`
   除以 h）。要二阶点值通量需 Nitsche + 边界导数二阶修正（m2589 建议 P1 项），本单不做。
4. **`steps*dt` 不是真实时长**：时间步自适应，解析对比必须用新加的 `final_time_reached`。
   本单第一版对比因此出现 78% 假误差（另有正弦级数漏 `(-1)^n` 的错误，已在脚本注释中写明推导）。
5. **适用**：周期/无壁粘性可压缩流 + **壁面瞬态（无滑移/等温壁）已可用于验证级算例**。
   **仍不适用**：边界层/壁面热流工程计算（常数 μ、Cartesian 网格、纯显式推进，
   稳定域 O(h²)，8 格推进到 t=0.1 仅 203 步但成本随 1/h³ 增长）。
6. 本机 load15 ≈ 40–58（nproc=128），本单全部为 1×8～2×32 小网格单线程，未起重算力进程。

## 6. 误差判定（逐项，显式回答是否 < 3%）

| 关键量 | 基准 | 实测（最细网格） | 相对误差 | < 3%？ |
|---|---|---:|---:|---|
| 速度剖面 u(y) | 解析 Dirichlet Stokes 模态 | 0.041 %（32 格） | 0.0004 | ✅ **是**（8 格亦 0.67%） |
| 速度剖面 u(y)（含 8 格最粗） | 同上 | 0.666 %（8 格） | 0.0067 | ✅ 是 |
| 壁面热流（P2） | `-kappa dT/dy` = -0.246479 | 1.184e-13（32 格） | 4.8e-13 | ✅ 是（机器精度） |
| 壁面热流（P1，点值） | 同上 | 2.567e-03（32 格） | **1.04 %** | ✅ 是（32 格）；**8 格 4.17% → 否**，一阶收敛，已声明为局限 |
| 稳态强形式残差 | 无基准（非观测量） | 4.5–5.1e-02 | — | 不作精度判据，仅回归护栏（§5.2） |
| 原崩溃配置稳定性 | 物理上界 `|u| ≤ U` | max|u| / U = 0.676 | — | ✅ 有界，判定通过 |

结论：**解析基准项全部 < 3%（除 P1 点值壁面热流在 8 格为 4.17%，随网格一阶收敛，如实声明）；
不存在被粉饰的项；m2589 的三条 `xfail(strict=True)` 已全部退休为通过判据。**
