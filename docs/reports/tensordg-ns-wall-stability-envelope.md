# TensorDG 壁面 Dirichlet 算子：稳定性包络（罚项 × 壁面梯度闭合 × 伴随项 × 阶数）

- 任务 m3595（platform 席自找活），分支 `agent/m3595`，日期 2026-11-04
- 工具：`tools/spectrum_ns_wall_envelope.py`（本单新增）；数据：`validation/ns_dg_2d_wall/stability_envelope.json`；图：`docs/figures/ns_dg_2d_wall_stability_envelope.png`；门（测试）：`tests/test_ns_dg_2d_wall_stability_envelope.py`
- 环境：CPU，float64，autograd 精确 Jacobian + `numpy.linalg.eig`；单核

## 0. 一句话结论

已交付的壁面算子**在整个选项包络内都没有增长特征值**（|max Re λ| ≤ 9.9e-13，谱幅度 2.3e+04，即机器 epsilon 量级），因此 m2731/m2920 提出的「max Re λ ∝ σ、任何罚项都补不回来」这条**先验规律在现行算子上已被证伪**（阴性对照：修复前的符号无关壁面通量在同一罚项扫掠下从 76.0 涨到 5867.0，仍严格 ∝ σ）；同时**首次实测** m2972 的对称（Nitsche 伴随）项确实只加耗散不加增长（min Re λ 加深 11.9% @P1、97.3% @P2）。**但**本单同时量出来的一条新欠账：解析稳态的壁面残差是 O(1) 而非随 h 收敛（4.518e-02 → 5.237e-02，观测阶 -0.04），且伴随项把它放大 8.74×（P1）——这就是伴随项必须保持 opt-in 的量化理由。

## 1. 案例介绍

二维压缩 Navier–Stokes（量纲一，`R = 1`，`T = p/ρ`，`c_v = 2.5`，`c_p = 3.5`，γ = 1.4），BR1/SIPG 粘性 DG，常 μ，`κ = μ c_p / Pr`。

| 项 | 值 |
|---|---|
| 域 | [0,1]²，x 周期，y 双壁（下壁静止、上壁 U = 1），均 T_w = 1，无滑移等温 |
| 网格 | 2×8 单元，P1 与 P2（谱），2×{8,16,32,64}（残差细化） |
| μ / Pr / κ | 0.1 / 0.71 / 0.492958 |
| 罚项 σ | 2(p+1)²：P1 → 8，P2 → 18 |
| 默认壁面梯度闭合 | `face`（m3139 定案） |
| 伴随项系数 | `WALL_ADJOINT_FACTOR = 2`（m2972） |
| 基准态 | 解析稳态 Couette：`u = U y`、`T = 1 + A y(1−y)`、`p = 1`、`A = μU²/(2κ)` |

**要判定的是什么**：把 `_rhs_ns` 在解析稳态处线性化得到的**半离散算子**，其谱的最大实部是否 ≤ 0（无增长模态）——即「壁面算子本身能不能自持推进」。这与时间步、CFL、瞬态积分器无关，是比「瞬态崩了」更强的事实。

## 2. 怎么做的

1. **精确 Jacobian**：`_rhs_ns` 对模态系数可微，用 autograd 逐行求导得 `J = ∂R/∂U`（2×8 P1 = 256 DOF，2×8 P2 = 576 DOF），再 `numpy.linalg.eig` 取谱。前序工具 `tools/spectrum_ns_wall.py::_jacobian/_spectrum` 复用（本单只加了 `wall_adjoint` 透传参数，不复制实现）。
2. **包络扫掠**（`tools/spectrum_ns_wall_envelope.py`）：
   - 罚项 σ ∈ {2, 8, 32, 128}（默认闭合，伴随 off / on）；
   - 壁面梯度闭合 ∈ {`face`, `fd2`, `taylor`}（σ = 8，伴随 off / on）；
   - 阶数 p ∈ {1, 2}（各自默认罚项）；
3. **阴性对照（防止门是空判）**：把壁面通量换成 m2782 `outward_sign` 修复前的符号无关实现（`tools.diag_ns_wall_spectrum.wall_flux_variant((1,1,1))`，逐字节等于当日交付），做同样的 σ 扫掠。
4. **一致性细化**：解析稳态投影后的 `max|_rhs_ns|` 随网格（2×{8,16,32,64}）的观测阶——「一致的稳定化」必须让这个残差随 h 掉，光有谱不够。
5. **机器门**：上述结论全部写成 pytest 断言（成长门槛 `FLOOR = 1e-9`，阴性对照 `> 50`）。

复现命令：

```bash
PYTHONPATH=. python3 tools/spectrum_ns_wall_envelope.py     # 写 JSON + 图（~3 min，单核）
PYTHONPATH=. python3 tools/render_ns_wall_envelope_report.py # 由 JSON 重新生成本文数字表
PYTHONPATH=. python3 -m pytest tests/test_ns_dg_2d_wall_stability_envelope.py -q
```

## 3. 计算结果

### 3.1 罚项扫掠（P1，默认 `face` 闭合，2×8 Couette 态）

| σ | shipped max Re λ | shipped min Re λ | adjoint max Re λ | adjoint min Re λ | 阴性对照 max Re λ | 对照/shipped 增长比 |
|---:|---:|---:|---:|---:|---:|---:|
| 2 | 1.151e-13 | -351.7 | 4.663e-14 | -388.9 | 76.0 | 6.6e+14 |
| 8 | -2.783e-13 | -1315.8 | -1.476e-13 | -1472.8 | 348.5 | 1.3e+15 |
| 32 | 8.184e-14 | -5180.7 | -2.839e-13 | -5811.9 | 1451.1 | 1.8e+16 |
| 128 | -9.901e-13 | -20642.6 | -5.315e-13 | -23173.5 | 5867.0 | 5.9e+15 |

- shipped 侧的 max Re λ 全程停在 9.9e-13 以内，而同一扫掠下阴性对照从 76.0 线性涨到 5867.0（16× 罚项 → 16.83× 增长）。→ **∝σ 规律只属于修复前的算子**。
- 伴随项（m2972）在各罚项下把 min Re λ 加深 11.9%（σ=8），而 max Re λ 仍在机器零：**只加耗散、不加增长**。

### 3.2 壁面梯度闭合（P1，σ = 8）

| 闭合 | adjoint off max Re λ | off min Re λ | adjoint on max Re λ | on min Re λ |
|---|---:|---:|---:|---:|
| `face` | -2.783e-13 | -1315.8 | -1.476e-13 | -1472.8 |
| `fd2` | 4.629e-14 | -1313.4 | -2.717e-14 | -1352.0 |
| `taylor` | -1.942e-13 | -1316.9 | -1.519e-13 | -1457.6 |

三种闭合都无增长模态 ⇒ 稳定性判定**不依赖闭合选择**（精度/一致性另说，见 §3.4）。

### 3.3 阶数（各自默认罚项）

| p | σ | adjoint | max Re λ | min Re λ |
|---:|---:|---|---:|---:|
| 2 | 18 | off | 4.360e-13 | -5568.9 |
| 2 | 18 | on | -1.850e-12 | -10986.5 |

P2 上伴随项把壁面耗散加深 97.3%（-5568.9 → -10986.5），远大于 P1 的 ~12%：壁面单元模态内容越多，缺失的导数投影那一半越重要。

### 3.4 解析稳态残差（一致性细化，2×{8,16,32,64} P1，σ = 8）

| 闭合 / 伴随 | 8 | 16 | 32 | 64 | 观测阶（8→64） | 最大残差 DOF（nx,ny,k,l,var）|
|---|---:|---:|---:|---:|---:|---|
| face|adjoint=off | 4.518e-02 | 4.864e-02 | 5.111e-02 | 5.237e-02 | -0.04 | (0, 0, 0, 1, 3) |
| face|adjoint=on | 3.949e-01 | 3.974e-01 | 3.995e-01 | 4.006e-01 | -0.00 | (0, 0, 0, 1, 3) |
| fd2|adjoint=off | 4.454e-02 | 4.037e-02 | 3.812e-02 | 3.696e-02 | +0.04 | (0, 7, 0, 1, 3) |
| fd2|adjoint=on | 3.204e-01 | 3.195e-01 | 3.192e-01 | 3.192e-01 | +0.00 | (0, 0, 0, 1, 3) |
| taylor|adjoint=off | 1.997e-01 | 2.068e-01 | 2.107e-01 | 2.126e-01 | -0.01 | (0, 7, 0, 1, 3) |

→ **解析 Couette 态不是现行格式的离散稳态**：残差 O(1)（阶 ≈ 0），不是离散误差量；峰值集中在壁面单元最高 y 模态的能量行（var = 3），即 P1 无法表示的粘性加热抛物温度。伴随项（∝ 同一 Dirichlet 亏损）把它放大 8.74× @P1、2.97× @P2。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **谱判定 ≠ 解精度**。本单只判「有无增长模态」，不重估解误差；壁面有界解的 3% 精度门已由 m2972 的有界驻波算例（相对 L2 = 0.49%）与`tests/test_ns_dg_2d_wall.py` 的设计阶测试覆盖，本单不重复主张。
2. **基准态带 O(1) 壁面残差**（§3.4）。因此「无增长模态」是关于**现行算子在该状态处**的线性稳定性陈述——这对推进代码是有效判据（m2782 修复前后瞬态行为与之定性一致），但不能反推「离散稳态 = 解析稳态」。真正的欠账是壁面闭合的一致性，不在谱。
3. **伴随项是 opt-in 的原因被量化了**：它把解析态残差放大 3–9×（∝ 同一亏损），而它带来的耗散增益在 P1 只有 ~12%。谁要把 `wall_adjoint` 设成默认，必须先修 §3.4 的闭合欠账。
4. **机器零的表述**：max Re λ 在 ±1e-12 内符号不稳定（谱幅度 3.5e2–2.3e4，相对 ~1e-16），故门槛用绝对 1e-9 而非「≤ 0」；阴性对照 > 50 保证门非空判。
5. **范围**：仅 Cartesian 2×8、P1/P2、单一基准态（解析 Couette）、μ = 0.1、Pr = 0.71；未覆盖 p = 0/3、非结构网格、可压缩性更强的基态、以及绝热壁。
6. **复用**：`tools/spectrum_ns_wall.py` 的 `_jacobian/_spectrum` 只加了 `wall_adjoint` 透传（向后兼容，既有 6 条谱测试仍绿），没有第二份 Jacobian 实现。

## 6. 误差判定（关键量 vs 基准逐项）

本单没有实验/文献标量基准，判据是**先验谱判据**；仍逐项给出与「基准」（修复前算子、以及「增长必须 ≤ 0」这一理论要求）的偏差：

| 关键量 | 实测 | 参照 | 偏差 | 是否满足 3% 判据 |
|---|---:|---:|---:|---|
| max Re λ（shipped，σ = 8） | -2.783e-13 | 0（理论要求 ≤ 0） | 相对谱幅度 2.1e-16 | ✅（机器零）|
| max Re λ（shipped，σ = 128） | -9.901e-13 | 0 | 相对谱幅度 4.8e-17 | ✅（机器零）|
| max Re λ（修复前，σ = 8，阴性对照） | 348.5 | 0 | 绝对 348.5 | ❌（O(10²)，门必须红）|
| shipped max Re λ 在 σ∈[2,128] 的绝对幅度 | 9.9e-13 | 0 | — | ✅（整段贴机器零；∝σ 规律无从体现，非「斜率变小」）|
| 伴随项耗散增益（min Re λ，P1） | 11.9% | > 0（理论要求） | — | ✅（符号正确，量级如实偏小）|
| 伴随项耗散增益（min Re λ，P2） | 97.3% | > 0 | — | ✅ |
| 解析稳态残差收敛阶 | -0.04 | ≥ p+1 = 2 | — | ❌ **honest FAIL（壁面闭合欠账，未修）** |

**显式回答**：谱判据（增长模态）与「是否 < 3%」等价的相对量给出 **✅**（相对谱幅度 1e-16 量级，远优于 3%）；而**解析稳态残差的收敛阶不达标**（实测 ≈ 0，要求 ≥ 2），该项本单**如实记为 FAIL，未修**；它属于壁面闭合（wall closure）的既有欠账，与 m2782/m2972 的稳定性修复是两件事。
