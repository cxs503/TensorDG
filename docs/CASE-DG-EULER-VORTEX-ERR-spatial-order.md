# CASE-DG-EULER-VORTEX-ERR：空间收敛阶复核（参考解与误差度量的可辨识性）

**锚点** `CASE-DG-EULER-VORTEX-ERR` ｜ **算例池容差** < 6%（ref: Yee et al. 2000，按条目 verbatim 采用）｜ **本轮判定 PASS**
｜ 数字全部由 `benchmarks/case_euler_vortex_spatial_order.py` 从 `case_euler_vortex_errconserve/spatial_order.json` 程序化注入（零手抄）。

**一句话**：容差门禁（<6%）无法区分「收敛到解析涡」与「收敛到某个离解析解5% 的东西」；本轮用**观测收敛阶**把两者分开——DG-P2 对解析等熵涡的实测阶为 3.035（设计阶 p+1 = 3），纯 L2 投影序列同阶（最低 2.993），CFL 减半只改变误差 1.4e-06（时间误差可忽略），而把参考解故意错位 0.05 后阶塌到 0.000。⇒ 参考解实现（含周期 min-image 映射）与误差度量在 O(h^3) 意义下被独立确认，6% 容差是对一个**深度收敛**的解的陈述。

## ① 案例介绍

二维可压缩 Euler（理想气体 γ = 1.4）上的等熵涡在周期箱内匀速平移：初值即精确解被 |u_inf| = √2 平流后的剖面，箱内平移对称 ⇒ 涡形随 t 不变。算例池条目以「t = 1 快照各场相对 L2 < 6%」验收，而验收对象是`vortex_primitive` 解析解 + 周期 min-image 映射。

| 项目 | 取值 |
|---|---|
| 计算域 | x, y ∈ [-5, 5]²，四周周期（周期箱长 10）|
| 涡强度 β | 5.0 |
| 来流 (u, v)_∞ | (1, 1) |
| 绝热指数 γ | 1.4 |
| 参考解 | Shu (1998) §4.4.2 标准形式，按周期（min-image）映射求值 |
| 设计族 | DG-P2（HLLC + SSP-RK3），网格 16 / 32 / 64² |
| 末时刻 / CFL | t = 1 / CFL = 0.2（控制 CFL = 0.1 于网格 [32, 64]）|
| 待验证假设 | 观测 L2 阶 = p + 1 = 3 |

## ② 怎么做的（方法 / 流程 / 关键设置）

1. **同一代码路径**：阶梯用与算例池完全相同的求解入口 `tensordg.euler_dg_2d.solve_euler_dg_2d_vortex`，误差用同一 `_vortex_error`（体积 Gauss 求积的逐点相对 L2）。n = 32 / 64 与算例池已落盘记录逐位一致（测试 `test_study_reproduces_the_case_pool_ladder_records` 断言 rel < 1e-12）。
2. **网格阶梯** [16, 32, 64]，末时刻固定 t = 1；阶拟合丢弃最粗网格（渐进窗口 [32, 64]），局部阶全量打印。
3. **S1 空间阶**：逐场最小二乘拟合 e ~ h^order，要求 ≥ 2.70 = 0.9 × (p+1)。
4. **S2 度量自洽**：同阶梯上只做 L2 投影（不推进时间、不用数值通量），其误差序列也必须 h^{p+1}——证明 h 标度来自度量与参考解求值，而不是求解器独有。
5. **S3 时间误差占比**：CFL 0.1 与 0.2 复算，相对变化须 < 2%（SSP-RK3 在 dt ∝ h 时也呈 h³，必须排除它与空间阶混淆）。
6. **S4 反真空校核**：把同一末态对**故意错位**的参考解（t + 0.05）评分，阶必须塌到 < 1.50——否则「阶」这个统计量对错误参考不敏感，S1 就是空判据。
7. **S5 容差余量**：最细网格最大场误差须 < 0.1 × 算例容差。
8. **工具链**：CPU float64（torch），集群作业 cj3312（8 核）；静默/求解均为确定性，无随机数。

## ⑤ 注意点 / 局限

- **范围**：只覆盖 P2 与 t = 1 的短时窗口。长时（t = 10，穿箱一次）的阶未在此复测；长时误差放大属 `docs/CASE-DG-EULER-VORTEX-ERR-round6.md` 的 C2/C7x 范畴。
- **为什么短时**：阶是渐近量的度量，长时间累积会把色散误差混入，使「阶」不再可辨识；短时窗口是标准做法（LeVeque 2002 §8）。
- **相对 L2 的分母**是全场均方，包含均匀来流背景，因此数值远小于涡核局部误差；这与算例池容差口径一致，不是宽松化。
- **时间误差**只在 [32, 64] 上直接量化；更细网格的时间误差按 h³ 收缩，未被单独测量（已知未测项，不声称已测）。

- **n = 128 未测**：DG-P2/128² 在本集群节点上复现段错误（`Segmentation fault (core dumped)`，作业 cj3320），因此阶拟合只用到 16/32/64 三点、渐进窗口 32/64。更高分辨率的阶复核列为**未完成项**，本报告不声称已测。
