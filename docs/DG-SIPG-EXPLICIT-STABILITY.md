## ① 案例介绍

两条生产路径的显式步长用的是**未经测量的手设常数**：

| 模块 | 代码规则 | 代码里的主张 |
|---|---|---|
| `advection_diffusion.solve`（RK4） | `dt_diff = 0.5*2.78*h^2/(50.0*sigma*nu)`，`sigma = penalty*(p+1)^2` | 「SIPG 算子谱半径 ≈ 50·sigma·nu/h²，p∈[0,3]」 |
| `ns_dg_2d.solve_navier_stokes_dg_2d`（SSP-RK3） | `S = dt*D*(p+1)^4/h^2 ≤ cfl_viscous*0.1` | 「二分实测 S_max ≈ 0.3–0.5，取 0.1 留 3–5 倍裕度」 |

两者都是在近似同一个无量纲量。本单把它测出来，而不是继续引用：

$$M\dot u = -K u,\qquad \lambda_{\max}(M^{-1}K) = c(p,\alpha)\,\alpha\,\nu/h^{2},\qquad \alpha = \text{penalty}\,(p+1)^{2}$$

于是显式 RK4 的稳定上限是 `dt_max = z_RK4/λ_max`，`z_RK4` 为积分器负实轴稳定区间。

## ② 怎么做的（四条独立测量通道 + 一条实证通道）

| 通道 | 对象 | 方法 |
|---|---|---|
| A 1D 精确 | `heat_1d.assemble_sipg_1d` 的 `M,K` | `M^{-1/2}K M^{-1/2}` 对称化后 `eigvalsh`，全谱精确 |
| B 2D 精确 | `sipg_sparse.assemble_poisson_2d_sparse`（Dirichlet 面） | Lanczos 求两端极端特征值 |
| C 2D 生产算子精确谱 | `advection_diffusion.rhs`（`nu=1`，零速度，`boundary='extrapolate'`） | 逐单位向量探测装配稠密矩阵，`eigvals` 全谱（无对称性假设） |
| D 2D 生产算子大网格趋势 | 同 C | 质量内积 Lanczos（`<u,v>_M`）40 步取极端 Ritz 值 |
| E 端到端实证 | 同 C | 直接对 `rhs` 做 RK4，二分「模态范数增长指数」过零点得 `dt_max` |

积分器稳定区间（本单重算，外部锚 = 经典 RK4 负实轴区间 2.785293563405282）：`z_RK4 = 2.785293563405280`（与文献相对差 6.378e-16）、`z_SSPRK3 = 2.512745326618329`。

## ⑤ 注意点

1. **生产 2D 算子不是严格对称的 SIPG**：对 `rhs` 逐向量探测出的稠密矩阵在质量内积下对称破缺 0.048（p=2, 4×4），周期边界同样 0.032，说明破缺来自内部面装配而非边界；因此 **只可用稠密探测（C）或幂迭代/实证（E）** 给生产算子的谱负责，Lanczos（D）仅作网格趋势参考，其正侧 Ritz 值是伪值（算子实际 `max Re λ` 见 3.2 表，量级 ~1e-4 相对）。
2. 生产算子（`extrapolate` 边界面，无边界罚项）的谱半径**大于**同阶 Dirichlet 装配谱（p=1：23.8668 vs 20.8183），所以用生产算子定安全系数是保守的一侧。
3. 只覆盖**线性常系数扩散 + SIPG 面通量 + 无 limiter**。NS 的粘性算子含速度—速度交叉耦合（BR1），其谱是复数集，本单的「负实轴区间」判据是近似；激波/正性滤波路径不能外推。
4. `c(p)` 随网格变化：粗网格（4×4）偏低 4–6%，报告一律取 N=16 的生产值；`penalty` 变化会整体平移 `c`，本单只测了代码默认的 `α=2(p+1)²`。
5. 实证二分的分辨率限制在阈值附近（增长指数在 `dt_max` 处二次平坦），最大相对差 6.94%（p=2, N=8），其余 <1%。

| 1D 谱 `h`-无关性（p=2，N=16 vs N=32） | — | 0.274% | 是 |

| 生产稠密谱 vs Lanczos（p=2，4×4） | Lanczos | 1.427% | 是 |
| 实证 `dt_max` vs 预测（逐行，E vs D） | 预测 | 最大 6.94% | 见 3.5（最大行 >3%，原因=近阈值二分分辨率） |
| 代码常数 50 vs 实测 `c(p)`（p=0..3） | 50 | -84.2% … +54.0% | **否** |

**结论（诚实版）**：

- `advection_diffusion` 的步长规则**安全但常数不对**：实测 `c` 从 p=0 的 7.9231 变化到 p=3 的 76.9941，单值常数 50 只在 p≈2 附近成立（p=0 偏差 -84.2%，p=3 +54.0%）。多出来的 `0.5` 因子充当了补偿：安全倍数从 p=0 的 12.6× 降到 p=3 的 1.30× —— **p=3 已是薄边**，若将来放开 p=4 必须换成 `c(p)` 表。
- `ns_dg_2d` 的 `S_max` 实测 0.159–0.261，**下界低于代码注释声称的 0.3**；但 `VISCOUS_STABILITY = 0.1` 仍把裕度保持在 1.59× 以上（不是注释说的 3–5×）。
- 两条规则都**没有失效**（安全倍数 > 1），本单不改数值行为，改的是注释/文档与一条有牙的回归门（`tests/test_sipg_explicit_stability.py`：未来若放开阶数或调整常数，安全倍数 <1 会直接测试失败）。
