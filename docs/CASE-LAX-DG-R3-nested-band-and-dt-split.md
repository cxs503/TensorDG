## ② 怎么做的

模态 DG（Legendre 基）+ HLLC 通量 + SSP-RK3，位置与星区量在每单元 10 点 Gauss 节点上重建；生产 CFL = 0.35。两项改动：

1. **R3 区域规则换轨**：解析区遮罩由 `4·dx` 改为固定物理半宽 `0.02`。理由：`dx` 缩放的带宽随加密变窄，区域在相邻两腿之间**不是同一个区域**（m16606 实测保留测度 +35.3 %）。旧规则（`4.0·dx`）保留在同一批解上并行测量（`diagnostics.r3_legacy_band`），判据变更全程留痕。
2. **时间误差分离**（m16606 F5 未运行项）：网格固定，只把 `dt` 按 CFL/1→CFL/2→CFL/4 细化三次。模型 `E(dt) = E0 + C·dt^q` 在三次**精确对折**下有闭式解 `q = log2((E1-E2)/(E2-E3))`，于是「时间项占基线 CFL 误差的份额」可算而不是估。预登记上限 `0.05`（超过即判定战线被 dt 污染）。

## ⑤ 注意点（坑 / 局限 / 适用范围）

- **换轨改了子判决，没改总判定**：旧规则下 P1 的密解析区阶被区域几何漂移压到 0.169；固定带下同一批解给出 2.696（需求 1.700）。P1 子判决因此翻转，但 P2/P3 在四套规则下都不达设计阶——**整体 honest-FAIL 保留**，不得用本文把锚点翻成 verified。
- P2/P3 的解析区阶仍受 TVB 限幅器 + 间断耗散层支配，这是方法属性；把 N 上限推高或换 WENO 限幅器才有望抬阶，属另一张单。
- 旧 4·dx 规则在新版里保留为 `diagnostics.r3_legacy_band`，并有测试锁死它「不嵌套」这一特征（`test_r3_region_rule_is_nested_across_the_ladder`）：一旦它变嵌套，测试即红，提醒复核这条判据变更的理由。
- 时间研究只覆盖 3 条腿、2 次对折；它给的是**基线 CFL 下时间项份额的上界估计**，不是全阶梯的时间阶认证。
- 未做项：与第三方 DG/FV 实现交叉；x86 CI 上逐位复核（本机 loong64）；求积点数敏感性（10 点 Gauss）。这些仍是 unknown，不当作 passed。
- 工件位置变更：`runs/` 在合并门禁里不进 `main`，本算例工件已改落 `docs/benchmarks/results/lax_case_pool/`（与 `lax_region_band` 同规），工件级测试由 skip 改为硬断言（缺失即红），空转普查里该模块不再 VACUOUS。
