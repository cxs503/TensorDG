# REPRO-DG-CKS1998 · CKS1998 §5.3 二维等熵涡旋设计阶验证

## 案例介绍

**物理背景**: Cockburn & Shu (JCP 141, 1998, "V: multidimensional systems") §5.3 的二维 Euler 方程光滑解精度测试。等熵涡旋是二维 Euler 方程组的经典解析解，用于验证 RKDG 格式在多维系统下的设计收敛阶。

**几何与参数**:
- 计算域: `[-5, 5]²`，周期边界
- 涡旋强度: β = 5
- 背景流: u∞ = v∞ = 1, ρ∞ = 1, p∞ = 1
- 终止时间: t = 1.0
- CFL = 0.2, SSP-RK3 时间积分

**解析解**:
```
ρ(x,y,t) = [1 - (γ-1)β²/(8γπ²) exp(1-r²)]^{1/(γ-1)}
u(x,y,t) = 1 - β/(2π) exp(0.5(1-r²)) (y-y₀-vt)
v(x,y,t) = 1 + β/(2π) exp(0.5(1-r²)) (x-x₀-ut)
p(x,y,t) = ρ^γ
```
其中 r² = (x-x₀-ut)² + (y-y₀-vt)²，γ = 1.4。

## 方法

**求解器**: `tensordg.euler_dg_2d.solve_euler_dg_2d` — 二维模态 DG，HLLC 通量，SSP-RK3 时间推进。

**误差度量**: 在张量 Gauss 节点上计算：
- L1 绝对误差: ∫|ρ_h - ρ_exact| dx dy
- L1 相对误差: L1 / ∫|ρ_exact| dx dy
- L∞ 误差: max|ρ_h - ρ_exact|

**收敛阶**: 相邻网格的观测阶 EOC = log(err_coarse/err_fine) / log(h_coarse/h_fine)

**判据**: Cockburn-Shu 容差 — 观测阶 ≥ p + 0.5（比设计阶 p+1 更宽松）

## 注意点

1. **P³ 的 L∞ 阶 (4.18) 略超设计阶 4**: 这在 DG 方法中是可能的，因为 L∞ 误差在某些情况下会表现出超收敛行为。

2. **P² 的 L∞ 阶 (2.58) 略低于设计阶 3**: 这可能是因为 SSP-RK3 的时间积分阶为 3，在较粗网格上时间误差开始影响 L∞ 误差的收敛。但 L1 阶 (2.92) 仍然接近设计阶。

3. **与 `design_order_euler_dg_2d.py` 的关系**: 该基准使用相同的解析解，但报告的是相对 L2 误差。本基准补充了论文格式的 L1 和 L∞ 误差，使 CKS1998 锚点的证据更完整。

4. **计算成本**: P³ 16×16 网格约 16 秒，全扫描约 2 分钟（单线程）。
