**Intended behavior**:
- 1D periodic linear advection u_t + u_x = 0, u(x,0) = sin(2πx), t=1
- 2D periodic linear advection, u(x,y,0) = 1 + sin(2πx)sin(2πy), t=0.5
- Verify observed convergence rate = p+1 for degrees p=1,2,3,4 (1D) and p=1,2 (2D)
- All rates within 3% of theoretical
- Tests must run the actual solver (not just read artifacts)

### F4: Incorrect error computation (m20026 issue: compared against initial field)
**Status**: ✓ FIXED. Uses `l2_error()` which compares against exact solution at time t.

### F5: Cross-code reference comparison
**Status**: ⚠ NOTE. The m20176 case verifies against theoretical p+1 order only. The separate benchmark `benchmarks/case_dg_advect_order.py` compares against Zheng Sun (2024) external reference, but that case has known failures (R2/R6 RK4 cap falsified, R3 mis-specified). ### F6: P4 order degradation at finest mesh
**Status**: ⚠ NOTE. P4 observed order drops to 4.79 at N=320 (expected 5.0). This is likely float64 round-off floor (error ~3.7e-14). The average order 4.93 is still within 3%. This is expected behavior, not a defect.
