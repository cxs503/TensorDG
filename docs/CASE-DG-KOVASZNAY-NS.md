# CASE-DG-KOVASZNAY-NS：定常 Navier–Stokes 的 DG 离散验证（Kovasznay 精确解）

> 本报告的每个数字均由 `benchmarks/verify_kovasznay_dg_2d.py` 写入 `validation/kovasznay/*.json`，再由 `tools/gen_case_kovasznay_report.py` 程序化注入，无手抄。未跑的配置如实标注「未跑」，不以缺失冒充通过。

## ① 问题设定与基准出处

定常不可压 Navier–Stokes 方程在二维只有一个已知的非平行精确解：Kovasznay (1948) 的衰减涡列叠加均匀来流。设流向为 x、涡波数 k、

```
lam = (Re - sqrt(Re^2 + 4 k^2)) / 2            （衰减率，Re=1/nu）
u   = 1 - exp(lam x) cos(k y)
v   = (lam / k) exp(lam x) sin(k y)
p   = p_ref - exp(2 lam x) / 2                 （密度 = 1）
```

该闭式解精确满足 u u_x + v u_y = -p_x + nu ∇²u、v 方向同类方程与 u_x + v_y = 0。

**出处**：L. I. G. Kovasznay, *Laminar flow behind a two-dimensional grid*, Proc. Cambridge Philos. Soc. **44** (1948) 58–62（闭式解原始文献）；格式与算例设定的次级参考：F. Bassi, S. Rebay, *A high-order accurate discontinuous finite element method for the numerical solution of the compressible Navier–Stokes equations*, J. Comput. Phys. **131** (1997) 267–279, DOI 10.1006/jcph.1996.5572。

**目标数值的取得方式（零手抄）**：本算例的 ref 不是文献表格里抄来的数，而是上面闭式解在求积节点上的**程序求值**；闭式解本身先被三条独立残差校核为真解（表 0）。因此不存在「抄错表」的风险面，同时也没有「文献给定了 Re=40、k=2π、24×24 下速度 L2 误差应等于多少」这类可对照的文献数字——本报告不对文献数值做逐位比对，而是用闭式解 + 网格/阶数/马赫数收敛三面交叉验证。

| 项目 | 取值 |
|---|---|
| 计算域 | x ∈ [-0.5, 1]，y ∈ [-0.5, 1.5]（k=2π 时正好 2 个周期）|
| 边界 | 流向两端给解析状态（HLLC 迎风 + Dirichlet 黏性罚），y 方向周期 |
| 雷诺数 | Re = 40（ν = 1/Re = 0.025）|
| DG 阶数 | k = 3（三次，模态 Legendre，张量积）|
| 网格 | 24 × 24 |
| 验收容差 | 速度相对 L2 误差 < 1 % |

**关于「k=3」的口径**：算例卡写 “Re=40, k=3, 网格 24x24”。在 DG 语境下 k 通常指多项式阶数，本报告以 **k=3 = 三次 DG（P3）** 为门禁配置；同时把 Kovasznay 公式里的涡波数 k 作为另一读法跑了 k=3（`wavenumber3`）的变体，两种读法都在表 1 中给出，不是二选一。

## ② 方法与实现

复用 TensorDG 已有的可压 Navier–Stokes DG 模块（`tensordg/ns_dg_2d.py`，张量积模态 Legendre 基 + HLLC 无粘通量 + BR1/SIPG 黏性通量 + SSP-RK3 显式推进），不另起炉灶；本算例新增两层：

1. **通流边界**：原模块的边界只有「无质量通量的不透壁」一种（wall dict 的无粘部分为 `[0, p, 0, 0]`），流入端会被当成固壁。这里给边界字典加一个可选 `"state"` 项，把无粘通量换成「给定鬼状态 ↔ 内部迹线」的 HLLC 通量，黏性部分继续用 Dirichlet 罚（`tensordg/ns_dg_2d.py::_boundary_flux`，向后兼容：无 `"state"` 时逐位不变，原有 6 个 ns_dg_2d 测试全绿）。
2. **不可压极限嵌入**：可压求解器没有「不可压」开关，因此把不可压解嵌入低马赫数：热力学压力取 p = p0 + p_dyn（p0 = c²/γ），密度保持 ρ0，使密度变化为 O(M²)。马赫数 M = max|u| / c 于是成为**离散化参数**，可被扫描（§⑤）。

| 组件 | 位置 |
|---|---|
| 闭式解 / 残差自校核 / 误差度量 / 驱动 | `tensordg/kovasznay.py` |
| 通流边界（新能力）| `tensordg/ns_dg_2d.py::_boundary_flux`（`"state"` 分支）|
| 算例驱动与工件 | `benchmarks/verify_kovasznay_dg_2d.py` → `validation/kovasznay/*.json` |
| 判据测试 | `tests/test_kovasznay_dg_2d.py`（8 项）|
| 一键复现 | `PYTHONPATH=. python -m benchmarks.verify_kovasznay_dg_2d --job primary` |

推进方式：以解析解为初场，显式推进到离散定常态（分块重启，重启经由模态求值器重投影，实测无损到 1e-13，见 `tests/test_kovasznay_dg_2d.py::test_modal_restart_is_lossless`）。每个分块记录相对 L2 误差与定常残差（模态 2-范数比），用于判定「是否已到定常」。

## ⑥ 失败模式、局限与工件

**已识别的失败模式 / 局限**

1. **定常残差不归零（声学振荡）**：以给定状态做出口时，亚声速出口仍有部分反射，残差在声学周期 2L/c ≈ 0.1 上振荡而不单调衰减（见 §5.4 表与 `docs/figures/kovasznay_steady_state.png`）。因此本算例判定「定常」用的是**误差平台 + 残差量级**，不是「残差 → 机器零」。
2. **误差下限由可压嵌入决定**：速度误差的绝对下限是 O(M²) 的密度扰动项；P3/24² 的 DG 离散误差（~1e-5）远低于该下限，所以本门禁真正检验的是「低马赫极限 + 通流边界 + 黏性算子」的组合，而不是纯 DG 插值精度。这也是把马赫数扫描写进报告的动因。
3. **k=3 的两种读法**：算例卡的 k 既可读作 DG 阶数也可读作涡波数，两者都给了，见 §① 与表 1；若算例池的本意是第三种含义（例如网格加密因子），本报告未覆盖。
4. **文献数值不逐位比对**：本算例的 ref 是闭式解（已被残差校核），Bassi & Rebay 1997 只作为格式/设定的次级出处；没有从该文抄录任何误差数字，因此也不存在与文献表格的逐位比对。
5. **单机单线程**：全部算例在控制面单线程跑（每步约 0.23 s，开销主导而非浮点），集群队列当时排队 411 个作业，重计算未能按规程上集群——已如实记为生态摩擦。
