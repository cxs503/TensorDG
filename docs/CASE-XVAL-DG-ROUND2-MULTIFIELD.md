# CASE-XVAL-DG-ROUND2-MULTIFIELD - 认证参考的多场扩展

> 锚点：`XVAL-DG-ROUND2-CERTIFIED-REFERENCE`（feature_ledger，acceptance <15%）
> 引擎新增：`benchmarks/xval_dg_round2_multifield.py`；测试：`tests/test_xval_dg_round2_multifield.py`
> 产物：`validation/xval_dg_round2/artifacts/multifield_audit.{json,md}` + 2 PNG
> 本文件由 `validation/xval_dg_round2/gen_multifield_report.py` 从审计 JSON 程序化生成，零手抄。

## 1. 案例介绍

Shu-Osher 激波/熵波相互作用（Shu & Osher 1988, JCP 77:439）的一维 Euler 系统，γ = 1.4，计算域 x ∈ [-5, 5]，t = 1.8，Mach-3 激波扫过静止的熵波。round-2 认证参考（`XVAL-DG-ROUND2-CERTIFIED-REFERENCE`）只认证了 **密度 ρ**，并据此把 11 条 DG 腿判为「< 3%」。但一篇系统守恒律的验证结论若只覆盖 ρ，对动量与能量是不成立的隐式外推：限制器可以在 ρ 上合格、在 ρu 上不合格。本单把认证与门限扩展到**全部三支守恒场**（ρ, ρu, ρE）与两个派生量（u, p），且不改动 round-2 引擎与其工件。

| 项 | 值 |
|---|---|
| 参考梯次（FV-WENO5/HLLC/SSP-RK3，CFL 0.3） | N = 800 / 1600 / 3200（认证参考落在 N=1600 网格） |
| DG 腿 | 11 条：P1/P2/P3 × N=200/400/800 @ CFL 0.4，外加 P2 N=400 @ CFL 0.1/0.2 |
| 认证工具 | `tensordg.certified_reference.certify`（Roache GCI, Fs=1.25，三拒绝规则） |
| 门限（源码内预声明） | gate 5.0%，strict 3.0%，oracle 1.0%，budget 0.01% |
| 派生量带宽规则 | 加性（三角不等式，保守）：additive(u=['rho_u', 'rho'], p=['rho_e', 'rho_u', 'rho']) |

## 2. 怎么做（方法/流程/关键设置）

1. **逐场独立认证**：对 ρ、ρu、ρE 各自在同一 FV 梯次上跑 `certify()`，得到各自的观测阶 p 与 GCI 带 U（不是把密度带复用给其他场）。
2. **派生量的带**：`u = ρu/ρ`、`p = (γ-1)(ρE - (ρu)²/(2ρ))` 由多个场合成，因此带按**加性规则**给出（源带求和），规则写死在源码 `BAND_RULE` 里，不允许在看到结果后改规则。
3. **门限扩展**：用 `judge()` 在 strict 3% 下逐腿逐场判 PASS/PASS_MARGINAL/FAIL（判据 `err + U < τ` 才算可分辨的 PASS），共 11 × 5 = 55 次比较。
4. **闭式 Oracle 扩展**：除密度平台值外，还检查平台 u = 2.629369、p = 10.33333，以及熵波后未扰动区的 u ≡ 0、p ≡ 1（精确）。
5. **新增两个守恒预算**：动量预算 `dP/dt = (ρ_L u_L² + p_L) - p_R`（出口 u_R=0，压力项仍然作用）、能量预算 `dE/dt = (E_L + p_L) u_L`。两者都是本算例的闭式结果，且比质量预算更狠：它们带着强通量项。质量行还与案例模块`tensordg.cases.shock_entropy.exact_mass_budget` 交叉校验。
6. **诊断（不设门）**：每条腿密度误差在激波带（|x-x_shock| ≤ 0.3）内的占比，以及「密度门对其他量是否忠实代理」的比值 MF6。

## 5. 注意点（坑/局限/适用范围）

1. **场的观测阶不同**（ρ: 1.2825，ρu: 1.3132，ρE: 1.3013），所以不能把密度带当作通用带：派生量的带必须显式传播。加性规则下 u、p 的带仍只占 3% 门的 5.4%~6.8%。
2. **P3 非单调（如实记录）**：N=800 上 P3 的 ρ 误差 0.670% 反而大于 P2 的 0.567%，ρu 上 0.794% vs 0.585%。这是 WENO 限制器对高阶模态的截断效应，不是参考噪声（同一参考下 P1/P2 严格单调）。它不改变 3% 门判决，但说明「高阶=更准」在本算例的激波区不成立。
3. **同族认证的局限**：五个量都在同一个 FV-WENO5 家族的梯次上认证，只能界定**网格误差**，界定不了该离散格式的系统性偏差。独立内容是 MF4/MF5（闭式解与 Rankine-Hugoniot 骨架），以及三个场观测阶彼此不同这一事实（共模重构缺陷会让它们同步移动）。
4. **预算闭式性的前提**：动量/能量预算依赖「所有波向右传播、出口面 u_R = 0」这一本算例几何；换终态时间或边界条件必须重推，不能照抄。
5. **派生量不是独立证据**：u、p 由同一批守恒场算出，误差高度相关，所以 MF3 里 u/p 误差小并不额外说明求解器更好，只说明误差集中在 ρu/ρE 上。

## 6. 误差判定（是否 < 3%）

| 关键量 | 基准 | 测量值 | 误差 | < 3% ? |
|---|---|---|---|---|
| 最坏腿（rho_u @ DG P1 N=200 CFL=0.4） | 3% 门 | 2.4895% | — | **yes** |
| ρu 最坏腿 | 3% 门 | 2.4895% | — | **yes** |
| ρE 最坏腿 | 3% 门 | 1.1804% | — | **yes** |
| 平台 ρ vs Hugoniot | 3.857143 | 3.857143 | 1.23e-10 | **yes** |
| 平台 u vs Hugoniot | 2.629369 | 2.629369 | 9.41e-11 | **yes** |
| 平台 p vs Hugoniot | 10.33333 | 10.333330 | 1.72e-10 | **yes** |
| 质量预算 | 31.089152189 | 31.089152449 | 8.35e-07 | **yes** |
| 动量预算 | 74.941855587 | 74.941855587 | 2.99e-11 | **yes** |
| 能量预算 | 295.943395913 | 295.943395913 | 3.02e-11 | **yes** |

**判定**：55/55 组腿×场在严格 3% 门下可分辨地 PASS；最坏 rho_u @ DG P1 N=200 CFL=0.4 为 2.4895%（裕度 0.5105 个百分点）。
参考自身的带 U 在 3% 门下占比最大的是 `rho` = 0.0276，远低于 1/3 的空洞性上限，因此门限不空洞（vacuity 规则成立）。全部关键量 vs 基准误差远小于 3%。

**诚实声明**：`accepted = True`，但 MF6 的 `rho_only_gate_conservative = False` —— 即「只测密度」这一做法对 ρu 略偏乐观（最大比值 1.1848，出现在 DG P3 N=800 CFL=0.4）。round-2 的 <3% 判决本身成立，但其**证据范围**原先只覆盖 ρ，本单把它补齐到五个量。
