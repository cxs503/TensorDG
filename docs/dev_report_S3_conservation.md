## 1. 案例介绍

物理背景：一维 Euler 方程组（γ = 1.4）的 Sod 激波管，初值

| 参数 | 左态 (x < 0.5) | 右态 (x > 0.5) |
|---|---:|---:|
| ρ | 1.0 | 0.125 |
| u | 0.0 | 0.0 |
| p | 1.0 | 0.1 |
| 域 | [0, 1]，透射（transmissive）端点 | |
| 终止时刻 | t = 0.2 | |
| 全局积分初值 | M = 0.562500, P = 0.000000, E = 1.375000 | |

选 t = 0.2 的原因是**可验证性**：此时最快特征线（稀疏波头，速度 u−c = −1.183）只到
x = 0.2634，激波只到 x = 0.8504，全部波系仍在域内，
因此端点状态恒等于初值 —— 这使全局守恒律可**解析积分**，得到不依赖任何数值格式的判据
`∫U(t) − ∫U(0) = t·(F(U_L) − F(U_R))`：

| 守恒量 | 解析增量 @ t = 0.2 |
|---|---:|
| 质量 | 0.000000e+00 |
| 动量 | 0.1800000000 |
| 总能 | 0.000000e+00 |

解析星态（`benchmarks/riemann_exact.py`，精确 Riemann 解）：
p* = 0.303130, u* = 0.927453, ρ*_R = 0.265574，
Rankine–Hugoniot 激波速度 W = 1.752156。

周期算例：线性对流 u_t + u_x = 0（u₀ = sin 2πx）、Burgers u_t + (u²/2)_x = 0（u₀ = 0.2 + 0.8 sin 2πx），
1-D 使用模态 Legendre DG + 迎风/Rusanov 通量，2-D 使用张量积 DG，时间推进 RK4 / SSP-RK3。

## 2. 怎么做的

新增三件工件（均在白名单内）：

| 文件 | 作用 |
|---|---|
| `tests/_conservation_tools.py` | 测量库：模态 P₀ 单元均值积分、标度漂移、Euler 守恒总量、解析边界通量预算、Rankine–Hugoniot 速度、激波位置传感器、log–log 阶估计、dt 自收敛差 |
| `tests/conservation_study.py` | 六组研究（周期不变量 / 边界预算 / RH 激波速度 / 离散激波尾部 / 场误差 / 时间阶）+ 17 条机器判据 + 自动产出 metrics.json、CSV、PNG、summary.md |
| `tests/test_conservation.py` | 18 条 pytest 判据；**先自检估计器**（合成序列、解析星态、传感器在精确解上的偏差），再用它判求解器 |

方法要点（都是"先造判据再动手"）：

1. **离散不变量**：模态基下 k=0 系数即单元均值，故 `h·Σū` 是离散积分（不是重构后的点值）。
   守恒量漂移必须停在 float64 舍入水平，且**不随加密增长**。
   零均值数据（sin）必须显式给标度（离散 L1 范数），否则 `|ΔM|/max|M|` 会把舍入放大成 100% 假漂移。
2. **边界通量预算**：解析预测 vs 实测增量，并把两个"竞争假设"（反射壁 ΔP = 0、丢端点面）一起打分，证明判据有区分力。
3. **Lax–Wendroff 弱解判据**：激波位置由密度在 `(ρ*+ρ_R)/2` 的线性插值过零确定；
   **先在精确解上标定传感器**（偏差 1.18e-05，否则会把传感器偏差误判成求解器误差），
   再对 4 个时刻最小二乘拟合 x_s(t)，与 RH 速度比。
4. **时间阶**：固定网格、只改 dt，用相邻两解的相对差做**自收敛**，空间误差自动抵消，得到纯时间阶。
5. **离散激波尾部**：在无物理信号的窗口测量残余，并用"同 dx 双倍域"对照实验排除边界闭环的影响。

## 5. 注意点（踩过的坑）

1. **零均值不变量不能自标度**。sin(2πx) 的离散质量 ~1e-17，用 `|ΔM|/max|M|` 会报"100% 漂移"。
   必须显式传离散 L1 范数作标度（`scaled_drift(history, scale=...)`）。第一次跑就踩了。
2. **粗网格上"不守恒"是假象**。200 cells 时质量漂移 ~1e-9，看起来像通量漏项；实际是离散激波尾部
   伸到了最后一个单元，边界确实有真实的数值流出。用"同 dx 双倍域"对照实验（§3.6）证伪了"边界缺陷"假设：
   双倍域数值一模一样。所以舍入级断言必须 `ncells ≥ 400`。
3. **传感器必须先标定**。过零插值在激波抹平 1 个单元时天然有 ~1e-5 的偏差；不先在精确解上量这个偏差，
   就会把传感器偏差算成求解器误差。
4. **时间阶不能用"对精确解的误差"**。空间误差地板会把 4 阶压成平台；只有同网格 dt 自收敛才是纯时间阶。
5. **3% 门只对文档分辨率成立**。`--quick` 冒烟用 400–800 cells，`sod_field_error_vs_exact` 会如实 FAIL（1600 cells 速度场 3.54%）；
   因此 quick 模式默认不写工件，避免冒烟跑覆盖 full 模式的入库数字。
6. **CPU 争用**：机器 load ~200（128 核），完整研究 ~5 min；容器工具单次调用 2 min 超时，
   因此所有长任务用 `setsid` 后台跑 + 日志轮询。

## 6. 误差判定（逐项，显式回答是否 < 3%）

| 关键量 | 基准/参考值 | 实测 | 相对误差 | 是否 < 3% |
|---|---:|---:|---:|:--:|
| Sod 激波速度 W vs Rankine–Hugoniot 解析值 | 1.752156 | 1.752251 | 0.0054% | 是 |
| Sod 激波速度（最粗网格 400 cells） | 1.752156 | 1.752946 | 0.0451% | 是 |
| 动量增量 vs 解析边界预算 t(p_L-p_R) | 0.1800000000 | 0.1800000000 | 5.535695e-12% | 是 |
| 质量积分漂移（相对初值，最坏） | 0 | 4.204e-12% | 4.204e-12% | 是 |
| 总能积分漂移（相对初值，最坏） | 0 | 4.021e-12% | 4.021e-12% | 是 |
| 密度场 vs 精确 Riemann 解（最细网格） | 解析解 | 1.1844% | 1.1844% | 是 |
| 速度场 vs 精确 Riemann 解（最细网格） | 解析解 | 2.8869% | 2.8869% | 是 |
| 压力场 vs 精确 Riemann 解（最细网格） | 解析解 | 0.7480% | 0.7480% | 是 |
| 时间离散阶 RK4（理论 4） | 4 | 4.000 | 0.000% | 是 |
| 时间离散阶 SSP-RK3（理论 3） | 3 | 2.994 | 0.202% | 是 |

结论：**全部关键量 vs 基准（解析 RH 速度、解析边界预算、精确 Riemann 场、RK 理论阶）相对误差均 < 3%**，
多数在 1e-2% 以下；舍入级判据（质量/能量漂移）在 1e-14 量级，比阈值 1e-12 低两个量级。

三点必须如实说明，不给余量打掩护：

1. 速度场是**最紧的一项**：3200 cells 时 2.8869%，距 3% 门只剩 0.11 个百分点；
   1600 cells 时为 3.5440%，**超过 3%**——
   即 3% 门只在 README 文档所述的分辨率（3200 cells，P0 一阶格式）成立，粗网格不成立。
2. 本单的场误差口径是**单元中心点值**对精确解逐点比较；`benchmarks/compare_euler_sod_1d.py` 用的是单元平均口径，
   同一算例给出 2.5177%。两者差 0.369 个百分点，来自抹平激波上的点值采样惩罚，不是求解差异。
3. 质量/能量"漂移"是相对初值的百分比，最坏 4.20e-14（质量）/ 4.02e-14（能量），已到 float64 舍入噪声地板，不能更小。
没有需要在报告里做 honest-FAIL 粉饰的项 —— 唯一"红"的是初版判据 `far_field_contamination`（把粗网格尾部当边界缺陷），
已通过对照实验修正判据本身，过程留在本节第 2 条，不隐藏。
