# CKS1998 二维 Riemann 算例：对角对称线上的**精确解**参考（验证欠账闭合）

> 锚点：`REPRO-DG-CKS1998`（Cockburn & Shu, *JCP* 141 (1998) 199–224 / *SIAM Review* 43(1) 2001），
> 验收原文「quantitative_targets 逐项容差」。本单 m23006（自找活·generalist 席，model deepseek-v4-flash）。
> 代码：`validation/repro_cks1998/riemann2d_diagonal.py`；回归门：`tests/test_riemann2d_diagonal_reference.py`（6 条，全绿）；
> 机器记录：`validation/repro_cks1998/artifacts/riemann2d_diagonal/*.json`（程序化写出，本文数字全部来自它们）。

## ① 案例介绍

四象限二维 Riemann 问题（Lax & Liu 1998, Config 3）是 CKS1998 把 RKDG 推广到多维系统的代表算例，
`solver = tensordg.euler_dg_2d.solve_euler_dg_2d_riemann`（HLLC + SSP-RK3 + TVB），
仓内既有验证（`docs/CASE-DG-CKS1998-2D-RIEMANN.md`、`tests/test_riemann_2d_cks1998.py`）**只能做结构性门**
（有限性 / 守恒漂移 / 正性 / 发散集成），因为该算例**没有闭式解**。

| 象限 | ρ | u | v | p |
|---|---:|---:|---:|---:|
| LL (x<.5,y<.5) | 0.138 | 1.206 | 1.206 | 0.3 |
| LR | 0.5323 | 0.0 | 1.206 | 0.3 |
| UL | 0.5323 | 1.206 | 0.0 | 0.3 |
| UR | 1.5 | 0.0 | 0.0 | 1.5 |

γ = 1.4；域 [0,1]²；透射边界；`t = 0.1`（本文的定量档），`cfl = 0.2`，P1，N = 32。

**关键结构性质**：该初值关于对角线 `y = x` **对称**（交换 x↔y 并交换 u↔v 后逐象限不变）。
旋转到 `X = (x+y-1)/√2, Y = (y-x)/√2` 后，ρ, p, u_X 是 Y 的偶函数、u_Y 是奇函数，于是

- 连续/能量方程在 Y=0 上的 `∂_Y(ρ u_Y)`、`∂_Y(u_Y(E+p))` 项 = 奇函数在 0 处的导数 = 0；
- X 动量方程同理；Y 动量方程中 `∂_Y(ρ u_Y² + p) = 0`（偶函数）且 `u_Y(0) = 0`。

⇒ **限制在对角线上的二维解精确满足一维 Euler 方程**，初值只有两个状态（LL 与 UR 在法向的投影）：

| | ρ | u_n | p |
|---|---:|---:|---:|
| 左（X<0, LL） | 0.138 | 1.70554 = (1.206+1.206)/√2 | 0.3 |
| 右（X>0, UR） | 1.5 | 0 | 1.5 |

因此对角线上的二维解 = 这两个状态的**一维 Riemann 精确解**（自变量 `ξ = X/t`），参考值由
`benchmarks.riemann_exact`（Toro 三波精确求解器，独立于 DG）给出。**这不是高分辨率自比，也不是拟合。**

解的波系结构（`benchmarks.riemann_exact` 精确解，程序化注入）：

| 量 | 值 |
|---|---:|
| 左行激波速 s | −1.53670 |
| 接触速 u* | −0.21408 |
| 右侧稀疏扇尾 u*+a* | 0.92632 |
| 右侧稀疏扇头 u_r+a_r | 1.18322 |
| 星区压力 p* | 1.15889 |

## ② 怎么做的

1. **沿对角线逐点求值**：对角单元 `(i,i)` 内取 `degree+2` 个 Gauss 点，`(ξ_j, ξ_j)` 映射到物理点
   `x = y = (i + (ξ_j+1)/2) h`（严格落在 y=x 上）；DG 解在该点由模态系数逐点求值
   `Σ_mn c_mn P_m(ξ_j) P_n(ξ_j)`（与求解器同一套原始 Legendre 基）。
   回归门 `test_diagonal_pointwise_evaluation_matches_the_modal_polynomial` 用**合成的随机系数**
   验证求值器与直接多项式求值逐位一致（max diff = 0.0）。
2. **同一批点取参考**：`ξ = X/t`，`benchmarks.riemann_exact.sample` 给精确 ρ, u, p。
3. **三个度量**（先定后跑，见模块常量）：
   - `diag_rho_l1_rel`：整条对角线的相对 L1（远场样本多，会把误差稀释——仅作披露）；
   - `diag_rho_l1_wave`：**波区**相对 L1，窗口 = [最左波 − 0.5, 最右波 + 0.5]（`WAVE_MARGIN = 0.5` 先写定）；
   - `diag_rho_l1_smooth`：剔除各波位置 ±2h_ξ 窗口后的光滑区 L1（h_ξ = √2 h/t 是对角线方向的单元跨度）。
4. **台站**由精确解自己的波系结构定义（`station_positions`：星区平台中点、稀疏扇中点），
   不手挑坐标；换初值时台站跟着走。
5. **否证实验**：另跑一个**破坏 y=x 对称**的初值（LL 的 v 取反号 ⇒ 对角附近横向剪切 u_Y = −1.706），
   用"它自己的法向状态"作参考跑同一判据——若判据对前提不敏感（空门），这个实验会照样"通过"。

## ⑤ 注意点 / 局限 / 适用范围

1. **稀疏扇极薄**：该组状态下右波稀疏扇只占 ξ ∈ [0.926, 1.183]（宽 0.257），N=32/t=0.1 时
   h_ξ = √2·h/t ≈ 0.44 —— 一个单元就跨整个扇，`fan_mid` 的 9.3 % 主要是分辨率，不是格式缺陷。
2. **星区平台同样薄**：左侧平台 ξ ∈ (−1.537, −0.214)（宽 1.32）只容 ~3 个采样点，`star_right`
   的 24.2 % 是"平台被两侧波面抹平侵蚀"，随 N 增大会下降（见 ⑥ 的验证方式）。
3. **本文只做到 N=32（本机 <120 s 限制）**：细化档（N=40/64/88, t=0.2）已递交集群
   `cj4528`、`cj4529`，递交时刻仍在排队（队列 70+）；**本文件不写未回的数字**。
4. **沿一条线采样无法还原二维单元均值**（对角 Gauss 点集不是二维求积规则），故本判据的口径是
   **点值沿对角线** vs 精确点值；这也是唯一没有"口径差"的比较方式（已写进模块与测试注释）。
5. **适用范围**：参考的正确性依赖两个前提——(i) 初值关于 y=x 对称；(ii) 边界条件的处理保持该对称
   （透射边界逐边对称，满足）。**对不对称初值该参考无效**，正则的否证实验量化了这一点。
   三叉点轨迹、马赫杆高度等"看图形"的量仍未定量，不做断言。
6. 判据在该分辨率下**不能**充当"3 % 精度门"（见 ⑥），它的作用是：把一条只有结构性门的二维算例
   变成**有解析参考、可被否证**的定量判据。

## ⑥ 误差判定（显式回答「是否 < 3 %」）

| 关键量 | 基准 | 误差 | < 3 %？ |
|---|---|---:|---|
| 对称残差 | 0（精确对称） | 3.20e−15 | **是**（机器精度） |
| 远场/光滑区 ρ | 一维精确 Riemann 解 | 0.021 % | **是** |
| 波区 ρ（含激波/接触） | 一维精确 Riemann 解 | 18.277 % | **否** |
| 台站 star_left / star_right / fan_mid | 一维精确 Riemann 解 | 9.96 / 24.17 / 9.28 % | **否** |
| 否证实验（波区） | 一维精确 Riemann 解 | 26.13 % | **否（本应否）** |

**结论（honest）**：本判据在 N=32/t=0.1 上**不是** 3 % 精度门 —— 波区 18.3 %、最差台站 24.2 %，
原因是激波/接触在 32 单元上被抹到 2–3 个单元、而波区在 ξ 方向只占 25 个采样点。
它成立的是**参考正确性**（远场 0.021 %、对称残差 1e−15、否证实验有效），
而不是"DG 解在二维 Riemann 上已达 3 % 精度"。后者需要细化档（`cj4528`/`cj4529`）
加"波区 L1 随 N 至少 N^-0.5 下降"的收敛门 —— 该门**尚未**给出，不在此处假装。
