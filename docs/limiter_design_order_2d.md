# TensorDG 2-D 限制器在光滑流上的精度代价：设计阶是否被保护？

> 任务：m3299（models 席自找活）· 分支 `agent/m3299` · 2026-11-04
> Python 3.11.6 / torch 2.7.1 / float64 / CPU · 工件：`validation/limiter_design_order_2d/sweep.json`、
> `validation/limiter_design_order_2d/sweep_P{1,2}.log`、`docs/figures/limiter_design_order_2d_*.png`
> 代码：`benchmarks/limiter_design_order_2d.py`、`benchmarks/report_limiter_design_order_2d.py`、
> `tests/test_limiter_design_order_2d.py`（6 测试）

## 1. 案例介绍（物理背景 / 几何 / 参数）

**问题**：`tensordg/euler_dg_2d.py` 是 2-D 可压缩栈的主力求解器，其 TVB/WENO 限制器在仓库里
只被**激波数据**验证过（`docs/limiter_2d_verification.md` 的挤压 Sod、Lax–Liu 四象限），
`docs/limiter_2d_verification.md` §5.3 只留了一句经验判断「光滑问题要么把 M 调大、要么别开」，
**从未在 2-D 光滑流上量化**。1-D 的同类账在 `docs/limiter_policy_verification.md`（m2500）已还，
2-D 的没还:任何人都不知道默认参数 `tvb_constant = 1.0` 会不会悄悄把主力求解器的观测阶砍掉。

**算例**：等熵涡（isentropic vortex）。它是 2-D Euler 方程的**精确解**——一个以背景速度平流、
压力/密度满足等熵关系的旋涡，因此误差直接对**闭式解**测（无制造源项、无数值参考解自证）。

| 项 | 取值 |
|---|---|
| 方程 | 2-D Euler，理想气体 γ = 1.4，无粘 |
| 计算域 | $[-5,5]^2$，双周期 |
| 初值 | 等熵涡，强度 $\beta = 5$，背景速度 $(1,1)$ |
| 末时刻 | $t = 0.5$（精确解随背景速度平移，仍在解析式给定） |
| 空间离散 | 张量积 Legendre 模态 DG，HLLC 法向通量，SSP-RK3，局部正性回退 |
| 初值投影 | 全模态 $L^2$ 投影（保设计阶，非单元平均） |
| CFL / 精度 | 0.2 / float64 |
| 网格 | P1: $16^2,24^2,32^2,48^2$；P2: $12^2,16^2,24^2,32^2$ |
| 限制器配置 | `none`、`tvb M=1`（**API 默认**）、`tvb M=10`、`tvb M=100`、`weno M=1`、`weno M=100` |

**要检验的理论**（Cockburn & Shu, *Math. Comp.* 52 (1989) 411–435）：TVB 判据把「单侧差偏离
minmod 斜率的量」与容差 $M h^2$ 比较。光滑数据下该偏离是 $O(h^2 u'')$，于是
**只要 $M > \max|u''|$（对守恒变量的量级），一个单元都不该被标记**，设计阶 $p+1$ 应原样保留；
反之 $M$ 小于该阈值时，被标记单元是**固定物理区域**（数量 $\propto 1/h^2$、比例与网格无关），
限制后的单元重建误差为 $O(h)$，全局 $L^2$ 误差应退化为 $O(h)$ ——**观测阶被钉在 1**。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **先算阈值，再看结果**（避免事后拟合）：`second_derivative_scale()` 用细网格（$h=0.005$）
   中心差分直接量初值在**守恒变量**上的二阶导峰值，得到预测阈值
   $\max|u''|_{\text{cons}} = 4.2103$（能量分量主导；$\rho$ 0.8052、$\rho u$ 0.8052、$\rho v$ 1.9739）。
   预测：$M=1$ **活**、$M=10$ **全静默**。
2. **限制器活动量可测**：不改库代码，benchmark 在运行时包裹
   `apply_tvb_limiter_2d`/`apply_weno_limiter_2d`，用**生产判据** `euler_dg_2d._troubled_1d`
   统计每次施加调用时被判为 troubled 的 (单元, 轴) 比例，记 `flagged_mean`（全过程均值）与
   `flagged_peak`。这样「限制器到底动了多少」不是靠猜。
3. **误差与阶**：复用 `benchmarks/verify_euler_dg_2d._vortex_error`（8 点 Gauss + LegGauss 权重），
   对 $(\rho,u,v,p)$ 逐场算相对 $L^2$；相邻网格给观测阶 EOC $=\log(e_{i}/e_{i+1})/\log(N_{i+1}/N_i)$。
4. **守恒审计**：质量取单元平均（mode 0,0，限制器**规定不许动**）之和乘面积，与 `none` 对比。
5. **可复现**：每个 run 完成即重写 `sweep_P*/json`（中断也可用），`report_*` 脚本合并两档阶数、
   打印下表并出图；图中数字全部来自 JSON，无手抄。
6. **回归测试**（`tests/test_limiter_design_order_2d.py`，6 个，18 s）把结论钉死：
   判据随 $M$ 单调、$M$ 大时与 `none` **逐位相同**、$M=1$ 时标记数 > 0 且阶掉、
   质量漂移为 0、不限制时设计阶达标。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **默认参数正好在最坏位置**：`solve_euler_dg_2d(limiter="tvb")` 的默认 `tvb_constant=1.0`
   低于本算例阈值 4.21，光滑流上会开限制器并把观测阶从 1.96/2.97 砍到 1.05/1.44。
   激波算例仍需小 $M$（放宽即丢激波捕捉），所以**不建议改默认值**，而是「用限制器先报 $M$，
   或用 `max|u''|` 定 $M$，光滑问题优先 `limiter=None`」。
2. **标记是守恒变量的最大值**：判据对 $(\rho,\rho u,\rho v,E)$ 取 max，能量分量的 $|u''|$ 最大
   （4.21 vs 密度 0.81），所以阈值由能量支配。只看密度二阶导会低估 $\sim 5$ 倍。
3. **$3\%$ 工程门在光滑算例上失去分辨力**：即使最坏的 `weno_M1`，$32^2$ P2 也只有 0.7957 % 误差，
   仍在 3 % 门内。**光靠 3 % 门无法发现阶数被砍**——这正是本单补齐的空白；判据必须同时看 EOC。
4. **限制器不破坏守恒**：TVB 路径质量漂移逐位为 0（mode 0 从不动），WENO 路径 1.4e-16（浮点乘加）。
5. **局限**：只用了一个光滑算例（等熵涡）、Cartesian 均匀网格、双周期、无粘、P1/P2（P3 未测）；
   $M^\ast$ 是本算例守恒变量二阶导的峰值，换算例/换末时刻需重算；方向分裂限制器与真 2-D WENO
   模板的差异本单不涉及；标记比例是「判据会标多少」，真实的精度损失只由表中误差体现。
6. **坑（工具层）**：`pkill -f limiter_design_order_2d` 会连自己所在的 shell 一起杀掉
   （命令行里含同样字符串）——长扫描务必用 `setsid nohup` + 精确匹配 `python -m ...` 收尾。

## 6. 误差判定（关键量 vs 基准，逐项）

基准＝等熵涡的**闭式精确解**（无近似），因此误差是「相对真值」的误差。

| 关键量 | 基准 | 实测 | 是否 < 3 % |
|---|---|---|---|
| P1 48² 密度误差 `none` | 精确解 | 3.908e-02 % | ✅ 是 |
| P1 48² 密度误差 `tvb M=1` | 精确解 | 2.303e-01 % | ✅ 是（但阶 1.05 ≠ 2 ❌） |
| P1 48² 密度误差 `weno M=1` | 精确解 | 2.926e-01 % | ✅ 是（阶 0.98 ≠ 2 ❌） |
| P2 32² 密度误差 `none` | 精确解 | 4.761e-03 % | ✅ 是 |
| P2 32² 密度误差 `tvb M=1` | 精确解 | 3.860e-01 % | ✅ 是（但阶 1.44 ≠ 3 ❌） |
| P2 32² 密度误差 `weno M=1` | 精确解 | 7.957e-01 % | ✅ 是（阶 0.93 ≠ 3 ❌） |
| `none` 观测阶 vs 设计阶 $p+1$ | 2 / 3 | 1.96 / 2.97 | ✅ 误差 2.0 % / 1.0 %（< 3 %） |
| `tvb M=1` 观测阶 vs 设计阶 | 2 / 3 | 1.05 / 1.44 | ❌ **否**（46 % / 52 % 欠阶） |
| 阈值预测 $M^\ast$ 与实测静默点 | 4.2103 | $M=10$ 零标记（区间 $(1,10]$ 覆盖 4.21） | ✅ 是（预测命中） |
| 限制器对质量的影响 | 0 | 0.0 / 1.4e-16 | ✅ 是 |

**结论**：2-D 限制器**能被调成无代价**（$M > \max|u''|$ 时与不限制逐位相同，设计阶完整保留），
但**默认 $M=1$ 在光滑流上不是小代价**：观测阶被钉在 ≈1，P2 最细网格误差放大 81 倍
（WENO 167 倍），尽管 3 % 工程门仍然通过。仓库此前只有 1-D 版本的这个结论，2-D 的账本单已还清。
