# REPRO-DG-CKS1998 · 双马赫反射三叉点的三波理论解析参照

> 锚点 `REPRO-DG-CKS1998`（Cockburn & Shu, JCP 141 (1998) 199--224, Part V）。
> 本单闭合 `docs/CASE-REPRO-DG-CKS1998-DOUBLE-MACH.md` §5-1 自认的唯一剩余欠账：
> 「三叉点轨迹、马赫杆高度…本仓**没有**可用的解析/半解析参考（三波理论需要解激波极曲线交点）」。

## 1. 缺口与方法

缺口原文（§5-1）：三叉点轨迹 / 马赫杆高度无数值判据。本单补的是**解析侧**：
伪定常三波（von Neumann）理论。在随三叉点平移的参考系里三条波都是定常斜激波：

* 入射激波定常 ⇒ `q sin(ω − χ) = W`，故 `q = W / sin(ω − χ)`；
* 未知量 2 个：轨迹角 `χ` 与反射激波法向角 `φ_r`；马赫杆法向取 `(−1,0)`
  （杆面垂直于壁面，经典闭合）；
* 条件 2 条：滑移线两侧 `p_3 = p_3'`、两侧速度平行同向。

实现 `benchmarks/dmr_three_shock.py`。**第二条独立实现**（`solve_three_shock_galilean`）
把杆角放开为未知、改用「杆后流在**实验室系**平行于壁面」闭合（3 未知 3 方程），
两者仅差一次伽利略变换，必须给出同一 `χ`：实测偏差
**1.00e-12 deg**（表 1），即相互独立复核通过。

* 脱体角 `θ_det(M=10) = 44.429 deg`；本例入射角 60° > θ_det ⇒ **附体正则反射不可能，
  必为马赫反射**——与算例定性一致（这是理论自洽性的第一道检查）。
* 三波 RH 通量残差 `≤ 4.6e-14`（机器精度），
  滑移线压力失配 `≤ 7.1e-15`、
  速度叉积 `≤ 1.1e-14`。
* **理论给出两支**（约 7.73° 与 7.73°）：强激波下的
  弱/强解二重性，三波理论本身**不能先验选支**。这是本单最需要如实记录的一点，
  不能拿「选一支好看」当结论。

## 3. 与数值解绑定的量

预测轨迹 `T(t) = (1/6 + q cosχ·t, q sinχ·t)`（`x=1/6` 为 t=0 时入射波面与壁面交点）。
它必须落在**唯一严格解**（入射平面波律 `analytic_front_x`）上：
`tests/test_dmr_three_shock.py::test_triple_point_trajectory_lies_on_the_exact_incident_front`
逐点校验偏差 < 1e-9。测量侧（从密度场提取三叉点）已实现并递交集群作业 **cj4099**
（P1 128×32 / P1 256×64 / P2 128×32，t=0.2）；**本文件写作时作业仍在排队**，
故本单**不给出**实测 χ 与理论的比较数字——不粉饰为已完成。

## 4. 测试

`tests/test_dmr_three_shock.py`：21 项（20 pass + 1 documented xfail）。

* 通量形式 RH 残差（独立于跳跃公式）、滑移线不变量、伽利略双实现一致；
* 预测轨迹落在严格解上、`χ` 可从轨迹点反演；
* `χ` 随入射角单调；退化输入**诚实抛 `NoThreeShockSolution`**（`mach=1` 用例）；
* 探测器的合成场校验：**诚实 FAIL** —— 杆脚外张（flare）时交点外推偏低约 4 个单元，
  故 `test_detector_finds_the_planted_triple_point` 保留为 `xfail`（并把偏差量级
  钉在 `test_detector_bias_on_a_flared_stem_is_bounded_and_documented`），
  不通过放松阈值把它洗绿。

## 5. 注意点 / 局限

1. **弱/强双解**：两支都满足全部 RH 与滑移线条件，需数值实验判别（作业 cj4099）。
2. **伪定常假设**：dMR 的 t>0 早期并非严格自相似（双马赫结构的第二个三叉点），
   理论轨迹是零阶参照，不是精确解。
3. 探测器在粗网格（dy≥0.03）上会把三叉点读低 2--4 个单元（见 §4 的 xfail），
   实测比较必须同时报告网格与探测器偏差。
