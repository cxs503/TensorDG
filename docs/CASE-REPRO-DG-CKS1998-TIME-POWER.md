# CASE · REPRO-DG-CKS1998 — 时间误差归因仪器的功率标定（eta 支路在可容许窗口内不可触发）

> 锚点：`REPRO-DG-CKS1998`（论文复现·CKS1998, JCP 141:199–224 / SIAM Review 43(1)），
> 验收原文「quantitative_targets 逐项容差」。单号 m22636（自找活·infrastructure 席）。
> 增量类型：**验证欠账 / 判据功率标定**——复核已合并的
> `CASE-REPRO-DG-CKS1998-VORTEX-TIME-ATTRIBUTION`（m22219，报告 20020）的结论，
> 不改任何求解器内核、不改任何已预登记常数。

## ① 案例介绍

CKS1998 §5.3 的二维等熵涡（ρ=1+O(5²), 周期盒 [-5,5]², γ=1.4, T=1.0）是锚点里唯一
有**解析解**的二维算例，因此也是"阶次偏差归因"的试验台：m22219 用
`eta = |e(CFL) − e(CFL/β)| / e(CFL)`（β=4，即 dt→dt/4）与"阶漂移"两条支路，
把 p1/p2/p3 的阶次偏差（3.19 %/4.76 %/3.00 %）判为空间主导（`SPATIAL_ISOLATED`），
其中 **eta 支路的读数是 0.00 %，判据 `eta ≤ 5 %`**。

本单问的是这个读数**能不能说明问题**：如果装置在该算例的可容许配置空间里根本
打不到 5 %，那么 "0.00 % ≤ 5 %" 是一条**空判据**，`SPATIAL_ISOLATED` 就只能靠
阶漂移支路成立（该支路 m22219 实测 0.00 %，本单不重改）。CKS1998 本身不给 eta 的
参考值（它是仪器指标，不是物理量），所以本单的"基准"是**装置自身可触发性**，
不是文献数字。

## ② 怎么做的

新增 `benchmarks/cks1998_vortex_time_power.py`（纯函数 + 复用
`cks1998_vortex_order_certification.run_case`，空间算子/初值投影/误差范数逐位同一）：

1. **CFL 梯子**：CFL ∈ {0.05, 0.1, 0.2, 0.4, 0.5}（生产点 0.2 两侧各有点），逐档配对
   CFL/4 得 eta；
2. **可容许窗口的硬边界**：`tensordg.euler_dg_2d.solve_euler_dg_2d` 有硬校验
   `0 < cfl <= 0.5`；本单递交 CFL=0.6 作**被拒负控**，实测抛
   `ValueError: invalid cells, final_time or CFL` ⇒ 窗口是硬的，不是软约定；
3. **正对照（检出率）**：用求解器 `dt=` 固定步长旁路该窗口，取
   `dt = k·dt(CFL=0.2)`，k ∈ {1,2,4,8,16,32}，用**同一** eta 仪器测量；
4. **二阶时间细化**（m22219 §5 局限 4 声明未做的 `dt→dt/β²`）：本单已实现并纳入
   仪器（`second_refinement`），本地档位不足（见 §5-2），生产网格档在集群作业 **cj4273**；
5. 判据：`eta(CFL) ~ A·CFL^s` 的 log-log 拟合外推出 eta 达到 5 % 所需的 CFL，
   若该 CFL 大于可容许上界 0.5 ⇒ `GATE_VACUOUS_IN_ENVELOPE`。

回归门 `tests/test_cks1998_time_power.py`：**22 条全部通过**（纯合成分支，不依赖求解器：
eta 定义/幂律反演/判据严格不等/CANNOT-FIRE 与 FIRE 两向判定/窗口缺失不给判决/
包络的 lost 分离/eta 只与 β 伙伴配对/不稳定与 NAN 不得进算术/二阶细化两向/
阶漂移支路两向/控制臂不得污染阶漂移键）。

## ③ 计算结果（程序化注入：`validation/cks1998_vortex_2d/time_power.json`）

P1、n=10（本地 shell 120 s 预算内的一档；生产网格 24/32 档见 cj4273），β=4：

| CFL | e(CFL) | e(CFL/4) | eta | 支路 |
|---:|---:|---:|---:|---|
| 0.2（生产） | 4.140564e-03 | 4.140572e-03 | 1.881e-06 | SILENT |
| 0.4 | 4.140516e-03 | 4.140571e-03 | 1.329e-05 | SILENT |
| 0.5（窗口上界） | — | — | 无 β 伙伴 | 只作窗口边界 |

| 量 | 值 |
|---|---|
| 拟合 eta = A·CFL^s | A = 1.7605e-04, s = 2.820（**2 点拟合**，r²=1.0 是构造性的，见 §5-1） |
| eta 达到 5 % 的外推 CFL | **7.41** |
| 可容许窗口上界 | 0.5 |
| 判决 | **GATE_VACUOUS_IN_ENVELOPE** |
| 被拒负控 | CFL=0.6 → `invalid cells, final_time or CFL` |
| 正对照（固定 dt） | eta(k=4)=4.55e-05, eta(k=8)=2.71e-04, **eta(k=16)=0.677 → FIRE**（等效 CFL 3.2）；k=32 发散（`nonphysical cell average in 2-D DG`） |

**结论（不粉饰）**：在生产 CFL=0.2 上 eta = 1.88e-06，比 5 % 的判据低 **4 个量级**；
幂律把 5 % 的触发点推到 CFL ≈ 7.4，而求解器在 CFL>0.5 处直接拒绝
⇒ **eta 支路在本算例的可容许配置空间内不可触发**，`eta ≤ 5 %` 是空判据；
它的"PASS"不构成"时间误差可忽略"的证据（虽然结论意义上它确实可忽略：正对照要到
等效 CFL 3.2 才 FIRE）。`SPATIAL_ISOLATED` 因此**只由阶漂移支路承担**。

## ⑤ 注意点 / 局限

1. **拟合只有 2 个点**（0.2 与 0.4；0.05/0.1 的 β 伙伴 0.0125/0.025 未跑）。s 的不确定度
   无法从 2 点给出。**判决对该不确定度是稳健的**：要让 eta(0.5) 触到 5 %，需要
   s ≥ -8.1（而实测两点给出 2.82）——结论对 s ∈ (0, -8.1] 全部成立。
2. **二阶细化（m22219 局限 4）本单未闭合**：本地 120 s 预算跑不完 CFL=0.0125 档，
   `second_refinement` 返回 `INSUFFICIENT_LEVELS`；生产网格 + β² 档在集群作业 **cj4273**
   （递交时排队位次 46，本单收尾仍未出队，**不据未回作业下任何结论**）。
3. **本地档位是 n=10 P1**，不是生产 24/32；eta 判据依赖 CFL 而不依赖 h（两个 CFL 上
   e 只差 1e-6 量级），但"生产网格上同样不可触发"这一句仍需 cj4273 复核。
4. 阶漂移支路本地被控制臂的键污染（已修：控制臂 `cfl=None` 且阶漂移只吃 `kind=="ladder"`
   的有限记录），本地不报该值——m22219 的 0.00 % 仍是唯一有效读数。
5. 本单**未改**任何预登记常数（`TIME_FRACTION_MAX=5 %` 等原样保留）：空判据的处置
   （把 eta_max 改登记为可测尺度，如 1e-4，或在证书里显式标注"本支路无功率"）
   属预登记变更，需与 owner/账本同步，本单只登记证据。

## ⑥ 误差判定

| 关键量 | 基准 | 实测 | 相对偏差 | 是否 < 3 % |
|---|---|---|---|---|
| eta（生产 CFL=0.2） | 无外部基准（仪器指标，非物理量） | 1.88e-06 | — | **不适用**：本单证明它**不可**作为误差量对标；它对 5 % 判据的余量是 4 个量级 |
| 幂律指数 s | 无外部基准 | 2.82（2 点） | 无不确定度可给 | **不能声称 < 3 %**（2 点拟合，已按诚实口径声明） |
| 触发 CFL | ≥ 0.5（可容许上界） | 7.4 | 15× 余量 | **是**（判决对该余量稳健，见 §5-1） |
| 正对照检出率 | 5 % 阈值 | 1/1（k=16 FIRE），窗口内 0 次误报 | — | 仪器已证明有检出能力 |
