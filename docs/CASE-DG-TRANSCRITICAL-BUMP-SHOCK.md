## ① 问题与案例（物理背景 / 几何 / 参数）

经典浅水驼峰算例的**壅水（choked）档**：Goutal & Maurel (1997) 溃坝工作组 test 3，
亦即 Delestre et al. (2013) SWASHES 中的 *Bump with shock*。

| 量 | 值 |
|---|---|
| 计算域 | x ∈ [0, 25] m |
| 地形 | z_b = 0.2·(1 − ((x−10)/2)²)，8 ≤ x ≤ 12；其余 z_b = 0 |
| 单宽流量 | q = 0.18 m²/s（定常，全程守恒） |
| 出口控制 | h(25) = 0.33 m（亚临界） |
| g | 9.81 m/s² |

壅水判据：亚临界支存在要求 `min_x (H − z_b) ≥ 1.5 h_c`。本算例
`h_c = (q²/g)^{1/3} = 0.148922 m`，出口决定的下游总能头
`H_R = h(25) + q²/(2g h(25)²) = 0.345164 m`，而峰顶处 `H_R − z_b,max = 0.145164 m < 1.5 h_c = 0.223383 m`
→ **光滑亚临界解不存在**，流态为：

亚临界（入口段）→ 峰顶临界（Fr = 1）→ 背风坡超临界 → **驻激波** → 亚临界（出口段）。

这正是 `tensordg.swe_steady_bump.bump_steady_state` 此前显式抛 `ValueError("... chokes ...")`
拒掉的那一档：仓内过去所有「运动定常态也是离散不动点」的验证都只覆盖了光滑亚临界支。

## ② 怎么做的（方法 / 关键设置 / 工具链）

**1. 解析解的三条构造（各自独立成立）**

- 光滑段能量守恒：定常动量平衡 `d/dx(q²/h + g h²/2) = −g h dz_b/dx` 与 `dH/dx = 0`
  等价（`H = z_b + h + q²/(2g h²)`），故 `h` 是三次方程 `h + q²/(2g h²) = H − z_b` 的一支。
- 峰顶必须过临界：峰顶是比能最小截面，`H_L = z_b,max + 1.5 h_c = 0.423383 m`（瓶颈条件）。
- 驻激波：零宽跳跃上质量与动量守恒（地形连续、无坡降力），
  `q = const`、`q²/h + g h²/2 = const`；能量头**下降**（激波损失）。
  激波位置 `x_s` = 两支动量通量相等的跑点，用**二分**求解标量残差。

**2. 参考解的独立性（防「自证」）**

`tests/test_swe_steady_bump_shock.py` 不使用模块的分支求逆作为基准，而是：

- 把定常 ODE `dh/dx = −z_b′/(1 − q²/(g h³))` 用 **RK4 独立积分**（在峰顶奇点外 1 cm 用局部渐近
  `h − h_c = ∓√(2 h_c·0.05/3)·δ` 起步），与闭式分支比对：背风坡 / 上游支 rel ≤ 5e-4；
  出口 backward（以 `h(25)=0.33` 这一**算例数据**为起点）rel ≤ 2e-5。
- 激波处逐条校验 Rankine-Hugoniot（动量通量相等 rel 1e-9）、能量损失正且等于两头头差（rel 1e-6）、
  Froude 数跨越 1（Lax 熵条件）。
- 激波位置的**鉴别力**：`x_s ± 0.05 m` 处残差 > 5e-3（即位置不是靠容差混过去的）。

**3. 生产格式测量（两把尺子）**

- **稳态缺陷**：把精确态插值到 DG 空间，直接用生产算子 `swe_1d._rhs` 求 `‖dU/dt‖/‖U‖`
  （`steady_state_defect`，`well_balanced=True` 路径，Audusse 静水重构 + 多项式地形坡源），
  与光滑亚临界算例（`validation/swe_steady_bump/`）同口径对比。
- **时间推进**：以精确态为初值、精确边界通量（定常）驱动 `solve_swe_1d`（RK3, CFL=0.4），
  记录存活到多久、是否因 `dt` 下溢中止、中止时刻的深度误差。
- 后处理区域规则**只由解析 `x_s` 决定**（±2 个单元带），不读数值场（避免 m16606 复核出的
  「区域规则可调 → 判据不稳健」问题）。

工具链：Python 3.11 / torch 2.7.1（loong64, nproc=128），`PYTHONPATH=.`，
驱动 `python validation/swe_steady_bump_transcritical/run_transcritical_bump.py --quick`（44 s 墙钟）。

## ⑤ 注意点（坑与边界）

1. **峰顶求逆的病态**：`dH/dh = 1 − q²/(g h³)` 在临界点为 0，能量头对 h 是二次平坦的，
   二分得到的 h 精度只到 `√(残差)`；因此解析解在峰顶给出 `H` 残差 ~7e-9、`Fr = 1 − 1.4e-8`，
   测试按此设定容差（不是放宽到「随便过」：其余位置残差 < 1e-7 仍是硬断言）。
2. **ODE 积分的峰顶奇点**：`dh/dx = −z_b′/(1 − q²/(g h³))` 在峰顶是 0/0；独立校验必须在
   峰顶外 1 cm 用局部渐近起步，否则 RK4 直接发散（本单曾踩，得到 1.8e5 的荒谬深度）。
3. **TVB 限幅器默认量级无效**：`tvb_constant=5` 在本算例（dx=0.25 m，二阶差 < M·dx²）几乎不触发，
   三档限幅器给出**逐位相同**的结果；只有 `M=1e-6`（几乎每步都限）才起作用——但也没能阻止中止。
4. **中止机制**：`dt` 下溢（`dt < 1e-15`，`swe_1d` 的 stall 分支）源于某节点深度被压到干底，
   `_primitive` 用 `DRY_DEPTH` 截断后速度爆掉；这**不是**物理发散：中止时刻的 L1 误差仅 0.5%。
5. **适用范围**：结论针对 `swe_1d` 现行 HLL + Audusse 静水重构 + SSP-RK 路径；
   若将来引入真正激波捕捉/熵稳定通量，需重跑本驱动（改进与否以缺陷表与中止时刻表为准）。
6. 本单未上集群（本机 load15≈97，全部运行 < 1 min，属轻量档）；N≥800 的缺陷档与 N=200/400 的
   时间推进档留待续单（见 §8）。

## ⑥ 误差判定：是否 < 3%？

| 关键量 | 基准 | 本单结果 | 误差 | 判定 |
|---|---|---|---|---|
| 解析解自洽：光滑段能量头（RK4 独立积分） | 闭式分支 | rel ≤ 5e-4（背风/上游支）、2e-5（下游支） | ≤ 0.05% | **是，<3%** |
| 激波 Rankine-Hugoniot 动量通量 | 两侧相等 | rel 1e-9 | ≈0 | **是，<3%** |
| 激波能量损失 vs 两头头差 | 一致 | rel 1e-6 | ≈0 | **是，<3%** |
| 时间推进：中止时刻深度 L1 误差 | 精确解 | 5.13e-03（无限制器）/ 7.25e-03（TVB） | 0.51% / 0.73% | **是，<3%**（但见下） |
| 时间推进：能否抵达定常态 | 需 →∞ 保持 | **t≈6–7 s 即中止** | 不适用 | **否 —— honest FAIL** |
| 稳态缺陷：跨临界 vs 0 | 0（若良态平衡成立） | O(1)，加密反增 | ≈100% | **否 —— 定常态不是离散不动点** |

**结论（honest FAIL）**：本算例的**解析解与验证链成立**（误差 ≪3%），但生产格式**不能**把跨临界定常态
作为演化解保持：无限制器/强 TVB 限制器均在 t ≈ 6–7 s（N=100）因节点干底导致 `dt` 下溢中止，
且离散稳态缺陷在激波处为 O(1) 且不随加密收敛。因此「良态平衡 ⇒ 运动定常态是离散不动点」
这一仓内既有表述必须**限定为光滑定常态**；跨临界档需要激波捕捉（或把激波位置作为内部界面）才可支持。
