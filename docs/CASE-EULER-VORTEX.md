# CASE-EULER-VORTEX：二维等熵涡精确解验证报告

> 本报告的每个数字均由 `benchmarks/case_euler_vortex.py` + `benchmarks/_case_euler_vortex_report.py` 从 `results/*.json` 程序化注入，无手抄；门禁由脚本计算。

## ① 问题设定与基准出处

二维可压缩 Euler 方程（理想气体 gamma = 1.4）的等熵涡（isentropic vortex）是 **解析精确解** 算例：初始场为等熵涡，均匀来流 (u,v)_inf=(1,1) 平移输运该涡，t>0 的精确解即初始剖面向下游平移。算例名 `EULER-VORTEX`，算例池指定的验收判据为**各原始变量相对 L2 误差 < 5%**。

| 项目 | 取值 |
|---|---|
| 计算域 | x,y in [-5,5]x[-5,5]，四周周期 |
| 涡强度参数 beta | 5（Sutherland 型标准取值）|
| 来流 (u,v)_inf | (1,1) |
| 绝热指数 gamma | 1.4 |
| 末时刻 | t = 1（敏感性另测 t = 0.5, 2）|
| 参考解 | 见文末出处；本报告先用数值残差独立校核其为真精确解（见 §④ 表 0）|
| 验收容差 | 各场相对 L2 < 5% |

**基准出处**：C.-W. Shu, 'Essentially non-oscillatory and weighted essentially non-oscillatory schemes for hyperbolic conservation laws', ICASE Report 97-65 / NASA CR-97-206253 (1998), §4.4.2 smooth isentropic vortex: domain [-5,5]^2, beta=5, (u,v)_inf=(1,1), gamma=1.4, periodic, exact solution; tolerance <5% relative L2 per primitive field.

## ② 方法与实现

两条**互相独立**的离散路径都被同一判据检验（这样判据不是被单一代码实现自证）：

1. 低阶基线 `tensordg/euler_2d.py::solve_isentropic_vortex`：P0（守恒型有限体积极限）+ Rusanov 界面通量 + SSP-RK3，初始场按 4x4 高斯点精确单元平均，误差度量 `vortex_error` 用 4x4 精确单元平均参考值 → 单元平均值相对 L2。
2. 高阶路径 `tensordg/euler_dg_2d.py::solve_euler_dg_2d_vortex`：张量积模态 DG（P1/P2/P3）+ HLLC 通量 + SSP-RK3，初始场为模态 L2 投影，误差度量用体积求积节点上的重构状态（`benchmarks/verify_euler_dg_2d.py::_vortex_error`），即**点值**相对 L2，两条路径共用同一精确解与同一验收线。

关键代码指针：

| 组件 | 位置 |
|---|---|
| 精确解 | `tensordg/euler_2d.py:37` `vortex_primitive` |
| P0 时间推进 | `tensordg/euler_2d.py:239` `solve_isentropic_vortex` |
| 高阶 DG 推进 | `tensordg/euler_dg_2d.py:773` `solve_euler_dg_2d_vortex` |
| 高阶误差度量 | `benchmarks/verify_euler_dg_2d.py:57` `_vortex_error` |
| 算例门禁/编排 | `benchmarks/case_euler_vortex.py` |
| 聚合与报告 | `benchmarks/_case_euler_vortex_report.py` |

参考解自校核（本算例新增，防止“拿错答案当基准”）：静止系下 `div F = 0`（精确解的判据）、平动系下 `U_t + F_x + G_y = 0`（空间导数用自动微分、时间导数用中心差分）、以及等熵律 `p = rho^gamma`、无散旋流 `div(u,v)=0`、径向动量平衡 `dp/dr = rho v_theta^2/r` 三项独立性质。

## ⑤ 收敛性与参数敏感性

收敛阶取相邻两分辨率的最大场误差比：`p = log(e_coarse/e_fine)/log(h_coarse/h_fine)`，与设计阶对比见上图与表 2。P0 在粗网格上受初始投影与度量方式影响观测阶低于 1，随网格加密向 1 收敛；P1/P2/P3 的观测阶落在设计阶附近。

| P2, 32x32 | t | CFL | 最大场误差 | <5%? |
|---|---|---|---|---|
| 敏感性点 | 0.5 | 0.2 | 0.0094% | 勾 |
| 敏感性点 | 1 | 0.1 | 0.0127% | 勾 |
| 敏感性点 | 1 | 0.2 | 0.0127% | 勾 |
| 敏感性点 | 1 | 0.4 | 0.0127% | 勾 |
| 敏感性点 | 2 | 0.2 | 0.2468% | 勾 |

敏感性结论：在 CFL 0.1~0.4 与 t=0.5~2 的范围内最大场误差处于 0.0094%~0.2468%，随 CFL 与末时刻变差但不改变量级，验收结论对该参数窗口稳定。

## ⑥ 失败模式、局限与工件

- P0 路径在 32x32 上单场误差超过 5%（见表 2），说明<5% 判据**不是**低阶格式在任意网格上都能满足；门禁配置因此固定为 P0 128x128 与 P2 32x32 两个点。
- 高阶误差度量是点值 L2，P0 是单元平均 L2，两者定义不同；跨族比较只用于量级判断，族内收敛阶比较才是严格判据。
- 本算例为光滑无激波算例，不检验限制器；涡核附近的极值抹平由格式耗散主导，P0 粗网格误差偏大属预期。
- 时间推进为 SSP-RK3，时间误差未单独做网格无关性研究（CFL 0.1~0.4 的敏感性覆盖了其量级）。
