# CASE-REPRO-DG-CKS1998 · G3 归因：网格内固体壁 == 域边界壁（逐位相等）

> 锚点 `REPRO-DG-CKS1998`（Cockburn & Shu, *The Runge-Kutta discontinuous Galerkin method
> for conservation laws V: multidimensional systems*, JCP **141** (1998) 199--224；台阶与
> 双马赫算例源自 Woodward & Colella, JCP **54** (1984) 115--173）。
> 单号 m21992（自找活·platform 席）；分支 `agent/m21992`。
>
> 本单只做一件事：把 `docs/CASE-REPRO-DG-CKS1998-FORWARD-STEP.md` §4(a) 里记为
> **honest FAIL/WITHHELD** 的 G3（网格内固体壁的激波反射定量正确性）从「两个嫌疑分不清」
> 推进到「**一个嫌疑被证伪**」。结论：`_solid_interface` 这条内壁面通量与已经验证过的
> 域边界壁路径**逐位相同**（max|Δ| = 0.0），旧 FAIL 不是内壁面通量的错。

---

## ① 案例介绍（物理背景 / 几何 / 参数）

前向台阶（CKS1998 §5.3，Mach 3）的两条固壁——`x = 0.6, y ∈ [0,0.2]` 与
`y = 0.2, x ∈ [0,0.6]`——都落在**计算域内部**，因此该算例要求求解器能在网格内部表达固体。
m21186 已实现该能力（`solid=` 布尔掩膜 + 内壁面滑移通量 + 固体单元冻结），但它的
定量正确性一直没有证据：G3 门在 30×1 / 40×1 P1 上读出的反射平台压力误差 93.3 %，
两个嫌疑（内壁面通量写错 / 反射平台在该网格上根本没有成形）**无法区分**。

本单不去重跑台阶，而是把 G3 拆成一个**不需要解析参考就能判**的对照实验：同一道反射
（Mach 2 正激波打壁）用两种方式表达壁面：

| 臂 | 壁面表达 | 代码路径 |
|---|---|---|
| `boundary` | 网格止于壁面，`bcs={"right":"wall"}` | 已由 `tests/test_euler_dg_2d_wall_bc.py` 验证的域边界壁 |
| `solid` | 网格越过壁面，壁后单元是冻结固体块 | `_solid_interface` 内壁面通量（本单被测路径） |

两臂用**同一批流体单元**（同样的 `nx_fluid`、同样的 `dx`、同样的初值、`limiter=None`），
因此可以逐单元、逐模态比较。

| 参数 | 值 |
|---|---|
| 入射激波 Mach 数 | 2.0（`pre = (rho, u, p) = (1, 0, 1)`，γ = 1.4） |
| 波后精确态（RH） | rho2 = 2.6667，p2 = 4.5 |
| 反射平台精确态（RH + 对反射 Mach 数二分） | rho5 = 6.0000，p5 = 15.0000 |
| 流体单元数 | 16（`dx = 0.02`，域长 0.32 = 壁面位置） |
| 壁后固体单元 | 3（仅 `solid` 臂，域长 0.38） |
| y 向 | `ny = 1`，`ymax = 0.5`（一维流动，y 只进稳定性步长） |
| 最终时刻 | 0.08；入射波到壁时刻 `wall_time = 0.05071` |
| CFL / 限幅器 | 0.12 / `None`（只留正性回退，`limiter_stage="final"`） |
| 步数 | 两臂同为 **378** 步（固体单元不缩小 dt） |

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **对照不变量**：壁面在同一个单元面上、流体单元一一对应时，两臂的解必须**逐位相同**。
   这不是「容差内接近」，而是强不变量——两臂除「壁面通量由谁提供」外没有任何差别，
   连 dt 都由流体单元决定（`_rhs` 不含固体单元的速度）。任何差异都直接归给内壁面通量。
2. **反射必须已经发生**：守卫测试断言 `final_time > wall_time` 且 `reflected_speed < 0`
   （反射激波确实朝气体里跑），否则两臂在反射前平凡相等，测试无意义。
3. **台账驱动的一致性**：`conservation_residual_total.mass/energy` 由求解器自己的
   `track_boundary_flux` 记账给出，用来确认「固体单元不搬运质量」。
4. **工具链（本单新增，均在仓内）**：
   - `tests/test_g3_embedded_wall_equivalence.py`：3 条门（反射已发生守卫 / 两臂逐位相等 /
     壁前出现压缩且质量守恒）；
   - `scripts/run_g3_wall_reflection_ladder.py`：两臂 × h-梯次（P1 29/58/116、P2 58）的
     定量梯次驱动，输出 `validation/forward_step/g3/g3_ladder.{json,csv}`；
   - `benchmarks/forward_facing_step.py::gate_wall_reflection` 增加 `ymax` 形参
     （默认 0.1 不变）——`ny = 1` 时 y 向只以 `speed_y/ymax` 进稳定性步长，算例退化成一维后
     `ymax` 是纯成本旋钮，没有它就压不下梯次的墙钟。

## ⑤ 注意点 / 局限 / 适用范围

1. **结论的边界**：本单证明的是「内壁面通量 == 域边界壁通量」，因此旧 G3 FAIL **不能**归因于
   `_solid_interface`。它**没有**证明「域边界壁的反射是准的」——后者的证据在
   `tests/test_euler_dg_2d_wall_bc.py`（另有 `WallReflection` 参考漂移的修复史，见
   `benchmarks/euler_dg_2d_wall_bc.py::WallReflection.state` 的 docstring）。
2. **贴壁单元的过冲是真实存在的**（rho 12.24 vs 6.0，+104 %）：这解释了为什么
   「缓冲带 + `min_plateau_cells`」是必需的，也说明**台阶算例的贴壁阻力不能直接拿单元均值
   当壁面压力**，需要壁面迹量（`obstacle_impulse`）而不是单元平均。
3. **发现的一个记账缺陷（本单未修，如实登记）**：`boundary` 臂的
   `conservation_residual_total.mass.relative` 返回 **nan**（`solid` 臂是 1.13e-14）。
   两臂物理同一、记账路径不同：域边界壁的通量把质量带进/带出域，相对残差的分母可能为 0，
   于是 `0/0`。这是记账口径问题，不是守恒破坏，但会让「守恒残差」这类门在 boundary 臂上
   静默失效（nan 与任何阈值比较都是 False）。**建议下一个单把它改成绝对值+尺度归一**。
4. **梯次未取回**：`cj3844`（两臂 × P1 29/58/116 + P2 58，`cores=4`）递交时排队位次 52，
   本单交接时仍在 `queued`。因此**没有**给出「哪一级网格上反射平台误差首次 < 3 %」的答案；
   按纪律记为 **not_run**，不写成通过。
5. **适用范围**：`ny = 1` 的退化对照只检验 x 向内壁面；y 向内壁面（台阶的竖直面）走的是
   同一 `_solid_interface` 的 axis=1 分支，未在本单独立对照。

## ⑥ 误差判定（逐项，显式回答「是否 < 3%」）

| 项 | 基准 | 实测 | 误差 | < 3 % ? |
|---|---|---|---:|---|
| 两臂解（全模态） | `boundary` 臂 | `solid` 臂 | **0.0** | **是**（精确相等） |
| 步数 | `boundary` 臂 378 | `solid` 臂 378 | 0 | 是 |
| 质量守恒（solid 臂） | 0 | 1.13e-14 | 1.1e-14 | 是 |
| 质量守恒（boundary 臂） | 0 | **nan** | 不可判 | **否（记账缺陷，见⑤.3）** |
| 贴壁单元 rho（t=0.08） | rho5 = 6.0000 | 12.2430 | **+104 %** | **否**（平台仅约 1.5 单元宽，过冲） |
| 采样带最差误差（29×1 P1） | rho5 / p5 | 见③(c) | **98.3 %** | **否**（`not_run`：可采样 2 < 3 单元） |
| 全域 L1（29×1 P1, rho） | 精确解 | 0.7297 | — | **否** |

**一句话**：唯一 < 3 % 的项是「内壁面 == 域边界壁」这条精确不变量（误差恰为 0），而这正是本单
要判的那一项；反射平台本身的定量仍**没有**在可判网格上闭合，`cj3844` 的梯次是它的下一步证据。
