# TensorDG 高阶（`ao`）限制器验证：受限制单元保持设计阶
> 本文件由 `benchmarks/limiter_ao_verification.py` 从 `artifacts/limiter_ao/metrics.json` 生成，数字零手抄。
> 复现：`PYTHONPATH=. python -m benchmarks.limiter_ao_verification`。
> 锚点：`NEW:CASE-DG-LIMITER-AO`（roadmap 项"WENO-type high-order limiter"的落地与验证）。
## ① 案例介绍
**物理背景。** 模态 DG 的激波捕获限制器把"问题单元"的多项式降阶：TVB/minmod 把高阶模态清零（单元内一阶），既有 WENO 限制器只组合**线性**候选（单元内二阶）。当检测器在**光滑区**触发（光滑极值、粗网格、严格 `limit_all` 策略）时，设计阶 `p+1` 就被限制器本身毁掉——这是 `tensordg/burgers_shock_1d.py` 里长期挂着的 roadmap 欠账。
**两个算例。**
| 算例 | 方程 | 参数 | 判据 |
|---|---|---|---|
| 强制限制收敛 | `u_t + u_x = 0`，周期正弦 `sin(2πx)` | P2，`t=0.5`，CFL=0.05，SSP-RK3，**每个单元每个 RK 级都限制**（`troubled_policy="all"`） | 观测 L1 阶 ≥ 2.7（设计 3 的 90%） |
| 激波捕获 | `u_t + (u²/2)_x = 0`，Riemann `u_L=1, u_R=0, x0=0.1`，`t=0.2`（RH 激波位 `x=0.2`） | P2，N=100/200，CFL=0.2，Rusanov 通量 | Gibbs 过冲 < 0.07、激波位误差 < 2 个单元、质量守恒缺陷 < 1e-12 |
## ② 怎么做的
新增 `tensordg/limiter_ao.py`（`kind="ao"`，已注册进 `tensordg.limiters._LIMITERS`）：

1. 以 `(2p+1)` 单元窗口 `i-p..i+p` 为范围，取其中全部 `p+1` 个连续 `p+1` 单元子模板，每个子模板用**平均量精确匹配**解出目标单元的 `p` 次多项式（模态系数：`A_s c = ū_s`，`A_s` 为 Legendre 模态在窗口各单元上的均值矩阵，一次求逆缓存）；
2. Jiang–Shu 光滑指示子写成二次型 `β = cᵀ B c`（`B` 由 `Σ_l 2^{2l-1}∫(q^{(l)})²dξ` 在求积节点上精确积分），免去逐单元循环；
3. WENO-Z 型权重：指示子按共同最大值归一，`τ = max β - min β`，`α_k = (1/n)(1 + (τ/(β_k+ε))^q)`，`q=2`——尺度无关，幅值缩放或网格加密都不会把权重推回理想权重（Jiang–Shu `ε` 的失效模式）；
4. 问题单元的多项式置为该组合，`mode 0` 用原单元平均回写（质量逐位守恒）；
5. 无完整窗口的边界单元（开域）逐行回退到已验证的 `apply_weno_limiter`，故它是 `kind="weno"` 的直接替换。
**为什么设计阶保得住。** 每个候选都是"匹配 `p+1` 个单元平均的 `p` 次多项式"，逐点误差 `O(dx^{p+1})`；`O(dx^{p+1})` 近似的凸组合仍是 `O(dx^{p+1})`——**权重取任意凸值都不掉阶**，非线性权重只决定跨间断时哪个子模板主导。这不是假设：下表把它当作判据来测。

## ⑤ 注意点
* `P1` 时 `ao` 的候选集与既有 WENO 限制器同为一阶线性集，两者只差权重公式（等权 vs `(1/6,2/3,1/6)`），实测受限制斜率相差约 11%——高阶收益从 `P2` 起才出现。
* 本实现是**分量式**限制：系统方程（Euler）的特征场限制仍未实现，`ao` 对系统只保证分量单调性，不保证 `u=m/ρ` 单调。
* 理想权重取等权（`1/n`）：所有候选同阶时等权即阶最优，但比 WENO-JS 的非对称最优权重耗散略高；未做耗散优化。
* **Gibbs 过冲略高于 TVB**：`ao` 在激波单元的过冲比 TVB 高约 10%（仍在 0.07 预算内），是"单元内保留高阶多项式"的代价——换来的是光滑区不掉阶；两者不可兼得，按用途选。
* 仅支持一维均匀网格与模态 Legendre 基（与 `tensordg.limiters` 其余限制器一致）。
## ⑥ 误差判定
| 关键量 | 基准 | 实测 | 判据 | 是否通过 |
|---|---|---|---|---|
| 强制限制下 P2 观测阶 | 设计阶 3 | 2.990 | ≥ 2.7（设计阶 90%） | PASS |
| 同上，TVB 对照 | — | 1.795 | 结构性 ≤ 2 | 对照（本应低阶） |
| 同上，WENO 对照 | — | 1.920 | 结构性 ≤ 2 | 对照（本应低阶） |
| 激波 Gibbs 过冲（三限制器最差） | < 0.07（仓库既有预算） | 6.667e-02 | < 0.07 | PASS |
| 激波位误差（最差） | Rankine–Hugoniot `x=0.2` | 3.531e-06 | < 2/N | PASS |
| 质量守恒缺陷（最差） | 0 | 5.052e-15 | < 1e-12 | PASS |

**是否 <3%？** 关键量是收敛**阶**而不是单点误差：观测阶 2.99 vs 设计阶 3 的相对偏差 0.34%，**< 3%**；TVB/WENO 对照的偏差分别为 40% / 36%，**远超 15% 不可接受线**——这正是本限制器存在的理由。激波算例无解析场的逐点 >3% 声明（间断解本身不适用逐点判据），改用上表的 Gibbs/位置/守恒三项判据。
