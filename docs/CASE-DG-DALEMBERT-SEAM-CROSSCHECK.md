## ① 案例介绍（物理背景 / 几何 / 参数）

一维均质线弹性杆（周期边界），速度—应力一阶双曲系统 `v_t - sigma_x/rho = 0`, `sigma_t - E v_x = 0`，`c = sqrt(E/rho)`。初始数据为静止杆中的 Gauss 速度脉冲 `v0 = exp(-((x-0.5)/0.05)^2)`、`sigma(x,0) = 0`；解析解为 d'Alembert 双行波（纯行波叠加，无物理弥散）。当 `c t > 0.5` 时两行波穿过周期缝回卷，单镜像闭式失效，必须用镜像级数或模态传播子。

| 参数 | 值 |
|---|---|
| 杆长 L | 1 |
| 密度 rho / 杨氏模量 E | 1 / 1 |
| 杆速 c | 1 |
| 脉冲中心 / 宽度 | 0.5 / 0.05 |
| 首次周期缝时刻 t_seam = min(centre, L-centre)/c | 0.5 |
| 校核时刻 t | 0.55, 0.7, 0.9, 1.3 |
| 探针位置 x_p | 0.8 |
| 镜像（第二次）到达理论时刻 (centre - x_p + L)/c | 0.7 |
| 判定容差 | 2 % |

文献锚：K. F. Graff, *Wave Motion in Elastic Solids*, 1975, 第 1 章（细杆纵波 d'Alembert 解、`c = sqrt(E/rho)`）。本环境读不到原书，报告内所有 ref 值均由闭式解或独立数值参考在程序内算出，无任何数字抄自原书表格。

## ② 怎么做的（方法 / 流程 / 关键设置）

四条互不共享代码实现路径的参考解（R0 = 现行判定参考）：

| 代号 | 参考解 | 过缝机制 | 独立性 |
|---|---|---|---|
| R0 | `tensordg.elastic_1d._dalembert_periodic_images`（反射算例实际判定用的那条） | 镜像级数求和 | 与被验证求解器同仓 |
| R1 | Fourier 伪谱**时间精确**传播子（每波数闭式矩阵指数） | 周期基天然含回卷，不需镜像 | 与 tensordg 数学无共享 |
| R2 | 本次用 numpy 从零重写的周期镜像级数 | 镜像级数 | 与 tensordg 无共享 |
| R3 | 交错蛙跳（Yee）细网 + Richardson 外推 | 网格 `roll` 原生过缝 | 与 tensordg 无共享 |

流程：

1. 四参考互校：`c t ∈ {0.55, 0.70, 0.90, 1.30}`，R1 模态数 2048，R3 细网 1024 单元；
2. DG（N=200/P2、N=320/P3，CFL=0.3，SSP-RK3）在同时刻对 R1、R0 求误差；
3. 过缝收敛阶：P2，N ∈ {100, 200, 400}，t=0.7；
4. 探针双到达：`x_p = 0.8` 的逐时间步 σ 序列（库内 in-cell 模态插值），抛物线求峰，测出发到达与镜像到达的时刻、符号与幅值；
5. 能量：DG N=200/P2 在 `c t = 0 → 1.3` 的弹性能量漂移；
6. 敏感度/故障注入：用**未经守卫**的单镜像闭式当判定参考，证明参考侧故障可检出（而不是把正确解判成错）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **判定参考也有过缝失效风险**：反射算例的多趟锚点全部以 R0 为基准；本条把 R0 与三条独立参考在回卷区互校，才算把「参考本身可能错」这一独立性缺口在 `c t > 0.5` 侧也堵上（此前只在 `c t = 0.2` 侧做过）。
2. **镜像级数截断**：R0 用实现默认镜像数 6、R2 用 8；Gauss 脉冲宽 0.05 衰减极快，残尾远低于判定门槛，故不影响结论。
3. **R3 只作粗但独立的参考**：Richardson 外推后仍有有限残差，比 R1 低若干量级；判 DG 达标够用，不可用于百万分之一级结论。
4. **探针求峰**：三点抛物线拟合是二阶插值，误差 ~dt²；若加密快照不降误差，则误差来自网格弥散（与母 crosscheck 报告一致）。
5. **`c t = 1.0` 是应力场的退化时刻**：周期杆下 `c t = L` 使 `V(x+L) = V(x)`，`sigma == 0` 恒成立（速度重聚为初始脉冲）。本基准首版把 `c t = 1.0` 纳入 σ 相对误差统计，得到 1e+12 % 的荒谬数字，真因是**度量的分母趋零**而非求解器失效；现已剔除，改为把它当作恒等式检查。任何拿 `c t = L/c` 判 σ 相对误差的算例都会踩这个坑。
6. **适用范围**：线性弹性、均质杆、周期边界、`c t ≤ 1.3`（两次过缝）；不涉及 clamped-free（另有算例）与非线性/变截面。

## ⑦ 审计补记（人工撰写，数字仍由脚本从 JSON 注入）

**唯一未通过的锚点是有意保留的 honest FAIL，不是粉饰项**：

- `Yee leapfrog (R3, Richardson) vs R1 past the seam (max)`：实测 3.543e-03 %，门槛 0.001 %，判定 FAIL。R3（Richardson 外推交错蛙跳）在母 crosscheck 报告中已被定性为「粗但独立」的参考（其 ⑤.5：外推后残差比 R1 差约 9 个量级）；把 R3 放到过缝区、细网 1024 单元时残差升到 3.543e-03 %，仍比 DG 判定门槛 2 % 低约 2.8 个量级，因此它作为「粗参考」依然可用，但不满足我为参考间一致性设的 0.001 % 严门槛。结论：**保留 FAIL，不调门槛**；若将来要用 R3 做千万分之一级裁判，须先加密细网或换参考。

**对照**：同一批锚点里 DG 解对 R1 的最坏偏差为 5.199e-03 %（2 % 门槛），说明「参考间严一致性」的缺口不影响母算例/反射算例的判定，只影响把 R3 当高精度基准使用的场合。
