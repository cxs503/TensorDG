# CASE · CKS1998 §5.1 smooth 2-D Euler accuracy test (TensorDG)

**锚点**：`REPRO-DG-CKS1998`（Cockburn & Shu, *The Runge--Kutta discontinuous Galerkin
method for conservation laws V: multidimensional systems*, JCP **141** (1998) 199--224）
**工件**：`benchmarks/cks1998_smooth_2d.py` → `validation/cks1998_smooth_2d/order.json`、
`validation/cks1998_smooth_2d/limiter.json`、`docs/figures/cks1998_smooth_2d_order.png`
**集群**：`cj2627`（order 扫描）、`cj2628`（TVB 阈值扫描），节点 n330，4 核
**测试**：`tests/test_cks1998_smooth_2d_order.py`（8 条）

## 0. 为什么要做这一单

本仓此前对二维 Euler 系统求解器 `tensordg.euler_dg_2d.solve_euler_dg_2d` 的**阶数证据只有一种**：
等熵涡（`benchmarks/design_order_euler_dg_2d.py`）与带限制器的等熵涡
（`benchmarks/limiter_design_order_2d.py`），两者都报**相对 L2** 范数。而论文 §5.1 报的是
**密度误差的 L1 与 L∞**，且用的**是另一个精确解**：

```
rho(x, y, t) = 1 + 0.2 sin(pi (x + y - 2 t)),      u = v = 1,   p = 1
```

即均匀流（u = v = 1）携带的熵波，周期盒 [0,2]²。**论文自己的算例与两个范数，在本仓从未测过。**
本单补上这一笔，并把论文"限制器对光滑解不降阶"的断言做成**可证伪的预登记预测**（见 §3）。

## 1. 案例介绍

| 项 | 取值 |
|---|---|
| 方程 | 二维 Euler，gamma = 1.4；HLLC 界面通量；模态 Legendre DG；SSP-RK3 |
| 精确解 | rho = 1 + 0.2 sin(pi (x + y - 2t))，u = v = 1，p = 1（**无人工源项**） |
| 区域 | [0,2] × [0,2]，两向周期 |
| 末时刻 | t = 0.5（波移 (0.5, 0.5)，仍在周期盒内） |
| 时间步 | CFL = 0.2（dt ~ h），阶数扫描固定 CFL |
| 网格 | P1: 16/24/32；P2: 12/16/24；P3: 8/12/16（相邻网格比 1.5，EOC 用真实网格比，不假设 2） |
| 范数 | 密度误差的 L1（积分）、L1 相对、L∞（张量 Gauss 点上的最大值） |

该精确解为什么成立：u、v、p 为常数时，动量方程与能量方程都退化为与连续性方程**同一个**
线性对流方程（Q_t + Q_x + Q_y = 0），因此正弦扰动只是被平移。
`tests/test_cks1998_smooth_2d_order.py::test_smooth_solution_satisfies_the_euler_residual` 用
自动微分把守恒形式的残差压到 **< 1e-12**（实测机器精度），即**基准本身也有门**，
不是"随便写个正弦当参考解"。

## 2. 怎么做的

1. `solve_euler_dg_2d` 走公开 API（`initial` 回调 + `periodic=(True, True)`），不改求解器一行；
2. 在**每个单元的 4×4 张量 Gauss 点**上求值模态解，与闭式解逐点比较，取 L1/L1_rel/L2_rel/L∞
   四种范数（`error_norms`）；
3. EOC = ln(e_coarse/e_fine)/ln(h_coarse/h_fine)，用**真实 h 比**；
4. 限制器阶段：TVB 常数 M ∈ {1, 3, 10} 与无限幅器（`limiter=None`）在**同一梯子**上对比；
5. 数字全部由脚本写出 JSON，本文档的表格由脚本从 JSON 生成（零手抄）。

## 5. 注意点 / 局限（诚实）

1. **论文原文表格未逐格比对**：本仓没有 JCP 141 的 PDF，故判据用论文**定理**（光滑解 p+1 阶）
   与**精确解**，论文具体表格数字一律记 withheld，不做数字级 PASS 声明。
2. **一个被本单否定的假设**：原先的担心（"SSP-RK3 的时间三阶会封顶 P3 的观测阶到 3"）在本算例
   **没有发生**：P3 在固定 CFL 0.2 下实测 3.98 / 4.06，
   已到设计阶 4。原因是对流速度 O(1)、网格 h >= 1/16 时空间误差仍主导。所以 `--order-matched-dt`
   （CFL(h) = CFL0 (h/h0)^((p+1)/3-1)）在本算例**不需要**；我按原计划递了 `cj2621`（P3 五网格 +
   匹配 dt），该作业不是判据来源，其结论不进入本单论断。这属于**被否定假设**，如实记在此。
3. **网格梯子偏短**（每阶 3 个网格、相邻比 1.5）：足以分开 p+1 与 p（观测阶与设计阶偏差 <0.1），
   但不足以排除 pre-asymptotic 窗口外的高阶交叉项；P1 的 L∞ 阶 1.90~1.93 略低于 2 即为此。
4. **t = 0.5 而非更长时间**：10 个周期盒内平移半盒；更长的 t 只是同一算例的重复平移，
   不增加信息量，故按计算预算取 0.5。
5. **限制器阶段只用 TVB**：WENO 方向分裂限制器未在本算例上测（其光滑流策略见
   `docs/weno_limiter_smooth_flow_policy.md`），属未做项。
6. **只测传导变量级**：密度以外的动量/能量误差同时写入 JSON（`norms` 四个分量齐全），
   文中只列表密度（论文口径）。
