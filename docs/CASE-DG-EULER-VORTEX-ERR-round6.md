# CASE-DG-EULER-VORTEX-ERR：等熵涡移动误差守恒（第 6 轮：全图件收口）

**锚点** `CASE-DG-EULER-VORTEX-ERR` ｜ **算例池容差** < 6%（ref: Yee et al. 2000，按条目 verbatim 采用）｜ **本轮判定 PASS**
｜ 数字全部来自 `case_euler_vortex_errconserve/metrics.json` 与 `case_euler_vortex_errconserve/projection_baseline.json`（零手抄）。

**一句话**：第 5 轮已补齐 12/12 检查点并新增 C6 阶梯完整性门禁与误差放大因子 A(t)，但文档引用的 `fig_amplification.png` 与 `fig_error_field_t1.png` 未落盘。本轮生成全部 4 张图件（误差-时间、不变量-时间、放大因子、误差场+剖面），并发布论文级平台报告。DG-P2/32² 穿箱一次（t=10）后误差放大 A=2.761（量级 1），证实「误差是网格/通量对的性质，不是计时器」。

## ① 案例介绍

二维可压缩 Euler（理想气体 γ = 1.4）上的**等熵涡**在周期箱内匀速平移：初值即精确解被 |u_inf| = √2 平流后的剖面，箱内平移对称 ⇒ 涡形随 t 不变 ⇒ 离散误差应是**网格/通量对的性质，而非时间的函数**。这就是本算例「误差守恒」四个字的判据来源。

| 项目 | 取值 |
|---|---|
| 计算域 | x, y ∈ [-5, 5]²，四周周期（面积 98 量级归一，熵泛函精确值 = 面积）|
| 涡强度 β | 5.0 |
| 来流 (u, v)_∞ | (1, 1)，c_∞ = 1 |
| 绝热指数 γ | 1.4 |
| 参考解 | Shu (1998) §4.4.2 标准形式，按周期（min-image）映射求值 |
| 末时刻阶梯 | t ∈ {1, 2, 5, 10}；t = 10 = 每轴恰穿一个周期箱 |
| 离散族 | DG-P2/32²（HLLC + SSP-RK3）、P0/64²、P0/128²、P0/256²（Rusanov + SSP-RK3）|
| 验收容差 | t=1 快照各场相对 L2 < 6%；长时由 C2（α ≤ 1）与 C6（无缺检查点）判定 |

## ② 怎么做的（方法 / 流程 / 工具链）

1. **周期参考修复（m20824）**：旧版用自由空间参考解，t>5 后参考解本身偏离周期解，导致「误差」被参考缺陷主导。修复后 `vortex_primitive` 接受 `period` 参数，用 min-image 映射求周期解。
2. **阶梯对账 + C6 门禁（round 5）**：`LADDER` 声明 12 个检查点，旧聚合器只看现有文件，11/12 也判 PASS。新增 `ladder_completeness()` 把声明 vs 落地对账，缺失即 FAIL。补齐 `dg_d2_n32_t10`（集群作业 cj3104，4684 步）。
3. **误差放大因子 A(t)**：新增 `vortex_err_projection_baseline.py`，用与求解器同一条投影代码路径算 e(0)（DG = L2 投影；P0 = 4×4 高斯精确单元平均），再给出 A(t) = e(t)/e(0)。
4. **场量云图（本轮）**：`vortex_err_field_figure.py` 生成 DG-P2/32² 在 t=1 的密度/压力逐点误差场 + y 中线剖面对比。
5. **放大因子图（本轮）**：从 `projection_baseline.json` 绘制 A(t) 半对数曲线，绿色带 A∈[1,2] 为「误差守恒」量级判据。
6. **聚合与发布**：`--aggregate --figures` 重新聚合 12 个检查点，门禁表/误差表/守恒表全部程序化生成，再由本脚本 POST 到 `/tensor/reports`。

## ⑤ 注意点与局限

1. **容差出处**：6% 取自算例池条目的 verbatim（ref: Yee et al. 2000），论文原文不在仓内，未二次核对；所有误差都是对**解析解**量的。
2. **A(t) 的族间可比性有限**：DG 的 e(0) 是 L2 投影误差，P0 的 e(0) 是单元平均表示误差，底数量级差 1–2 个量级，A 只能在同一族内看趋势。
3. **单网格单 CFL**：DG 族仍是单一 32² 网格、CFL = 0.2，α 与 A 的网格/CFL 依赖性本轮未测，是明确的未完成项。
4. **P0 长时误差**：P0 族 t=10 最大场 14.3% 远超 6% 容差，这是一阶格式耗散累积的预期行为，不承担精度验收。

**结论**：DG 设计族在 t=1 与 t=10 两个检查点的最大场误差都 **< 3%**（分别为 0.0094% 与 0.0152%），输运到 t=10 后的误差放大 2.761 倍（量级 1，证实误差守恒）。P0 族 t=1 的 4.93% 未全部 < 3%，它是刻意保留的一阶交叉校核路径（C5 用它证明第二套代码在收敛），不承担精度验收。
