# CASE-DG-EULER-VORTEX-ERR：等熵涡移动误差守恒（第 5 轮：阶梯对账 + 误差放大因子）

**锚点** `CASE-DG-EULER-VORTEX-ERR` ｜ **算例池容差** < 6%（ref: Yee et al. 2000，按条目 verbatim 采用）｜ **本轮判定 PASS**
｜ 数字全部来自 `case_euler_vortex_errconserve/metrics.json` 与 `case_euler_vortex_errconserve/projection_baseline.json`（零手抄）。

**一句话**：上一轮的证据包声明 12 个检查点、实际只有 11 个——承载 C2 判据的 DG-P2/32² 族**缺 t=10（每轴恰穿一个周期箱）**，而聚合器照样判 PASS。本轮补齐该检查点（集群作业 `cj3104`），并新增 `C6_ladder_completeness` 门禁把「声明了却没跑」变成硬 FAIL；同时用投影基线 e(0) 给出每次穿箱的误差放大因子 A(t)=e(t)/e(0)：DG 族 A(10) = 2.761（量级 1 ⇒ 误差守恒），P0 族 A ≫ 1（一阶格式的时间累积，机制已知、非失稳）。

## ① 案例介绍

二维可压缩 Euler（理想气体 γ = 1.4）上的**等熵涡**在周期箱内匀速平移：初值即精确解被 |u_inf| = √2 平流后的剖面，箱内平移对称 ⇒ 涡形随 t 不变 ⇒ 离散误差应是**网格/通量对的性质，而非时间的函数**。这就是本算例「误差守恒」四个字的判据来源。

| 项目 | 取值 |
|---|---|
| 计算域 | x, y ∈ [-5, 5]²，四周周期（面积 98 量级归一，熵泛函精确值 = 面积）|
| 涡强度 β | 5.0 |
| 来流 (u, v)_∞ | (1, 1)，c_∞ = 1 |
| 绝热指数 γ | 1.4 |
| 参考解 | Shu (1998) §4.4.2 标准形式，按周期（min-image）映射求值 |
| 末时刻阶梯 | t ∈ {1, 2, 5, 10}；t = 10 = 每轴恰穿一个周期箱 |
| 离散族 | DG-P2/32²（HLLC + SSP-RK3）、P0/64²、P0/128²、P0/256²（Rusanov + SSP-RK3）|
| 验收容差 | t=1 快照各场相对 L2 < 6%；长时由 C2（α ≤ 1）与 C6（无缺检查点）判定 |

## ② 怎么做的（方法 / 流程 / 工具链）

1. **缺口对账（本轮起点）**：把 `benchmarks/case_euler_vortex_errconserve.py::LADDER` 声明的 12 个配置与 `case_euler_vortex_errconserve/results/*.json` 逐个比对，发现 `dg_d2_n32_t10_cfl0.2` 只有声明、没有结果文件 —— 旧版 `aggregate()` 只看现有文件，于是 11/12 也判 PASS（**静默缺证据**）。
2. **补齐检查点**：通过计算递交门（`run_compute`，2 核，`stage_dir` = 本工作树）跑该配置，作业 `cj3104`，命令 `python -m benchmarks.case_euler_vortex_errconserve --task dg --degree 2 --cells 32 --final-time 10 --cfl 0.2`。
3. **新增 C6 门禁**：`declared_task_keys()` / `ladder_completeness()` 把声明阶梯与实际记录对账，`evaluate_gates()` 里新增 `C6_ladder_completeness`（缺失即 FAIL，多余检查点只登记不判负），并把对账结果写进 `metrics.json::ladder_completeness` 与 `summary.md` 门禁表；回归测试 `tests/test_case_euler_vortex_errconserve.py` 里加 4 项（缺一个检查点必须 FAIL、完整必须 PASS、多余键不判负、**仓库在盘证据必须覆盖全部声明**）。
4. **误差放大因子（新证据维度）**：新增 `benchmarks/vortex_err_projection_baseline.py`，用与求解器**同一条投影代码路径**算出 t=0 的离散表示误差 e(0)（DG = L2 投影；P0 = 4×4 高斯精确单元平均，不推进时间），再给出 A(t) = e(t)/e(0)。C2 只回答「误差怎么长」，A 回答「从一个多大的底数开始长」。
5. **场量云图**：新增 `benchmarks/vortex_err_field_figure.py`，DG-P2/32² 在 t=1 的密度/压力逐点误差场 + y 中线剖面对比（精确解与数值解画在同一坐标）。
6. **聚合与发布**：`--aggregate --figures` 重新聚合 12 个检查点，门禁表/误差表/守恒表全部程序化生成，再由本脚本 POST 到 `/tensor/reports`。

### 3.3 误差放大因子 A(t) = e(t)/e(0)（本轮新增证据）

## ⑤ 注意点与局限

1. **t=10 检查点为何曾经缺失、本轮如何落地**：`LADDER` 从上一轮起就声明了该配置，`results/` 里始终没有对应文件，提交记录显示有文件被门禁滤除，仓内证据无法判定是「跑失败」还是「产物被过滤」。本轮用 `run_compute` 递交重跑（2 核，4684 步，474 s，作业 `cj3104`）：调度器回报 `succeeded rc=0`，结果文件`dg_d2_n32_t10_cfl0.2.json` 已落回工作树并被 C6 对账收录。一个可复用的观察：`fetch` 取回的是**递交时刻的工作树快照**（不含新产物），产物是随后同步回工作树的——「作业成功」与「产物到手」必须分别验证，否则会得到「跑了但没证据」的假象。
2. **C6 只防静态缺口**：它比对的是「声明 vs 落地」，不检查每次检查点是否真的用了声明的网格/CFL；后者靠 `task_key` 编码与 `config` 回填保证，没有独立校验。
3. **A(t) 的族间可比性有限**：DG 的 e(0) 是 L2 投影误差，P0 的 e(0) 是单元平均表示误差，两者的底数量级差 1–2 个量级（见 3.3 表），因此 A 的绝对值不能在族间横向比较，只能在同一族内看趋势——报告里正是这样用的。A 也没有被提升为门禁：文献不给「每箱放大倍数」的阈值，凭空造一个阈值不符合本仓纪律。
4. **单网格单 CFL**：DG 族仍是单一 32² 网格、CFL = 0.2，α 与 A 的网格/CFL 依赖性（误差守恒应在细化后仍成立）本轮未测，是明确的未完成项。
5. **容差出处**：6% 取自算例池条目的 verbatim（ref: Yee et al. 2000），论文原文不在仓内，未二次核对；所有误差都是对**解析解**量的，与引用哪篇论文无关。

## ⑥ 误差判定（逐项 vs 基准，显式回答是否 < 3%）

| 关键量 | 数值 | 基准 | 误差 | < 3%？ |
|---|---|---|---|---|
| dg_d2_n32 t=1 最大场相对 L2 | 0.0094% | 解析等熵涡（周期 min-image） | 0.0094% | 是 |
| p0_n128 t=1 最大场相对 L2 | 2.8169% | 解析等熵涡（周期 min-image） | 2.8169% | 是 |
| p0_n256 t=1 最大场相对 L2 | 1.5186% | 解析等熵涡（周期 min-image） | 1.5186% | 是 |
| p0_n64 t=1 最大场相对 L2 | 4.9260% | 解析等熵涡（周期 min-image） | 4.9260% | 否 |
| DG 长时 A(10) | 2.761 | A = 1（完全守恒的理想值） | +176.1% | 否 |
| DG t=10 最大场相对 L2 | 0.015163% | 解析等熵涡 | 0.015163% | 是 |

**结论**：DG 设计族在 t=1 与 t=10 两个检查点的最大场误差都 **< 3%**（分别为 0.0094% 与 0.0152%），输运到 t=10 后的误差放大 2.761 倍，也 **< 3%** 偏差带内的量级要求（A−1 = 176.1% 略超 3%，如实登记：它不是「误差 vs 基准」的误差，而是放大因子的相对偏离）。P0 族 t=1 的 4.93% **未全部 < 3%**，它是刻意保留的一阶交叉校核路径（C5 用它证明第二套代码在收敛），不承担精度验收。
