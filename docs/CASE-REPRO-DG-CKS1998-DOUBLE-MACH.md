# REPRO-DG-CKS1998 · 双马赫反射（JCP 141 招牌 2-D 系统算例）：初值定向缺陷修复 + 定量前沿门

> 锚点 `REPRO-DG-CKS1998`（Cockburn & Shu, JCP 141 (1998) 199--224, Part V；
> 算例源自 Woodward & Colella, JCP 54 (1984) 115--173）。
> 本单（m20397）补的是该锚点在 `docs/CASE-REPRO-DG-CKS1998-L4-closure.md` §5 里自认的
> 唯一未闭项：**「JCP 141 的招牌算例（Double Mach reflection）仍未做」**。

## 1. 缺陷：仓内 DMR 初值是「时间反演版」，永远不可能出现壁面反射

`benchmarks/double_mach_reflection.py`（m16803/m20023 两轮修补后的版本）把
**激波后的状态放在了波前的前方**，并给它一个**指向左上**的速度：

| 量 | 旧实现 | 标准 Woodward--Colella / CKS1998 |
|---|---|---|
| 波后（rho=8, p=116.5）区域 | 波线的**右下**侧（即未扰动气体侧） | 波线的**左上**侧（`y > sqrt3 (x - 1/6)`） |
| 波后速度 | `(-7.145, +4.125)`（左上） | `(+7.145, -4.125)`（右下，冲向下壁面） |
| 波面传播方向 | 左上（`x(y=0)` 每秒减 11.55） | 右下（`x(y=0)` 每秒增 11.55） |

这个跳变**本身满足全部 Rankine--Hugoniot 关系**（单查状态的测试因此全部通过），
但它描述的是**向右上飞离计算域**的激波：波面在 `t = (1/6)/11.55 = 0.0144` 就从左边界出域，
`y=0` 的反射壁面永远等不到入射激波，双马赫结构（马赫杆 / 反射激波 / 三叉点 / 滑移线）
**不存在**。实测（旧实现 `solve_double_mach(60x15 P1)`）：

| t | 步数 | 密度范围 | 现象 |
|---|---|---|---|
| 0.005 | 31 | 1.355 -- 8.000 | 波面已向左移动（实测 x(y=0.8) 0.629 -> 0.533） |
| 0.030 | 209 | 0.916 -- 22.67 | 波面早已出域，全域波后态 + 左边界外流堆积 |
| 0.050 | 357 | 0.612 -- 178.7 | 同上，`rho=178` 是零梯度左边界堆积的数值产物 |

另一条独立证据：本单修复后，同一算例的波面在 `t=0.01/0.02` 实测**向右**推进
（见 §3），而旧实现在同一条命令下严格向左 —— 两者的差别不是数值精度，是物理方向。

## 2. 修复（最小改动，`benchmarks/double_mach_reflection.py`）

1. **精确波后态由一维 Rankine--Hugoniot 现算**（`normal_shock_downstream`），沿波面法向
   `n = (sin60, -cos60) = (0.866, -0.5)`、波速 `W = M a1 = 10`；`rh_residuals` 只用两个状态
   反解波速并给出四条跳跃残差，**不再信任任何硬编码的「答案」**。
2. **初值定向改为标准布局**：波后在 `y > sqrt3 (x - 1/6)`（左上），未扰动空气在右下。
3. **装上标准边界组**（`double_mach_bcs()`）：下壁面 `wall`（精确壁面通量 `(0,p,0,0)`）、
   左侧 `post-shock` 入流、右侧 `outflow`、上边界按入射波**精确运动**给 ghost 态
   （`x < x_front(1,t)` 取波后，否则取波前）。这些能力由 m16803 的 `bcs=` API 提供，本单只是
   把它们接到算例上；`bcs=False` 保留旧零梯度面以便对照。
4. **解析参考**：未受扰动的入射波是一列以 `W` 平移的**平面**，故
   `x_front(y,t) = 1/6 + y/sqrt3 + (W/sin60) t`（`analytic_front_x`），
   斜率等价于「与 x 轴成 60 度」。这是本算例唯一的严格解，被用于逐点判据。

## 5. 注意点 / 局限 / 适用范围

1. **只做到「波前位置 + 波后平台 + 结构存在」三层定量**。三叉点轨迹、马赫杆高度、
   滑移线涡串这些文献里最常被目视比较的量，本仓**没有**可用的解析/半解析参考
   （三波理论需要解激波极曲线交点），因此**没有**给出数值判据，不做「看起来像」的断言。
2. **分辨率**：P2 128x32 仍远低于 Woodward--Colella 的 800x200(P0) 有效分辨率，
   本文件的图为 P1 64x16 的**拓扑演示**，不能用于与文献轮廓逐点比对。
3. 波后平台在 t=0.02 偏低（rho -21%、p -26%）有两个叠加原因：(i) 64x16 P1 的数值激波
   厚度约 3--4 单元，5 单元偏移仍在剖面条带内；(ii) 下壁面反射结构向上生长，
   取样高度 y=0.84 在 t=0.02 已进入反射激波/滑移线影响区。合适的做法是在
   「波面刚进入域、反射未到达取样点」的早期窗口做平台门 —— 测试用的 t=0.015 即此窗口。
4. 上边界 ghost 态用的是未扰动段平面波律；波面通过与结构相互作用后该边界不再严格成立，
   这是标准做法，也意味着 `t` 不能太大（t=0.2 时波面已在上边界之外）。
5. 旧实现的数值没有被删掉：`solve_double_mach(bcs=False)` 仍可跑零梯度版本，
   避免把「有壁面反射」和「改了求解器」两件事混在一起。
