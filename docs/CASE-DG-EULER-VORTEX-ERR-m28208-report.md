## ① 案例介绍（物理背景 / 几何 / 参数表）

二维可压缩 Euler 方程（理想气体 γ = 1.4）中的**等熵涡**（isentropic vortex），以恒定速度 |u_inf| = √2 在周期域 [-5,5]² 中平流输运。密度/压力扰动具有高斯包络，流动处处等熵，存在封闭形式的解析解（Shu 1998 §4.4.2 标准形式）。精确解无变形地平移，因此离散误差应是**网格/格式的属性**而非时间的属性——这正是"误差守恒"在涡输运中的物理含义。

| 参数 | 值 |
|---|---|
| 域 / 边界条件 | [-5, 5]²，双周期（周期箱长 L = 10） |
| 涡强度 β | 5.0 |
| 来流速度 (u, v)_∞ | (1, 1)，\|u_inf\| = √2 ≈ 1.4142 |
| 绝热指数 γ | 1.4 |
| 参考解 | 解析等熵涡（周期 min-image 映射，machine-verified） |
| 设计族 | DG-P2（张量积模态 Legendre + HLLC + SSP-RK3） |
| 网格阶梯 | 16 / 32 / 64（每轴） |
| 末时刻 / CFL | t = 1 / CFL = 0.2（控制 CFL = 0.1） |
| 待验证假设 | 观测 L2 阶 = p + 1 = 3（≥2 为验收下限） |

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **同一代码路径**：阶梯用与算例池完全相同的求解入口 `tensordg.euler_dg_2d.solve_euler_dg_2d_vortex`，误差用同一体积 Gauss 求积的逐点相对 L2（`benchmarks.verify_euler_dg_2d._vortex_error`）。n = 32 / 64 与算例池已落盘记录逐位一致（回归测试 `test_study_reproduces_the_case_pool_ladder_records` 断言 rel < 1e-12）。
2. **网格阶梯** [16, 32, 64]，末时刻固定 t = 1；阶拟合丢弃最粗网格（渐进窗口 [32, 64]），局部阶全量打印。
3. **S1 空间阶**：逐场最小二乘拟合 e ~ h^order，要求 ≥ 2.70 = 0.9 × (p+1)。
4. **S2 度量自洽**：同阶梯上只做 L2 投影（不推进时间、不用数值通量），其误差序列也必须 h^{p+1}——证明 h 标度来自度量与参考解求值，而不是求解器独有。
5. **S3 时间误差占比**：CFL 0.1 与 0.2 复算，相对变化须 < 2%（SSP-RK3 在 dt ∝ h 时也呈 h³，必须排除它与空间阶混淆）。
6. **S4 反真空校核**：把同一末态对**故意错位**的参考解（t + 0.05）评分，阶必须塌到 < 1.50——否则「阶」这个统计量对错误参考不敏感，S1 就是空判据。
7. **S5 容差余量**：最细网格最大场误差须 < 0.1 × 算例容差。
8. **工具链**：CPU float64（torch 2.7.1 / numpy 2.4.6）；静默/求解均为确定性，无随机数。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **n = 128 未测**：DG-P2/128² 在本集群节点上复现段错误（`Segmentation fault (core dumped)`，作业 cj3320），因此阶拟合只用到 16/32/64 三点、渐进窗口 32/64。更高分辨率的阶复核列为**未完成项**，本报告不声称已测。
2. **为什么短时**：阶是渐近量的度量，长时间累积会把色散误差混入，使「阶」不再可辨识；短时窗口（t = 1）是标准做法（LeVeque 2002 §8）。
3. **相对 L2 的分母**是全场均方，包含均匀来流背景，因此Therefore数值远小于涡核局部误差；这与算例池容差口径一致，不是宽松化。
4. **时间误差**只在 [32, 64] 上直接量化；更细网格的时间误差按 h³ 收缩，未被单独测量（已知未测项，不声称已测）。
5. **适用范围**：本结论适用於双周期边界下的等熵涡输运。壁面反射、激波捕捉等场景需另行验证。
