## ① 案例介绍

二维可压缩 Euler 方程（γ = 1.4）中，等熵涡在双周期方箱内以匀速平移。流场处处等熵、扰动为高斯包络，故有闭式解析解；平移不改变涡的形状，因此离散误差应当是网格/格式属性而不是时间属性——这正是本算例（误差守恒）与快照算例 `EULER-VORTEX` 的区别所在。

| 参数 | 值 |
|---|---|
| 域 / 边界 | [-5, 5]²，双周期 |
| γ | 1.4 |
| 涡强度 β | 5.0 |
| 来流速度 | (1, 1)，u_inf = √2 ≈ 1.41421 |
| 周期长度 | L = 10（每轴），整周期时间 T ≈ 7.0711 |
| 参考解（聚合口径） | `min_image` 周期 min-image 折叠 |
| 参考解缺陷（自由空间 vs 周期公式，t=1） | 9.217e-03 % |
| min-image 截断地板（t=1，最大场） | 1.446e-04 % |

## ② 怎么做的（本轮的方法）

前 11 轮已经把 11 条判据（C1–C11）建成机器可判定的形式，缺的只有**证据**：

1. **缺的阶梯检查点**（C6）：`LADDER` 声明但 `results/` 里没有文件的配置，本轮经计算门以 8 分片跑完（`--shard i/8`；分片器对 0-based/1-based 两种约定都恰好划分一次，不会漏掉第 0 条）。
2. **溯源未知的旧读数**（C11）：结果文件写在 `reference_model` 字段存在之前，聚合器过去用「默认 min_image」填补——那是假设而不是证据，而这个假设在本算例前 3 轮正好被打破过（早期读数是对自由空间公式测的，涡折叠后 t>5 时自由空间公式不再是周期解）。本轮用 `tools/provenance_certify.py` 以**同一配置**对当前参考解重放，要求复现原读数到 1e-9（相对）。
3. **判据不动、阈值不动、旧读数不改**：本轮唯一的输入变化是「缺的文件有了」与「旧文件有了证书」；聚合器沿用 round 11 的版本，因此判定是可复核的。

工具链：`tensordg.euler_dg_2d`（模态 DG + HLLC + SSP-RK3）、`tensordg.euler_2d`（P0 有限体积 + Rusanov，独立第二代码路径）、`benchmarks/case_euler_vortex_errconserve.py`（算例驱动 + 聚合器）、`tools/provenance_certify.py`（重放证书）。

## ⑤ 注意点

1. **补的是账，不是阈值**：本轮没有移动任何容差、没有改判据定义、没有重跑已有读数。C6/C9/C11 的判据文本与 round 11 完全一致。
2. **「排队」不等于「通过」**：round 10/11 把待跑检查点登记在 `PENDING_RUNS`，C6 只读结果文件，因此当时正确地判为 INCOMPLETE。本轮把作业跑完、文件落盘后，同一判据才可能通过——这正是该判据要防的错误。
3. **旧读数只被复核、不被替换**：C11 的重放是独立重跑，存档读数保持原样；复现要求 1e-9 相对偏差（实测在 0 … 1e-12 量级），留出的余量只覆盖 BLAS/线程非确定性，不足以放过另一个参考解或另一套格式。
4. **p=3 的读数分辨率**：p=3 的离散误差已接近周期 min-image 参考的速度场截断地板，其 alpha 应按「参考受限」登记，不作强判据（地板研究见 `case_euler_vortex_errconserve_lattice/reference_floor.json`）。
5. **P0 长时不满足 6%**：一阶有限体积族在 t=10 的误差远超快照容差，这是格式阶数的固有属性；C1 按 t=1 快照判，长时读数只作 C1x 登记，不作判据。
6. **容差与文献的绑定关系**：6% 这个数字逐字取自算例池条目（ref: Yee, Sandham & Djomehri, JCP 162 (2000)），**没有**从原文重新推导——论文正文不在仓内。本文所有验收读数都是对**闭式解析解**测量的，因此结论不依赖「该容差是否出自该论文」，只依赖该条目声明的容差数值。解析解本身（域 [-5,5]²、β=5、u_inf=(1,1)、γ=1.4）见 Shu (1998) §4.4.2；其满足 Euler 方程已由 `case_euler_vortex.py --task residual` 独立验到 1e-10。
