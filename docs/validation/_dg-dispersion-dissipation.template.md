## 1. 案例介绍

TensorDG 的 `advection_1d` / `advection_2d` 是整条验证链的基线求解器：模态 Legendre 基、
迎风（upwind）数值通量、周期边界、经典 RK4，二维为张量积形式。它们此前的验证全部是
**终态 L2 误差对精确平移正弦波**（收敛阶 $p+1$、$2p+1$ 与质量守恒），属于"解"的度量。
但这两个求解器同时是全仓其它波传播算例的时间积分骨架，还有两条从未被验证的隐式契约：

1. **色散与耗散**：单个 Fourier 模态的数值相速度、数值衰减率与精确值的关系。这是波求解器
   的真正精度指标——L2 误差可能由振幅误差主导，掩盖相位（波形）误差，反之亦然；
2. **时间步规则**：求解器硬编码 `dt = cfl*h/((2p+1)|a|)`（1-D）与
   `dt = cfl/((2p+1)(|ax|/hx+|ay|/hy))`（2-D），其中除数 `2p+1` 是**未经检定的启发式**：
   它不来自任何已归档的稳定性分析，而 `euler_1d` / `burgers_1d` / `advection_2d` 均复用同一族规则。

因此本单把这两条欠账一次性结清：用**生产算子本身**（不复制组装代码）做半离散 Bloch 谱分析，
所有结论锚定在闭式解析结果上。

**分析对象与参数**

| 项 | 取值 |
|---|---|
| 方程 | $u_t + a u_x = 0$（1-D，周期）；$u_t + a_x u_x + a_y u_y = 0$（2-D） |
| 对流速度 | $a=1$（1-D）；$(a_x,a_y)=(1,0.5)$（2-D） |
| 单元数 | $N \in \{4,8,16,32,64\}$（1-D）；$N_x=N_y \in \{5,6\}$（2-D） |
| 多项式阶 | $p \in \{0,1,2,3\}$（求解器允许的全部阶） |
| 通量 | 迎风；参考单元 Legendre 模态基 |
| 时间积分 | 经典 RK4（稳定域实轴截距 $\rho=2.78529$） |

## 2. 方法

**算子即生产算子。** 把 `tensordg.advection_1d._rhs` 作用在单位向量上，逐列取出半离散算子
$A$（$du/dt = Au$）。这不是"重写一遍离散"，因此不存在分析与实现漂移的可能；文中另用
"一个 RK4 步 vs 生产求解器一步"的对照把这一点量化（见锚点表）。

**Bloch 分解。** $A$ 在单元指标上是块循环矩阵，故取 $\theta \in (0,\pi]$、
$v_{j}=\mathrm{e}^{\mathrm{i}\theta j}w$ 的不变子空间，得每个波数下 $p+1$ 个半离散频率
$\lambda_\ell(\theta)$。实现上有两条互相独立的路径，并互为对照：

- 投影法：$S = V^{\mathsf H} A V / N$（$V$ 为 Bloch 试验矩阵）；
- 块符号法：$A$ 的块矩阵 $A_r$（$r\in\{0,\pm1\}$）给出 $S(\theta)=\sum_r A_r \mathrm{e}^{\mathrm{i}\theta r}$，
  对任意 $\theta$ 成立，故可细扫 $\theta \to 10^{-4}$。

**物理分支。** 精确色散为 $\lambda_{exact}=-\mathrm{i}ak$。$p\ge2$ 时 $p+1$ 条分支在粗分辨率处
交叉，因此**不用"最近特征值"匹配**，而是从 $\theta\to0$ 起用特征向量连续性追踪，
并统计追踪歧义（相邻分支特征向量重叠度差 $<10^{-3}$ 即记为歧义）。

**判据（机器可执行，见 `tests/test_dispersion.py`）**

| 编号 | 判据 | 阈值 |
|---|---|---|
| A1 | $p=0$ 符号 = 闭式一阶迎风 FTBS 符号 $\lambda=(a/h)(\mathrm{e}^{-\mathrm{i}\theta}-1)$ | $10^{-12}$ |
| A2 | 块符号 vs 全算子投影（特征值多重集距离） | $10^{-10}$ |
| A3 | 由 $A$ 组装的 RK4 步 vs 生产 `solve_advection` 一步 | $10^{-12}$ |
| A4 | 能量稳定性：全部模态 $\max\mathrm{Re}\,\lambda$ | $\le 10^{-10}$ |
| A5 | 相位误差阶 = $2p+2$ | $\pm0.35$ |
| A6 | 时步规则落在 RK4 稳定域内，$cfl_{max}\ge0.5$，默认 $cfl=0.08$ 余量 $\ge3$ | — |
| A7 | 负控：超限步长必须真失稳 | $L_2>0.5$ |

## 4. 注意点（局限与适用范围）

1. **只分析半离散算子**。RK4 稳定域用的是实轴截距 $\rho=2.78529$；RK4 在虚轴附近还能多容忍一点，
   所以 $cfl_{max}$ 是**偏保守**的下界——这对"规则是否安全"的结论方向正确，但不能当成精确实用上限。
2. **时间离散误差未包含在色散/耗散曲线里**。曲线是空间算子的性质；有限 $dt$ 会叠加时间相位误差
   （$\mathcal{O}((ak\,dt)^4)$，RK4）。因此 3.1 的 `ppw` 是空间精度的必要条件，不是整机精度的充分条件。
3. **$p=3$ 的 `ppw @1%` 撞 Nyquist 上限**（$\theta\to\pi$ 时两对特征值简并：$\mathrm{Re}\lambda$ 出现
   成对退化），该值应读作"$\le 2.2$ ppw"，仅具指示性；对应记录中 `at_nyquist_limit=true`。
   同理，任何 $\theta$ 接近 $\pi$ 的读数都受分支简并影响。
4. **二维只做了 $5\times5$ / $6\times6$ 的谱半径锚点**（ndofs $\le$ 576），足以证明
   `wave_rate=|ax|/hx+|ay|/hy` 与 `2p+1` 除数组合**在安全侧**（比值 2.00/6.00/11.84/19.16 与一维同阶），
   但不是二维全角度谱的完备分析；各向异性速度、非结构/非张量积网格未覆盖。
5. **耗散是粗分辨率下的首要误差源**：所有 $p\ge1$ 的容差都是"每波长振幅衰减"先触线（见
   `diss_at_theta_max ≈ 容差` 而 `phase_err_at_theta_max` 小 1–2 个量级）。实践含义：
   冲激/间断类算例靠加密到"相位够准"还远远不够，迎风通量的数值耗散才是主导。
6. **验收范围**：结论只对当前 `advection_1d`/`advection_2d` 的迎风通量+RK4 组合成立；
   若后续换成 LDG/BR1 扩散项或不同限制器，需重跑同一分析器（工具已参数化）。

## 5. 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 基准 | 实测偏差 | 是否 <3% |
|---|---|---|---|
| $p=0$ Bloch 符号 | 闭式 FTBS 解析符号 | $4.44\times10^{-15}$（相对 $a/h=16$ 约 $2.8\times10^{-16}$） | ✅ 是（远小于） |
| 块符号 vs 全算子投影 | 同一算子的两种独立离散化 | $\le 4.82\times10^{-13}$ | ✅ 是 |
| 谱算子 vs 生产求解器一步 | `solve_advection` 实跑 | $\le 1.40\times10^{-17}$ | ✅ 是 |
| 相位误差阶（$p=1,2,3$） | 解析预期 $2p+2$ = 4,6,8 | 实测 3.99 / 5.99 / 7.98（偏差 $<0.3\%$） | ✅ 是 |
| 相位误差阶（$p=0$） | 解析预期 2 | 实测 2.00 | ✅ 是 |
| 时步规则安全性 | 谱半径反解的 $cfl_{max}$ | 规则默认 $cfl=0.08$ 相当于 $cfl_{max}$ 的 5.7%–6.5%（余量 $\ge 12.7\times$） | ✅ 是（安全侧） |
| 能量稳定性 | $\mathrm{Re}\,\lambda\le0$ | $\max\mathrm{Re}\lambda$ 全为负（$-6.1\times10^{-1}$ 至 $-5.0\times10^{-11}$） | ✅ 是（无正实部模态） |
| 负控失稳 | $cfl_{max}=1.395$ 的预测 | $cfl=2.0$ 实测 $L_2=1.75\times10^{1}$（放大 $6\times10^{3}$ 倍） | ✅ 是（预测与实测同向同量级） |
| `ppw` 表 | 无独立解析基准（判据本身是容差定义） | — | 声明：**无基准**，不作 <3% 判定；其内部自洽性由 A5 的阶数锚点间接保证 |

**结论**：7 项有基准的量全部落在 $10^{-12}$ 量级的实现精度或 $<0.3\%$ 的阶数一致上，远优于 3% 门限；
唯一无外部基准的是 `ppw` 容差表（性质定义，非精度断言），已显式声明。
