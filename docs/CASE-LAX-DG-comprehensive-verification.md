## ① 案例介绍（物理背景 / 几何 / 参数）

Lax (1954) 激波管 / Toro (2009) Test 2 是可压缩 Euler 方程的**标准 Riemann 问题验证算例**。
一维域 `[0, 1]` 内隔膜 `x₀ = 0.5` 分隔两常状态，比热比 γ = 1.4，快照时刻 t = 0.13。
隔膜移除后产生四道波：左稀疏波（head → tail）、接触间断、右激波。

| 参数 | 左态 | 右态 |
|---|---|---|
| (ρ, u, p) | (0.445, 0.698, 3.528) | (0.5, 0.0, 0.571) |

精确 Riemann 解闭式可得（星区压力/速度通过 Newton 迭代求解两激波/激波-稀疏函数）：

| 量 | 值 |
|---|---|
| p* | 2.466098 |
| u* | 1.528723 |
| ρ*_L（等熵稀疏） | 0.344568 |
| ρ*_R（Rankine–Hugoniot） | 1.304085 |
| x 稀疏波头 | 0.157637 |
| x 稀疏波尾 | 0.287229 |
| x 接触间断 | 0.698734 |
| x 右激波 | 0.822312 |

**为什么这个算例重要**：它自带不依赖第三方求解器的参考值，是验证高阶格式在间断附近
行为的"试金石"——稀疏波检验光滑区精度，接触间断检验耗散，激波检验稳定性。

**台账验收**：`ref: 精确解｜容差 < 3 %`（全场 relative L2，三量逐一 < 0.03）。

### 3.6 限制器臂对比（N = 400 @ P3）

| 限制器 | rel L2 ρ | vs unlimited | verdict |
|---|---|---|---|
| none（无限幅） | 3.116 % | 基准 | FAIL |
| TVB | 7.039 % | 2.26× 恶化 | FAIL |
| WENO | 6.447 % | 2.07× 恶化 | FAIL |

**结论**：在 P3/N=400 上，TVB/WENO 限幅器将问题单元退化为线性重构，
属于过度限制，使 L2 密度恶化 2× 以上。限幅器不是补救手段。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **honest FAIL 不可粉饰**：p3.N400 的 3.116 % > 3 % 是诚实结论。C3/R3 同时 FAIL
   表明间断面压阶是 DG 方法在含激波问题上的固有属性，不是实现缺陷。
2. **达标靠加密不靠提阶**：在间断存在下，全场收敛阶 < 1（P3 仅 0.484），
   提高多项式阶数不能弥补分辨率不足。
3. **限幅器不是补救手段**：TVB/WENO 在 P3/N=400 上使误差恶化 2×，
   因为限幅器将高阶单元退化为线性重构。
4. **认证构型的最小性只在网格内成立**：p2.N800 是 DOF ≤ 3200 网格内的最小达标构型，
   不对未测 (p, N) 断言。
5. **参考解仲裁只证明参考值可信**：不改变 DG 侧的 FAIL 结论。
6. **元数据 `dt` 陷阱已修复**：`meta["dt"]` 是残步而非步长，
   新增 `dt_mean = final_time/steps` 和 `dt_last` 字段（m18266）。

| 关键量 | 基准 | 数值 | 相对误差 | < 3 % ? |
