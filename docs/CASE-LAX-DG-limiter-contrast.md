## ① 案例介绍

Lax (1954) 激波管 / Toro (1999) test 2：`[0,1]` 域，隔膜 `x0 = 0.5`，γ = 1.4，快照 t = 0.13，精确解由 Riemann 求解器逐点给出（不依赖第三方解）。

| 参数 | 左态 | 右态 |
|---|---|---|
| (ρ, u, p) | (0.445, 0.698, 3.528) | (0.5, 0.0, 0.571) |

**待回答的问题**：算例池 `CASE-LAX-DG` 的现行 verdict 是 FAIL，失败的两道闸门是 C3（全场相对 L1 收敛阶 ≥ 1.0）与 R3（解析区相对 L1 阶 ≥ 0.85·(p+1)）。池子的所有腿都是**无限机制**跑的（`limiter=None`，只有 Zhang–Shu 正性缩放）。于是有两种互斥解释：

1. 求解器/离散有问题（真缺陷）；
2. P3 腿在积分一个未正则化的振荡解——限幅器缺位导致的 Gibbs 波纹把 L1 阶压低。

本算例用**算例池自己的闸门函数**检验解释 2：若装上激波捕捉机制后 C3/R3 变为 PASS，解释 2 成立；若装上后仍 FAIL，则池子的 FAIL 不是「缺限幅器」能解释的，该闸门在当前离散族下不可达，需要重新预登记。

## ② 怎么做的

* **机制**：`none`（引用池子已提交的基线，不重算）、TVB 限制器（Cockburn–Shu，每 SSP-RK3 子步 / 仅步末两种施加策略）、传感器门控模态人工黏性 `kind="av"`（Persson–Peraire 传感器 + SVV 指数滤波）。AV 用库默认参数，**未**在 Lax 上调参。
* **阶梯**：只用失败的 P2/P3 两阶，N = 100/200/400（P1 腿的费用被省掉，范围收缩在此声明；P1 的池子数字在 §⑤ 并列引用）。
* **闸门**：`gate_c3` / `gate_r3` 原样复用，`R3_BAND_WIDTH = 0.02` 不变，容差未按结果回调。
* **振荡度量**：每个腿把残差 `ρ_h − ρ_exact` 在四个固定物理窗口上归约（稀疏波扇区 / 星区左平台 / 星区右平台（接触后）/ 未扰动右态），报告 `max|res|`、`mean|res|`、`bias` 与**符号翻转率**（相邻节点残差变号的比例，用来区分「抹平但单调」与「真的有波纹」）。窗口边界：

| 窗口 | 区间 |
|---|---|
| rarefaction_fan | [0.1776, 0.2672] |
| star_left | [0.3072, 0.6787] |
| star_right | [0.7187, 0.8023] |
| undisturbed_right | [0.8423, 0.9800] |

## ⑤ 注意点与范围

### 5.1 C1 的参照物是「同一 locator 的等值线交点」，不是解析波边

`gate_c1` 把数值解与精确解**用同一个 level locator** 定位再比较。接触/激波上两者重合（偏移 < 1e-3），但稀疏波扇内 locator 返回的是 `RAREFACTION_LEVEL_FRACTION` 等值线交点，与解析特征边有**固定偏移**：

| 波 | 解析位置 | locator 位置 | 归一化偏移 |
|---|---|---|---|
| contact | 0.698734 | 0.698734 | 0.00 % |
| rarefaction_head | 0.157637 | 0.168957 | 3.31 % |
| rarefaction_tail | 0.287229 | 0.272314 | 7.01 % |
| shock | 0.822312 | 0.822311 | 0.00 % |

最大归一化偏移 **7.01 %**，大于 C1 自己的容差 2.00 %。结论：C1 的 PASS 应读作「数值与精确解在同一等值线定义下一致」，**不能**读作「波边位置误差 < 2 %」。这是标注问题，不是数值缺陷；池子文档里把 C1 写成「vs 解析位置」的地方据此更正。

### 5.3 局限

* 只跑了 P2/P3（失败的阶），P1 腿未纳入；P1 的池子数字见 `docs/CASE-LAX-DG.md`。
* AV 用库默认参数（在 Sod/N=64 上定的），未在 Lax 上调参；若调参后 C3/R3 变 PASS，那属于「调参后可达」，不是「机制缺位」。
