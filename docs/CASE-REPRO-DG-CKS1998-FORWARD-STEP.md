# CKS1998 · 前向台阶（Mach 3）与「网格内固体障碍」能力

> 锚点 `REPRO-DG-CKS1998`（Cockburn & Shu, *The Runge-Kutta discontinuous Galerkin
> method for conservation laws V: multidimensional systems*, JCP **141** (1998) 199--224；
> 台阶算例源自 Woodward & Colella, JCP **54** (1984) 115--173）。
>
> 本单交付的是该论文**唯一还没有表示手段**的算例所需的能力：**网格内部的固体障碍**。
> 状态一句话：**能力已实现、四条闭合门通过、反射门仍未通过（honest FAIL）；论文算例的
> 生产分辨率运行已递交集群（cj3040）但交接时仍在排队，数值未取回。**

## 1. 缺口：为什么这台求解器跑不了前向台阶

`solve_euler_dg_2d` 的边界只能挂在**计算域外壳**上（`bcs` 的键是
`left/right/bottom/top`，值可以是 `"wall"` / `"outflow"` / ghost callable）。
双马赫反射（`docs/CASE-REPRO-DG-CKS1998-DOUBLE-MACH.md`）之所以做得成，是因为它的
反射壁正好落在 `y = 0`；而前向台阶的两条固壁面——竖直面 `x = 0.6, y ∈ [0, 0.2]` 与
水平面 `y = 0.2, x ∈ [0, 0.6]`——**都在域内**，没有任何参数能表达它们。
`expand_audit_tensordg.md` 的缺口账里这一项是以「2-D 系统算例集不全」记的账。

## 2. 做了哪些改动（最小集）

`tensordg/euler_dg_2d.py`：

| 组件 | 内容 |
|---|---|
| `normalise_solid(solid, nx, ny, device)` | 新增。布尔 `(nx, ny)` 单元掩膜；形状不符即报错（**不做广播**——广播错的掩膜会错封单元）；全固/无固都有明确语义 |
| `_solid_interface(...)` | 新增。固体-流体内部面把 HLLC 换成本征滑移壁通量 `(0, p, 0, 0)`，**压力取流体侧迹**；两固相邻面通量为 0 |
| `_zero_solid_face(...)` | 新增。固体单元的外壳面通量置 0（否则 `ledger` 会把「固体里流出来的质量」记成边界通量） |
| `_solid_face_sum(...)` | 新增。域内固体面的壁面通量和（带符号），给出**障碍物对气体的动量反作用** |
| `_freeze_solid(...)` | 新增。固体单元在每个 RK 级/限幅/正性投影后恢复为初始投影，永不被更新 |
| `_rhs(..., solid=)` / `_axis_fluxes(..., solid=, wall_rate=)` | 残差在固体单元置 0；`ledger["solid_rate"]` 输出障碍物冲量 |
| `solve_euler_dg_2d(..., solid=)` | 新增形参；`dt` 估计只用流体单元；`metadata` 增加 `solid_cells` / `obstacle_impulse` / `conservation_residual_total` |

`solid=None`（所有历史调用方）路径**逐位不变**：`_solid_interface` 直接原样返回 interface，
`_rhs` 不乘掩膜、不带 `solid_rate`。

**过程中抓到并修掉的一个真缺陷**：`_solid_interface` 里「左侧固体/右侧流体」与
「右侧固体/左侧流体」两个分支的迹**互换了**，于是壁面压力取的是**固体单元冻结的初值**而
不是流体侧压力。A/B 证据（`x_wall=1.0` 的内壁反射、40×1 P1）：修前贴着壁的流体密度被
"顶"成 `0.70–0.92`（应在 6.0 附近），即壁面几乎不推气体；修正后同一算例的贴壁剖面回到
`3.8 → 2.67`（入射波后态）方向正确。这个缺陷只有靠独立参考（精确双激波解）才能发现——
自由流保持、守恒、台阶上游这些门**都发现不了它**（它们对称，对换左右无感）。

## 3. 通过的门（本机实跑，数字由程序打印，零手抄）

| 门 | 设置 | 结果 | 判据 |
|---|---|---|---|
| G1 内部壁面保持自由流（精确） | 24×12 P2，横向内壁条带，t=0.05，114 步 | 相对偏差 **1.9e-12** | < 1e-10 ✅ |
| G2 含障碍物封闭方腔守恒（精确） | 24×24 P1，t=0.1，147 步 | 质量 **4.99e-15**、能量 **4.10e-15**、含冲量的动量 **3.97e-15** 相对残差 | < 1e-12 ✅ |
| G2′ 障碍物确实施力 | 同上 | `obstacle_impulse[y_momentum] = 8.30e-3`（非零） | 需 > 0 ✅ |
| G4 台阶算例未扰动上游（精确） | 24×8 P1，t=0.12 | 上游 `rho` 相对偏差 **< 1e-10**；`obstacle_impulse[x] < 0`（阻力） | < 1e-10 ✅ |
| API 校验 | 错形状/全固掩膜 | `ValueError` | 必须拒绝 ✅ |
| G3 内部壁面激波反射 vs 精确双激波解 | 30×1 P1 / 40×1 P1，壁在 x=0.5 / 1.0 | **未通过**（见 §4） | < 3 % ❌ |

质量/能量为什么能到机器精度：壁面通量 `(0, p, 0, 0)` 的质量与能量分量为 0，域内固体面
与外壳壁面都不搬运质量/能量，所以「域积分变化 = 边界通量 + 障碍冲量」是**恒等式**而不是
小误差判据。动量分量不为 0 是物理的（障碍物反推气体），必须把 `obstacle_impulse` 计入后
才闭合——这正是本单加 `_solid_face_sum` 的理由。

## 4. 未通过 / 未完成（honest FAIL，不粉饰）

**(a) G3 内部壁面激波反射门未通过。** 精确参考是
`benchmarks.euler_dg_2d_wall_bc.WallReflection`（入射激波由 Rankine--Hugoniot 现算，
反射激波 Mach 数由跳跃条件二分），只把壁面从「域边界」换成「域内固体块」。
- 首次配置（40×1 P1、`x_shock=0.95`、`x_wall=1.0`）读出平台区 `p ≈ 1.0`（应 15.0），
  误差 93.3 %。诊断：该几何下**入射波后只有 1–2 个流体单元**，反射激波无处成形，
  采样点也落在波前未扰动区——门是**几何退化**，不是判据太严。
- 改为 `x_shock=0.2`、`x_wall=0.5`、30×1 P1（域长 0.6）后重跑，本次交接时**仍失败**
  （pytest 单测已用 `xfail(strict=False)` 记录，理由指向本文）。**残余偏差的物理归因未定**：
  可能是反射后壁面附面/激波与固体冻结态相互作用的建模问题，也可能是 P1 + 30 单元的
  分辨率不足。**未取回**更细分辨率（集群 64×1 P2 门在 `benchmarks/forward_facing_step.py`
  的 `gate_wall_reflection` 里已写好）的判定，因此本门记为 **WITHHELD/FAIL**，不算通过。
- 反过来说：**结论不因此动摇** §3 的四条精确门（它们是独立的、且已通过），但「域内固体壁
  的激波反射定量正确」这一条**没有证据**。

**(b) 论文算例（Mach 3 台阶，60×20 P1，t=2.0）未取回。** 运行已作为集群作业 **cj3040**
（16 核，`python -m benchmarks.forward_facing_step --profile quick --final-time 2.0`）递交，
交接时排队位次 14。因此本报告**没有**台阶的密度范围、阻力系数 `Cd`、激波位置与收敛性数字，
也**没有图**（图由该作业的 `validation/forward_step/forward_step_density.png` 生成）。
按报告纪律显式说明：缺图的理由是生产算例运行未完成，不是省事。

**(c) 已知限制（代码层面，写在这里以免下次踩）**
- 固体必须**网格对齐**（无 cut-cell / ghost-fluid）：斜壁、曲面体不支持；
- 固体单元被冻结在初始投影态，因此限幅器的相邻模板会把固-液界面当成强间断，
  贴壁流体单元实际被限到一阶；这对激波算例可接受，对边界层类问题不可接受；
- `solid` 与 `periodic` 同轴时，固体跨周期缝的绕接按 roll 处理（有语义，但无专门校验）；
- 无限制器（`limiter=None`）时 Mach 3 台阶在 t≈0.02 内即出现非物理单元均值（实测），
  本算例必须配 TVB（`tvb_constant=1.0`）或 WENO；WENO 在该算例上同样失败（另一条线索）。
