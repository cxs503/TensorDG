# Manning bottom friction in the 1-D shallow water solver

Status: 2026-11-11. Repository: TensorDG. Scope: `tensordg/swe_1d.py`
(`_rhs`, `solve_swe_1d`, `manning_friction_slope`, `manning_normal_depth`),
`validation/swe_manning_friction/study.py`, `tests/test_swe_manning_friction.py`.

This document is the reference that `tests/test_swe_manning_friction.py` points
at. The numeric block in §3 is **generated** by the study script and compared
against `validation/swe_manning/metrics.json` by that test, so it cannot rot
into a hand-carried number.

## 1. What was added, and what is verified

Before this change the 1-D shallow water equations in TensorDG carried **one**
source term only, the bed slope: `-g h ∂z_b/∂x`. There was no bottom friction
anywhere in the repository (`grep -ri friction tensordg/` returned nothing), so
the scheme could not hold a *steady* open-channel flow: every flow on a slope
accelerates without bound, and none of the channel-flow literature
(normal depth, gradually varied profiles, Chézy/Manning resistance) could be
used as a reference.

Added: an opt-in Manning drag term `manning_n` (SI roughness coefficient,
`n = 0` bit-for-bit identical to the legacy scheme), plus two public helpers

* `manning_friction_slope(u, h, n) = n² |u| u / h^(4/3)` (dimensionless
  hydraulic gradient, sign follows the flow),
* `manning_normal_depth(q, S0, n) = (q n / √S0)^(3/5)` (uniform-flow depth).

| Item | Reference | Gate | Status |
|---|---|---|---|
| Flat-bed inertial decay (magnitude and sign of the sink) | Exact ODE `u = u0/(1+g n² u0 t/h^(4/3))` | rel. error < 1e-9 | verified (§3A) |
| Uniform flow at the normal depth on a slope | Exact fixed point `h_n = (q n/√S0)^(3/5)` | drift < 1e-9 + gate power | verified (§3B) |
| Dry-bed dam break with drag | Physicality, mass, monotone runout | mass error < 1e-6 | verified (§3C) |
| `n = 0` compatibility | Legacy scheme | bitwise identical | verified (§3D) |
| 2-D / 3-D friction | — | — | **not implemented** (§5) |

## 2. Discretisation

Conservative SWE with bed slope and Manning friction (unit width):

```
∂h/∂t   + ∂(h u)/∂x = 0
∂(h u)/∂t + ∂(h u² + g h²/2)/∂x = -g h ∂z_b/∂x - g n² |u| u / h^(1/3)
```

The friction term is the bottom shear written per unit mass,
`-τ_b/ρ = -g h S_f` with `S_f = n²|u|u/h^(4/3)`, which is the standard Manning
closure (Chow 1959, §5; equivalent to a Chézy coefficient `C = h^(1/6)/n`).

It is projected inside `_rhs` **exactly like the bed-slope source**, at the same
Gauss points and with the same weak-form factor:

```
S_k = -(2k+1)/2 · g n² Σ_q w_q ( |u| u / h^(1/3) )(x_q) φ_k(ξ_q)
```

Two consequences matter:

1. For a cellwise-constant state only the `k = 0` mode is non-zero, so the
   friction sink and the bed-slope source cancel **algebraically** — there is no
   splitting error, and the steady state is a fixed point to round-off rather
   than to `O(dt)`. This is what §3B measures (9.6e-13) and why the sink is not
   applied as an operator-split post-stage velocity update.
2. The quadrature is exact for polynomial data, so the source does not add an
   `O(dx)` force error of its own.

Normal depth follows from the momentum balance with `u = q/h`:
`g h S0 = g n² u² / h^(1/3)` ⟹ `h^(4/3) S0 = n² u²` ⟹ `u = (1/n) h^(2/3) √S0`,
i.e. `h_n = (q n / √S0)^(3/5)`.

### Error judgement

All three quantitative gates are met, two of them at round-off rather than at a
tolerance (see §3A/§3B). There is no case where the friction implementation is
accepted while exceeding a 3 % band: the two analytic references are met at
1e-12 and 1e-12, i.e. nine orders inside the 3 % project standard. Only the
dry-bed case has no analytic reference (the Ritter solution is frictionless) and
is therefore *not* claimed as an accuracy result for friction: it is a
physicality/conservation result plus a monotonicity result in `n`.

## 4. The drag limiter: why an explicit sink needs one

A first version capped the time step by the local friction rate
`g n² |u| / h^(4/3)`. On the dry-bed dam break that made `dt` collapse as soon
as the wetting front thinned (`h^(1/3) → 0`) and the run stalled at
`t ≈ 0.17 s`; without any cap the same run diverged outright
(`FloatingPointError: Nonphysical SWE state`), because the sink removed more
momentum in one step than the film carried and reversed the flow.

The shipped treatment is the drag limiter of Liang & Marche (2009): the sink is
capped so that one step cannot remove more momentum than a cell carries,

```
|g n² |u| u / h^(1/3)| ≤ h |u| / dt
```

friction may stop a cell but never reverse it. The cap is inactive whenever
`dt g n² |u| / h^(4/3) < 1`, which is exactly the smooth regime of §3A/§3B
(`friction_capped_steps = 0` there — recorded in the artifact, so the fixed-point
result is demonstrably not produced by the limiter), and it is what makes §3C
run: with it the front stays physical, mass errors stay at 1e-9 and the runout
decreases monotonically with `n`. `friction_limiter=False` restores the
unbounded source and emits a warning; it exists for audit only.

## 5. Limitations (explicitly not claimed)

* **2-D is not implemented.** `swe_2d.py` still has the bed-slope source only;
  adding the same projected sink there is the natural next step and is not done
  here.
* **Steady *sloped* flow on the `well_balanced=True` path.** The Audusse
  hydrostatic reconstruction is built for a lake at rest; it was measured on the
  same normal-depth state (§3B, last row) and also returns to round-off, but
  that is an observation for a *smooth, continuous* bed, not a theorem: on a bed
  with a finite jump the reconstruction changes the trace states and a sloped
  uniform flow is not expected to be a fixed point. The verification contract of
  this change is the default (piecewise-linear bed, shared-face HLL) path.
* **Manning closure validity.** `n` is a depth-averaged roughness parameter; the
  formula is empirical and is not valid for very shallow films (`h` below a few
  cm) or for transitionally rough/vegetated beds, where a depth-dependent
  `n(h)` or a Chézy/Darcy-Weisbach formulation with a friction factor is
  required. The limiter keeps such runs stable; it does not make the *model*
  valid there.
* **Explicit drag.** Friction is integrated inside the RK stages (no implicit
  solve), so accuracy at large `dt g n² |u| / h^(4/3)` degrades to first order
  in the source; the limiter guarantees boundedness, not accuracy, in that
  regime. No test asserts accuracy there.
* **No bed-load / sediment coupling, no Coriolis, no wind stress** — out of
  scope.
