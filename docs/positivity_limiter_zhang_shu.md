# DG 正定保正标度限制器（Zhang–Shu）实现与 123 双稀疏波验证

> 锚点：NEW（总账无对应条目）。本单新增能力：`tensordg.euler_dg_1d.solve_euler_dg_1d(positivity="scale")`
> ——以 **Zhang & Shu (JCP 2010)** / **Zhang, Xia & Shu (JCP 2012)** 的标度限制器替换历史上
> 「整单元退回一阶平均」的正定兜底（`positivity="collapse"` 保留以作基线）。

## ① 案例介绍

| 项 | 值 |
|---|---|
| 算例 | Toro (2009) *Riemann Solvers…* 3rd ed. Table 4.1 **test 2**（"123 problem"）：左右对称双稀疏波 |
| 左右状态 | (ρ,u,p)_L = (1, −2, 0.4)，(ρ,u,p)_R = (1, +2, 0.4)，γ = 1.4 |
| 星区（本单独立求得的解析值） | p* = 1.893873e-03，u* = 0.0，ρ* = 见 ① 注 |
| 波系位置（t = 0.15） | 左头 0.0878，右头 0.9122（均在域内，`inside_domain=True`） |
| 计算域 / 时间 / CFL | [0,1]，t = 0.15，diaphragm = 0.5，CFL = 0.12 |
| 离散 | 模态 DG（Legendre，p = 2/3）× HLLC 通量 × SSP-RK3，64 位 |
| 物理背景 | 星区压强比初值低两个数量级（近真空），高阶多项式在该区必然越界 → 正定处理是刚需而非可选项 |

注：ρ* 由 `exact_double_rarefaction(...)["rho_star"]` 给出，见测试 `test_star_density_matches_toro_table`
（与 Toro 表值 2.185e−2 相对偏差 < 1%）。

## ② 怎么做的

1. **限制器（新实现）**：单元解写成 `u_θ = ū + θ(u − ū)`，θ ∈ [0,1]。密度对守恒量线性、
   压强对守恒量凹，故对任一检查点（Gauss/Legendre 求积点 + 左右迹）
   `ρ(u_θ) = ρ̄ + θ(ρ_i − ρ̄)`、`p(u_θ) ≥ p̄ + θ(p_i − p̄)`。
   逐点求使 ρ、p 都不低于相对地板 `η·平均值` 的最大 θ，取单元内最小值为 `_scaling_factors`；
   `_positivity_scale` 仅缩放高阶模态，**单元平均值逐位不变**，可容许单元 θ = 1 时逐位不变。
2. **接入**：`solve_euler_dg_1d(..., positivity="scale"|"collapse"|"none")`，默认 `"scale"`；
   每个 SSP-RK3 子步后施加，并记录活动量 `positivity_stats`（受限制单元子步数 / 最小 θ）。
3. **独立解析参照**：本单不复用求解器的星压迭代，另写 `_pressure_function` + 二分法求 p*，
   再由 Riemann 不变量闭式给出两道扇形（`a = [(γ−1)(u_L−ξ)+2a_L]/(γ+1)`，`u = ξ+a`；右侧对称），
   构造上满足扇头 a = a_L、扇尾 a = a*。
4. **工具链**：`python -m benchmarks.positivity_limiter`（本文表格由图/表脚本从
   `artifacts/positivity_limiter/metrics.json` 程序化注入，零手抄）；
   `pytest tests/test_positivity_scaling_limiter.py`（10 项门禁）。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **"none" 必然非物理**：p = 2/3 在 N = 60 上不做任何处理都抛 `FloatingPointError`——这正是门禁的探测力，
   也说明正定处理在本算例是刚需（`test_untreated_high_order_state_is_nonphysical`）。
2. **精度增益有限但一致**：N = 60 时 p = 2 的 L1(ρ) 降 15.2%、L1(p) 降 22.6%；p = 3 降 7.0% / 14.9%。
   增益随 p 增大反而减小（collapse 触发次数 84→192，但标度限制器活动更密），说明本算例在粗网格上
   主体误差来自扇区解析度而非限制器；不要把它当成"高阶一定更准"的证据。
3. **仍然耗散**：scale 的最小压强 4.1e−3（p=2）仍高于解析 p* = 1.89e−3，即近真空核仍被抹平——
   标度限制器只保证不越界，不保证低耗散。
4. **计算预算**：控制面 nproc=128、load15 ≈ 114（本单开工时实测），按容量纪律只做轻量跑，
   sweep 限定 N = 60、p = 2/3；未做网格收敛阶扫描（那需要 N ≥ 100 的多档 + p 递增，留待集群空闲时补）。
5. **二维未接入**：`tensordg/euler_dg_2d.py` 仍是整单元 collapse 兜底，本单未改（避免把未验证改动混入主营路径）；
   建议作为后续条目（2D 标度限制器 + 强爆炸/近真空 2D 算例）。
6. **不是严格证明**：Zhang–Shu 的正定保持结论要求通量为正定保持型（HLLC 在相应 CFL 条件下满足）且时间推进为
   凸组合（SSP-RK3 满足），本实现按子步施加标度限制器，属该框架的标准工程实现；但本仓没有对 CFL 上界做机器证明，
   只做了实测（CFL = 0.12 稳定）。
7. **适用范围**：1 维、理想气体 γ = 1.4、模态 DG p ≤ 3；不适用于多维/真实气体/移动网格。

## ⑥ 误差判定（逐项，显式回答「是否 <3%」）

| 关键量 | 基准 | 实测 | 误差 | 是否 <3% |
|---|---|---|---|---|
| 相对 L1 误差 密度 ρ（p=2, N=60, scale） | 解析解 | 2.52% | — | **是** |
| 相对 L1 误差 压强 p（p=2, N=60, scale） | 解析解 | 3.41% | — | **否** |
| 相对 L1 误差 速度 u（p=2, N=60, scale） | 解析解 | 2.33% | — | **是** |
| 相对 L1 误差 密度 ρ（p=3, N=60, scale） | 解析解 | 3.41% | — | **否** |
| 相对 L1 误差 压强 p（p=3, N=60, scale） | 解析解 | 4.58% | — | **否** |
| 相对 L1 误差 速度 u（p=3, N=60, scale） | 解析解 | 3.57% | — | **否** |
| 星压 p*（独立二分法） | Toro 表值 1.89e−3 | 1.893873e-03 | 0.205% | **是** |
| 精度增量 L1(ρ)（p=2） | collapse 基线 | 降 15.2% | — | 判据「≤−5% 即改进」，通过 |
| 精度增量 L1(p)（p=2） | collapse 基线 | 降 22.7% | — | 通过 |

**结论（honest）**：星区锚点与密度/速度场在 p=2、N=60 上 < 3%（2.52% / 2.33%），但**压强场 3.41% 超出 3%**，
p=3 时三项均 >3%（3.4% / 4.6% / 3.6%）——即粗网格下「设计阶并未兑现」这一事实必须如实登记，不能因限制器
改进了相对误差就宣称达标。规模更大的网格（N ≥ 100）本单因容量纪律未跑，收敛阶与 <3% 达标性**留作未完成项**。
