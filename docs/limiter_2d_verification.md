# 2-D TVB / WENO limiter verification (TensorDG)

> 复核对象：已合并的 `tensordg/euler_dg_2d.py` 限制器（m21xx 二维 Euler DG 交付）。
> 本次工作树分支：`agent/m2503`；工件：`validation/limiter_2d/verify.json`、
> `validation/limiter_2d/figures/limiter_2d_summary.png`、`tests/test_limiter_2d.py`（12 条）。

## 1. 案例与动机

二维高阶 DG 求解器（`solve_euler_dg_2d`，模态 Legendre 基 + HLLC + SSP-RK3 + 局部正性过滤）
此前只带一个 `limiter="tvb"`，并且 troubled-cell 判据 `_troubled_1d` 对两个方向**一律**
用 `torch.roll` 取邻元——这在 `periodic=(False, True)` 的挤压 Sod 上等于把网格另一端的值
当成边界邻元。README 把「多维限制器」列为未完成项，仓库也从未有过 2-D WENO。

本单做两件事：**(i) 复核并修正边界判据；(ii) 补齐方向分裂的 2-D WENO 限制器**，两者都用
解析基准验证。

几何/参数：2-D Cartesian，(x, y) ∈ [0,1] × [0,0.25]，`periodic = (False, True)`；
Sod 初值 (ρ,u,p) = (1, 0, 1) | (0.125, 0, 0.1)，膜片 x = 0.5，t = 0.2，CFL 0.2，
P1（100 格）与 P2；TVB 常数 M = 1.0。

## 2. 方法

1. **边界判据**：`_troubled_1d(averages, axis, spacing, M, periodic)` 新增 `periodic` 形参，
   由 `solve_euler_dg_2d` 的 `periodic` 标志逐轴传入。周期轴照旧 `torch.roll`；出流轴改为
   夹取邻元，并且**把该轴的两个端单元从 troubled 集合中移除**——夹取后的单侧模板有一个零增量，
   任何单调剖面都会被误判成极值（第一轮实现踩到这个坑，见 §5.2），因此端单元保持高阶多项式
   而不限，这与 1-D 限制器的既有约定一致。
2. **2-D WENO**：`apply_weno_limiter_2d` 按方向逐轴做 WENO3 重构（Qiu & Shu 2005 的
   方向分裂版本）：问题单元的该轴模态 1 取 WENO 加权斜率 `w0 s0 + w1 s1 + w2 s2`
   （`s0=(u_i-u_{i-1})/h`，`s1=(u_{i+1}-u_i)/h`，`s2=(u_{i+1}-u_{i-1})/2h`，
   权重由经典 WENO3 光滑指示子给出），该轴模态 ≥2 清零，另一轴模态保持不变。
   模态 0 永不修改，故守恒逐位保持。
3. **验证工具**：`benchmarks/verify_limiter_2d.py` 四个探针（判据／重构／Sod／守恒），
   数字全部由脚本程序化写入 `validation/limiter_2d/verify.json`；图由该 JSON 绘制。
   运行：`PYTHONPATH=. python -m benchmarks.verify_limiter_2d --threads 4`（本机 121 s）。

## 3. 计算结果（直读 `verify.json`）

### 3.1 判据探针（挤压 Sod 初值，100 格）

| 判据 | 标记为 troubled 的单元 |
|---|---|
| 旧：一律 `roll`（周期包裹） | [0, 50] |
| 新：按 `periodic` 分轴 | [50] |

单元 0 处于均匀左态（ρ=1），旧判据把网格另一端 ρ=0.125 当作左邻元，于是每个 RK 子步都
误判为问题单元；新判据只标记真正的膜片单元 50。

### 3.2 光滑场重构探针（ρ = 1 + 0.2cos πx，P2，16 格，纯限制器一步）

| 限制器 | 判据 | 子格相对 L2 | 边界单元误差 | 内部最大误差 |
|---|---|---|---:|---:|
| TVB | 旧（包裹） | 1.219e-02 | 1.706e-03 | 2.802e-02 |
| TVB | 新（分轴） | 1.220e-02 | 2.759e-03 | 2.802e-02 |
| WENO | 旧（包裹） | 1.554e-02 | 8.483e-03 | 4.821e-02 |
| WENO | 新（分轴） | 1.547e-02 | 2.759e-03 | 4.821e-02 |

边界单元误差下降 3.07 倍（WENO）；
TVB 的 minmod 斜率被包裹值直接压成 0，故两种判据差别较小。内部误差（2.8e-2 / 4.8e-2）来自
M = 1、h = 1/16 时 `variation > M h²` 会标记光滑极值单元——这是 TVB 常数选取的固有行为，不是本次缺陷。

### 3.3 挤压 Sod vs 精确 Riemann 解（P1，100 格，t=0.2）

## 5. 注意点（坑 / 局限 / 适用范围）

1. **账面数字与实测不符（本次最实质的发现）**：`docs/verify_euler_dg_2d_resolved.md` §3.2 把
   「P1 / 100 格 / TVB」的挤压 Sod 记为 ρ 0.761%、p 0.707%。这两个数字恰好是
   **不开限制器**（仅正性过滤）的结果；开 TVB 实测为 2.007% /
   1.999%。两者都在 3% 门内，但「TVB 行的数字」不能作为
   限制器路径的证据引用。该文档未改动，此处留证。
2. **夹取模板 + 不剔除端单元 = 新的误判源**：第一轮实现让端单元参与判据，单侧模板的零增量使
   `minmod(0, Δ) = 0 ≠ Δ`，任何单调剖面在端单元都「非单调」，光滑仿射数据被误限
   （`tests/test_limiter_2d.py::test_affine_data_is_untouched` 抓到）。最终方案是分轴判据
   ＋端单元不参与限制。
3. **TVB 常数 M 不是普适的**：M = 1 在 h = 1/16 时会标记光滑极值，子格误差 ~3-5%。
   用限制器做光滑问题必须按 `M ≳ max|u''|` 调参或直接不开。
4. 限制器降低总变差（0.934 → 0.885）和过冲（ρ_max 1.0070 → 1.0006），代价是 L2 精度
   （0.761% → 1.705%）。这是激波捕捉的正常代价，但对本算例（P1、100 格、仅正性过滤已无振荡放大）
   限制器并非必要。
5. 局限：方向分裂 WENO 不是真二维 WENO 模板；只验证到 P2、Cartesian、无粘；四象限二维
   Riemann 算例（无解析解）本轮因算力预算未跑，正性/网格自收敛证据沿用 m21xx 记录。

## 6. 误差判定（关键量 vs 基准，逐项）

| 关键量 | 基准 | 实测 | 是否 <3% |
|---|---|---|---:|
| 挤压 Sod ρ 相对 L2（WENO） | Sod 精确 Riemann 解 | 1.705% | ✅ 是 |
| 挤压 Sod p 相对 L2（WENO） | 同上 | 1.785% | ✅ 是 |
| 挤压 Sod ρ 相对 L2（TVB） | 同上 | 2.007% | ✅ 是 |
| 挤压 Sod p 相对 L2（TVB） | 同上 | 1.999% | ✅ 是 |
| 2-D WENO 退化为 1-D WENO | 已合并的 1-D 实现 | 逐位相同（0.0） | ✅ 是 |
| 限制器守恒性 | 单元平均不变 | 漂移 2.3e-15 | ✅ 是 |
| 边界判据误判数 | 解析（单元 0 为均匀态） | 旧 2 个 / 新 1 个 | ✅ 是 |
| 四象限二维 Riemann | **无解析解** | 本轮未跑（算力预算） | — 已声明原因 |

**判定：新增的 2-D WENO 路径与修正后的 TVB 路径均满足 3% 门；边界误判缺陷已闭合，
账面数字不符已留证。**
