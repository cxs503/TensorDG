## 1. 案例介绍

### 物理背景

一维稳态对流-扩散方程是验证高阶数值方法的标准基准问题：

```
a u'(x) - D u''(x) = 0,   x ∈ [0, 1]
u(0) = g_L,  u(1) = g_R
```

其中 `a` 为对流速度，`D` 为扩散系数，Péclet 数 `Pe = a·L/D` 表征对流与扩散的相对强度。

### 解析解

当 `g_L = 0, g_R = 1` 时，精确解为指数边界层：

```
u(x) = (exp(Pe·x) - 1) / (exp(Pe) - 1)
```

该解在 `Pe >> 1` 时呈现强边界层特征（x=1 附近急剧变化），是检验数值方法分辨率的严苛测试。

### 总通量守恒

精确总通量 `J = a·u - D·u'` 在全域为常数：

```
J = a / (1 - exp(-Pe))
```

这一守恒律提供了独立于 L2 误差的离散一致性检验。

### 原单目标参数

| 参数 | 目标值 | 说明 |
|------|--------|------|
| Péclet 数 | 1, 10, 100 | 覆盖扩散主导到对流主导 |
| 多项式阶数 | P1, P2, P3 | 验证设计阶收敛 |
| 网格数 | 16, 32, 64, 128 | h-收敛研究 |
| 收敛阶 | ≥ p+1 | P1≥2, P2≥3, P3≥4 |

### 后续任务的经验

**SIPG 惩罚参数**:
- 必须满足 `penalty > C·(p+1)²/h`，其中 C 为与问题相关的常数
- 惩罚过小会导致解不连续，破坏收敛性
- 测试 `test_collapsed_sipg_penalty_is_detected_by_the_l2_gate` 验证了这一控制

**上风/下风通量**:
- 在 SIPG 惩罚足够大时，上风和下风对流通量给出相同解
- 因此**不能**用通量方向作为负对照
- 真正的实现控制是惩罚参数崩溃测试

**分辨率极限**:
- cell Peclet 数 `Pe_cell = a·h/D` 是关键参数
- 高阶方法允许更大的 cell Peclet（P3 可达 3.1，P1 仅 0.4）
- 欠分辨时误差急剧增大，必须显式测量而非假设

### 适用范围

- 本模块仅适用于**稳态**一维问题
- 全局直接求解，O(N³) 复杂度，仅用于小规模验证
- 不适用于生产计算（需迭代求解器）
- 扩展到二维/三维需要重新设计数据结构
