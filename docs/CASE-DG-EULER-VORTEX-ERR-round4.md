# CASE-DG-EULER-VORTEX-ERR（第4轮）：超线性误差增长被证伪 —— 是精确解缺陷，不是格式耗散

**锚点** `CASE-DG-EULER-VORTEX-ERR` ｜ ref: Yee et al. 2000 ｜ 容差 <6%
**类别：defect_fix + falsified_hypothesis（上一轮 FAIL 的成因是验证器缺陷）**

## ① 案例介绍
二维可压缩 Euler（gamma=1.4）等熵涡，计算域 [-5,5]²（L=10）四周周期，beta=5，均匀来流 (1,1)，
t ∈ {1,2,5,10}。涡心位置 (t,t)：t=5 落在周期角点，t=10 **已整整平移一个箱长**。

## ② 怎么做的
1. 复核上一轮 alpha=3.295 的"误差超线性增长"。
2. 逐项排除候选机制：正性滤波误触发（monkeypatch 计数）、末步未截断（已核 `dt=min(cfl/rate, final_time-time)`）。
3. 用**网格加密判据**判定：截断误差必须随加密下降；不下降即为参考解缺陷。

## ③ 计算结果（本单新跑，程序化）

| 检查 | 结果 | 判读 |
|---|---|---|
| 正性滤波 @DG n=32,t=10 | calls=14054, **steps_with_repair=0, cells_repaired=0** | 惰性，非成因 |
| DG-P2 @t=1, n=8/16/32 | 0.562 / 0.0819 / 0.01265 %，观测阶 **2.78 / 2.69** | 格式确为高阶 |
| DG-P2 @t=10, n=8/16/32 | **16.02 / 16.43 / 16.44 %** | **与网格无关 ⇒ 非截断误差** |
| 精确解 @t=10 | rho ∈ [1.0000,1.0000]，max abs dev **0.000e+00** | 参考退化为均匀来流 |
| 参考缺陷 vs 真周期解 @t=10 | u,v **16.23 %**，p 8.98 %，rho 6.90 % | 与实测 16.44 % 同大小 |
| 修复后 ref(t=10) vs ref(t=0) | **5.6e-16 / 1.1e-15** | 周期一致性成立 |
| 修复对 t=1 的影响 | max dev rho **5.7e-08** | 亚容差，不扰动快照结论 |

**根因**：`vortex_primitive` 用原始伽利略平移 `x - u t`。当 `|u|t >= L/2 = 5` 涡峰移到箱外，
参考解退化为均匀来流而数值解仍带涡 ⇒ 测得"误差"= 涡与来流的范数距离（16.23%），**与网格无关的常数**。
上一轮 alpha=3.295 拟合的是这个参考缺陷，不是误差守恒性。
