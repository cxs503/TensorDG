# CASE-DG-EULER-VORTEX-ERR 第 7 轮：阶数轴与设计阶（误差守恒的范围闭合）

判定：**INCOMPLETE**（不可判定门禁：['C6_ladder_completeness', 'C8_degree_invariance', 'C9_design_order']；失败门禁：无）

## ① 案例介绍

二维等熵涡在周期箱 [-5,5]² 内以 u_inf=(1,1) 匀速平移（β=5, γ=1.4）。精确解在平移下形状不变，因此**误差应当是网格属性而非时间属性**——这正是算例池条目 `CASE-DG-EULER-VORTEX-ERR`（ref: Yee et al. 2000，容差 <6%）要判定的东西。一轮过箱时间 L/|u_inf| = 10。

| 参数 | 值 |
|---|---|
| 域 | [-5,5]^2 |
| 涡强 β | 5.0 |
| 背景态 | [1.0, 1.0] |
| 容差（快照） | 6% |
| 离散 | 模态 DG（HLLC + SSP-RK3，L2 投影初值）与 P0 有限体积（Rusanov） |

## ② 怎么做的（本轮增量）

前三轮的设计空间只动**网格轴**与 **CFL 轴**，多项式阶数固定 p=2，所以「误差守恒」严格说只是关于 p=2 的陈述；且「误差是网格属性」从未用**实测收敛阶**验证过。本轮：

1. **C8 阶数不变性**：新增 p=1、p=3 两个族（n=32, CFL 0.2，t=1/2/5/10），与设计阶 p=2 用同一条上界 alpha ≤ 1；并要求至少 2 个阶数可判。
2. **C9 设计阶**：在 t=1 与 t=10（一次过箱）两个检查点上，用 n=32/64 的观测空间阶检验是否达到 0.8×(p+1)（p=1 → ≥1.6，p=2 → ≥2.4）。0.8 是 C5 已在用的同一约定，不是对着结果调出来的数。
3. **双过箱**：设计族新增 t=20 检查点，C2 的拟合窗口不再被钉在单次过箱上。
4. p=1 的 n=64 族给满 4 个检查点，使其同时是 C7 的设计点（两点族会让 C7 在细网格上失明）。

全部检查点经计算递交门（作业 cj3432，13 分片）落盘；本文数字由 `benchmarks/case_euler_vortex_errconserve.py --aggregate` 从 `results/*.json` 程序化注入，零手抄。
