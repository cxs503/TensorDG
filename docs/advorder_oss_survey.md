## 5. Selection (sedimented to `oss_solutions`)

**Chosen**: stage-matched RKDG: (p+1)-stage explicit RK per degree; SSP-RK(5,4) at p=4; observed order compared with the reference column using one shared estimator

**Rejected alternatives**:

- `RK4 for every degree (round 1)` — stage count does not match the reference column; at p=4 the time integrator caps the observed order
- `6-stage order-5 Butcher RK at p=4 (round 2 default)` — order matched but the stage count did not; the reference column has 5 stages
- `claim order = stages = p+1 at p=4` — impossible: explicit 5-stage methods cannot reach order 5 (Butcher barrier)
