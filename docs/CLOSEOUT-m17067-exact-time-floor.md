# CASE-DG-PREFINEMENT-EXPONENTIAL：p=7/8 实测（精确时间积分）与时间积分地板

## ① 案例介绍
一维周期线性对流 `u_t + u_x = 0`，初值 `sin(2πx)`（整函数，处处解析），终时 `T=1`（一整周期，精确解=初值平移）。
固定网格 `ncells=16`，只做 p 加密，`p=1..8`
（库上限 `MAX_DEGREE=8`）。理论基准：Babuska & Suri (1994) SIAM Review 36(4) 578–632，解析解下误差随 p 指数衰减
`||u-u_h|| <= C exp(-sigma p)`。

锚点背景：已发布算例止步 p=6，`measurement_floor.json` 里 p=7/8 是**外推值**（σ=3.9271 从 p=6 外推），
此前审计把 p≥7 记为 not_run。本单把 p=7/8 变成实测，并查出 p≥7 无法测量的真实原因。

## ② 怎么做的
线性半离散系统 `du/dt = L u` 的精确时间解是 `exp(L t) u0` ⇒ **完全去掉时间误差**，测到的是纯空间误差：

1. 用**出厂右端项** `tensordg.advection_1d._rhs` 逐列装配稠密算子 L（不重写格式），线性性残差
   2.02e-16；半离散总质量守恒（周期 DG），质量漂移
   1.91e-17；
2. 矩阵指数用新增的 `tensordg.convergence.expm_scaled_squaring`（80 位 longdouble 缩放-平方 + 泰勒），
   并以**另一套控制参数**（threshold 0.25/0.125、τ 20/26 项）复算作控制检验：相对差
   0.00e+00；`scipy.linalg.expm`（float64）只在
   `eps·||L||₁·t < 0.1·误差` 的 p 上作对照（合格 p=[1, 2, 3, 4, 5, 6]，
   相对差 1.59e-07）；
3. L2 用 longdouble 求积（`4p+16` 点，2× 阶收敛校验相对差 2.64e-14）；
4. **浮点地板两层**：表示地板 `eps₆₄·||u_h||`，以及**算子表示地板**——对 float64 装配的 L 施加 1e-16 相对随机扰动，
   看 L2 误差的响应（3 个种子取最大）。层高者决定该 p 能否"测量"；
5. 出厂 RK4（CFL 0.04）同 p 对照，量化时间误差占比；p=8 另跑 CFL=0.0050（步数
   54400）做**独立积分器交叉验证**；
6. 复核发布值：p=1..6 的 RK4 结果与已发布工件最大相对差 0.00e+00。

## ⑤ 注意点
- **p≥7 not_run 的真因是时间积分地板，不是 roundoff**：表示地板只有 4.751e-13，
  而 RK4 在 p=8 停在 4.320e-13（空间误差的
  93 倍）。出厂的「时间收敛」判据是**相对**判据，
  高 p 时要求 dt 小到"微小空间误差的 1%"，代价极高；本单用精确时间积分绕开它。
- **p=8 实测 4.627e-15，是表示地板 1.57e-16 的 29 倍，但对 float64 装配算子的 1e-16 相对扰动响应为 4.75e-13（SNR 0.0）**，故 p=8 的数值应按"已解析但接近算子地板"读，拟合权重低于 p≤7。
- 发布外推方向正确、幅度偏保守（实测低于外推），**连续性假设成立**；但常数 σ 外推 2 阶已有
  46% 偏差，不宜再往后推。
- **honest 负结果：p=8 的精确时间值未被独立确认**。同一求解器改用出厂 RK4、CFL 降到 0.0050（步数 54400，时间误差已可忽略）得到 1.287e-14，是精确时间值 4.627e-15 的 2.78 倍；而 p=8 的 float64 算子表示地板（1e-16 相对扰动响应）为 4.75e-13，大于该信号本身。⇒ p=8 只能作为**上界**引用，不能作为「指数律延续到 p=8」的证据。这也否定了上游 CLOSEOUT-m16918 §4 的推断「p=8 信噪比约 55，仍可测」——真正的限制是算子表示 + 浮点运算，不是表示地板。
- 适用面仍是一维周期线性对流光滑解；`exact_time_solution` 只对**线性**算子成立（非线性误用会被线性性残差闸拦下）。
