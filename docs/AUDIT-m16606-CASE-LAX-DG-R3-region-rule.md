## 3. 核心发现：R3 的区域规则不是嵌套的

被审 R3 遮罩（`lax_case_pool.py`）：

```python
mask &= np.abs(points - waves["positions"][name]) > R3_BAND_CELLS * dx   # R3_BAND_CELLS = 4.0
```

`dx` 是单元宽（`modal_fields` 返回批心间距），所以**剔除带随加密而变窄**：N=100 时带宽 0.02、
N=400 时 0.01（P1–P3 同）。于是「解析区」在相邻两腿之间**不是同一个物理区域**——粗腿剔掉的
点，在细腿被纳入。实测保留测度变化：

| 区域规则 | 带宽是否随 dx 变 | 保留测度（粗腿 → 细腿） | 相对变化 |
|---|---|---|---|
| `band_4h`（发布规则） | 是（0.02 → 0.01） | 0.680 → 0.920 | **+35.3 %** |
| `nested_0p01`（固定 0.01） | 否 | 0.920 → 0.920 | 0.0 % |
| `nested_0p02`（固定 0.02） | 否 | 0.840 → 0.840 | 0.0 % |
| `nested_0p05`（固定 0.05） | 否 | 0.600 → 0.600 | 0.0 % |

同一批 DG 解、只换区域规则，density 的最细一对阶（`gate_r3` 口径，密度为门控量）：

| 规则 | P1 阶 | P2 阶 | P3 阶 | P1 需求 1.7 | P2 需求 2.55 | P3 需求 3.4 |
|---|---|---|---|---|---|---|
| `band_4h`（发布） | 0.170 | 0.940 | 0.225 | FAIL | FAIL | FAIL |
| `nested_0p01` | 1.615 | 1.433 | 0.266 | FAIL | FAIL | FAIL |
| `nested_0p02` | **1.800** | 1.598 | 0.273 | **PASS** | FAIL | FAIL |
| `nested_0p05` | 1.225 | **2.129** | 0.317 | FAIL | FAIL | FAIL |

更强的证据：在 N=64→128（P1，本次新增的极粗对照）上，发布规则的解析区误差**随加密变大**
（5.985e-04 → 1.152e-03，测得阶 **−0.945**），四套固定带宽规则则都 > 1 阶
（1.273 / 1.610 / 1.716）。误差随 h 减小而增大的唯一来源是**区域在变大**，不是离散误差。

## 4. 发现（按严重度）

### F1（HIGH，已在本单给出定性与定量证据；判据未改）R3 的发布规则度量的是区域几何，不是离散误差
- 证据：保留测度 +35.3 %；P1 解析区误差非单调（64→128 阶 −0.945）；P1 阶从 0.170（发布规则）
  变到 1.225–1.800（固定带宽）；P3 的最粗两腿 band_4h 误差 4.914e-03 → 4.917e-03（几乎不降）。
- 影响：`docs/CASE-LAX-DG.md` 里「解析区阶被相邻间断污染压到一阶以下」的**归因里混入了测量伪影**；
  这条叙述本身需要按规则重写（本次已在 doc 追加更正段）。
- 修复建议（未改判据、未改 `lax_case_pool.py`，保持与台账原文可追溯）：R3 改为固定物理带宽
  （建议 0.02，与同文件 `wave_positions` 已有的 `max(4dx, 0.02)` 口径一致），带宽在跑数前写死。

### F2（MEDIUM）P1/P2 的 `R3 = FAIL` 不稳健
- 证据：P1 阶在 1.225–1.800 之间摆动，阈值 1.70 —— 换规则可 PASS 可 FAIL；P2 阶 1.433–2.129，阈值 2.55。
- 判定：**不得**据此判「P1/P2 实现有缺陷」，只能判「未达设计阶且测量对区域规则敏感」。

### F3（MEDIUM）P3 的 `R3 = FAIL` 稳健 —— 诚实 FAIL 保留
- 证据：四套规则下 P3 阶只有 0.225–0.317（需求 3.4）；三个场量都一致（ρ 0.266–0.317、u 0.341–0.376、p 0.328–0.336）；且 P3 全阶梯误差近乎不动（4.914e-03 → 4.917e-03 → 4.207e-03）。
- 解释：P3 阶梯上限 N=400（h=2.5e-3），TVB 限幅器在间断附近把三阶降为局部一阶，剩余区域
  仍被 8 个单元尺度内的耗散层覆盖；这是方法属性而非区域伪影。
- 结论：`CASE-LAX-DG` 整体 verdict 保持 `FAIL`，**不得**用本次审计把锚点翻成 verified。

### F4（LOW，已修复）工件缺失导致 2 条工件级测试长期 skip
- 原状：`runs/lax_case_pool/` 不存在，`test_committed_artifact_is_self_consistent`、

- 现状：本次复现运行已落盘 `metrics.json` / `profiles.npz` / `summary.md` / 3 张图；
  `pytest tests/test_lax_case_pool.py tests/test_lax_region_band.py` = **17 passed, 0 skipped**。

### F5（LOW，记录）时间离散未独立研究
- R3/C3 的阶是「空间+时间混合」阶：`dt = CFL·h/(2p+1)`（CFL=0.35）固定比例收紧，P3 时 RK3 的
  时间误差可能参与压阶。本次未做 cfl→cfl/2→cfl/4 的时间收敛研究，**未运行项**，见 §6。
