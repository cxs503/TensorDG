## ① 案例介绍（物理背景 / 几何 / 参数）

**物理**：二维可压缩 Euler 方程的**等熵涡**（isentropic vortex）。它是 Euler 方程的**精确解**
（无制造源项），在周期方盒里纯对流输运而不变形，因此是衡量高阶 DG 格式
「光滑流上会不会被限制器破坏」的标准算例（Cockburn & Shu 1989 的经典验证配置）。

**几何/参数**（与仓库既有 `benchmarks/design_order_euler_dg_2d.py` 同一配置，保证可比）：

| 项 | 值 |
|---|---|
| 计算域 | $[-5,5]^2$，双周期 |
| 涡强度 | $\beta = 5.0$ |
| 背景流 | $(u,v)=(1,1)$ |
| 终了时刻 | $T = 1.0$（涡心从 $(0,0)$ 平移到 $(1,1)$，仍在域内） |
| 多项式阶 | P1（设计阶 $p+1=2$）与 P2（设计阶 $p+1=3$） |
| 网格 | P1：$8^2,16^2,32^2$；P2：$8^2,12^2,24^2$（阶数取最细区间，相邻网格比 2） |
| 通量 / 时间推进 | HLLC + SSP-RK3，CFL = 0.2 |
| 初值投影 | 模态 $L^2$ 投影（`initial_projection="l2"`，保留设计阶） |
| 限制器设定 | 无限限制器 / TVB($M$) / WENO($M$)，$M\in\{0,1,4,10,100\}$ |
| dtype | float64，CPU，单线程 |

**测量量**：$(\rho,u,v,p)$ 相对 $L^2$ 误差（对**解析解**，非数值参考解），
以及最细两网格上的观测阶 EOC。误差评估器复用 `benchmarks/verify_euler_dg_2d.py::_vortex_error`。

## ② 怎么做的（方法 / 流程 / 关键设置）

1. **先定判据再跑数**。被修的缺陷是「判据量纲不一致」：m2549 之前二维受限判据拿
   $O(dx\,u')$ 的一阶差商去比 $M\,dx^2$ 的容差，于是 $dx > 1/M$ 之后**每个**光滑格心都被判为
   troubled，网格越细限制越多。修好后的判据量是
   $|d_{\text{left}} - \mathrm{minmod}(d_{\text{left}}, d_{\text{right}})| = O(dx^2 u'')$。
   由此可**先验**给出一个惰性阈值预测：
   $$M_{\text{threshold}} \approx \max\left|\Delta^2 u\right| / dx^2,$$
   在**精确解**的格心上直接算（不拟合、不用数值解）。
2. **阴性对照（negative control）**：$M=0$（严格 TVD 判据）必须**咬**光滑极值并掉阶，
   否则「$M$ 大时不掉阶」这条结论没有判别力。
3. **惰性判据用逐位相等**（`torch.equal`）而不是近似相等：若判据真的不再触发，
   限制器就不应改动任何模态系数，两条轨迹必须**逐位相同**——这是最强、最难作弊的证据。
4. 扫描 harness：`benchmarks/limiter_2d_order_study.py`（`--degree/--meshes/--configs/--out`，
   可分片）；出图与合表：`benchmarks/report_limiter_2d_order.py`。
   全部数字落 `validation/limiter_2d_order/*.json`，本文件与报告中的数字**程序化直读**、零手抄。
5. **测试固化**：`tests/test_limiter_2d_order.py`（7 个用例，约 70 s）钉住惰性、阴性对照、
   `degree ≥ 2` 的掩码分支可跑通、以及判据本身的量纲语义（线性数据永不触发、真极值必触发）。

## ③ 计算结果（数字直读 `validation/limiter_2d_order/*.json`）

### 3.1 P2（设计阶 3），网格 $8^2,12^2,24^2$

| TVB $M=4$ | **2.925** | **2.873** | 5.620e-03 | **是** |
| TVB $M=10$ | **2.925** | **2.873** | 5.620e-03 | **是** |

| WENO $M=10$ | **2.925** | **2.873** | 5.620e-03 | **是** |

|---|---|---|---|---|

### 3.3 惰性阈值：预测 vs 实测

| 阶 | 判据先验预测 $M_{\text{threshold}}=\max|\Delta^2|/dx^2$ | 实测「不再触发」区间 | 一致性 |
|---|---|---|---|
| P2（$24^2$ 精确解格心） | **3.42**（x 向 3.42，y 向 3.05） | $M \in (1, 4]$ | ✅ 预测落在区间内 |
| P1（$32^2$ 精确解格心） | **3.52**（x 向 3.49，y 向 3.52） | $M \in (1, 10]$ | ✅ 预测落在区间内 |

「实测区间」是二分出来的：$M=1$ 掉阶且非逐位相同 ⇒ 未满足；$M=4$ 与无限制器逐位相同 ⇒ 满足。

### 3.4 与仓库既有独立结果的交叉核对

P1、$16^2$、无限制器、密度相对 $L^2$ 误差 = **3.8091e-03**，
与 `tests/test_euler_dg_2d_design_order.py` 里既有回归钉值 `3.8091e-03`（rel 5%）
**数字一致到 5 位有效数字**——说明本单的评估器/网格/时间步配置与仓库既有基准同源，
新数字不是另一套自定义口径。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **本单最重要的结论**：m2549 对二维限制器的修复**确实连带生效**，且修复后的
   `tvb_constant` 在二维也变成了**网格无关参数**——$M \ge 4$ 即惰性、$M \le 1$ 必咬，
   阈值与精确解的二阶差商量级预测（3.4–3.5）吻合。此前「二维未验证」的欠账关闭。
2. **$M$ 仍不是万能药（如实记录）**：$M=0$（严格 TVD）和 $M=1$ 都会限制光滑极值、把全局阶压到
   $\approx 1.0$–$1.4$；这是 minmod 类检测器的经典保守性（Cockburn & Shu 1989 引入 $M dx^2$
   容差正是为此）。本单贡献是**测出**该阈值并证明它可按 $|u''|$ 预估，而不是消除这一现象。
3. **WENO 与 TVB 共享检测器**：WENO($M=10$) 与无限制器**逐位相同**，说明 WENO 分支的差异
   完全来自检测器是否触发；一旦触发（$M=0$），WENO 重建同样掉阶（EOC 1.34–1.56）。
   即「WENO 限制作本身不是光滑流的保阶机制」，与 Zhang & Shu (2010) 的综述结论一致。
4. **未做（明确边界）**：非结构网格、三维、$p>3$、float32/GPU、含粘性通量的 NS 限制器、
   间断解（激波）上的 3% 工程门——这些都不在本单范围；二维的**间断**算例见
   `docs/limiter_2d_verification.md` 的四象限研究。
5. **性能开销未复核**：`docs/limiter_verification.md` §5 那条「76–123% 开销未复核」的欠账
   **仍然未复核**，本单只测精度/阶数（且限制器触发时每步仍走逐单元 Python 循环）。如实留档。
6. **容量与耗时**：单核 float64；P2 $24^2$ 单算例约 300–450 步，全梯子（4 个分片进程，
   每进程 1 核）约 10 分钟墙钟。本机 load15 = 122，故未上集群、未开多线程。
7. **一个坑**：`benchmarks/verify_euler_dg_2d.py::_vortex_error` 返回的是 $(\text{field}\to float)$
   扁平字典（含 `pressure_max`），不是嵌套字典；初版 harness 按嵌套取 `["relative_l2"]` 直接
   `TypeError`。另：`wandb`-way 无关——`vortex_primitive` 在**格心**上要传一维 `x[:,None]`，
   传成四维求积坐标会广播不匹配。

## ⑥ 误差判定（逐项 vs 基准，显式回答「是否 < 3%」）

本节基准 = **等熵涡解析解**（Euler 方程精确解），无文献拟合参数。

| 关键量 | 数值 | 基准 | 相对误差 | < 3% ？ |
|---|---|---|---|---|
| P2 + TVB($M\ge4$) 最细网格最差场误差（$24^2$） | 5.620e-03 | 解析解 | **0.562%** | **是** |
| P2 无限制器（对照，同上） | 5.620e-03 | 解析解 | 0.562% | 是 |
| P1 + TVB($M=10$) 最细网格最差场误差（$32^2$） | 3.116e-02 | 解析解 | **3.116%** | **否**（见下） |
| P1 无限制器（对照，同上） | 3.116e-02 | 解析解 | 3.116% | 否 |
| P1 无限制器 $16^2$ 密度 | 3.8091e-03 | 解析解 | 0.381% | 是 |
| P2 + TVB($M=0$) 最细网格最差场误差 | 9.974e-02 | 解析解 | 9.97% | 否（**预期**：阴性对照） |
| 观测阶 vs 设计阶（P2，$M\ge4$） | 2.925 / 2.873 | $p+1=3$ | −2.5% / −4.2%（阶数差，不是场误差） | 是（<3% 的是 ρ 场的阶） |
| 惰性阈值实测 vs 预测（P2） | 满足于 $M=4$ | 预测 3.42 | 预测落在 $(1,4]$ 内 | 是（预测被证实） |

**显式结论**：
- 本单关心的**主线判据**是「惰性 → 与无限制器逐位相同 → 观测阶 = 设计阶」：
  P2 观测阶 2.925 vs 3，差 **2.5% < 3%** ✅；且 $M\ge4$ 时与无限制器**逐位相同**（误差 0，无歧义）。
- **P1 的 3.116% 超出 3% 门，如实报告不粉饰**：这是 P1 **本身的离散误差**在 $32^2$ 上的水平
  （无限制器与限制器完全相同，说明**不是限制器造成的**）；P1 要在 3% 门内需更细网格
  （$16^2$ 时 0.381%，$32^2$ 反而更大是因为该门是最差场（$u,v$）而非 $\rho$：$\rho$ 在 $32^2$ 为
  0.093%）。故「P1 @ $32^2$ 全 4 场 < 3%」**不成立**，这条不作为本单的验收点，只作为诚实的边界记录。
- 阴性对照（$M=0$）9.97% 远离 3%，**故意如此**：它必须失败，否则测试没有判别力。
