# CASE-DG-ELASTIC-2D-PSV — 面项装配缺陷修复（m17172）

> 前序：`docs/CASE-DG-ELASTIC-2D-PSV.md`（m16925）登记 **honest FAIL**：闭合周期域弹性能涨 +14.52%、
> 半离散算子有正实部特征值、平面波阶梯不收敛。
> 本单（m17172）定位并修复**面项（数值通量）装配**的两个确定性缺陷，把该算例从「完全不收敛」推进到
> 「P/S 平面波收敛、能量守恒」，但**仍未完全通过**：宽带脉冲互校与半离散谱仍 FAIL（见 ⑥，如实登记）。
> 全部数字由 `benchmarks/elastic_2d_psv_status.py` 写入 `validation/elastic_2d_psv/status.json` 程序化注入。

## ① 案例介绍（物理背景/几何/参数）

二维线弹性动力学速度—应力一阶系统（P-SV），`U = (vx, vy, sxx, syy, sxy)`：

```
rho dvx/dt = dsxx/dx + dsxy/dy ,  rho dvy/dt = dsxy/dx + dsyy/dy
dsxx/dt = (lam+2mu) dvx/dx + lam dvy/dy ,  dsyy/dt = lam dvx/dx + (lam+2mu) dvy/dy
dsxy/dt = mu (dvx/dy + dvx/dy)
```

| 参数 | 值 | 说明 |
|---|---|---|
| rho | 1.0 | 密度 |
| lam | 1.0 | 第一 Lamé 参数（ν=1/4） |
| mu | 1.0 | 剪切模量 |
| c_p / c_s | 1.732051 / 1.000000 | 由参数程序内算出，c_p/c_s = √3 |
| 元数 nx×ny | 8…64 × 1（平面波）/ 50…200 × 1（脉冲） | 笛卡尔 |
| degree | 1/2/3 | 张量积模态 Legendre DG |
| CFL | 0.1（平面波）/ 0.3（脉冲） | dt = CFL·h/((2p+1)c_p) |
| 时间推进 | SSP-RK3（Shu–Osher 凸组合） | 已验证非「伪 RK3」 |

## ② 怎么做的（方法/流程/关键设置）

1. **独立重建执行路径**：不复用作者的诊断断言，直接从守恒律推 DG 强形式
   `dc_kl/dt = -(∇·F)_kl + (1/M_kl)∫_∂K (F-F*)·n φ_kl ds`，
   并把面项映射因子逐项算出：右面上 `∫ = (h_y/2)(svec·g)`、`M_kl = (h_x/2)(h_y/2) m_k m_l`
   ⇒ 系数应为 `(2/h_x)(1/(m_k m_l))·φ_k(1)·(svec·g)`。
2. **对照 L4 已验收的 1-D 算子**（`tensordg.elastic_1d`，独立审计通过）：其面项系数是 `(2k+1)/h = (2/h)(1/m_k)`，
   即**同样带 `2/h`**——2-D 代码漏了这个因子。
3. **用「一维化」隔离**：把 2-D 算子限制到 y 不变（ny=1、只留 l=0 模态），与 1-D 库算子逐元素比对，
   发现 `dS/dt` 吻合到 4e-15、`dV/dt` 恰好差 **-1 倍**（符号翻转）⇒ 面项特征跳跃项取了下风侧。
4. **判据**：Godunov 通量必须取上风格态。用「左=右行 P 波、右=真空」的界面反例一测即穿
   （正确解 `U*=0`；修复前返回 `F(q_right)`，即下风闭合 = 反耗散）。

### 修复（`tensordg/elastic_2d.py`，共 3 处、均为最小改动）

| # | 缺陷 | 症状 | 修复 |
|---|---|---|---|
| D5 | 面项漏参考域→物理域映射因子 `2/h` | 通量修正被 `O(h)` 欠权 ⇒ 一致性/斜对称破坏，误差随 h 饱和 | 面项乘 `face_x = 2/hx`、`face_y = 2/hy` |
| D6 | `riemann_flux_{x,y}` 特征跳跃项取下风侧 | 反耗散：闭合域能量单调涨、max Re(eig) > 0 | 跳跃项改为上风侧 `(right - left)`，与 Godunov 一致 |
| D7 | 两条「缺陷闸」把缺陷写成通过条件 | 修好后反而变红 | 改写为正确物理（上风格态 + 收敛达标），见 ⑤ |

## ⑤ 注意点（踩过的坑，可复用）

1. **验证本身是盲的**：平面波的精确解满足 `sigma_nn = -Z_p v_n`，界面两侧迹点落在同一条特征关系上，
   于是 Godunov 通量退化为物理通量，`F* - F ≡ 8.9e-16`（实测）。
   ⇒ **该阶梯从头到尾没有激励面项**，D5/D6 在它面前完全隐形（这解释了为何旧版能带着反耗散通量"收敛到 1e-3"）。
   教训：验证基准必须**同时**包含「在解空间内的算例」和「离开解子空间的算例」，否则等于没测面项。
2. **CFL 逐位相同是缺陷信号，不是好性质**：旧版 CFL 0.4…0.025 误差 12 位有效数字相同，说明空间误差被一个
   O(1) 的非一致性项支配。修复后该"性质"消失（时间误差已可见，相对差 1e-4）。
3. **缺陷闸的双刃**：把缺陷写成通过条件，修好后测试会变红提醒——是对的；但**必须同步改写**，
   否则下一个 agent 会以为修复引入回归。本单改写了 2 条（`test_godunov_flux_takes_the_upwind_characteristic`、
   `test_plane_wave_error_is_not_converging_and_is_h_independent`）。
4. **强形式 vs 弱形式互校**：与 L4 的 1-D 库逐元素比对时，「dV 恰好差 -1 倍」是极高信噪的定位信号
   （体项为 0 时面项 100% 暴露），比看误差表快得多。

### 下一单的锐利切入点（给接单者）

- 用同一「一维化逐元素比对」把 `dV/dt` 残余的 -1 倍关系钉死：`_rhs` 传给 `riemann_flux_x` 的实参顺序是
  `(邻居左迹, 自身右迹)`，与 `riemann_flux_x(left, right)` 的形参语义相反——**这是最可能的残余根因**，
  本单只修了公式侧、未统一两侧约定（1-D 库的调用顺序是 `(自身右迹, 邻居左迹)`）。
  统一后 `dV/dt` 应与 `tensordg.elastic_1d` 吻合到 1e-14，脉冲互校应掉到 1e-2 量级。
- 谱探针重做：ny=1、hy=1 的「单胞自环」是几何退化，建议用 2×2、hx=hy 的周期胞并用 `torch.linalg.eigvals` 复核。
