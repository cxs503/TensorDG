## ① 案例介绍

Lax (1954) / Toro test 2 激波管：`[0,1]` 域，隔膜 `x0 = 0.5`，γ = 1.4，快照 `t = 0.13`。左态 (ρ, u, p) = (0.445, 0.698, 3.528)，右态 (0.500, 0.000, 0.571)。解含四道波：左稀疏波（head/tail）、接触间断、右激波，位置与星区状态均有闭式表达。

网格阶梯（与算例池完全相同）：N=100·P1、N=200·P1、N=400·P1、N=100·P2、N=200·P2、N=400·P2、N=100·P3、N=200·P3、N=400·P3；CFL = 0.35，终止时刻 0.13。

## ② 怎么做的

1. **单一旋钮**：三个分支除 `limiter` 外全部参数相同（HLLC 通量、SSP-RK3、float64、10 点 Gauss 输出、正性与限幅阶段均取仓内默认），所以分支间的差异只能来自限幅器。
2. **判据不改**：`C1/C2/C3/R3/R5` 与容差**直接从** `benchmarks.lax_case_pool` 导入（C1 = 2.000 %、C2 = 5.000 %、C3 阶 ≥ 1.0、R3 阶 ≥ 0.85·(p+1)、R5 设计阶偏差 < 3.000 %），R3 区域规则沿用固定物理带宽 0.02（m16606 F1 的嵌套规则）。
3. **复现自检**：分支 `none` 必须逐位复现已跟踪的算例池记录 `docs/benchmarks/results/lax_case_pool/metrics.json`；实测结论 **PASS**，最大相对差 0.0（判据 < 1e-9）。
4. **同一批后处理**：三支共用同一个 `_leg()`，区域遮罩、加权 L1、波位/盘值定位代码完全相同——保留测度三支互等（见 ③.3）。

## ④ 注意点 / 局限

* **只动了一个旋钮**：`limiter_stage`（`every`/`final`）与 `tvb_constant` 的组合**未研究**；若某分支 FAIL 的成因是「每子步都限幅把光滑单元重投影」，本实验不能排除，只能说明它在当前默认下不成立。
* **限幅器不是 TVD 证明**：仓内实现为局部正性/振荡回退，`R5` 之外的激波强度外推（更强激波、二维钝体）不适用本结论。
* **阶数判据与误差判据必须分开读**：`C3/R3` 是收敛阶阈值，不参与台账 <3 % 的百分比口径（见 ⑤）。
* **墙钟**：见 `metrics.json` 的 `arms.*.wall_seconds`；限幅分支每步多一次邻域检修，故步数与墙钟都高于基线。
