## ① 案例介绍

二维可压缩 Euler 方程（γ = 1.4）的等熵涡在周期方箱 [-5,5]² 中以匀速 |u_inf| = √2 平移。
密度/压力扰动为高斯包络，流场处处等熵，故有闭式解析解。
真解在平移下**不变形**，因此离散误差应是网格/格式属性，而非时间属性。

| 参数 | 值 |
|---|---|
| 域 / 边界 | [-5, 5]²，双周期 |
| 涡强度 β | 5.0 |
| 来流速度 | (1, 1)，|u_inf| = √2 ≈ 1.4142 |
| 周期长度 | L = 10（每轴） |
| 整周期时间 | T = L/|u_inf| ≈ 7.07（对角输运） |
| 参考解 | 周期 min-image 折叠 |
| 容差 | 6%（相对 L2，t=1 快照） |
| 声明检查点 | 40 |
| 已落盘 | 40/40 |

## ⑤ 注意点与局限

1. **C11 证据溯源**：7 个 DG-P2 检查点待重放证书。已有 12 个证书的先例表明
   replay delta 在 1e-13 ~ 1e-12 量级，预期全部通过。详见
   `docs/CASE-DG-EULER-VORTEX-ERR-c11-closure-plan.md`。

2. **P0 长时误差**：一阶格式在 t=10 时误差达 14.3%（n=64），
   这是耗散抹平涡核的固有属性，非失稳。C1x 保留原始读数。

3. **参考解截断地板**：min-image 模型在速度场有 ~1.5e-6 的截断地板，
   P3 度误差（0.0006%）接近此限，但仍在容差内。

4. **误差放大因子**：DG 族 A(10) = 1.77–4.89（量级 1 ⇒ 误差守恒），
   P0 族 A 达 10³ 量级（一阶格式的时间累积，机制已知）。
