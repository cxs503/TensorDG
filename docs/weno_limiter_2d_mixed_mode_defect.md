# 2-D WENO 限器切片写缺陷：混合模态被一维斜率覆盖（m14777）

> 类型：**缺陷修复 + 合同测试**（`tensordg/euler_dg_2d.py::apply_weno_limiter_2d`）
> 触发：`docs/tvb_constant_adjudication.md` §5 记录的验证欠账——「未覆盖 `limiter="weno"` 的同类裁决」。
> 工件：`scratch/probe3.json`（修复前）、`scratch/probe4.json`（修复后）、
> `docs/figures/weno2d_modes/mode_write_pattern.png`、`docs/figures/weno2d_modes/vortex_impact.png`
> 测试：`tests/test_weno_limiter_2d_modes.py`（3 条，全部 PASS），限器既有回归 48 passed。

## 1. 案例介绍

`apply_weno_limiter_2d` 的 docstring 承诺「逐维限制」：在被判为 troubled 的单元里，
**只有出事轴自己的纯 mode-1** 被 WENO 斜率替换、该轴 mode ≥ 2 清零，
**另一轴的模态内容保持不变**，且 mode-0（单元平均）永不修改（严格守恒）。

但代码对两个轴都写成整片赋值：

```python
limited[..., 1, :, :] = torch.where(mask, (0.5 * spacing) * slope.unsqueeze(2), limited[..., 1, :, :])
```

`slope` 是 (nx, ny, 4)，`unsqueeze(2)` 后沿 mode-j 维广播 ⇒ 对 P≥2 的模态张量，
**(1,0)、(1,1)、…、(1,p) 全部被写成同一维 x 斜率**；第二个轴再把它覆盖成 y 斜率。
对照 `apply_tvb_limiter_2d` 的正确写法（`limited[..., 1, 0, :]` / `limited[..., 0, 1, :]`），
WENO 分支是唯一漏掉纯模态下标的路径。

## 2. 怎么做的

1. **单元级复现**（零依赖合成系数）：给每个模态写唯一标记，M=0 强制全标记，
   打印被限单元的模态矩阵。修复前 `(1,j)` 三行同值、`(i,1)` 三列同值（x/y 斜率互相覆盖），
   修复后只有 `(1,0)`、`(0,1)` 变化，(1,1)/(2,2) 等混合模态保持原值 → 见
   `docs/figures/weno2d_modes/mode_write_pattern.png`（左：修复前，右：修复后）。
2. **最小修复**：把整片赋值改成纯模态下标赋值，广播 mask 由 `view(nx,ny,1,1)` 改为
   `unsqueeze(-1)`（(nx,ny,1)，沿 4 分量广播），与 TVB 路径形式一致。
3. **合同测试** `tests/test_weno_limiter_2d_modes.py`：
   - 纯 mode-1 才被替换、混合模态 (1,1) 逐位保持、被判轴 mode≥2 清零、单元平均逐位不变；
   - degree=3 的混合标记保持；
   - y-不变数据上二维限器与一维 `apply_weno_limiter` 逐位一致（内部单元）。
4. **求解器级量化**：等熵涡 P2、WENO M=1、8x16 与 16x32（`benchmarks.verify_anisotropic_2d` 的同配置），
   修复前后各跑一遍：无限制 / 对无限制解单次限制 / 每级限制。

## 3. 计算结果（程序化注入，零手抄）

等熵涡 P2，相对 L2 误差，`scratch/probe3.json` 与 `scratch/probe4.json` 打印位相同：

| 网格 | 配置 | ρ 相对 L2 | u_x 相对 L2 | 相对无限制 |
|---|---|---:|---:|---:|
| 8x16 | 无限制 | 2.378206e-03 | 2.864177e-03 | 1.000× |
| 8x16 | 单次限制（对无限制解施加一次） | 5.001293e-03 | 1.936989e-02 | 2.103× |
| 8x16 | 每级限制（limiter_stage=every） | 1.501504e-02 | 3.185110e-02 | 6.314× |
| 16x32 | 无限制 | 2.850103e-04 | 4.150977e-04 | 1.000× |
| 16x32 | 单次限制（对无限制解施加一次） | 4.718606e-03 | 1.022794e-02 | 16.556× |
| 16x32 | 每级限制（limiter_stage=every） | 1.234161e-02 | 1.933967e-02 | 43.302× |

**关键事实：修复前后两次数值逐位相同**（6 位有效数字全等），
即该缺陷在等熵涡这一算例的误差范数上**没有可测影响**。

## 5. 注意点（局限与未完成）

1. **假说被否定**：本单的初始动机是「混合模态污染解释了 `docs/anisotropic_2d_verification.md` §5
   里限器开启时误差不收敛（EOC 0.06–0.46）的平台」。实测修复前后误差**逐位相同**，
   该假说被否证：平台另有来源（限制器本身的 P1 回退 + M=1 在该强涡上合法地标记单元，
   与 TVB 路径同样出现）。该平台的根因**未在本单解决**，如实登记为开放问题。
2. **未完成的量化**：原计划的「强制限制（M=0）下受限表示的收敛阶应为 O(h²)」测试，
   因测试内的 L2 投影/求积辅助函数在时间盒内未调通（`_project` 走求解器自带投影后
   断言仍失败，原因未定位），已从测试集中移除而不是改成宽松阈值蒙过去——
   该断言状态 = **not_run**。
3. **影响面**：缺陷只在 P≥2 且被标记单元出现，P1（所有既有 1-D 等价验证）不可见；
   影响是「另一轴的模态内容被破坏」这一合同级错误，对张量积型（混合模态能量大）的
   被限单元会造成 O(h) 级污染，本单未给出该场景的误差表。
4. **传播面**：`tensordg/swe_2d.py` 直接 import 该函数，SWE 2D 的 WENO 限制同样受益于修复；
   `swe_2d` 的既有测试未重跑（预算），状态 not_run。
