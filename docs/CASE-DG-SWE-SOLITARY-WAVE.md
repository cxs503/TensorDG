## ① 案例介绍（物理背景 / 几何 / 参数表）

**物理背景**：1872 年 Boussinesq 给出经典孤立波解析解——在平底水深 `h0` 上，
一个振幅 `a`、宽度 `w = √(4h0³/(3a))`、以非线性波速 `c = √(g(h0+a))` 传播的
`sech²` 型波峰。它是弱非线性、弱色散 Boussinesq 方程族的精确解；而本仓求解的
**一维非线性浅水方程（SWE）** 正是该族方程的无色散首阶极限。因此对**小振幅**
（`a/h0 ≪ 1`）与**短传播距离**，SWE 解应保持 Boussinesq 剖面：波峰高度保持到
`O((a/h0)²)`，波前以非线性速度 `c = √(g(h0+a))` 推进（线性速度 `c0 = √(gh0)`
仅在 `a → 0` 极限下恢复）。

**几何与参数**（平底 `z_b = 0`，一维通道）：

| 项 | 值 | 说明 |
|---|---|---|
| 方程 | 1-D SWE：∂h/∂t+∂(hu)/∂x=0；∂(hu)/∂t+∂(hu²+½gh²)/∂x=0 | 平底无源项 |
| 重力 | g = 9.81 m/s² | 常设 |
| 静水深 | h0 = 1.0 m | |
| 波幅（主算例） | a = 0.02 m | a/h0 = 0.02（小振幅） |
| 波宽 | w = √(4h0³/(3a)) = 8.165 m | Boussinesq 特征宽度 |
| 非线性波速 | c = √(g(h0+a)) = 3.1633 m/s | 解析锚 |
| 线性波速 | c0 = √(gh0) = 3.1321 m/s | 对比参考 |
| 域 | x ∈ [-60, 100] m（160 m） | 波尾在边界 < 0.003% a |
| 初值 | h(x,0)=h0+a·sech²(x/w)；u(x,0)=c·(h-h0)/h | 标准孤立波播种 |
| 传播距离 | 2–5 个特征宽度 w | t_end = 5.16–12.91 s |
| 数值格式 | 模态 Legendre DG（P1/P2）+ HLL + SSP-RK3 | CFL=0.15（P1）/0.08（P2） |
| 网格 | 200/400/800 单元 | dx = 0.8/0.4/0.2 m |

**无量纲数**：

| 无量纲数 | 定义 | 值 |
|---|---|---|
| 振幅比 | a/h0 | 0.02（主算例）；0.005–0.05（扫描） |
| 速度比 | c/c0 = √(1+a/h0) | 1.00995 |
| 无量纲传播距离 | x* = (c·t)/w | 2–5 |
| 网格分辨率 | w/dx | 10–41 单元/波宽 |

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

**方法**：复用 TensorDG 现有 DG 浅水求解器 `tensordg/swe_1d.py`（模态 Legendre
DG P1/P2 + HLL 数值通量 + SSP-RK3 时间积分 + 正性保持），以 Boussinesq 孤立波
剖面作初值，在平底域上传播，将终态剖面与解析解逐点比对。

**关键设置**：
1. **初值**：`h(x,0) = h0 + a·sech²(x/w)`，`u(x,0) = c·(h-h0)/h`——这是
   SWE 求解器标准孤立波播种（质量通量条件 `(u-c)h = -ch0` 的等价形式）。
2. **波峰测量**：用**亚网格抛物线插值**（过 argmax 胞及其两邻胞的抛物线顶点）
   定位波峰，避免波速被网格量化（`dx` 级误差）。
3. **解析锚**：Boussinesq 精确解 `η_ref(x,t) = h0 + a·sech²((x-c·t)/w)`，
   与数值解在同一网格上逐点比对。
4. **误差度量**：峰值高度相对误差、峰值速度相对误差（`x_peak/t` vs `c`）、
   剖面相对 L2、质量漂移。

**工具链**：`python docs/benchmarks/swe_solitary_wave.py`（全量基准）→
`artifacts/swe_solitary_wave_metrics.json`（机器可读指标，程序化注入）→
`docs/figs/swe_solitary_wave_*.png`（matplotlib 图）。无随机数，可复现。

**算例矩阵**：
- 主算例：a=0.02，2 波宽，N=400，P1
- 长时算例：a=0.02，5 波宽，N=400，P1
- 时间序列：a=0.02，2 波宽，6 个快照（N=200）
- 收敛研究：a=0.02，2 波宽，N=200/400/800，P1
- 振幅扫描：a/h0=0.005/0.01/0.02/0.05，2 波宽，N=400
- 阶数对比：a=0.02，2 波宽，N=400，P2（CFL=0.08）

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **波速测量的网格量化**：初版用 argmax 胞中心定位波峰，波速误差在粗网格
   （N=200，dx=0.8 m）上振荡到 4.5%（网格量化伪影）。改用**亚网格抛物线插值**
   后，波速误差收敛到 ~1.95% 且随分辨率稳定——这是本单的关键修正。
2. **SWE 与 Boussinesq 的物理差异**：SWE 无色散，Boussinesq 孤立波不是 SWE 的
   精确稳态解。波速误差 ~1.95%（a/h0=0.02）是**物理演化**（波前轻微陡化），
   随 a/h0 线性增长（振幅扫描证实），非数值误差。因此本基准**只适用于小振幅**
   （a/h0 ≤ 0.03 时波速误差 < 3%）；大振幅（a/h0=0.05）波速误差 4.7% 超门限，
   属预期（SWE 与 Boussinesq 的 O(a/h0) 差异）。
3. **域宽**：波尾 `sech²` 在 6w 处衰减到 < 0.003% a，域 [-60,100] 保证边界
   无反射污染（质量漂移 3e-9 证实）。
4. **P1 vs P2**：孤立波是光滑场，P1 已足够精确（P2 仅步数更多、结果相同）；
   P2 需更小 CFL（0.08）——高阶格式在波前附近的已知限制。
5. **适用范围**：本基准验证 DG SWE 求解器对**小振幅孤立波**的传播能力
   （波高保持 + 非线性波速）。不适用于验证色散效应（需 Boussinesq/Serre 类
   方程，见 `tensordg/dispersive.py` 的 KdV 色散基准）。
