# CASE-LAX-DG 分辨率闭合研究（p3 阶梯对 3 % 台账门）

> 工件：`docs/benchmarks/results/lax_resolution_closure/metrics.json`  
> 生成：2026-11-14T11:26:01Z　墙钟：1385 s　配置：p = 3，CFL = 0.35，阶梯 N = [200, 400, 800, 1600]，限幅器 = none（登记臂）  
> verdict：**PASS**，闭合网格 = **800**

## ① 案例介绍

`CASE-LAX-DG` = Lax (1954) 激波管（Toro 1999 test 2）：`[0,1]` 域、隔膜 `x0 = 0.5`、γ = 1.4、快照 `t = 0.13`，左态 (ρ,u,p) = (0.445, 0.698, 3.528)、右态 (0.5, 0, 0.571)。解析波系为左稀疏波（头/尾）、接触间断、右激波，四者位置都有闭式解，参考值由`benchmarks/riemann_exact.py` 独立给出。

台账 `CASE-LAX-DG` 的验收原文是「ref: 精确解｜容差 < 3 %」。算例池把这条读成**生产腿 `p3.N400` 的全场相对 L2**，并如实记下 **FAIL（3.1156 %）**。本单据此追问一个不同的问题：

**这个 3 % 门在已登记的计算配置（p3、无限幅器）下，靠 h-细化是否可达？可达的最小实际算过的网格是哪个？**

## ② 怎么做的

1. **h-细化到闭合**：登记配置（p3、CFL 0.35、无限幅器、精确 Riemann 参考）在 N ∈ [200, 400, 800, 1600] 上重跑；每条腿在单元 Gauss 节点上测三个原始量的全场相对 L1/L2，以及 R3 规则的固定物理带（±0.02）掩码 L1。
2. **单旋钮归因**：在生产网格 N = 400 上只切换 `limiter`（none / tvb / weno），其余全部固定，用来把「p3 不准是因为无限幅（Gibbs 振荡从三个间断漏到平台）」与「p3 算子本身有错」分开。
3. **闭合判据预先声明**：`PASS` 仅当**实际跑过**的某条腿在**全部三个量**上 L2 ≤ 容差；功率律外推出来的 `N*` 只作模型预测记录，**永远不计为通过**。
4. **p3 算子健康度另测**：`tests/test_lax_p3_smooth_order.py` 在光滑周期熵波上测 p3 设计阶（实测 4.0097，设计 4），把「算子错」这一假设先行否证。

## ⑤ 注意点

1. **闭合 ≠ 台账原文已通过**。台账登记的是生产腿 `p3.N400`，那条腿的诚实结论仍是 FAIL；本单给出的是「同一配置在哪个网格上达到同一容差」，是接受准则的**分辨率限定**，不是改口径。
2. **p3 的观测阶远低于设计阶 4**：光滑流上 p3 实测 4.00（`tests/test_lax_p3_smooth_order.py`），所以低阶不是算子错，而是无限幅方案在间断附近产生的振荡污染了全场范数——这正是不连续解上阶门可以 FAIL 的原因。
3. **限幅器不是补救手段**：单旋钮对比里 tvb/weno 都让 L2 变差（见 3.2），本仓这两种限幅器都把问题单元**退化为线性重构**，在 p3 上属于过度限制。
4. **外推不作证据**：3.3 的外推网格只用于说明「门是否在可负担范围内」，任何 `PASS` 都必须落在实际算过的腿上（测试已钉死这条）。
