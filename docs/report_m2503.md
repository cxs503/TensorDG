## 1. 案例介绍

**物理背景**：二维高阶 DG 欧拉求解器（`solve_euler_dg_2d`，模态 Legendre 基 + HLLC + SSP-RK3 + 局部正性过滤）。此前已合并版本（m21xx 二维 Euler DG 交付）只带一个 `limiter="tvb"`，且 troubled-cell 判据 `_troubled_1d` 对两个方向**一律**用 `torch.roll` 取邻元——在 `periodic=(False, True)` 的挤压 Sod 上，非周期 x 轴等于把网格另一端的值当成边界邻元。README 把「多维限制器」列为未完成项，仓库也从未有过 2-D WENO。本单属**验证欠账类**：对已合并限制器做复核并补齐验证。

**几何 / 参数**：

| 项 | 值 |
|---|---|
| 域 | (x, y) ∈ [0,1] × [0,0.25] |
| 周期性 | periodic = (False, True) |
| 初值 | Sod：(ρ,u,p) = (1,0,1) \| (0.125,0,0.1)，膜片 x = 0.5 |
| 时刻 | t = 0.2 |
| CFL | 0.2 |
| 阶数 | P1（100 格）与 P2 |
| TVB 常数 | M = 1.0 |
| 环境 | torch 2.7.1，4 线程 |

**本单范围**：(i) 复核并修正边界判据；(ii) 补齐方向分裂的 2-D WENO 限制器；两者均用解析基准验证。

## 2. 怎么做的

1. **边界判据**：`_troubled_1d(averages, axis, spacing, M, periodic)` 新增 `periodic` 形参，由 `solve_euler_dg_2d` 的 `periodic` 标志逐轴传入。周期轴照旧 `torch.roll`；出流轴改为夹取邻元，并且**把该轴的两个端单元从 troubled 集合中移除**——夹取后的单侧模板有一个零增量，任何单调剖面都会被误判成极值（第一轮实现踩到此坑，见 §5.2），因此端单元保持高阶多项式而不限，与 1-D 限制器既有约定一致。
2. **2-D WENO**：`apply_weno_limiter_2d` 按方向逐轴做 WENO3 重构（Qiu & Shu 2005 方向分裂版本）：问题单元的该轴模态 1 取 WENO 加权斜率 `w0 s0 + w1 s1 + w2 s2`（`s0=(u_i-u_{i-1})/h`，`s1=(u_{i+1}-u_i)/h`，`s2=(u_{i+1}-u_{i-1})/2h`，权重由经典 WENO3 光滑指示子给出），该轴模态 ≥2 清零，另一轴模态保持不变。模态 0 永不修改，故守恒逐位保持。
3. **验证工具**：`benchmarks/verify_limiter_2d.py` 四个探针（判据／重构／Sod／守恒），数字全部由脚本程序化写入 `validation/limiter_2d/verify.json`；图由该 JSON 绘制。运行：`PYTHONPATH=. python -m benchmarks.verify_limiter_2d --threads 4`（本机 121 s）。

**工具链**：Python 3 + torch 2.7.1（4 线程）；matplotlib 绘图；pytest 跑 `tests/test_limiter_2d.py`（12 条）。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **账面数字与实测不符（本次最实质的发现）**：`docs/verify_euler_dg_2d_resolved.md` §3.2 把「P1 / 100 格 / TVB」的挤压 Sod 记为 ρ 0.761%、p 0.707%。这两个数字恰好是**不开限制器**（仅正性过滤）的结果；开 TVB 实测为 2.007% / 1.999%。两者都在 3% 门内，但「TVB 行的数字」不能作为限制器路径的证据引用。该文档未改动，此处留证。
2. **夹取模板 + 不剔除端单元 = 新的误判源**：第一轮实现让端单元参与判据，单侧模板的零增量使 `minmod(0, Δ) = 0 ≠ Δ`，任何单调剖面在端单元都「非单调」，光滑仿射数据被误限（`tests/test_limiter_2d.py::test_affine_data_is_untouched` 抓到）。最终方案是分轴判据 ＋ 端单元不参与限制。
3. **TVB 常数 M 不是普适的**：M = 1 在 h = 1/16 时会标记光滑极值，子格误差 ~3-5%。用限制器做光滑问题必须按 `M ≳ max|u''|` 调参或直接不开。
4. 限制器降低总变差（0.934 → 0.885）和过冲（ρ_max 1.0070 → 1.0006），代价是 L2 精度（0.761% → 1.705%）。这是激波捕捉的正常代价，但对本算例（P1、100 格、仅正性过滤已无振荡放大）限制器并非必要。
5. 局限：方向分裂 WENO 不是真二维 WENO 模板；只验证到 P2、Cartesian、无粘；四象限二维 Riemann 算例（无解析解）本轮因算力预算未跑，正性/网格自收敛证据沿用 m21xx 记录。
6. **补报特有**：原单声明在档案中截断；平台侧工件目录未留档；原 commit `e2b83e5` 不在本地仓库（分支曾重建后经 PR #18 合入，merge commit `c53f0c97`）；原结果图未留档（本图由 `verify.json` 重绘）。

**判定（honest-FAIL，如实保留）**：原单结论为 **FAIL**，本补报如实保留、不粉饰。据已合入的验证记录，复核在**此前已合并**的二维 Euler DG 限制器中发现实质缺陷：(a) 边界判据缺陷（旧判据在非周期轴误判单元 0 为 troubled）；(b) 账面数字不符（此前合并文档的 TVB 行实为不开限制器数字）。修正后的路径（分轴 TVB ＋ 新增 2-D WENO）在全部关键量上满足 3% 门。FAIL 判定的具体口径在档案中未留档（原单声明截断），本报告不将其重新解释为 PASS。
