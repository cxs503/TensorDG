# TensorDG#235 重开第2轮：Sod管速度验证门修复报告

## ① 案例介绍

**物理背景**：Sod激波管是可压缩Euler方程的标准验证算例。初始时刻x=0.5处有隔膜，左侧(ρ=1,u=0,p=1)，右侧(ρ=0.125,u=0,p=0.1)。隔膜破裂后产生左行稀疏波、接触间断和右行激波。

**验证目标**：2D Euler DG求解器在挤压Sod算例上，速度场的相对L2误差<3%（P2/64网格，t=0.2）。

## ② 怎么做的

**修复内容**（tests/test_euler_dg_2d_velocity.py）：

1. **修正能量值**：`_sod_left()`和`_sod_right()`返回的保守变量中，能量E应为`p/(γ-1)`，原代码错误地除以了`(γ-1)`两次。
2. **添加隔膜偏移**：精确Riemann解的自相似变量应为`(x - 0.5)/t`，原代码使用`x/t`。
3. **补充稀疏波扇区计算**：原精确求解器在稀疏波扇区直接设u=s_m，应改为线性变化。
4. **修正接触间断位置**：从0.664修正为0.628。

## ③ 计算结果

数值解星区速度u≈0.93，精确解u≈0.64，偏差约45%。

## ⑤ 注意点

数值解星区速度异常（u≈0.93 vs 精确u≈0.64），疑似HLLC通量实现问题，需另立案调查。
