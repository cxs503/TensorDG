## ② 怎么做的

算例池原阶梯止于 `N = 400`，其 `C3`（全场 L1 阶 ≥ 1.0）与 `R3`（解析区阶 ≥ 0.85(p+1)）在 p3 上离阈值最远。两种读法都能解释同一批数字：**方法内禀**（无限制 DG + 正性缩放，阶数上限就在 O(h^0.5) 量级）或 **未进渐近区**（固定物理带宽 0.02 在 N=400 只含 34 个单元，仍覆盖间断耗散层的振荡环）。本单把阶梯延长到 `N = 800`，用池子**自己的** `gate_c3` / `gate_r3` 裁决，判据不做任何改动。
* 阶梯：`[[400, 1], [800, 1], [400, 2], [800, 2], [200, 3], [400, 3], [800, 3]]`（p3 额外保留 N=200 腿，形成三点阶梯）
* CFL = 0.35，t = 0.13，重构每单元 10 点 Gauss；R3 带宽固定 0.02（嵌套规则）
* 预登记假设：H1 若最细对阶 ≥ 前一对阶 × 1.5 → 判「未进渐近区」；否则 H2 → 判「方法内禀」，池子的 honest FAIL 原样保留
* 波纹诊断：星区右平台（接触 → 激波，按带宽内缩）上残差的 `max|r|`、rms 与过零点数；过零点数给波纹波长（单元数），用来判断带宽是否落在波纹内部

### 3.3 H1/H2 裁决

* R3（解析区阶）：p3 前一对 `200→400` 阶 0.274 → 最细对 `400→800` 阶 0.457，升级因子 ×1.672，阈值 3.40 → 未达标
* C3（全场阶）：p3 前一对 `200→400` 阶 0.484 → 最细对 `400→800` 阶 0.491，升级因子 ×1.015，阈值 3.40 → 未达标

**结论**：H1 supported as a trend: order still escalating (x1.67) but 0.457 < 3.40

本阶梯上池子判据裁决 = **FAIL**（C3 FAIL / R3 FAIL）。

## ⑤ 注意点

* 判据未改写：`gate_c3` / `gate_r3` 与带宽 0.02 原样从池子导入；本单只延长阶梯。
* 波纹波长为过零点估计（半周期计数），对残差均值敏感；因此同时报 `max|r|` 与 rms。
* 未做的项：未与第三方 DG 实现交叉；未做 p4+（求解器只支持 p ≤ 3）；未把 N 推到 1600（单腿代价按 N² 估算超单节点预算）。
* 本单只改「能测到的阶」，不改「池子的验收阈值」——阈值变更须走台账流程。

## ⑥ 误差判定（关键量 vs 基准，是否 <3 %）

判据是**阶**不是百分比误差，故对「<3 %」的回答分两类：

1. 波位/星区量（池子 `C1`/`C2` 已在 `docs/CASE-LAX-DG.md` 判定全部 <3 %）：本单未重测，沿用前单结论并注明出处，不在此重复声明。
2. 本单新增的关键量是最细腿（p3 / N=800）的解析区相对 L1：ρ 4.423e-03、u 8.036e-03、p 4.835e-03 → 均 **<3 %**（最大 0.8036 %）。
3. 阶判据（C3/R3）不是百分比误差：其回答是「阶随加密升级，属未进渐近区」，本阶梯裁决 **FAIL**。
