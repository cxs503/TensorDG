# Thacker (1981) 抛物盆地晃动：验证欠账复核（m6377）

> 上游：TensorDG@2859ce4（main）。仓：TensorDG。分支：agent/m6377。
> 前序：`docs/thacker_validation_gap.md`（m6315）与 `docs/validation_status_report.md` 把该算例记为
> **CRITICAL 验证缺口**（"误差 O(100%)，速度场完全错误"）。本单对这条结论做复核。

## 1. 结论摘要（先给判定）

| 项 | m6315 的结论 | 本单复核结果 |
|---|---|---|
| 参考解正确性 | 视为权威解析解 | **有误**：速度幅值公式错，差 4.90 倍 |
| 早期（t=0.1 s）自由面误差 | 22.3% | **0.055%**（P1 N=50，同一求解器） |
| 早期速度场 | "完全错误" | **0.41%**；旧判据的错误来自参考解 |
| 长时（t=0.5 s ≈ 1/3 周期）误差 | O(100%)/发散 | **≈12% 且不随网格收敛**（真实缺陷，未解决） |
| 边界条件 | 猜测"反射/周期 BC 不匹配" | **部分正确**：默认透射闭合反射出射波；新加解析边界通量后可彻底消除质量漂移 |

即：**m6315 的参考解是错的，其"速度场完全错误"与 t=0.1 s 的 22% 误差是伪缺陷**；
但 **t≳0.3 s 的 ~12% 误差是真实缺陷**，且它是"不收敛型"误差，需要后续单独立项。

## 2. 正确的解析解（本单推导 + 独立验证）

床面 `z_b = -h0 (1 - (x/L)^2)`，初值 `eta(x,0) = h0 + A x / L, u = 0`。自由面保持**平面**、速度**空间均匀**：

```
omega    = sqrt(2 g h0) / L                       = 4.4294 rad/s   (T = 1.4185 s)
s(t)     = (A / L) cos(omega t)                   自由面斜率
u(t)     = -(A omega L / (2 h0)) sin(omega t)     均匀速度，幅值 1.1074 m/s
eta_c(t) = h0 + A^2/(4 h0) sin^2(omega t)
eta      = eta_c + s x ,   h = eta - z_b
```

它精确成立当且仅当三条标量恒等式成立（本单已用中心差分逐点核验，见测试）：
`s_t = 2 h0 u / L^2`、`eta_c,t = -u s`、`u_t = -g s`；三者蕴含两个 PDE 残差恒为零
（另用 sympy 对连续形式做过残差=0 的符号验证，见 `validation/swe_thacker/diagnostics/`）。

m6315 用的速度是 `u = -A omega sin(omega t)/g`，幅值 0.2258 m/s：
**1.1074 / 0.2258 = 4.90 倍**（正确幅值为 `A omega L/(2 h0)`，不是 `A omega/g`）。
其 `eta` 只差一个 O(A²/4h0)=0.0625 m 的抬升项，故自由面判据"看起来还能用"，速度判据全错。

## 3. 独立交叉验证（排除"求解器对/参考解错"的自我循环）

为排除只用 TensorDG 自证的可能，本单另写一个**独立的一阶有限体积 Rusanov 求解器**
（numpy，N=400/2000，使用同一解析边界通量）：t=0.5 s 时
`eta` 相对 L2 误差 **0.61%**（N=400）/ **0.27%**（N=2000），`u` 误差 3.03%/1.24%。
→ 参考解与物理是对的；DG 侧 ~12% 的偏差属求解器缺陷。

网格加密（N=25/50/100/200，P1 与 P2）后误差**不下降**：12.73→12.25→12.03→11.93%（P1, t=0.5），

且两者总水量收敛到**不同的错误值**（3.624 vs 3.10，真值 3.413）——这是质量守恒型缺陷的指纹。

## 6. 未解决 / 诚实说明（不粉饰）

* **长时 ~12% 且不收敛**：真缺陷，本单只定位不含修复。已知线索：
  (a) 误差在 t≈0.25 s 之后才起来，正好在波穿越域 `2L/c ≈ 0.40 s` 量级，可疑边界耦合；
  (b) 半离散残差检验显示**质量方程残差为机器零、动量方程残差为一阶 O(dx)**，即半离散算子
      对解析解只满足一阶相容（源项 `-g dbdx c_k` 与通量散度只在静水状态严格抵消）；
  (c) 施加解析边界通量后 `P1 N≥40` 会触发 `Nonphysical SWE state` 守卫（t≈0.3 s），
      提示边界通量与内部截断态之间存在能量注入——这是下一张单最该查的点。
* P2 比 P1 更差、两者水量收敛到不同错误值：尚未定位，疑与源项/模态配点在高阶时的不一致有关。
* 本单未改动求解器数值内核（只加可选边界接口），因此上述缺陷原样保留。
