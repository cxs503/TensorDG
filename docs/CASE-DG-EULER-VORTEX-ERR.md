## ① 案例介绍

二维可压缩 Euler 方程（理想气体 γ = 1.4）的**等熵涡（isentropic vortex）**是解析精确解算例：初始场为等熵涡，均匀来流 (u,v)_∞ = (1,1) 平移输运该涡，t > 0 的精确解即初始剖面向下游平移。

| 项目 | 取值 |
|---|---|
| 计算域 | x, y ∈ [−5, 5] × [−5, 5]，四周周期边界 |
| 涡强度参数 β | 5 |
| 来流 (u,v)_∞ | (1, 1) |
| 绝热指数 γ | 1.4 |
| 精确解 | Shu (1998) §4.4.2 标准形式；周期映射通过 min-image 实现 |
| 验收容差 | 各原始变量相对 L2 < 6%（算例池指定，ref: Yee et al. 2000） |

**物理背景**：等熵涡在周期域中匀速平移，涡的形状保持不变。因此离散误差应是网格/通量对的属性，而非时间的函数——这就是"误差守恒"的含义。若误差随时间超线性增长（α > 1），则说明格式存在非物理的误差放大机制。

## ② 方法与流程

两条**互相独立**的离散路径被同一判据检验：

1. **高阶 DG 路径**：张量积模态 DG（P2）+ HLLC 界面通量 + SSP-RK3 时间推进，L2 投影初始态，误差度量用体积求积节点上的重构状态（点值相对 L2）。
2. **低阶 P0 路径**：P0 有限体积 + Rusanov 界面通量 + SSP-RK3，初始场按 4×4 高斯点精确单元平均，误差度量用单元平均值相对 L2。

**五项门禁判据**：

| 判据 | 内容 | 门限 |
|---|---|---|
| C1 快照容差 | t = 1 时各族最大场相对 L2 | < 6% |
| C2 误差守恒 | DG 设计族 e ~ t^α 的 α ≤ 1.0 | α ≤ 1.0 |
| C3 离散守恒 | 质量/动量/能量漂移 | < 1e-10 |
| C4 熵预算 | \|ΔS\|/S(0) | < 0.001 |
| C5 交叉收敛阶 | P0 在 t=1 的观测阶（n=64/128/256） | ≥ 0.8 |

## ⑤ 注意点与局限

1. **DG t = 10 检查点**：本单通过集群作业 cj3051 递交了 DG-P2/32² t = 10 的计算，但因输出工件未正确回传，该检查点暂未纳入聚合。复现命令：
   ```
   PYTHONPATH=. python3 benchmarks/case_euler_vortex_errconserve.py --task dg --degree 2 --cells 32 --final-time 10 --cfl 0.2 --threads 8
   ```

2. **P0 长时误差累积**：P0 一阶格式的耗散导致涡核抹平，误差随时间线性累积（α ≈ 0.5–0.6）。这是格式属性，不是 bug。C1x 长时最差 14.3%（p0_n64_t10）如实保留。

3. **参考缺陷**：t ≥ 2 时若使用自由空间精确解（非周期映射），速度场误差会被严重高估（t = 5 时达 14%）。本算例已修正为周期参考，详见 `reference_defect_percent` 字段。

4. **误差度量差异**：DG 用点值 L2，P0 用单元平均 L2。跨族比较只用于量级判断，族内收敛阶比较才是严格判据。
