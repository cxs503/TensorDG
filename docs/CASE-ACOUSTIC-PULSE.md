## ① 案例介绍（物理背景/几何/参数）

线性化 Euler 方程的经典气动声学验证问题（Tam & Webb 1993 JCP 107:262；Tam & Dong 1996 JCP 125:215）：
静止均匀流体中一个轴对称高斯压力脉冲向四周辐射。TensorDG 的生产 2-D Euler DG 求解器
（`tensordg.euler_dg_2d`，HLLC + SSP-RK3，模态 Legendre 基）在**小扰动极限**下求解该问题，
与线性化解析解逐点比较。

| 参数 | 值 |
|---|---|
| 背景状态 | ρ0 = 1, p0 = 1, γ = 1.4 ⇒ c0 = 1.183216 |
| 脉冲 | p'(r,0) = A exp(−α r²)，A = 0.001，b = 0.4，α = ln2/b² = 4.332170 |
| 初始速度 | u = v = 0（纯声学模态：ρ' = p'/c0²，无熵模态） |
| 计算域 | [−5,5]²，周期边界；t_end = 2.0（c0·t_end = 2.366 ≪ 5，无周期回卷） |
| 网格/阶 | N = 32/48/64，p = 1/2/3，CFL = 0.4，无限制器 |

**精确解**（本单新增，`tensordg.acoustics`）：速度势 → 波方程 → 0 阶 Hankel 变换给出

    p'(r,t) = A/(2α) ∫₀^∞ e^{−s²/(4α)} cos(c0 s t) J0(s r) s ds

`t=0` 时该积分恒等于初始高斯（测试断言到 1e-12）。大时间轴上渐近式（两次分部积分，s=0 端点主导）
为 **p'(0,t) ≈ −A b²/(2 ln2 c0² t²)**：负号（稀疏尾波）与 t⁻² 衰减都能被数值积分逐点复核
（t=10 相对误差 0.25%，t=20 0.06%）。

## ② 怎么做的（方法/流程/关键设置）

1. 精确解用**复合 Gauss–Legendre**（240 面板 × 24 点，缓存）求 Hankel 积分：单个 Big-Gauss
   规则需 O(10³) 特征值求解（47 s）且不必要；复合规则的 `panels×2 / nodes×2` 加密给出
   <1e-9（相对 A）的收敛性测试。
2. 比较口径：数值场取模态 P0 系数（**单元平均**），精确解取同单元的 4×4 GL 平均 —— 消除
   O(h²) 投影偏差，误差度量只反映离散误差。
3. 度量：`rel_l2_pressure`（波形）、`peak_rel_error`（幅值耗散，**验收 8% 就落在这里**）、
   `entropy_noise_relative` = max|ρ'−p'/c0²|/A（虚假熵，O(A) 量级）、`phase_error_pct`
   （沿 y=0 射线首个零点位置的相位误差）、`energy_ratio`（离散线性能量 / 同网格初始离散能量）。
4. 工件：`runs/acoustic_pulse_2d/`（本单随附 `ladder_stdout.json`，完整 `metrics.json` 由
   `python -m benchmarks.acoustic_pulse_2d` 生成），图 `docs/figures/acoustic_pulse_*.png`。

## ⑤ 注意点（踩过的坑/局限）

1. **初版渐近式写错**：先按 2-D 几何扩散猜了 `A b /(√ln2 c0 t)`（t⁻¹），被数值积分立即否证
   （比值 0.01–0.10 且号相反）；正确结果是 t⁻² 且为负号。教训：渐近式也必须用独立路径校验。
2. **零点位置不能沿网格对角线取**：N 为偶数时没有单元中心落在原点，早期版本沿 `[i,i:]` 取
   "射线"，实际走的是对角线（r = √(x²+y²) 而非 x−x0），得到 phase error ~1000% 的伪结果；
   改为把单元平均双线性插值到 y=0 射线后，phase error 降到 ≤1.52%。
3. **能量归一化**：用连续解析能量 A²π/(4αρ0c0²) 作分母会把 L2 投影损失算进"数值耗散"，粗网格
   下产生 >5% 的伪耗散；改用同网格离散初始能量后该度量只含格式耗散。
4. 局限：未做时间收敛研究（dt 由 CFL=0.4 与空间步长耦合）；A=1e-3 保证线性化误差 O(A)≪1%，
   但未量化 A=1e-2 的非线性偏离；未与第三方求解器交叉。
