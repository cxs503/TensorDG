# CASE-DG-ADVECT-ORDER（第2轮）：同阶时间格式复测 + 精确误差拆分

**锚点** CASE-DG-ADVECT-ORDER ｜ **判据** 收敛率（观测阶 vs 外部 ref 同阶列，±0.1）｜
**算例** 1-D 周期线性对流，manufactured solution `u(x,0)=sin(2πx)`，`t=1` ｜
**仓库** TensorDG ｜ **总判定** **FAIL**（未过项：M2_stages, M5_dt_order；未测项：无）

## ⓪ 误差判定（是否 <3%）

1. **收敛率（本算例声明的判据）**：P1–P4 观测阶与 ref 同阶列的**绝对**偏差最大
   0.047（相对偏差最大 2.37%）→ **✅ <3%**。
2. **时间误差占比**：cfl=0.2 下 `E_time/E_total` 最大 6.73%（阈 10%）
   → **✅**，即所测阶来自空间离散，不是时间格式污染。
3. **L2 幅值 vs ref**：**无基准可比** —— ref 表未给出 Δt/CFL，且比值为 0.67/0.19/0.06/0.02（逐网格近乎常数），
   说明两码同阶不同常数；本轮把"级数差"这一解释**证否**（见 §5），故幅值不作判据。

## 1. 案例介绍

一维周期线性对流 $u_t+cu_x=0$，$x\in[0,1)$，$c=1$，$u(x,0)=\sin(2\pi x)$，$t^*=cT/L=1$。
精确解解析已知，故可测**观测收敛阶**（光滑解应 $p+1$）。

| 项 | 符号/定义 | 值 |
|---|---|---|
| 单元数 | $N$ | 20, 40, 80, 160 |
| 多项式阶 | $p$ | 1, 2, 3, 4 |
| CFL | $c\Delta t/h$ | 0.2 |
| 时间格式 | 本轮 | 阶数匹配表：$p+1$ 阶 / $p+1$ 级 |
| 无量纲末时 | $t^*$ | 1.0 |

**ref 出处（数值，零手抄）**：Zheng Sun，
*Reducing polynomial degree by one for inner-stage operators affects neither stability type nor accuracy order of the Runge-Kutta discontinuous Galerkin method*，Mathematics of Computation (AMS)，
DOI 10.1090/mcom/4037，表 `tab:acc-sin-1d-uni`；
由 `tools/fetch_ref_advorder.py` 机械解析（仅取 `sdA-RKDG` 之前的**标准 RKDG** 半边，
列 `RK2DG1/RK3DG2/RK4DG3/RK5DG4`，级数 2/3/4/5）。

## 2. 怎么做的

1. **补能力**：新增 `tensordg/runge_kutta.py`（Euler / RK2-Heun / RK3-Kutta / RK4 / RK5-Butcher 显式表 +
   `tableau_for_degree` 最小级数选择），`solve_advection` 增加 `euler|rk2|rk3|rk5` 入口，
   **`rk4`/`ssp_rk3` 走原手写分支，逐位不变**（有回归测试绑定存档 L2）。
2. **同阶复测（A）**：$p$ 用 $p+1$ 阶/$p+1$ 级格式跑 $N$=[20, 40, 80, 160] 阶梯，
   与 ref 同阶列对比；阶估计沿用第 1 轮**同一最小二乘估计器**（`fit_with_floor`，$E<10^{-12}$ 舍入排除）。
3. **精确误差拆分（B、C）**：线性对流的 DG 半离散系统是线性的，故 `expm(L·T)u₀` 是其**精确解**
   （$L$ 由求解器自身 `_rhs` 逐单位向量生成，不另写一套空间算子）。
   与精确解比 → $E_{time}$（纯时间误差）；与连续解比 → $E_{total}$；$E_{space}$ 由精确半离散解给出。
4. **时间阶独立实测（D）**：固定网格，`dt` 逐次减半，对精确半离散解测斜率 = 设计阶。

## 5. 注意点（踩坑/局限）

- **坑 1（表写错）**：Kutta-RK3 表初稿误写为 `a₃=(-1,1), b=(1/6,2/3,1/6)`，标量探针实测 1 阶；更正为 `a₃=(-1,2), b=(1/6,4/6,1/6)` 后标量/半离散双路均达 3 阶。若无独立阶检验，此错会静默污染整轮复测。
- **坑 2（判据设计）**：全局误差斜率在细端受 float64 舍入污染（实测 12.5 阶这种假信号），故改用「一步局部误差」+ 拟合窗口下限 $10^{-14}$；这是第 1 轮 R6 型假信号同类问题的根治办法。
- **局限 1**：ref 未公布 Δt/CFL 与通量形式，L2 幅值无法判定；本轮只能排除「级数差」这一解释。
- **局限 2**：精确拆分用稠密 `expm`，仅适用小网格（$N\le16$，矩阵维 $N(p+1)\le80$）；大网格结论以「$E_{time}$ 随 $\Delta t^{{p+1}}$ 迅速衰减」外推，未逐网格做稠密矩阵。
- **局限 3**：`solve_advection` 的 `rk4`/`ssp_rk3` 分支为保持逐位兼容未并入通用驱动器，两条路径的等价性由阶测试与回归测试间接覆盖，未做逐位等价断言。
