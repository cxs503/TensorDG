## 1. 案例介绍

一维周期线性对流 $u_t+cu_x=0$，$x\in[0,1)$，$c=1$，$u(x,0)=\sin(2\pi x)$，$t^*=cT/L=1$。
精确解解析已知，故可测**观测收敛阶**（光滑解应 $p+1$）。

| 项 | 符号/定义 | 值 |
|---|---|---|
| 单元数 | $N$ | 20, 40, 80, 160, 320 |
| 多项式阶 | $p$ | 1, 2, 3, 4 |
| CFL | $c\Delta t/h$ | 0.2 |
| 时间格式 | 本轮 | 级数匹配表：`tableau_for_degree(p)` → P1=rk2(2级/2阶)，P2=rk3(3级/3阶)，P3=rk4(4级/4阶)，P4=ssp_rk54(5级/4阶) |
| 无量纲末时 | $t^*$ | 1.0 |

**ref 出处（数值，零手抄）**：Zheng Sun，
*Reducing polynomial degree by one for inner-stage operators affects neither stability type nor accuracy order of the Runge-Kutta discontinuous Galerkin method*，Mathematics of Computation (AMS)，
DOI 10.1090/mcom/4037，表 `tab:acc-sin-1d-uni`；
由 `tools/fetch_ref_advorder.py` 机械解析（仅取 `sdA-RKDG` 之前的**标准 RKDG** 半边，
列 `RK2DG1/RK3DG2/RK4DG3/RK5DG4`，级数 2/3/4/5）。

## 2. 怎么做的

1. **补能力**：新增 `tensordg/runge_kutta.py`（Euler / RK2-Heun / RK3-Kutta / RK4 / SSP-RK(5,4) / Butcher-RK5
   显式表 + `tableau_for_degree` 先匹配级数、再取该级数可达的最高阶），`solve_advection` 增加
   `euler|rk2|rk3|ssp_rk54|rk5` 入口，**`rk4`/`ssp_rk3` 走原手写分支，逐位不变**（有回归测试绑定存档 L2）。
2. **同阶复测（A）**：$p$ 用 $p+1$ 级格式（$p\le3$ 时同时是 $p+1$ 阶）跑 $N$=[20, 40, 80, 160, 320] 阶梯，
   与 ref 同阶列对比；阶估计沿用第 1 轮**同一最小二乘估计器**（`fit_with_floor`，$E<10^{-12}$ 舍入排除）。
3. **精确误差拆分（B、C）**：线性对流的 DG 半离散系统是线性的，故 `expm(L·T)u₀` 是其**精确解**
   （$L$ 由求解器自身 `_rhs` 逐单位向量生成，不另写一套空间算子）。
   与精确解比 → $E_{time}$（纯时间误差）；与连续解比 → $E_{total}$；$E_{space}$ 由精确半离散解给出。
4. **时间阶独立实测（D）**：固定网格、步数逐次加倍，对精确半离散解测斜率 = 设计阶（判据 ±0.2）。

## 5. 注意点（踩坑/局限）

- **坑 1（表写错）**：Kutta-RK3 表初稿误写为 `a₃=(-1,1), b=(1/6,2/3,1/6)`，标量探针实测 1 阶；更正为 `a₃=(-1,2), b=(1/6,4/6,1/6)` 后标量/半离散双路均达 3 阶。若无独立阶检验，此错会静默污染整轮复测。
- **坑 2（判据设计）**：全局误差斜率在细端受 float64 舍入污染（实测 12.5 阶这种假信号），故改用「一步局部误差」+ 拟合窗口下限 $10^{-14}$；这是第 1 轮 R6 型假信号同类问题的根治办法。
- **坑 3（报告漂移）**：本报告的 M2/M5 结论曾以手写常量形式留在渲染器里，在实现修好之后仍把 PASS 印成 FAIL / NOT RUN，且渲染器本身在 Python 3.10/3.11 下是语法错误（f-string 内复用同引号）。现所有判据文字由 `metrics.json` 的 `checks` 生成，并由 `tests/test_advorder_round2_evidence.py` 断言「文档 ↔ 证据」一致。
- **M2 = PASS（级数匹配）**：逐阶所用表的级数与 ref 列一致（P1=rk2(2级/2阶)，P2=rk3(3级/3阶)，P3=rk4(4级/4阶)，P4=ssp_rk54(5级/4阶)，ref 级数 2/3/4/5），且每阶都取该级数能达到的最高阶（`min(p+1, 可达阶)`）。$p=4$ 的 ref 列 `RK5DG4` 是 **5 级 4 阶**：5 级 5 阶显式 RK 不存在（Butcher 障碍），第 2 轮把它当成 `order = stages = p+1` 才留下假 FAIL。
- **M5 = PASS（时间阶实测）**：固定网格、步数逐次加倍，对 `expm(L·T)u₀` 精确半离散解测斜率，实测 P1=2.000/P2=3.000/P3=4.000/P4=4.000，设计阶 P1=2/P2=3/P3=4/P4=4，最大偏差 0.000（容差 ±0.2）。早期版本把 `dt`（随细分减小）当作分辨率变量传给假定分辨率递增的估计器，得到负斜率并记为 NOT RUN；按步数拟合后四个阶全部实测。
- **局限 1（L2 幅值）**：ref 未公布 Δt/CFL 与通量形式，L2 幅值无法判定；本轮只能排除「级数差」这一解释（比值 0.62/0.19/0.06/0.02，逐网格近乎常数）。
- **局限 2（稠密 expm 的规模）**：精确拆分用稠密 `expm`，仅适用小网格（本轮最大 $N=16$，矩阵维 80）；大网格结论以「$E_{time}$ 随 $\Delta t^{p+1}$ 迅速衰减」外推，未逐网格做稠密矩阵。
- **局限 3（网格阶梯）**：各阶阶梯为 P1: [20, 40, 80, 160, 320]；P2: [20, 40, 80, 160, 320]；P3: [20, 40, 80, 160, 320]；P4: [20, 40, 80, 160, 320]（全阶同阶梯）。
- **局限 4（双路径，已闭合）**：`solve_advection` 的 `rk4`/`ssp_rk3` 分支为保持逐位兼容未并入通用驱动器。本轮补上逐位等价断言：无限制器时两条路径在 float64 圆整内一致（注册表即手写核所跑的格式），非线性限制器（WENO/AO）下两者重组方式不同、差异可测——这就是两条路径保留的原因。实测见 `benchmarks/advorder_rk_path_equivalence.py`、`docs/CASE-DG-ADVECT-ORDER-round2-limitation4.md`，断言见 `tests/test_case_dg_advect_order_matched_rk.py`。

## 6. 本轮修订（重开轮）

1. **渲染器可用性**：本脚本曾含 f-string 内复用同引号的写法，在 `requires-python >= 3.10` 下是 **SyntaxError**（Python 3.11 实测无法 import），即第 2 轮之后它根本跑不起来，文档只能靠手改。
2. **结论漂移**：M2/M5 的结论与 $p=4$ 的设计阶曾是手写常量，实现修好后仍把 PASS 印成 FAIL / NOT RUN。现由 `metrics.json` 的 `checks` 与 `dt_order_probes[*].design_order` 生成。
3. **证据补齐**：P4 阶梯由 20–160 扩到 ref 全阶梯 20–320，`--assemble` 重新汇总后，`metrics.json` 是四阶齐全的规范包（此前存档只有单阶、判 FAIL）。
4. **回归护栏**：`tests/test_advorder_round2_evidence.py` 断言「文档 == 渲染器对当前 metrics 的输出」，并把设计阶取自探针（`degree + 1` 的错误假设会把 $p=4$ 的正确答案判成 ❌）。
