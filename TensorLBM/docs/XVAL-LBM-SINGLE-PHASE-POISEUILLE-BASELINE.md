# XVAL · LBM 单相 Poiseuille 基线骨架（XVAL-LBM-SINGLE-PHASE-POISEUILLE-BASELINE-SKELETO）

**对象**：`lettucecfd/lettuce` 的 `lettuce/ext/_flows/poiseuille.py:30`
（体力驱动的单相平面槽道，流向周期，解析抛物面作参照）＋
`lettuce/ext/_reporter/error_reporter.py:11`（可复用误差报告器 + 预注册容差门）。
**产出**：`src/tensorlbm/poiseuille_baseline.py`（基线骨架）＋
`tests/test_poiseuille_baseline.py`（16 项，全绿）＋
`benchmarks/poiseuille_baseline_run.py`（完整阶梯，投计算队列）、
`benchmarks/poiseuille_baseline_figures.py`（轻量证据 + 图）、
`outputs/xval_poiseuille_baseline/{summary,law_check}.json` + 2 张图。

**一句话结论**：把体力项换成 Guo(1993) 一致格式、把解析参照写进半程反弹
**自己的**壁面约定之后，收敛解的形状与解析抛物面**逐点到机器精度一致**；唯一残留
误差是均匀滑移，且满足闭式 `(48ν²−1)/L²`。在 `τ* = 1/2 + 3/√48 ≈ 0.9330`
处滑移正好抵消，误差回落到 4e-13；在常规 `τ=0.8、Ny=32` 配置下 rel-L2 =
**5.78e-4（0.058%）**，远低于 1% 预注册门与 15% 生态上限，更远低于 3% 论文级门。

---

## 1. 为什么要做「基线骨架」而不是再加一个 benchmark

仓内既有 `benchmarks/poiseuille.py` 在自己交付配置上报 ~11% rel-L2 误差
（独立审计 `docs/AUDIT-m21003-XVAL-LBM-MASS-EXCHANGE-SELECTOR.md`、`audit/`
下 m21040 复核亦是此结论）。11% 这样的数字之所以危险，是因为它**无法归因**：
体力格式、壁面约定、步数、归一化混在一起，谁都可以说「再多跑几步就好了」，也可以
把容差从 5% 改到 12% 就算通过。

本骨架把这件事拆成四个相互独立、可单独证伪的东西：

1. **规范化算例**：`Nx` 流向周期、`y=0` 与 `y=Ny-1` 为固壁、常体力 `F`；
2. **声明壁面约定的解析参照**（`wall_origin` 显式写成 `0.5` 或 `0.0`）；
3. **可复用误差报告器**：rel-L2 / rel-L∞ / 滑移量 / 形状误差 / 峰值误差，
   归一化常数写在代码里（`_relative_errors`）；
4. **预注册容差门** `ReL2Gate`：容差是**输入**，构造期就拒绝 `>15%`、`≤0`，
   运行时拒绝 `None`/`NaN`/`inf`（`WITHHELD` 不算通过）。

收敛判据也是显式的：残差 `max|Δu|/u_max` 低于 `residual_tol` 才允许读误差，
未收敛的样点会被门判 FAIL（`test_gate_fails_an_unconverged_transient`）。

## 2. 方法

* **格点/碰撞**：D2Q9，BGK，`ν = cs²(τ − 1/2)`；`f → f − ω(f − f_eq) + F_i`；
  壁面用既有 `boundaries.HalfwayBounceBack`（Ladd 1994 / Krüger 2017 ch.8）。
* **体力**：`F_i = w_i (1 − ω/2)[3(e_i·F) + 9(e_i·u)(e_i·F) − 3(u·F)]`
  （Guo, Zheng & Shi 1993），动量定义随之改为 `ρu = Σ e_i f_i + F/2`。
  旧基准用的 `w_i 3 e_x F` 保留为 `forcing="simple"`，只用于量化差异。
* **解析参照**：半程反弹把无滑移面放在「末流体点与固壁点的中点」。固壁在
  `y=0`、`y=Ny-1` 时无滑移面在 `y=0.5` 与 `y=Ny-1.5`，故**槽宽 L = Ny−2**、
  节点 i 距壁 `i−0.5`：`u(y) = F/(2ν)(y−0.5)(L−(y−0.5))`，
  `u_max = F L²/(8ν)`。旧基准的参照写的是 `y=0..Ny−1`（L = Ny−1），
  两者差**半个格子**。
* **收敛判据**：每 `check_every` 步测 `max|Δu_x|/u_max < residual_tol`
  （默认 1e-12；图/阶梯按需放到 1e-7~1e-10，均比被测量小两个量级以上）。
* **初始条件**：`rest`（冷启动，诚实）与 `analytic`（缩短瞬态；稳态唯一，
  `test_initial_condition_does_not_change_the_steady_state` 证明无关性）。

### 3.1 主算例（`BASELINE_SPEC["canonical_case"]`：Nx=8, Ny=32, τ=0.8, F=1e-5, Guo, 半程壁）

| 量 | 数值 |
|---|---|
| 槽宽 L / ν / u_max(解析) | 30 / 0.1 / 1.1237e-2 |
| 收敛步数（冷启动，残差<1e-11） | 21200 |
| rel-L2（对解析抛物面） | **5.7778e-4（0.058%）** |
| rel-L2（去掉均匀滑移后的形状误差） | 2.7e-11（机器精度） |
| 均匀滑移 / F | −0.650（= 6ν − 1/(8ν)） |
| 质量漂移 | −3.4e-10 |

### 3.2 闭式误差律（本轮的核心发现）

在 `ν ∈ [0.033, 0.333]`、`L ∈ {6, 14, 30}`（Ny = 8/16/32）上逐点复核
（`outputs/xval_poiseuille_baseline/law_check.json`，全部为收敛解）：

```
rel-L2(有符号) = (48 ν² − 1) / L²            (实测/定律 = 1.000000)
均匀滑移 / F   = 6 ν − 1/(8 ν)
```

| τ | ν | 实测 rel-L2（Ny=16, L=14） | 定律 \|48ν²−1\|/L² |
|---|---|---|---|
| 0.6 | 0.0333 | 4.8296e-3 | 4.8299e-3 |
| 0.8 | 0.1000 | 2.6530e-3 | 2.6531e-3 |
| 1.0 | 0.1667 | 1.7007e-3 | 1.7007e-3 |
| 1.5 | 0.3333 | 2.2109e-2 | 2.2109e-2 |

| Ny | L | 实测 rel-L2（τ=0.8） | 定律 |
|---|---|---|---|
| 8 | 6 | 1.4444e-2 | 1.4444e-2 |
| 16 | 14 | 2.6531e-3 | 2.6531e-3 |
| 32 | 30 | 5.7778e-4 | 5.7778e-4 |

读法：`48ν²/L²` 是半程反弹已知的 `O(ν²)` 滑移项，`−1/L²` 是半格壁面约定残留，
两者在不同 ν、L 上都不需要拟合。**推论**：`48ν² = 1` 即
`τ* = 1/2 + 3/√48 ≈ 0.9330127019` 时滑移抵消，误差只剩舍入：
实测 Ny=8 rel-L2 = 4.4e-13、Ny=16 = 3.4e-13（`slip_free` 节，点值逐点存于
`law_check.json`，图 `fig_poiseuille_law.png` 右）。这是一条**可证伪**的预测
（测试 `test_slip_free_tau_star_reaches_roundoff` 钉住）。

### 3.3 1% 预注册门的适用范围

`rel-L2 ≤ 1%` 在 τ ∈ [0.5, ~1.4] 内成立；`τ=1.5`（ν=1/3）时 2.21% —— 仍远低于
3% 论文级门，但已经**超出 1% 门**。因此骨架把「τ ≤ 1.4 且 L ≳ 14」写进适用范围，
而不是把容差调大。

### 3.4 旧交付 11% 的归因（修正我自己开工时的假设）

| 因素 | 量级（收敛解/实测） | 证据 |
|---|---|---|
| 欠收敛（2000 步瞬态） | 峰值速度低 17.3%，rel-L2 占 ~13.3% | `summary.json` A 节：rel-L2 = 13.7%，`rel_u_max` = −17.3% |
| 节点心参照（半格错位） | 同一收敛解对节点心参照 rel-L2 = 14.6% | Ny=16 实测；τ=0.8/Ny=32 下形状误差 3.3% |
| 体力格式（simple vs Guo） | **仅均匀滑移差 F/2（≈0.17%），形状项两者都是机器精度** | `test_forcing_schemes_differ_only_by_the_half_force_momentum` |

**诚实纠正**：开工时的假设是「旧的 `w_i 3 e_x F` 是一阶格式，是 11% 的主因」。
实测**否证**了这一点——两种体力格式的稳态解只差 `F/2` 的均匀速度（因为动量定义
就是差 `F/2`），形状误差都在 1e-11 量级。11~14% 真正的主因是**欠收敛**与
**解析参照的半格壁面错位**。这对后续所有 LBM 验证单都是可复用的判据：
先查参照约定与残差，再怀疑离散格式。

## 5. 注意点 / 局限

* 均匀滑移是半程反弹 + 体力的固有属性，不是 bug：形状精确、滑移 `O(ν²)`。
  需要「零滑移」时用 `τ*`；需要一般 τ 下提高精度时靠加大 L（`L⁻²`）。
* 解析参照的 L 必须与所用的壁面算符一致（半程 vs 节点心 vs 插值反弹），
  否则误差里混进半格项——这正是旧基准的问题。
* 本骨架只覆盖单相、二维、`y` 流向均匀的平面槽道（流向周期）。不覆盖 3D、
  MRT/TRT 交叉验证、非均匀网格、壁面函数；这些要在别的条目里各自预注册。
* `Nx=4~8` 是刻意的：流向均匀，多给流向格子只增加成本；`Nx=64` 仅用于复刻
  旧交付配置（`summary.json` A 节）。
* 旧交付复刻得 13.7%，与审计记录的 ~11% 不同：壁面算符实现与归一化细节不同
  （本骨架按 `u_max` 解析峰值归一化、流体点全纳入），量级一致，结论不变。
